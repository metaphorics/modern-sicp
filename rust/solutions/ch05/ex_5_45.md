# Exercise 5.45: comparing factorial stack use (T)

## Approach

Measure total stack pushes and maximum depth for recursive factorial
in three implementations: the 5.4 explicit-control evaluator, compiled
code, and the special-purpose factorial machine. Compare inputs 5 and
10. These counters expose both execution cost and peak stack space; the
special-purpose controller is the hand-designed reference point.

## Map class

`T`.

## Sample answer

For n = 5, the evaluator uses 144 pushes and reaches depth 28, compiled
code uses 31 pushes and depth 14, and the special-purpose machine uses
8 pushes and depth 8. Compilation substantially reduces stack use
relative to interpretation, though it does not match the specialized
machine. Results for n = 10 are reported by the implementation.
