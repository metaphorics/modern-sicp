# Exercise 5.16: instruction tracing, on and off

Tracing is a hook the monitor calls just before each executed
instruction; on, it renders the assembled instruction in constructor
notation; off, no hook is installed and nothing prints. The
count is taken in the driver as well, so tracing never disturbs it.

`ex_5_16 ()` runs gcd(12, 8) with tracing on (fourteen lines, two
full loop passes plus the final test and taken branch), then the same
machine on (20, 14) with tracing off and pins the silence: zero trace
lines, answer 2.
