# Exercise 4.5: cond arrow clauses (T)

## Approach

`WithArrow` takes over the cond clause and evaluates clauses directly instead
of rewriting to ifs, so the arrow's test runs exactly once and its value feeds
the recipient -- the naive rewrite `(if test (recipient test) ...)` would test
twice. `assoc` and `cadr` are installed as primitives.

## Map class

`T`.

## Sample answer

The book's example returns 2: `assoc` finds `(b 2)`, `cadr` takes its value. A
plain-clause cond still answers clause by clause.
