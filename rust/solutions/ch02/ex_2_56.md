# Exercise 2.56: extending `deriv` with exponentiation

## Approach

The exercise's own `Expr` extends the section's with a `Pow` variant
and a `make-exponentiation` constructor that folds `u^0 = 1` and
`u^1 = u`. `deriv` gains one more match arm for the power rule
`d(u^n)/dx = n * u^(n-1) * du/dx`, valid for a constant integer
exponent (checked with a match, erroring by type if the exponent is
not a number literal). For `x^3`: `n = 3`, `u = x`,
`du/dx = 1`, so the derivative folds to `3 * x^2 * 1`, and the `* 1`
simplifies away, leaving `(* 3 (** x 2))`.

## Map class

`A`: an exponentiation case added to the expression enum, matching the
map's Rust class for this row.

## Deviation

None. `make-exponentiation`'s exponent is required to already be a
number (as the book's own examples always use), reported as a type
mismatch otherwise rather than symbolic differentiation of a variable
exponent, which the book does not ask for.
