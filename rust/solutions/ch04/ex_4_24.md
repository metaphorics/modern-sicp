# Exercise 4.24: analysis versus execution time (T)

## Contract

Checked Rust source admitted once, analyzed once, then compared through
`run` and `run_analyzed_program` over repeated executions.

## Lesson

The benchmark separates direct execution from retained-plan execution and
checks byte-identical stdout before recording durations. The frozen public
API exposes the analyzed plan but not a timing-independent analysis fraction,
so the test reports durations without asserting which engine is faster.

## Map class

`T`.

## Sample answer

Both paths print `233\n`; direct and retained analyzed timings are nonzero
after warmup.
