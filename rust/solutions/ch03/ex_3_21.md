# Exercise 3.21: the queue printed as its items

## Approach

The book's Ben inserts `b` and `d` into a queue and prints it, and
Eva Lu Ator points at the confusion: the default printer shows the
queue's internal front/rear pointer pair, so the readout is
`((b d) d)` where the queue holds `b` then `d`. The Rust solution
runs the same insert/delete/insert sequence and reports both views:
`print_queue` walks the nodes from the front and answers `(b d)`,
while the raw pointer-pair reading reproduces the book's misleading
`((b d) d)`. The tests also confirm the fixed printer is a pure
reader, answering the same items twice with the queue unchanged.

## Map class

`A: queue nodes need Rc RefCell`. The queue's nodes are shared
mutable cells under `Rc`; the printer the exercise asks for is a
traversal over those cells, and the misleading view is what the two
pointer fields name from outside.

## Deviation

None. The book's sequence and both printed forms are kept exactly.
