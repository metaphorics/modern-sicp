# Exercise 2.70: the rock song

## Approach

Generate the tree from the eight-symbol alphabet with exercise 2.69's
`generateHuffmanTree`, encode the 36-symbol song with exercise 2.68's
`encode`, and count the bits.

## Numbers

The encoding needs **84** bits. The song has 36 symbols, so the best
fixed-length code over eight symbols needs 3 bits each: **108** bits.
The song round-trips through `decode` under the generated tree, whose
weight is 36 and whose root symbol set covers all eight symbols.

## Map class

T (translate). (The map's bit-savings idea cell for this row is chosen
by ocaml; the assertion is required of every edition by the book's
question.)

## Deviation

The song's words are encoded as the alphabet's exact symbols (the
lyric's "a" is the alphabet's `A`), so the symbol lists match the pair
list case for case.
