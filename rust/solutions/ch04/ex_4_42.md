# Exercise 4.42: liars puzzle (T)

## Approach

Each girl's two clauses are independent typed claims. The search binds one
truth value per clause, requires exactly one true clause per girl, and keeps
the five ranks distinct. The surviving ordering is therefore derived from the
letters rather than hard-coded.

## Map class

`T`.

## Sample answer

The unique ranking is `Betty 3`, `Ethel 5`, `Joan 2`, `Kitty 1`, `Mary 4`.
