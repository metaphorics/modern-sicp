# Exercise 2.52: square limit variations (translate)

The map class is `T`, exercised at the three strata the statement
names. (a) `ex_2_52_wave` is the wave painter with three added
segments forming a smile. (b) `ex_2_52_corner_split` uses one copy
of each split image per corner (`beside (below painter up) (below
right corner)` instead of the doubled `top_left`/`bottom_right`).

the other side (`beside quarter (flip_horiz quarter)` over
`below half (flip_vert half)`), the changed pattern of the
`square_of_four` version.

The tests check each level's effect is visible: the smile adds 3
segments per wave, and the variant corner split of level 2 has fewer
segments than the main text's (25 vs 38 for a 20-segment base), both
