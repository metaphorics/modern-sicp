# Exercise 4.61: the next-to rules (T)

## Approach

The base rule fires on the list head, the recursive rule strips it; the
interleaved rule streams answer the head pair first.

## Map class

`T`.

## Sample answer

`(?x next-to ?y in (1 (2 3) 4))` answers `(1 next-to (2 3) ...)` then
`((2 3) next-to 4 ...)`; `(?x next-to 1 in (2 1 3 1))` answers
`(2 next-to 1 ...)` then `(3 next-to 1 ...)`. The book's pinned order
differs by scan direction; this edition's data base is chronological.
