# Exercise 2.6 — Church numerals (adapt)

The map class is `A`: the encoding survives, but Scheme's untyped
`zero`/`add-1` become OCaml values whose type states the encoding
outright, `('a -> 'a) -> 'a -> 'a`, "apply `f`, some fixed number of
times, to `x`."

`one` and `two` are `add_1 zero` and `add_1 one` reduced by hand
(substituting the definition of `add_1` and simplifying), not calls to
`add_1` itself, matching the exercise's ask. `church_add a b` applies
`f` via `a`, starting the pipeline from `b f x` instead of `x`,
producing a numeral that applies `f` `a + b` times without ever
calling `add_1`. `church_to_int` reads a numeral back as an `int` by
handing it `((+) 1)` and `0`; `ex_2_06 () = 3`.
