## Exercise 2.64: list-to-tree

Part a: `partialTree(elts, n)` builds a balanced tree from the first `n`
elements of `elts` by splitting them three ways: `leftSize = (n - 1) / 2`
elements go to the left subtree (built first, recursively), the very
next element becomes this node's own entry, and the remaining
`n - (leftSize + 1)` elements go to the right subtree (built from
whatever the left call did not consume). The function returns the built
tree paired with the elements past position `n`, which the caller (or,
recursively, the right subtree's own build step) needs to keep going.
For `[1, 3, 5, 7, 9, 11]` (`n = 6`), `leftSize = 2`: the left subtree
covers `[1, 3]`, entry `5` is next, and the right subtree covers the
remaining `[7, 9, 11]`. Recursing the same way on each half gives the
tree with `5` at the root, `1` on the left with `3` as `1`'s right
child, and `9` on the right with `7` and `11` as its two children — see
`E2_64Test.kt` for the exact shape asserted.

Part b: `partialTree` calls `makeTree` exactly once per element, and
recurses into strictly smaller `n` at each call with no wasted work
outside dividing the list, so building a tree of `n` elements takes
`Θ(n)` steps.

Class: T, per the map — a direct translation, adapted only insofar as
Kotlin returns a `Pair<Tree, List<Long>>` where the book conses a tree
and a list together.

Deviation: none.
