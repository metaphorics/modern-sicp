# Exercise 4.10 — a new surface syntax for the same evaluator (translate)

The map class is `T`. The statement asks for a new syntax with
`eval` and `apply` untouched; in this edition the surface is already a
value, the typed `Ast`, so the new syntax is a `term` datatype and the
whole exercise is its translation into that AST. `from_new_syntax`
maps `Lit` to a self-evaluating expression (quoted when the literal is
data), `Name` to a variable reference, `Fn` to a one-expression
lambda, `Do` to a `begin`, and `Call` to an application. `eval` is the
unmodified base evaluator, which is the exercise's point: the syntax
change stops at the translation.

Sample: `ex_4_10 ()` answers `["16"; "#[compound-procedure]"]` — the
`Do` that stores the translated `Fn` under `square` and `Call`s it on
4 through the untouched evaluator, then the translated `Fn` evaluated
on its own.
