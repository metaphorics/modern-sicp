# Exercise 3.63: what the local guesses stream buys

## Approach

Both variants wrap the same probed improve step; a `SqrtProbe` counts
`sqrt-improve` calls. Alyssa's `sqrtStreamShared` builds the guess
stream once per call with the tie-before-force cell, so each tail is
forced once and memoized: `stream-ref` to index k costs k improve
calls (k = 5 -> 5, k = 6 -> 6). Louis's `sqrtStreamFresh` calls the
whole procedure again in every tail, so reaching element k rebuilds a
fresh cascade of k(k+1)/2 calls (15 and 21 for k = 5 and 6). Both
produce element for element the same guesses as the section's
`sqrtStream` (checked on a six-element prefix at x = 2).

## Map class

`T` (map row 3.63: direct translation with a counter probe).

## Deviation

None. On the statement's second question: with a plain `(lambda ()
...)` delay and no memoization, Alyssa's version loses its advantage,
because every force of the map's delay recomputes the improvements it
has already done, and element k then costs a triangular cascade on
every walk, matching Louis's redundant work.
