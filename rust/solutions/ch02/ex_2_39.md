# Exercise 2.39: `reverse` via folds

## Approach

The `fold_right` version appends each element at the far end of the
already-accumulated rest (`append` of a one-element list), while the
`fold_left` version conses each arriving element onto the front of the
accumulator. Both produce the same reversed list; their costs differ,
which the rationale notes the way the book's own discussion of these
combinators does.
