# Exercise 4.52: if-fail (T)

## Approach

`if-fail` evaluates its first expression against the continuation as
usual. The engine's clause matches the evaluation result.
When the `Backtrack` that survives the first expression arrives -- the
engine has run the search dry by exhausting and popping every inner
choice frame -- the second expression evaluates against the same
continuation. Its value then flows to the answer as the book's example
shows.

## Map class

`T`.

## Sample answer

`(if-fail (let ((x (an-element-of '(1 3 5)))) (require (even? x)) x)
'all-odd)` answers `all-odd`; with 8 in the list it answers `8`.
