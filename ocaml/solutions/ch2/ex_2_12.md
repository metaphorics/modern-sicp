# Exercise 2.12 — center-percent constructor (translate)

The map class is `T`. `make_center_percent c p` reuses
`make_center_width` with the width recovered from the percentage
(`c *. p /. 100.0`), and `percent` is its inverse, `width i` scaled by
`abs (center i)` and multiplied back up by 100; `center` is
unchanged, exactly as the exercise says.

`ex_2_12 () = (6.8, 10.0)`: the center and percent of a 6.8-ohm
10%-tolerance resistor built with `make_center_percent`.

Addition 2.12a is documented separately in `ex_2_12a.md`.
