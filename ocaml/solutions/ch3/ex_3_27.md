# Exercise 3.27 — memoized fib via a table (adapt)

The map class is `A`: the book's memo table is drawn as an
environment diagram trading a saved procedure for a shared cell; this
edition trades the diagram for a counted trace instead, since a
closure's captured `Hashtbl.t` has no picture worth drawing that the
numbers do not already say more precisely. `memoize` wraps any
`int -> int` function in a table lookup, counting hits and computes in
two `int ref`s; `memo_fib_steps` applies it to the self-referential
memo-fib of the statement. The 26 computes are one per distinct
argument 0 through 25; the 23 hits are every repeated lookup along the
recursion, dwarfed next to the plain recursive `fib`'s 242785 calls
for the same input.

Sample: `ex_3_27 ()` answers `(75025, 75025, 26, 23, 242785, true)`.
