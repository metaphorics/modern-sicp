## Exercise 2.47: frame constructors

Approach: the book offers two Scheme constructors for the same three
fields, a `list` version and a `cons`-of-`cons` version, and asks for
matching selectors. Kotlin's `Frame` data class (carried in the shared
`Painters.kt` because `frameCoordMap` needs it earlier than this
exercise's position) already plays the `list` role. This file supplies
the second representation directly, `FramePair = Pair<Vect, Pair<Vect,
Vect>>`, with `originFramePair`/`edge1FramePair`/`edge2FramePair` reading
`.first`, `.second.first`, `.second.second`, and a `frameCoordMapPair`
built only from those selectors. The test proves both representations'
coordinate maps agree on the unit square's four corners for the same
origin and edges.

Class: T. The two representations translate directly; Kotlin's `Pair`
nesting mirrors Scheme's `cons` nesting closely enough that no new
concept is needed.
