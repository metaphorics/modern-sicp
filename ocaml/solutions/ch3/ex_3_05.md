# Exercise 3.5: Monte Carlo integration (translate)

The map class is `T`. `monte_carlo` restates the main text's
tail-recursive trial loop; `random_in_range` and `estimate_integral`
follow the statement's own procedures line for line. The one real
choice is the random source: `random_in_range` takes a
`Sicp_common.Random.t` explicitly rather than hiding it in a closure,
so the estimate is reproducible under test from a fixed seed, the
same choice @ref{1.2.6}'s `fermat_test` already made for primality
testing.

Sample: `ex_3_05 ()` estimates pi by the area of a unit circle over
5000 trials with seed 42; the reference value is close to `Float.pi`
but not exact, being a Monte Carlo estimate, so the test checks it
against a tolerance rather than an exact literal.
