# Exercise 1.21: smallest divisors of 199, 1999, 19999

## Approach

Run the section's `smallestDivisor` - trial division up to `sqrt(n)` -
on each number. The end test means a prime is reported as itself.

## Numbers

`smallestDivisor(199)` is `199` (199 is prime), `smallestDivisor(1999)`
is `1999` (1999 is prime), and `smallestDivisor(19999)` is `7`
(`19999 = 7 x 2857`).

Translated row: the statement is unchanged apart from the procedure
name. No host caveat applies - the values are tiny and `number` is
exact.
