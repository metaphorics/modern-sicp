## Exercise 2.46a: vectors as a data class with operator functions

Approach: this is the section's one chosen tailored addition, taken from
the map's idea for exercise 2.46, "vectors as a data class or tuple."
`Vect` is already a plain two-field data class (exercise 2.46); this
addition gives it `operator fun plus`, `minus`, and `times` so `a + b`,
`a - b`, and `a * s` read as ordinary vector algebra instead of function
calls, each a one-line delegate to `addVect`/`subVect`/`scaleVect`. The
tests check both the direct delegation and two algebraic laws
(commutativity of `+`, distributivity of `*` over `+`) with `checkAll`
over generated doubles, using an epsilon comparison because floating
addition is not perfectly associative.

Deviation: none beyond the addition itself; `frameCoordMap` and every
painter combinator keep using the named functions, so the operators are
purely a convenience the reader can opt into.
