# Exercise 5.24: the switch as a basic controller form

The base controller's switch segment evaluates the discriminant once and checks case tests in source order until one matches. It then runs only that clause body, or the default body if no case matches. The admitted TypeScript subset rejects implicit fallthrough (TS7029), so the example spells out both additions directly in the matching case body. A `break` still stops the switch.

The session answers the classify values, the selected-body totals 11, 10, and 100, and a clause test that is a variable read. Each case test is checked at most once in order until a match; no later case body runs by fallthrough.
