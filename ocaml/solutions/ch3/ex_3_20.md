# Exercise 3.20: environment diagram of pair mutators (replace)

The map class is `R`: the SICP exercise asks for the environment
diagram of Scheme's procedural `cons`/`set-car!`/`set-cdr!`, whose
bindings only a Scheme evaluator's frame structure can show. This
edition's replacement keeps the same procedural-pair construction (
`proc_cons x y` returns a record of four closures over two mutable
cells) and asks the same question about it: does `z`'s two slots,
built as `proc_cons x x`, still physically designate `x` after
`set_pcar (z.pcdr ()) 17`? Physical equality on the closure records
stands in for the diagram's arrows, and the mutation is visible
through either slot since both close over the same two cells.

Sample: `ex_3_20 ()` answers `("17", true)`.
