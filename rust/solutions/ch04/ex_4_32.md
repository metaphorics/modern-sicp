# Exercise 4.32: chapter 3 streams versus lazy lists (T)

## Approach

The 4.2.3 procedural pairs delay both slots, so a pair constructs without
computing and a dormant armed slot forces only when it is the one demanded. The
chapter 3 comparison stays eager, per D18: the chapter's `cons-stream` evaluates
its car at construction, which the strict `cons` primitive beside this
evaluator shows. The self-referential `ones` definition is the constructive
demonstration: it terminates in one step because nothing is forced.

## Map class

`T`.

## Sample answer

`(car (cons 7 (/ 1 0)))` -> 7; `(cdr (cons 7 (/ 1 0)))` -> division by zero on
demand; the eager strict constructor `(car (cons (/ 1 0) 7))` -> division by
zero at construction; `(define ones (cons 1 ones))` -> ok.
