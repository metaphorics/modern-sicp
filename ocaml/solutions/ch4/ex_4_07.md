# Exercise 4.7: let* as nested lets (adapt)

The shared grammar has no `let*` and the core never parses text, so
the form travels as a `shape` of bindings and body.
`let_star_to_nested_lets` folds the bindings rightmost-innermost into
single-binding `let`s; empty bindings reduce to the body alone. The
statement's question is answered yes: once the rewrite exists,
evaluating it needs only an `eval` that handles `let`, which is the
one clause this module's dispatch adds. The base evaluator's arithmetic
primitives are strictly binary, so the program's `(+ x y 5)` is
written as its nested equivalent `(+ (+ x y) 5)`.

Sample: `ex_4_07 ()` answers `["39"; "39"; "7"]`: the statement's
program through the shape lowering, the same program written as the
nested lets the lowering produces, and the empty-bindings boundary.
