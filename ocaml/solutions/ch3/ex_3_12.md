# Exercise 3.12 — append! mutates the tail; missing car (adapt)

The map class is `A`: the book's point is that `append` builds a
fresh chain of pairs while `append!` performs surgery on the last
pair of its first argument, and that distinction survives verbatim in
a language with a dedicated mutable-pair type. `Mpairs.append` walks
`x` and conses each element onto `y`, leaving `x` untouched;
`append_bang` finds `x`'s `last_pair` with the existing walker and
`set_cdr`s it to `y`, so `x` itself grows a new tail. The only real
adaptation is Scheme's missing-response blanks: the exercise asks the
reader to predict two prior interaction values, which this edition
just computes and returns instead of leaving unprintable.

Sample: `ex_3_12 ()` answers
`("(a b c d)", "(b)", "(a b c d)", "(b c d)")` — the pure `append`
leaves `(cdr x)` at `(b)`, but after `append!` the same call answers
`(b c d)`, since `x`'s last pair now points at `y`.
