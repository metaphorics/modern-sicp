# Exercise 3.50: multi-stream map over cold sequences

## Approach

The book's `stream-map` with a variadic argument list becomes a function
taking the procedure and a list of `Sequence` streams. The body holds one
iterator per stream and yields in lockstep: each round checks every cursor
has a next element, applies the procedure to the list of fetched elements,
and stops the moment any stream runs dry. That answers both gaps in the
statement's definition: the emptiness test is "any iterator exhausted"
(the book's gap on `(car argstreams)`), and the head and tail fetches are
the `next` calls into each cursor. An empty list of streams yields an
empty result. Cold `Sequence` carries the exercise per the edition's
regime split: the walk recomputes on a second pass, which costs nothing
here because no delayed cell is observable.

## Map class

`T` (map row 3.50: Kotlin T).

## Deviation

None. The variadic procedure list is a `List<Sequence<T>>` parameter, the
shape the edition's Kotlin API gives multi-argument maps.
