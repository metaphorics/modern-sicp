# Exercise 4.28: forcing the operator (T)

## Contract

`lazy-memo/1` over typed `LazyExpr::{Apply,Lambda,Thunk,Force,Let,Emit}` data.

## Lesson

The operator thunk is forced to a callable before the delayed argument is
bound. The closure body then forces its parameter, so the operand effect is
observable after the operator effect.

## Map class

`T`.

## Sample answer

The ordered effect log is `operator`, then `operand`.
