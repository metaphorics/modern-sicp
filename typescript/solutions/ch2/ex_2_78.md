# Exercise 2.78: the tower's bare base case

## Approach

The statement asks for the attach-tag, type-tag, and contents operations that treat
ordinary
numbers as themselves; this file's implementations are `attachTagTsNumber`,
`typeTag78`, and `contents78`. A bare `bigint` names itself `ts-number`:
`typeTag78` answers `"ts-number"` for a bare bigint and the datum's tag
otherwise; `contents78` answers the bigint itself; and the ordinary-number
`attachTagTsNumber` is the identity. The implementation builds no pair wrapper for the
tower's base level, which is exactly the book's point.

## Numbers

`typeTag78(7n)` and `typeTag78` of the tagged form both answer `"ts-number"`;
`contents78(7n)` and `contents78` of the tagged form both answer `7n`; the
identity `attachTagTsNumber(7n)` is `7n`; and `add(3, 4)` through the section table
still answers `7`.

## Map class

A (untagged numbers need a union with a bare case): the datum union gains the
bare `bigint` member, and every consumer narrows with `typeof` instead of
unpacking a pair.

## Deviation

The section module was retrofitted to this spelling, so every later exercise
(2.79 on) builds on bare bigints rather than on tagged pairs.
