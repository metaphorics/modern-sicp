## Exercise 2.6: Church numerals

Approach: a Church numeral of type `Church<T>` is a function that applies
its `(T) -> T` argument `n` times to a starting value. Substituting
`churchAddOne(churchZero())` by hand gives `{ f -> { x -> f(x) } }`, which
applies `f` once, so that is `churchOne` directly; `churchTwo` applies `f`
twice, the same pattern one step further. `plusChurch(a, b)` applies `f`
`a` times and then `b` more times, which is `a + b` applications in total,
without ever counting through `churchAddOne`. `churchToLong` decodes a
numeral by handing it `{ x -> x + 1L }` and a starting value of `0L`.
`churchOne + churchTwo` decodes to `3`.

Class: A. The idea survives unchanged; the statement gains the explicit
generic function type `Church<T>` that Kotlin's static typing needs where
Scheme's untyped `lambda` needed none. Deviation: none beyond that typing.
