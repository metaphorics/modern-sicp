## Exercise 2.65a: tree sets cross-checked against java.util.TreeSet

Approach: this is the section's one chosen tailored addition, taken from
the map's idea for exercise 2.65, "tree sets as balanced maps." `treeOf`
builds this section's hand-rolled `Tree` (exercises 2.63/2.64) from a
`Set<Long>`; `ex_2_65a` computes the union and intersection of two fixed
sets both ways, with `unionSetTree`/`intersectionSetTree` (exercise
2.65) and with the JDK's own `java.util.TreeSet`, a real balanced
(red-black) tree implementation independent of anything in this book.
It checks the two agree, ignoring order. The test file promotes this
single check into a Kotest property test (`checkAll`) over many
generated pairs of `Long` sets, so the cross-check runs on far more
inputs than the one worked example.

Deviation: none beyond the addition itself; the section's own
`unionSetTree`/`intersectionSetTree` are unchanged and remain the
authoritative implementation everywhere else.
