# Exercise 5.33: factorial-alt and factorial

The two orderings of the multiplication, `n * factorialAlt(n - 1)` and `factorial(n - 1) * n`, compile to the same size of code with the same save discipline. The difference between them is the multiplication's operand order, which changes which operand is live across the recursive call, not the shape of the compiled code. The test pins the two summaries equal: statement for statement and save for save.
