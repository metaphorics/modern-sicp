# Exercise 4.4: and and or as special forms (T)

## Approach

`WithAndOr` adds the two clauses on the seam and evaluates them directly, so
subexpressions re-enter the full evaluator. Short circuit is the specification:
the first false stops `and`, the first true value is `or`'s answer, and a later
operand that would raise never evaluates.

## Map class

`T`.

## Sample answer

`(and)` is `#t`, `(and 1 2 3)` is 3, `(and 1 #f (car 5))` is `#f` without an
error, `(or)` is `#f`, `(or #f 7 (car 5))` is 7, `(or #f #f)` is `#f`.
