# Exercise 5.10: a new instruction syntax behind isolated procedures

The exercise asks for a change of instruction syntax where the change
touches exactly one place. The solution defines the new surface in
`E5_10.kt`: a sealed `NStmt` wrapping one of the book's instructions
(`NBook`) plus three register-to-register forms, `NCpy` for
`(assign a (reg b))`, `NInc` and `NDec` for the add-one and
subtract-one assigns. `syntaxExpand` maps the new surface to the
book's instructions, one expansion procedure per new form, and runs
before assembly, before labels are scanned. The simulator proper
never sees the new forms.

Two machines are written in the new syntax and run: the book's gcd
machine with its two register shuffles written as `cpy` lines, which
answers its usual 2 for gcd(206, 40), and a countdown that exercises
`dec` and `inc`. The countdown controller initializes `sum` to zero
with an explicit assign before the loop; without that line the first
`inc` would read the `*unassigned*` initial content and the machine
would be wrong, so the initialization is load-bearing, not ceremony.
The pins are `gcd(206, 40) in the new syntax = 2` and
`countdown(3) sum = 3`, one run per new form plus the cpy pair.
