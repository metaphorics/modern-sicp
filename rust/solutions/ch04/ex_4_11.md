# Exercise 4.11: the frame as an association list (T)

## Approach

The base frame is the crate's mutable name table, so this exercise builds the
alternative beside it: an environment is a list of frames, each frame a list of
`(name . value)` bindings. `alist_lookup` scans frames outwards,
`alist_define` conses onto the first frame, and `alist_set` mutates the value
cell of the binding it finds, so aliasing stays visible the way the book's
`set-cdr!` makes it.

## Map class

`T`, for comparison against the base representation.

## Sample answer

Inner x shadows with 2, `set!` rebinds it to 10, the outer frame keeps its own
1, and z is `unbound variable: z`.
