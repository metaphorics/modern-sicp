# Exercise 5.24: cond as a basic controller form (T)

## Approach

The closed enum with one exhaustive `match` is the `ev-cond` loop made static: each arm selects its actions by shape, the payload arm returns its carried value the way a bodyless clause returns its predicate's value, and a missing arm is rejected at admission, which is the `else`-less default made static.

## Map class

`T`.

## Sample answer

The three signals answer `0`, `30`, and `100` on both engines. The match missing an arm fails admission with class `Type` before any effect runs.
