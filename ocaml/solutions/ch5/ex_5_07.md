# Exercise 5.7: the designed machines on the simulator

The map class is `T`. The two machines of Exercise 5.4 (the recursive
and the iterative exponentiation controllers) are assembled by the
section's simulator exactly as the book's `make-machine` assembles
them: registers declared, the shared arithmetic table installed, the
controller text checked for unknown registers, operations, and labels
before any instruction exists.

`ex_5_07 ()` runs the recursive machine on (2, 10) and (3, 5) and the
iterative machine on the same inputs, answering
`["1024"; "243"; "1024"; "243"]`. The recursive machine exercises the
stack: each level saves and restores `continue` only, the economy the
5.1 analysis anticipated.
