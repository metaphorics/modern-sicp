# Exercise 5.46: comparing Fibonacci stack use (T)

## Approach

The Fibonacci recurrence runs two ways at n = 5, 6, and 7: the counted compiler run and the special-purpose machine. Each row carries both counters for both implementations with Fibonacci answers. Depths climb everywhere while each compiled push count tops the sum of its two predecessors — measured rows, not an extrapolated ratio.

## Map class

`T`.

## Sample answer

Answers are `5`, `8`, `13` on both implementations. Depths climb on both; compiled pushes grow super-additively.
