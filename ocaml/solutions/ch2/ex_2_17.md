# Exercise 2.17 — last-pair (translate)

The map class is `T`. `ex_2_17` walks the list until it reaches the
last cell: the match on `[ _ ]` is the base case, returning the
singleton list the statement asks for, and the `_ :: rest` arm
recurses on the tail. The nonempty-list precondition is enforced
where Scheme's version would tear a `cdr` off a non-pair: the `[]`
case raises `invalid_arg` at the door with the precondition in the
message.

Sample: `ex_2_17 [23; 72; 149; 34] = [34]`.
