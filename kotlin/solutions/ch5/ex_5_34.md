# Exercise 5.34: compiling iterative factorial

The recursive factorial must resume its multiplication after each
self-call. An iterative factorial instead passes its accumulator as
an argument to a call in tail position, so that call can reuse the
current continuation rather than accumulating pending multiplications.

`compiledFactorialAnnotation` compiles a factorial call for inputs
1 through 6 and runs the compiled instruction sequence on
`Compiler.machine`. Each displayed push count and maximum depth
comes from that run's monitored stack. The final line checks whether
the measured maximum depth remains independent of the input.
