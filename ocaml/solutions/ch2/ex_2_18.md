# Exercise 2.18 — reverse (translate)

The map class is `T`. The solution is the standard accumulator
reversal: cons each item onto an accumulator that starts empty. The
helper's self-call is its entire result, so OCaml runs it in constant
stack, matching the iterative discipline the book teaches in 1.2.1
even though the exercise itself only asks for the recursive
observation. No library `List.rev` is used; the exercise is the
definition.

Sample: `ex_2_18 [1; 4; 9; 16; 25] = [25; 16; 9; 4; 1]`.
