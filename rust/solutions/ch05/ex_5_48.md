# Exercise 5.48: adding `compile-and-run` (T)

## Approach

A host program that builds guest source, admits it, and runs it is the edition's `compile-and-run`: the compiler is available during execution. Two staged variants prove the staging is real — the generated constant decides the answer. Nothing is quoted, canned, or precompiled; each run admits fresh source text.

## Map class

`T`.

## Sample answer

The staged `6 * 20` prints `120`; restaging with `7` prints `140`, each on both engines.
