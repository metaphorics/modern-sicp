# Exercise 1.10 — Ackermann's function (translate)

The map class is `T`. `ackermann` translates the `cond` into a chain of
`if`/`else if`, no other change.

`ackermann 1 10 = 1024`, `ackermann 2 4 = 65536`, `ackermann 3 3 = 65536`,
matching the book's values.

`f n = ackermann 0 n` always takes the `x = 0` branch: `2 * n`. `g n =
ackermann 1 n` unfolds `ackermann 0 (ackermann 1 (n - 1))`, doubling
`ackermann 1 (n - 1)` at every step down to `g 1 = 2`, so `g n = 2 ** n`
for `n >= 1` (`g 0 = 0` since `x = 0` is checked first). `h n = ackermann
2 n` unfolds to `g (ackermann 2 (n - 1))`, so `h n = 2 ** (h (n - 1))` for
`n >= 1` with `h 1 = 2`: a tower of `n` twos (`h 2 = 4`, `h 3 = 16`,
`h 4 = 65536`), again with `h 0 = 0`. The book's worked example, `k n =
5 * n * n`, is stated directly.

The test pins the triple `(1024, 65536, 65536)` and checks `f`, `g`, `h`
against these closed forms for the first several `n`.
