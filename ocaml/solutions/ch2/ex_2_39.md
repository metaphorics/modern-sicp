# Exercise 2.39 — reverse via folds (translate)

The map class is `T`. Right-to-left: cons each element onto the
result (`fun x y -> x :: y`), which rebuilds the list in order.
Left-to-right: cons each element in front of the accumulated result
with swapped arguments (`fun x y -> y :: x`), which pushes later
elements to the front. Both agree with 2.18's `reverse`.

Samples: both give `[25; 16; 9; 4; 1]` on `[1; 4; 9; 16; 25]`.
