# Exercise 5.50: compiling the metacircular evaluator (A: evaluator source in the object language)

## Approach

Compile the provided object-language `METACIRCULAR` evaluator and use
it to evaluate factorial 5. The session checks both the numeric answer
and a side-effect probe, then compares machine steps for compiled
factorial, stack pushes for factorial interpreted by the 5.4 evaluator,
and machine steps when factorial is interpreted by the compiled
metacircular evaluator. This makes the cost of another interpretation
level measurable.

## Sample answer

The compiled metacircular session returns `120` and the probe result
`(tick tick tick)`. The solution computes an interpretation-price ratio
from the level-2 and level-0 instruction counts and asserts that level 2
uses more than 100 times as many machine steps. Wall-clock time is also
reported, but it is run-dependent and is not a pinned result.
