# Exercise 2.50: flip-horiz and the rotations (translate)

The map class is `T`. Each transformation is one `transform_painter`
call that only names the derived frame: origin at `(1, 0)` with
edges `(0, 0)` and `(1, 1)` for the horizontal flip; `(1, 1)`,
`(0, 1)`, `(1, 0)` for the 180-degree rotation; `(0, 1)`, `(0, 0)`,
`(1, 1)` for the 270-degree rotation.

The tests paint the outline painter through each transformation and
check the corners land where the geometry says: for instance
`flip_horiz` maps the unit outline to segments through `(1, 0)` and
`(0, 1)`, and `rotate_180` maps `(0, 0)` to `(1, 1)`.
