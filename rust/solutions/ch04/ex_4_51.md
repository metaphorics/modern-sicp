# Exercise 4.51: `permanent-set!` (T)

## Approach

`Set` records the assignment on the trail and rolls it back when the branch
fails. `Persist` skips the trail, so the failed attempt remains visible in the
engine's binding table. The comparison is the restoration discipline itself.

## Map class

`T`.

## Sample answer

After the failed branch, the trailed count is absent and the permanent count
is still `1`.
