# Exercise 4.11: frames as association lists

The map class is `T`. Each frame is one list of name-to-cell bindings instead of names beside values. Lookup and assignment search outward through every frame; definition touches only the first frame.

Sample: `ex_4_11 ()` answers the printed frames `"[x = 100] -> [z = 3; x = 10; y = 20]"`, the shadowed and outer reads, an unbound lookup, and an arity mismatch.
