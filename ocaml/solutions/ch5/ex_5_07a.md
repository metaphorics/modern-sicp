# Exercise 5.7a: a direct computation as each run's oracle (edition addition)

The map's tailored idea for the 5.7 cell, `chosen: ocaml`: pair each
simulated run with a direct host computation of the same function.

The oracle rule: the direct host computation is authoritative, and a
machine is correct exactly when every simulated answer equals its
oracle's answer at every shared argument. Agreement is asserted, not
displayed. A mismatch renders the line with `MISMATCH`, which the
tests would catch.

the iterative factorial machine of Exercise 5.1 (one recursive
process, one iterative) on the shared argument set n = 0..6, with the
host's recursive `fib` and loop-based `factorial` as their oracles.
