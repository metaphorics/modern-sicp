# Exercise 2.52a — SVG view-box transform with a golden test
(tailored addition, this edition)

The map's idea column for 2.52 offers "euler square-limit variant";
this edition chooses the view-box transform instead and records the
pick in `docs/exercise-map.md`. The addition extends 2.52's picture
language work at the renderer level, which is this edition's
representative surface: painters return segments, and the SVG text
is where the drawing becomes an artifact.

`render_view_box ~view_box ~size frame painter` is the main text's
renderer with the view box as an explicit argument, so the same
painted segments can be shown through any window of the plane — a
margin (`"-0.1 -0.1 1.2 1.2"`), a tight crop, or a wider canvas.
`ex_2_52a ()` renders the `square_limit` of `wave` at level 4 through
that margin view box and returns the SVG text.

The golden test is the point of the exercise: the expected SVG text
is checked in at `test/ch2/golden_ex_2_52a.svg`, and the test
compares the renderer's output to it byte for byte. Any change in
the picture language's geometry — a flipped rotation, a moved
segment — fails the test, while pure refactoring passes it, which is
exactly the contract a golden file should enforce.
