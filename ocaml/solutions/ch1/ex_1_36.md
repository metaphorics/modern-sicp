# Exercise 1.36: printed fixed-point iterations (translate)

The map class is `T`. `fixed_point_traced` is the section's
`fixed_point` with a `print_endline` of every guess before it is
tested, using the section's own `for-each`/`display` convention (D29):
printed lines carry no `=>` marker, and the returned value's line ends
the sequence. It also returns the number of steps taken, since "with
and without average damping" asks for a comparison, not just a value.

Solving `x^x = 1000` is a fixed point of `x -> log 1000 / log x`. The
book's own warning applies here too: starting from a guess of `1.`
divides by `log 1. = 0.`, so both runs start from `2.`, as the
exercise permits ("you cannot start with a guess of 1"). Undamped, the
search takes 34 steps to `4.555532270803653`; average-damped, 9 steps
to `4.555537551999825`, matching to within the search's own
`0.00001` tolerance. `ex_1_36 ()` returns both pairs.
