# Exercise 3.56: Hamming's S via merge

## Approach

The statement asks for the stream S of positive integers with no prime factors other than 2, 3,
or 5, ascending with no repetitions, by filling the blanks of `const S = consStream(1, () =>
merge(⟨??⟩, ⟨??⟩));`. The fill nests the scaled branches: `consStream(1, () => merge(scaleStream(S,
2), merge(scaleStream(S, 3), scaleStream(S, 5))))`, using the section module's `merge`, which on
equal heads emits the value once and advances both inputs.

The proof the map's tailored cell calls for, that S is exactly the 5-smooth numbers, each once,
in ascending order, has three parts.

Every element is 2^a 3^b 5^c: 1 = 2^0 3^0 5^0. Each later element leaves a merge as k times the
head of some scale branch, so it is k times an earlier element of S for k in 2, 3, 5; by
induction on position, every element is 5-smooth.

Every 2^a 3^b 5^c appears: 1 is in S. For (a, b, c) other than (0, 0, 0), divide out one copy of
a prime p with a nonzero exponent; the quotient is a smaller 5-smooth number, in S by strong
induction on n, and n is p times it, so n is the head of the p-scaled branch by the time the
merge has consumed everything smaller.

Each appears exactly once: merge of two strictly increasing streams is strictly increasing. The
emitted head is the smaller; after emitting, the branch that held it advances to something
strictly larger, and the other branch's head, if equal, was consumed too, so the next minimum is
strictly larger than the last output. Scaling by 2, 3, or 5 preserves strict increase, and
`consStream` prepends 1, smaller than every scaled element. A strictly increasing stream has no
repetitions; in particular the double-count at equal heads, where 6 arrives from both the 2
branch and the 3 branch, is emitted once and both pointers advance.
