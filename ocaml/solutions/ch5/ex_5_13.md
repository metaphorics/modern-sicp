# Exercise 5.13: registers derived from the controller text

`derive_registers` scans the parsed instructions with the base simulator's
register scan (`instruction_registers`), keeping first-use order and
dropping duplicates; `make_controller_machine` assembles with that
scan instead of a supplied list. The machine's own `flag` is still
allocated by the constructor, which is where the book allocates it
too; a controller naming an undeclared register still fails the
assembly check, only now the check runs against the scan.

`ex_5_13 ()` assembles and runs the GCD and Fibonacci machines with no
register list at all: gcd(206, 40) = 2 and fib 6 = 8, the scan having
found every register the machines touch.
