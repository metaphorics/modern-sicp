## Exercise 2.18: reverse

Approach: a tail-recursive accumulator moves each `PairCell.first` onto
the answer and continues through `PairCell.second`, preserving all
elements in reverse order. Class: T, direct translation using Kotlin's
`tailrec` as an explicit loop optimization. Deviation: the function
returns a typed `Datum` chain; the sample's string result uses
`renderDatum` as its canonical host rendering.
