# Exercise 4.9: iteration constructs as derived forms

## Approach

Iteration belongs to derived forms, not to new evaluator machinery. The
while expression becomes a loop in an immediately called block over the
guest's own `while` statement; the range loop binds its variable and its
limit exactly once (`@@limit`) and then walks `name` from `from` to `to`
inclusively with `while`, stepping `name` at the end of each body. The
loop's value is `undefined`, the statement layer's own answer. The
derivation is total, so the constructs work inside procedure bodies —
termination needs no new machinery and no escape through the host.

## Numbers

A range loop over `1..5` accumulating into `total` answers `15`, and the
manual recursion `sumTo(5)` also answers `15`. A while summing `1`
through `4` answers `10` at top level and the same while nested in a
procedure body answers `10`. A while with a false predicate never runs:
`ran` stays `0` and the loop answers `undefined`. A range loop over
`3..3` runs its body once, `once` is `3` and `runs` is `1`, pinning the
inclusive bound.

## Class and deviations

Translated row. Deviations: the loop's value is `undefined` (the old
solution answered the empty list, the typed analog being the statement
layer's own value), and the inclusive bound is written `name <= limit`
directly — the old solution needed `(< v (+ limit 1))` only because that
primitive table shipped no `<=`. The limit binding `@@limit` is the
generated-name device that keeps nested loops from capturing each
other's bounds.
