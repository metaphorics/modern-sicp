# Exercise 2.38: fold-left versus fold-right

## Approach

`fold_left` is one loop combining the accumulator with each element
left to right; the section's `accumulate` plays `fold-right`. Division
gives 3/2 against 1/6 because `/` is not associative. The nesting
demonstration uses `Nest`, where the right fold hangs each new element
off the right end and the left fold off the left end, printing
`(1 (2 (3 ())))` against `(((() 1) 2) 3)`. The stated property: `op`
must be associative and commutative, so the grouping and the end the
initial value sits on stop mattering.

## Map class

`T`: the statement translates directly; the nested-list demonstration
rides the edition's tree type because Rust lists are homogeneous.

## Deviation

The nesting demonstration uses `Nest` rather than heterogeneous pairs,
as above; the division results and the property are the book's.
