## Exercise 3.17: count distinct pair identities

Approach: `countDistinctPairs` keeps a list of `PairCell` objects seen
during one traversal. It follows both fields but counts a cell only on its
first visit. The list uses `===`, so structurally equal cells remain
distinct.

Why the list is explicit: it makes identity membership visible in the
host-language traversal without relying on an equality-based set. The list
is local to a call, so one run cannot affect the next.

What the tests say: the count-3, count-4, and count-7 graphs from exercise
3.16 each report three distinct cells. A repeated call on a shared graph
also returns three both times.

Class: A (identity membership is explicit in the host traversal).

Deviation: no identity-hash table is introduced.
