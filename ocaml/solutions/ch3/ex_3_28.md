# Exercise 3.28 — or-gate primitive (translate)

The map class is `T`: `or_gate` is a direct translation of the
book's `and-gate` with `logical_or` in place of `logical_and`,
attaching an action to both input wires that schedules the new output
one `or_gate_delay` after either input changes. The simulator
underneath (agenda, wires, `propagate`) is the section's shared
machinery from 3.3.4, already built and tested by `run_sec_3_3`; the
exercise itself is purely the truth table, checked both through the
simulated gate (one full propagation per input combination) and
through the pure `logical_or` function directly.

Sample: `ex_3_28 ()` answers `((0, 1, 1, 1), 0, 1, 1, 1)`.
