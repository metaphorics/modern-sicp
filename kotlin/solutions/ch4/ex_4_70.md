# Exercise 4_70: the let bindings of add-assertion!

## Approach

Take a snapshot of the typed database's first two `QFact` answers,
append a third fact, then query again. The original snapshot remains
`a, b`; the new query sees `a, b, c`. This preserves the lesson of
binding the old stream before changing the stored collection.

## Answer

Hand-derived, unrun expectation (`E4_70Test`): `?x = a`,
`?x = b` in the snapshot; `?x = a`, `?x = b`, `?x = c` after
the append; `snapshot unchanged: true`.

## Deviation

The old cyclic mutable-stream failure is not reproduced by
`QueryDatabase`'s chronological fact list.
