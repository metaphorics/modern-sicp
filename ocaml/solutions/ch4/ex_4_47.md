# Exercise 4.47: Louis's parse-verb-phrase (translate)

Louis's version works in this evaluator, because an `amb`'s
alternatives are analyzed but evaluated lazily, one at a time only when
the search tries them: the recursive `(parse-verb-phrase)` inside the
second alternative is entered only after the first alternative (the
bare verb) has failed for a given input position. The demonstration
runs Louis's definition against the section grammar and pins the same
parses the original produces for the ambiguous sentence. Interchanging
the two expressions in the `amb` would diverge: the recursion would be
tried before any word is consumed, and since the recursive alternative
performs a choice only after descending, the search would never reach
`parse-word` to consume a word. (Its alternatives would loop forever
before the first `require`.)
