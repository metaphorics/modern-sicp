# Exercise 5.10: a new surface syntax behind isolated syntax procedures

The new surface keeps the book's instructions, wrapped as `book` lines,
and adds three register-to-register forms: `cpy(a, b)` for
`(assign a (reg b))`, and `inc(r)` and `dec(r)` for the add-one and
subtract-one assigns. Each expands by one procedure in this file and
nowhere else: `syntaxExpand` maps the new forms to book instructions
before labels are scanned, so the simulator proper never sees them, and
changing the surface syntax touches exactly these four procedures.

Two machines run in the new syntax. The gcd machine's two register
shuffles become `cpy` lines and answer the usual 2 for gcd(206, 40); a
countdown that decrements `count` and increments `sum` three times sums
3, exercising both `inc` and `dec`. The test pins both lines.
