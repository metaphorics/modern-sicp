# Exercise 2.20: `same-parity` with a rest parameter

## Approach

Scheme's dotted-tail notation becomes a Rust rest parameter: a fixed
`first` argument plus a `&[i128]` slice holding the remaining
arguments, which is the same two-part shape `(define (f x . y) ...)`
gives the book. The procedure filters the leading argument together
with the rest by parity and collects the survivors into a `List`. Rust
functions cannot be variadic the way `+` and `list` are, and the
section's prose says so: a homogeneous slice is the language's
rest-parameter shape, and genuinely heterogeneous variadics need macros,
which is out of scope for the book's subset.

## Map class

`A`: the variadic-mechanism part of the statement is re-expressed for
Rust's rest parameters; the parity-filtering exercise itself is
unchanged.

## Deviation

None beyond the mechanism substitution the map prescribes.
