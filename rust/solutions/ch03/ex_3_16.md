# Exercise 3.16: count-pairs double counts

## Approach

The book asks what Ben's `count-pairs` returns on four structures
whose true pair counts are all different. The Rust solution builds
the first three exactly as drawn: a plain `(a b c)` chain, counted
correctly as 3; `((a b) b)`, whose second pair is reached by two
routes and counted twice, 4; and `((a b c) a b c)`, whose whole
three-pair spine is shared between the car and the cdr and counted
seven times. The fourth structure has no answer to print, since the
count never returns on it; the solution closes a ring with
`make_cycle` and reports `has_cycle` as true, standing in for the
count that would never come back.

## Map class

`T`. The book's procedure is translated directly over the section's
pairs; the counted routes and the missing fourth answer are the
statement's own content.

## Deviation

The fourth structure's report is a cycle detector's boolean rather
than a hang. The statement's own answer to that structure is that
the count never returns, and a boolean that proves the ring is the
runnable form of the same finding.
