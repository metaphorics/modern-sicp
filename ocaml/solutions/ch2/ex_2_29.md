# Exercise 2.29: binary mobiles (adapt: recursive variant type)

The map class is `A` (map row: "branch structure needs recursive
variant type"). The constructors given in the statement become the
variant type `mobile = Mobile of branch * branch`, `branch = Branch
of int * structure`, `structure = Weight of int | Hanging of mobile`;
the four selectors of (a) are one-line pattern matches. (b)
`total_weight` folds the two branches, resolving each structure to a
weight or a recursive call. (c) `balanced` compares branch torques
(length times weight) and requires every hanging submobile balanced.

(d) is answered with a second module, `Cons_repr`, where the same
shapes are plain pairs (`mobile = branch * branch`, `branch = int *
structure`), and `total_weight`/`balanced` are rewritten in tuple patterns.
patterns. The exercise's question, "how much do you need to change",
has a compiler-checked answer in OCaml: only the selector layer, and
the compiler points at every place that reads the old shape. The
tests build the same symmetric mobile in both representations and
check equal weights and balance.
