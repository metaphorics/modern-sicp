# Exercise 3.55: partial-sums

## Approach

The statement asks for `(partial-sums S)`: the stream of S0, S0 + S1, S0 + S1 + S2, ..., with
`(partial-sums integers)` shown as 1, 3, 6, 10, 15, .... The book's shape is a self-referential
`consStream` of the head of S and the sum of the partial sums with the rest of S; the solution
translates it directly, guarding the empty stream. The section's approximating streams already
use a module `partialSums` of the same definition, so the exercise re-states it under the name
`partialSumsEx` and the tests cross-check the two agree element-wise, which pins both the
exercise's own definition and the section's dependency on it.

## Pins

Computed by running. `streamTake(partialSumsEx(integers), 6)` is 1 3 6 10 15 21, the
statement's example. `streamTake(partialSumsEx(ones), 6)` is 1 2 3 4 5 6. `partialSumsEx` and
the module's `partialSums` agree over the first 30 integers and over the first 20 of
`piSummands(1)` (identical float operations in identical order). The empty stream in answers
the empty stream.

## Map class

T (translate: syntax changes only). All four columns are plain T; the OCaml column's `Lazy.t`
changes only where the memoization sits, not the definition.

## Deviation

The exported name is `partialSumsEx` rather than `partialSums` because the section module
already exports the same definition under the book's name for the 3.5.3 approximating streams;
the tests assert the two are element-wise equal rather than duplicating a second silent copy.
