# Exercise 4.15: the halting argument made executable (translate)

The map class is `T`. The statement's argument runs instead of being
narrated: the evaluator carries a fuel budget, every evaluation spends
one unit, and an exhausted budget answers the typed fuel error, so a
non-terminating object program observes as an error instead of
hanging. `halts?` is the thought experiment cut down to its decision:
a constant oracle defined in the object language, probed through the
evaluator before the diagonal runs. Under the yes oracle, `(try try)`
walks into `run-forever` until the fuel runs out; under the no oracle
it returns `halted` for a program the yes run just proved cannot halt.
Whichever way `halts?` decides, the diagonal makes it wrong; the two
traces are that proof.

Sample: `run_forever_trace ()` answers
`["halts? answered #t"; "Error: invalid form: the fuel is exhausted"]`,
`halts_trace ()` answers `["halts? answered #f"; "halted"]`, and
`ex_4_15 ()` answers both in order.
