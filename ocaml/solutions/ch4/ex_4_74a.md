# Exercise 4.74a: the flatmap frame measurement (this edition's addition)

The measurement behind 4.74b. A frame is counted when it is emitted into the
output of the flatmap under test, once per frame, in emission order; the
pinned queries are finite and read to the end, so each count is exactly the
size of the flatmap outputs in the three replaced paths (`find_assertions`,
`Not`, `Holds`). The shared query exercises the first two paths; the salary
query `and([salary, ?person, ?amount], holds(>, ?amount, 30000))` exercises
the third.

Both evaluators emit the same frames in the same order and count the same
number of them, because every procedure mapped over a frame stream in these
paths returns the empty stream or a singleton: the book's interleaving and
Alyssa's first-survivor selection then combine identical frames.

