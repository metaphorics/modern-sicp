# Exercise 3.54: mul-streams and the factorial stream

## Approach

`mulStreams` multiplies heads and recurses on the tails, ending at
`LStream.Empty` when either argument runs out; overflow-checked
multiplication keeps the Long contract. `factorials` is the
self-referential top level value: its tail zips the stream itself with
the integers, so element n + 1 multiplies element n by n + 1 and the
stream counts 1, 1, 2, 6, 24, ... The tests pin the eight-element
prefix, `streamRef(factorials, 20)` at 20! = 2432902008176640000 (the
largest factorial Long holds, checked against the python3 value), and
`mulStreams` against `ones` and a finite pair.
