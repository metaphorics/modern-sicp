# Exercise 1.11: f by recursive and by iterative process

## Approach

The recursive function is the definition as written. The iterative one
carries the window `(f(k-2), f(k-1), f(k))` as three state variables and
slides it with `next = f(k) + 2*f(k-1) + 3*f(k-2)` until `k` reaches
`n`: the same shape as `factorialIter`, constant space, an explicit loop
because this host turns no self-call into a jump.

## Numbers

The ladder from the definition: `f(0..6)` = `0, 1, 2, 4, 11, 25, 59`;
`f(10) = 1892`, `f(15) = 142717`, `f(20) = 10771211`. Both spellings
agree for every `n` in `0..25`.

## Class and deviations

Adapted row, per the map: "iterative form as loop". The book's
tail-recursive formulation is stated as a loop over the state variables,
with the sliding window named in the doc comment. No other deviation.
