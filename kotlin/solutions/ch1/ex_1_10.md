## Exercise 1.10: Ackermann's function values

Approach: `ackermann` is the direct translation of the four-clause
definition into a `when`. Evaluating the clauses down to the `y = 1` base
case gives `ackermann(1, 10) = 2^10 = 1024` and
`ackermann(2, 4) = ackermann(3, 3) = 65536`. `ackermannF(n) = 2n`, read
directly off the `x = 0` clause. `ackermannG(n) = 2^n` for `n >= 1`
(`ackermannG(0) = 0`), because each increment of `y` in `ackermann(1, y)`
doubles the running total starting from `ackermann(1, 1) = 2`.
`ackermannH(n)` is a tower of `n` 2's, read right to left, for `n >= 1`
(`ackermannH(0) = 0`), because `ackermann(2, y)` evaluates to
`ackermann(1, ackermann(2, y - 1))`, that is, 2 raised to the prior tower.

Class: T (translate). Deviation: the book's own names `f`, `g`, `h`, `k`
are renamed `ackermannF`, `ackermannG`, `ackermannH` for clarity in a
package where every exercise's top-level names are visible to every
other exercise file in this section; `k(n) = 5n^2` needs no procedure of
its own, since the exercise only asks for its closed form, already given
in the book text.
