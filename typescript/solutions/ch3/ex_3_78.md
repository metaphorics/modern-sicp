# Exercise 3.78: solve-2nd, the second-order feedback loop

## Approach

The statement's equation `d^2y/dt^2 - a dy/dt - b y = 0` rearranges to
`y'' = a y' + b y`, and Figure 3.35's network is two `integral` boxes
in series: the derivative loop feeds the position loop, and the sum of
the derivative tap scaled by `a` and the position tap scaled by `b`
feeds the first integrator. This edition spells the section's delayed
integral `integralDelayed`, so `solve2nd` builds the position stream
as `integralDelayed(() => dy, y0, dt)` and the derivative stream as
`integralDelayed` of `streamMap2((yy, d) => a * d + b * yy, y, dy)`;
the thunked integrands make the mutual reference of the two `const`
bindings legal with no assignment.

## Pins

Computed by running. Damped oscillator `a = -0.1`, `b = -1`, that is
`y'' = -0.1y' - y`, from `y0 = 1`, `dy0 = 0`, at `dt = 0.01`: the
first five values are `1 1 0.9999 0.9997001 0.9994004099`; at index
500 (t = 5) the value is `0.18510721623125634` and at index 4000
(t = 40) it is `-0.09990880783812048`, so the envelope decays:
`|y(40)| < |y(5)|`. The windowed maxima over the last half period of
each segment agree, `0.18510721623125634` (indices 460 to 500) versus
`0.09990880783812048` (indices 3960 to 4000), so the decay is the
envelope's, not a phase accident.

Undamped `a = 0`, `b = -1`, from `y0 = 0`, `dy0 = 1`, at step 0.01,
compared against `Math.sin` at `streamRef` index `t / dt`:

| t | stream y | Math.sin(t) | error |

| 1 | 0.8456705645316805 | 0.8414709848078965 | 0.0041995797237840415 |

## Map class

T (translate: syntax changes only). The row's tailored idea, the
damped oscillator solution stream, is the tests' work, done here with
the pinned first values and the two envelope comparisons.

## Deviation

Two measured deviations from the natural first guess. First, at step
`dt = 0.1` the damped case never decays: the loop's two-step
amplification matrix `[[1, dt], [b dt, 1 + a dt]]` has determinant
`1 + a dt - b dt^2 = 1 - 0.01 + 0.01 = 1` exactly, so the discrete
loop conserves amplitude and the run at that step oscillates forever
(measured `|y[50]| = 0.2377` versus `|y[400]| = 0.6425`). The damped
test therefore runs at `dt = 0.01`, where the determinant is 0.9991
and the damping shows. Second, the 1e-3 tracking target is not
reachable at step 0.01 with the section's first-order integrator
(largest measured error 0.00917); the tests pin the honest 1e-2 bound
at step 0.01 and prove the 1e-3 target at step 0.001, where it holds
with margin.
