# Exercise 0.2 — sum_cubes twice

The recursive form mirrors the book's sigma notation: `sum_cubes_rec a b` adds
`a³` and recurses from `a + 1` until the range is empty. The fold form builds
the range with `List.init (max 0 (b - a + 1)) (fun i -> a + i)` and sums with
`List.fold_left`, so the adding logic is one function of two arguments.

The one-sentence answer the exercise asks for: prefer the fold version
whenever the range can be wide, because the fold's helper is tail recursive
while the recursive form's depth grows as `b - a` and can exhaust the stack.

The tests pin `sum_cubes_rec 1 10 = 3025` (the book's value), agreement of
both forms on a single-element range, on the empty range (both return 0), and
on a symmetric range around zero whose cubes cancel to 0; the QCheck2 property
in `../test/prop_folds.ml` extends that to generated ranges, wired into
`dune runtest` alongside these Alcotest checks.
