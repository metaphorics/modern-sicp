# Exercise 5.9: no labels in operation operands

The book permits a label among operation operands (the text's
`make-primitive-exp` accepts it and 5.9 asks to forbid it). The
section's simulator follows the book: its `source` type admits
`Label_ref` in any operand position. The solution's `check_operands`
scans every `Assign_op`, `Test`, and `Perform` and refuses a
`Label_ref` input, and its `make_machine` runs that check before
assembling, so the restriction is enforced at assembly without
changing the simulator. A label is still a legal source for a plain
`Assign`, which is how `continue` receives return addresses.

`ex_5_09 ()` pins both sides: the controller
`Assign_op ("a", "+", [ Reg "b"; Reg "c" ])` assembles and answers
`5`, and the same assign with `Label_ref "there"` in operand position
reports
`bad instruction: an operation input is a register or a constant, not the label there`.
The failure is typed, at assembly, before execution.
