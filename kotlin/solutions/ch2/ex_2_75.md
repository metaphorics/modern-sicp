## Exercise 2.75: message-passing make-from-mag-ang

Approach: `makeFromMagAngMessagePassing` is analogous to the given
`makeFromRealImagMessagePassing`, closing over `mag` and `ang` instead of
`x` and `y`, and answering the same four messages by the same
trigonometric relations run the other way.

Class: T, per the map; a direct translation of the book's own worked
example into this exercise's message object shape.

Deviation: the section's example in `book/ch2/2.4.texi` (2.4.3, message
passing) throws on an unanswered message, matching the book's `(error
...)`; this exercise's local `ComplexObject` returns the absent option
`null` instead, since the exercise itself does not ask for that error
path and a nullable result reads more directly here than a raised error
would.
