# Exercise 5.18: traced registers

A traced register overrides the one write path: `makeTracedRegister`
wraps the plain register and reports `name: old -> new` on every store
before the store happens. The machine builds all of its named registers
from the traced class through the `makeRegister` option, and the flag
stays an ordinary register, so only the controller's registers report,
matching the book's intent that the trace name the registers the
controller names.

The test pins the gcd(12, 8) log line by line: the two inputs land in
`*unassigned*` registers, each division step stores `t`, then `a`, then
`b`, and the final test on `b` = 0 takes the branch, so the last two
lines are `a: 8 -> 4` and `b: 4 -> 0` and the answer line reads
`gcd(12, 8) = 4`. Eight stores for three division steps are the
controller's three assigns per pass, which is the register trace
doubling as an execution trace.
