Exercise 5.42: lexical addressing in the code generators.

With the `lexical` configuration, `compile-variable` emits
`(op lexical-address-lookup) (const frame) (const displacement)
(reg env)` when `find-variable` locates the name -- two constants
where the book prints one list constant, the edition's spelling --
and falls back to `lookup-variable-value` for the globals the
compile-time environment cannot address. The pinned run applies the
section's nested-lambda example to five arguments: `(* 3 6 10)` = 180
answered entirely through lexical lookups on the lexical machine
(`Sec_5_39`'s).
