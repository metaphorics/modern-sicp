# Exercise 4_62: the last-pair rules

## Approach

A base rule for one-element lists and a step rule recursing on the dotted tail. The unanchored query rebinds a fresh renamed tail each application and never terminates.

## Answer

Hand-derived, unrun expectations (`E4_62Test`): both forward
queries end in `3`; `(last-pair [2, ?x] ...)` binds `?x = 3`.
The bounded backward query takes three answers with list lengths
one, two, and three, each ending in `3`.

## Deviation

None.
