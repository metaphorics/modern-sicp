# Exercise 1.18: the Russian peasant method (translate)

The map class is `T`. `mult_iter` combines exercise 1.16's invariant
technique with exercise 1.17's doubling and halving: the invariant is
`total + a * b`, unchanged whether `b` is even (double `a`, halve `b`)
or odd (fold one `a` into `total`, decrement `b`). When `b` reaches 0 the
invariant reads `total`, the answer, and the self-call is the whole
result at every step, so this is an iterative process with `Theta(log
b)` steps and `Theta(1)` space, the logarithmic iteration exercise 1.16
asked for, specialized to multiplication.

The test pins `ex_1_18 3 7 = 21` and checks agreement with `ex_1_17`
(exercise 1.17's recursive version) over several pairs, including 0 and
an even second argument.
