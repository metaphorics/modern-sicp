# Exercise 3.33: averager constraint (translate)

The map class is `T`: `averager a b c` composes the section's
`adder` and `multiplier` primitives exactly as the book specifies (
`a + b` feeds one factor of a multiplier whose other factor is a
constant 2, and the product is constrained equal to `c`), using the
`Constraints` support already built and tested in `sec_3_3.ml`. The
same network runs in both directions within one test: setting `a` and
`b` derives `c` as their average; later setting `c` and `a` (after
forgetting the earlier values) derives the missing `b`, which is the
constraint-propagation point the whole 3.3.5 subsection makes.
