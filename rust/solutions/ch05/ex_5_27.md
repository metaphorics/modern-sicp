# Exercise 5.27: the recursive factorial on the monitored stack (T)

## Approach

Each non-base level of the Figure 5.11 machine saves `continue` and `n`, so both stack measures fit `2n - 2` with the base level discounting itself. Seven runs check the answers against the running factorial and both measures against the formula. The guest recurrence runs on both engines with a positively counted compiled depth.
