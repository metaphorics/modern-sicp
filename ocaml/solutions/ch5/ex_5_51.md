Exercise 5.51: the explicit-control evaluator in C.

The translation is the controller itself: registers are struct
fields, every `ev-` entry point of 5.4.1 to 5.4.4 is a C label in one
`eceval` function, `(assign continue (label l))` stores a label
address and `(goto (reg continue))` is `goto *R_continue` (the GNU
computed-goto extension), and the stack is an array with the same
push/pop discipline. The object world -- pairs, symbols, environment
frames, the primitive table -- is the run-time support the exercise
requires. `compile_and_run` builds the translation with the system C
compiler and runs the book's factorial session: ok, then 120.
