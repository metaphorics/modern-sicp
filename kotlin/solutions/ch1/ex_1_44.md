## Exercise 1.44: smoothing and n-fold smoothing

Approach: `smooth(f)` averages `f` at `x - dx`, `x`, and `x + dx`.
`nFoldSmooth(f, n)` is `repeated(::smooth, n)(f)`: `repeated` from
exercise 1.43 is applied to the *transformation* `smooth`, not to `f`
directly, so this instantiates `repeated` at
`T = (Double) -> Double` rather than `T = Double`, the same generic
function serving both exercises (each file keeps its own private
copy, per this edition's per-exercise-file convention).
`smooth(square)(2)` is `4.000000000066667`, a small `dx`-scale
perturbation of the exact 4; five-fold smoothing the same function at
the same point gives `4.000000000333333`, a slightly larger but still
tiny perturbation, since each smoothing pass compounds a little
numerical noise without moving the underlying value.

Class: T (translate). Deviation: none. The tailored idea 1.44a
(denoise synthetic noisy samples) was not chosen as this section's one
addition.
