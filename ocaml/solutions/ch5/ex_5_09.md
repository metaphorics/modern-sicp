# Exercise 5.9 — no labels in operation operands

The book permits `(label ...)` among operation operands (the text's
`make-primitive-exp` accepts it and 5.9 asks to forbid it). This
edition's operand grammar is stricter from the start: an operation
input is written `(reg r)` or `(const c)`, and the reader refuses
everything else at parse time — the exercise's enforcement, already in
place at the syntax layer the simulator consumes.

`ex_5_09 ()` pins both sides: the controller assigning
`(op +) (reg b) (reg c)` assembles and answers `5`, and the same
assign with `(label there)` in operand position reports
`bad instruction: an operation input is written (reg r) or (const c)`.
The failure is typed, at assembly, before execution.
