# Exercise 4.9: design iteration constructs (T)

## Approach

Two constructs, `while` and `until`, each evaluated directly: the predicate and
body re-enter the evaluator per iteration, so nested forms get the whole
language. Iterative processes run in constant host stack here for free --
the loops are host loops, which is the Rust idiom the edition states in 1.2.

## Map class

`T`.

## Sample answer

`(while (< i 5) (set! i (+ i 1)))` leaves i at 5; `(until (> j 12) ...)` leaves
j at 13.
