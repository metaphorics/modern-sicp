# Exercise 3.9: environment structures of two factorials

## Approach

The book asks for the environment structures of the recursive and
iterative factorials at `(factorial 6)`. The Rust replacement (map class
`R`) asks the same question of the call stack, because in Rust the
frames of the book's diagram are stack frames and nothing discards them
early. The solution instruments both versions with a `Cell<u64>` depth
recorder: the recursive version passes `depth + 1` into each call and
takes the maximum at entry, the loop version never leaves depth 1. The
test pins the book's answer (720 by both roads) together with the
predicted stacks: six frames deep against one.

## Map class

`R: diagram call stack, no TCO`. The drawing became a measurement, and
the footnote's tail-recursion honesty became the exercise's point: the
loop is the only version with a constant-space guarantee.

## Deviation

The iterative version is a `for` loop rather than the book's
`fact-iter` helper, matching the edition's 1.2.1 convention that
iterative processes in Rust are loops. Depth is carried in an explicit
parameter plus a shared `Cell`, so the traced factorial stays a plain
function.
