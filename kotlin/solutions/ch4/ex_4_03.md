# Exercise 4.3: data-directed dispatch by table

## Lesson

Evaluation by tag becomes data: a `Map` from tag names to handler
functions replaces the dispatch, so a new clause installs with one
entry instead of an edit. The probe shows the additivity the book is
after -- the base table answers numbers but misses addition, and the
late-installed `add` entry answers the sum through the same driver.

## Map class

`A` (map row 4.1: `when` dispatch). The table is guest data over the
sealed family; handlers narrow their variant and defer to the kernel.

## Deviation

None. The tag function covers every sealed variant, so dispatch stays
total as clauses install.

## Answer

- Base table: `42`, then the missing clause fails.
- Extended table: the sum answers `5`.
- Pin: `tableDispatchTranscript() == "42\nerror\n5\n"`.
