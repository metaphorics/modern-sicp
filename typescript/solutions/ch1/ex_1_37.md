# Exercise 1.37: continued fractions, both processes

## Approach

The recursion evaluates the fraction from its deepest term, returning 0 past
term `k`; the loop twin runs `i` from `k` down to `1`, carrying the fraction
built so far. Node gives no tail-call guarantee, so the loop is the host
shape of part (b). Accuracy is measured against the closed form
`1/phi = (sqrt(5) - 1)/2`, and "accurate to 4 decimal places" is read as
absolute error below `1e-4`.

## Numbers

The all-ones fraction oscillates in on `1/phi = 0.6180339887498948`:
`k = 8` gives `0.6176470588235294`, `k = 10` gives `0.6179775280898876`
(error `5.6e-5`), `k = 12` gives `0.6180257510729613`, `k = 14` gives
`0.6180327868852459`. The smallest `k` with error below `1e-4` is `10`
(`k = 9` is still `0.61818...`, error `1.5e-4`). One caveat the numbers
expose: with "correct rounding to 4 places" as the bar, `k = 11` would
round to `0.6181` and only `k = 12` settles - the truncations converge
alternately from above and below.
