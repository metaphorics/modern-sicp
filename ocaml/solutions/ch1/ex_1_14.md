# Exercise 1.14: count-change tree for 11 cents (translate)

The map class is `T`. The exercise asks for a drawing and an order-of-growth
argument; the code counts the tree's nodes instead of drawing it, one
call to `cc` per node (a call that returns 1 or 0 is a leaf; a call that
recurses is an interior node).

The tree for `cc 11 5` (amounts and remaining kinds annotate the calls
that matter; every branch bottoms out at the `amount = 0`, `amount < 0`,
or `kinds_of_coins = 0` cases) has 55 nodes total; `ex_1_14 ()` measures
this directly rather than asking the reader to count by hand.

**Orders of growth.** Space is `Theta(n)`, the amount: the deepest path
subtracts pennies one at a time, so the recursion depth (and hence the
stack) grows linearly with the amount. Steps grow much faster. Let
`T(a, k)` be the number of calls to change amount `a` with `k` kinds of
coins. `T(a, 1)` is `Theta(a)` (one call per penny). Each additional kind
of coin sums `T(a, k-1)` copies at every multiple of the new
denomination, roughly `a / d` of them, so `T(a, k)` gains one degree of
`a` per kind: `T(a, 2)` is `Theta(a^2)`, `T(a, 3)` is `Theta(a^3)`, and
with 5 kinds `T(a, 5)` is `Theta(a^5)`.
