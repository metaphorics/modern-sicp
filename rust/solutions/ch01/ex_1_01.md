# Exercise 1.1: evaluate a sequence of expressions in order

## Approach

The book shows eleven printed results in order, including the Boolean
comparison. The solution records that output sequence as `Printed::Number`
and `Printed::Boolean` values rather than erasing the Boolean or turning
all results into strings:

```rust
#[derive(Debug, PartialEq, Eq)]
pub enum Printed {
    Number(i64),
    Boolean(bool),
}

pub fn ex_1_01() -> Vec<Printed> {
    use self::Printed::{Boolean, Number};

    let mut printed = Vec::with_capacity(11);
    printed.extend([
        Number(10),
        Number(5 + 3 + 4),
        Number(9 - 1),
        Number(6 / 2),
        Number(2 * 4 + (4 - 6)),
    ]);
    let a: i64 = 3;
    let b: i64 = a + 1;
    printed.push(Number(a + b + a * b));
    printed.push(Boolean(a == b));
    printed.push(Number(if b > a && b < a * b { b } else { a }));
    printed.push(Number(match a {
        _ if a == 4 => 6,
        _ if b == 4 => 6 + 7 + a,
        _ => 25,
    }));
    printed.push(Number(2 + if b > a { b } else { a }));
    printed.push(Number(
        match a.cmp(&b) {
            std::cmp::Ordering::Greater => a,
            std::cmp::Ordering::Less => b,
            std::cmp::Ordering::Equal => -1,
        } * (a + 1),
    ));
    printed
}
```

The test checks the typed output sequence in the same order as the book's
eleven calls.

## The two silent lines

The two `let` bindings produce no output. The equality comparison does:
with `a = 3` and `b = 4`, `a == b` prints `false` between `19` and `4`.
It is evaluated and recorded at that position rather than discarded.

## The three-way comparison

The final printed expression branches on the ordering of `a` and `b`.
`match a.cmp(&b)` is its direct Rust form (three exhaustive arms on
`Ordering`, not an if/else-if chain), and it is what the edition's lints
(`comparison_chain`) require once more than one `if`/`else if` compares
the same two values.

## Test

With `a = 3` and `b = 4`, the reference solution's test checks all eleven
results in order: `10, 12, 8, 3, 6, 19, false, 4, 16, 6, 16`.
