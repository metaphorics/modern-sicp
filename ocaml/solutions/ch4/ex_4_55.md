# Exercise 4.55: three simple queries (translate)

Each query runs against a fresh data base loaded with the full Microshaft
personnel file in the book's insertion order; the demo pins, per query,
the query text itself followed by one line per answer (the driver's
display-stream), so a query with no answers is just its own line, which
is how `[(supervisor ?x ?x)]` pins empty. The matcher is a strict
pairwise walk, so `(accounting ?title)` spans exactly two elements: it
matches Cratchet's `(accounting scrivener)` but not Scrooge's
three-element `(accounting chief accountant)`: the same strictness that
keeps Reasoner's traineeship out of the section's `(computer ?type)`
transcript. The dotted form `(accounting . ?title)` retrieves the whole
division, so the demo pins the prescribed query and the dotted one;
`(address ?name (Slumerville . ?where))` uses the dotted form for the
same reason, every Slumerville address carrying a street and a number.
Deliberate deviations: both dotted queries, and the extra
`(supervisor ?x ?x)` observation the exercise's list motivates.

```
(supervisor ?x (Bitdiddle Ben))
(supervisor (Hacker Alyssa P) (Bitdiddle Ben))
(supervisor (Fect Cy D) (Bitdiddle Ben))
(supervisor (Tweakit Lem E) (Bitdiddle Ben))
(job ?name (accounting ?title))
(job (Cratchet Robert) (accounting scrivener))
(job ?name (accounting . ?title))
(job (Scrooge Eben) (accounting chief accountant))
(job (Cratchet Robert) (accounting scrivener))
(address ?name (Slumerville . ?where))
(address (Bitdiddle Ben) (Slumerville (Ridge Road) 10))
(address (Reasoner Louis) (Slumerville (Pine Tree Road) 80))
(address (Aull DeWitt) (Slumerville (Onion Square) 5))
(supervisor ?x ?x)
```
