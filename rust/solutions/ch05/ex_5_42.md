# Exercise 5.42: lexical-address code generation (T)

## Approach

With lexical addressing enabled, compile and run the nested-lambda
example. Bound variables are emitted as frame and displacement
constants for `lexical-address-lookup`; variables absent from the
compile-time environment continue through the global lookup operation.
The compiled block is checked for representative address operands, and
the resulting program is executed by the evaluator machine.

## Map class

`T`.
