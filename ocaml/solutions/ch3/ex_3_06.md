# Exercise 3.6: rand with generate and reset (translate)

The map class is `T`. `make_rand` closes over a
`Sicp_common.Random.t` held in a `ref` so `Reset` can replace it
outright rather than mutating in place. `Generate` draws the next
value from the current generator; `Reset new_seed` builds a fresh
generator from `new_seed` and installs it, discarding the old one.
Scheme's `((rand 'reset) new-value)`, a message that returns a
procedure still waiting for the new value, collapses into one
`Reset new_value` message, since OCaml has no need for the
intermediate procedure.

Sample: `ex_3_06 ()` draws a value, resets to a different seed and
draws again (discarded), then resets back to the original seed and
draws once more; the first and third draws are equal, demonstrating
that resetting to a seed reproduces the sequence from that seed.
