# Exercise 2.78 — primitive type tags (adapt)

The map class is `A`: the exercise asks `type_tag`, `contents_of`, and
`attach_tag` to use the host's own type system for ordinary numbers
instead of a `("scheme-number" . n)` pair, and OCaml's variant
constructors already are that internal type system. `value` gains a
bare `Num of float` case beside `Tagged of tagged`; `type_tag` reads
`"scheme-number"` off a bare `Num` with no lookup and `t.tag`
otherwise, `contents_of` is the identity on a bare `Num` (a number's
contents, per the exercise, is the number itself) and `t.contents`
otherwise, and `attach_tag` is the identity when the tag is
`"scheme-number"` — attaching that tag to a `Num` cannot add a
wrapper, since `contents` must already be a `Num` — and builds a
`Tagged` record for every other tag.

`ex_2_78 ()` returns `(type_tag (Num 5.), contents_of (Num 5.) = Num
5., type_tag (attach_tag "rational" (Num 0.)))`: `"scheme-number"`,
`true`, and `"rational"`, evidence that a bare number needs no wrapper
while every other tag still gets one.
