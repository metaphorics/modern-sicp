# Exercise 2.36: `accumulate-n`

## Approach

The fill: combine all the first elements with `accumulate`, then recur
on the sequence of all the `cdr`s. The terminating condition is the
book's `null?` test on the first sequence, answered with the empty
result rather than an error, so the recursion winds up the columns and
unwinds them in order. The test pins the book's `(22 26 30)`.
