# Exercise 3.4: lockout after seven bad passwords

## Approach

`GuardedAccount` adds a `Cell<u32>` of consecutive failures and an installed
alarm closure to the password account of exercise 3.3. A wrong password
increments the counter and calls `call_the_cops` when the count goes past
seven; a correct password zeroes it. The alarm is a caller-supplied
`Rc<dyn Fn()>`, so the test can observe the call through a shared counter
instead of a mock. The test checks both boundaries the wording depends on:
seven consecutive failures must not trip the alarm, the eighth must, and a
correct password in between must reset the count.

## Map class

`T`: the statement translates directly; `call-the-cops` becomes an installed
closure because a Rust function value is the book's procedure.

## Deviation

None.
