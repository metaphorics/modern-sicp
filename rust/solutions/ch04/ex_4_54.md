# Exercise 4.54: require as special form (T)

## Approach

The book completes `analyze-require`: evaluate the predicate, succeed
with `ok` when it holds, fail otherwise. The edition's clause shape is
a continuation, so the solution defines `RequireSpecial`, a variant
evaluator whose dispatch recognizes `(require p)` ahead of the section
dispatch, evaluates `p` against a continuation that answers `ok`
through the rest of the computation or calls the engine's `fail` --
the missing arm the exercise asks for. Every other form, including
nested definitions and `an-element-of`, goes to the section evaluator
unchanged; the base language still installs `require` as an ordinary
procedure, so the two routes are observationally equal.

## Map class

`T`.

## Sample answer

`(require (> 2 1))` answers `ok`; `(require (> 1 2))` runs dry with no
more values; inside a search the clause prunes the odd branches --
`(let ((x (an-element-of '(1 2 3 4 5)))) (require (even? x)) x)`
answers 2 then 4.
