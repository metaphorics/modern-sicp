# Exercise 3.56: Hamming numbers via merge

## Approach

The stream is defined by the four facts of the statement: it begins
with 1, and its remaining elements are exactly the elements of its own
scalings by 2, 3, and 5. So `S` is `1` consed onto the merge of
`(scale-stream S 2)` with the merge of `(scale-stream S 3)` and
`(scale-stream S 5)`, the fill the statement asks for. Each scaling
maps over the same self-referential name, so all three read one shared
memoized spine and every Hamming number is computed exactly once. The
merge keeps the streams ordered and, on equal heads, advances both
sides while emitting the value once: 12 arrives as `2 x 6` and
`2^2 x 3` but is emitted a single time. That duplicate elimination is
the construction's no-repetitions point, so the test asserts the
pinned first 15 elements and, separately, strict increase over the
first 200 -- a repetition or a descent would fail the `windows(2)`
comparison.

## Map class

`T`. The statement translates whole. The one Rust wrinkle is
mechanical: the self-referential `define S` becomes
`self_stream(|s| ...)` with `s.stream()` inside the single tail thunk,
the crate's stated pattern for a name used in its own tail.

## Deviation

None.
