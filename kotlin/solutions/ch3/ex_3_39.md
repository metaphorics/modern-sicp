# Exercise 3.39: which serialized outcomes remain

## Approach

The program serializes only the multiplication; the assignment of its
result stays bare. The solution splits P1 into the protected square and
the bare assignment, and P2 into one protected increment. Three
schedules exist and all three are forced: square then increment (101),
increment then square (121), and square, switch, increment, stale write
(100). The sorted set is {100, 101, 121}: 110 is gone because P1's two
reads sit inside one protected block, and 11 is gone because P2's
increment is atomic, so its write of 11 cannot land after P1's
assignment. The test also re-checks the fully serialized pair (101,
121) for contrast.

## Map class

`T`. The partially serialized program and the five original
possibilities are the statement's own.

## Deviation

None. The three remaining values match the standard answer.
