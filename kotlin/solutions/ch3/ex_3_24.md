## Exercise 3.24: let the caller choose key equality

Approach: `makeTable(sameKey)` supplies a predicate over `Datum` keys. The
default table uses `structurallyEqual`; callers can instead treat nearby
`Whole` keys as equivalent or compare `Symbol` names without case.

Why the predicate belongs to the constructor: every record scan uses the
same comparison for lookup, insertion, and overwrite. No later operation
can silently fall back to a different equality rule.

What the tests say: a near key finds and overwrites a record, a far key
misses, the default table retains its structural equality, and a symbol
predicate works on `Symbol` keys.

Class: T (the caller controls the host-data equality policy).

Deviation: the API compares typed datum values.
