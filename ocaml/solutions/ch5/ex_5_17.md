# Exercise 5.17: the labels preceding a traced instruction

The label information is retained at assembly: the machine carries a
`labels_before` array the label scan filled, so the trace can announce
each instruction's labels without touching the instruction stream.
The count lives in the driver, not the trace, so printing cannot
disturb it: fib 3 traced counts 51, the untraced machine's own
number.

`ex_5_17 ()` traces fib 3: each pass through the loop opens with
`fib-loop:`, the returns open `afterfib-n-1:` and `afterfib-n-2:`, the
base case announces `immediate-answer:`, and the answer line carries
the undisturbed count.
