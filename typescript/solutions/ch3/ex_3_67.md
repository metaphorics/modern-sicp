# Exercise 3.67: all pairs of two streams

## Approach

The statement modifies `pairs` to emit every pair (i, j), both orders,
and the hint says to mix in an additional stream. The modification
keeps the head pair separate and interleaves three parts: the rest of
the first row, (S0, T1), (S0, T2), ..., the first column below the
head, (S1, T0), (S2, T0), ..., and the recursive `allPairs` of the
cdrs. Putting the column inside the recursive part, so the shape is
`interleave(row, interleave(column, rest))`, keeps every component
stream infinite without starving the others.

## Pins

(1, 1), (1, 2), (2, 1), (1, 3), (2, 2), (1, 4), (3, 1), (1, 5),
(2, 3), (1, 6), (4, 1), (1, 7).

Both orders appear in the walked prefix, at pinned positions:
(1, 2) at index 1 and (2, 1) at index 2; (2, 3) at index 8 and
(3, 2) at index 12.

Against the module's pairs: (1, 2) is at index 1 in both streams, but
(2, 1), pinned absent from the first 5000 module pairs (that stream
carries only pairs with i <= j), sits at index 2 in the modified
stream. The first four pairs of the two streams already differ at
index 2: (2, 1) against (2, 2).

## Map class

T (translate: syntax changes only). The statement's modification and
the hint's additional stream carry over whole; the pairs travel as
two-element arrays.

## Deviation

The assignment brief describes the module's pairs as showing (2, 1)
"later"; measured, it never shows at all (absent through the first
5000 pairs), because `pairs` only emits the i <= j half of the array.
The pinned contrast is recorded as measured: absent there, index 2
here. The position walker is restated from exercise 3.66 with a
pointing doc comment, since exercises do not import across solution
files.
