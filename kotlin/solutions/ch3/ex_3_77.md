# Exercise 3.77: integral in the integers-starting-from style

## Approach

`integralAlt` builds `consStream(initialValue) { ... }` whose tail thunk
forces the delayed integrand, checks the book's `stream-null?` case
(an empty integrand ends the stream), and otherwise recurses with the
remaining integrand re-delayed and the accumulated value stepped by
`initialValue + dt * integrand.head`. The first element never touches
the integrand, which is exactly what lets `solve`'s feedback loop close.
`solveAlt` is the 3.5.4 network: the delayed integrand is tied to
`streamMap(f, y)` after `y` exists, in the same tie-before-force shape
as the prelude. Pins: a finite integrand 1, 2, 3 at `dt = 0.5` from 10
gives `10.0, 10.5, 11.5, 13.0` and then ends; `solveAlt({ y -> y },
1.0, 0.001)` at index 1000 is `2.716923932235896`, the historical pin,
because the accumulation order differs from the prelude's
`(dt * i) + int` only by commuting the addition, which is exact in
floating point; and `solveAlt` agrees with the prelude `solve` element
for element over the first 1001 values.
