# Exercise 3.37: expression-style constraint combinators (translate)

The map class is `T`: `c_add`/`c_sub`/`c_mul`/`c_div`/`cv` each build
a fresh output connector, wire an `adder` or `multiplier` primitive
(with a `constant` connector standing in for `cv`), and return the
output: the same "hide the connector plumbing behind ordinary
function calls" trick the book performs, translated without change
since it never depended on Scheme's syntax. `celsius_fahrenheit_
converter` then reads as the book's one-line network,
`F = 9C/5 + 32`, built entirely from these combinators; the property
suite in `prop_sec_3_3.ml` drives it bidirectionally over many
integer Celsius values to confirm the whole expression-style network
still propagates in both directions like the primitive one does.

Sample: `ex_3_37 ()` answers `(77, 100, 6, 7)`.
