# Exercise 4.79: environments instead of renaming (T)

## Approach

Rule application binds the conclusion's parameters fresh: the frame's
old formal bindings are shadowed, `unify_match` writes this
application's parameter bindings against the pattern, and a parameter
the pattern left untouched is re-linked to the binding it replaced, so
an argument variable the body fills stays shared write-through with the
enclosing query. Bounded queries only: the evaluator collects answer
vectors.

## Map class

`T`.
