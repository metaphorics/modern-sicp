# Exercise 2.53 — predicting printed variant values (replace)

The map class is `R`: SICP exercise 2.53 asks what the Scheme
interpreter prints for a handful of quoted expressions, which is a
question about Scheme's reader and printer, not about this edition's
material. The replacement keeps the number and asks the same kind of
question in OCaml terms: given the section's `symbol = Sym of string`
constructor and a few list, `List.hd`/`List.tl`, and `memq`
expressions, what does OCaml print?

The seven expressions mirror the book's seven, adapted where a
Scheme list mixed symbols and sublists in a way `symbol list` cannot
represent (OCaml's lists are homogeneous). The solution computes the
seven printed strings from the real values with small `show_*`
helpers and states the predicted strings as the expected values in
the accompanying test, so a wrong prediction and a wrong `show`
function are both caught by the same assertion.

Sample: `ex_2_53 ()` is a seven-element string list beginning with
`[Sym "a"; Sym "b"; Sym "c"]` and ending with
`Some [Sym "red"; Sym "shoes"; Sym "blue"; Sym "socks"]`.
