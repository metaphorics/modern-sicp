# Exercise 2.31: tree-map, an abstraction over square-tree

## Approach

Exercise 2.30's two square-tree spellings differ only in the function
applied at the leaves, so the recursion over Leaf and Node lifts into
`treeMap(f, t)` and square-tree becomes `treeMap` applied to the
squaring function. The solution keeps `squareTree` as the one-line
rewrite the exercise asks for, and the test checks it against the 2.30
answer. A second test applies `treeMap` with increment to confirm the
procedure is generic in the leaf function, which is the point of the
abstraction.

## Numbers

`treeMap((x) => x * x, t)` on the 2.30 tree renders
`"[1, [4, [9, 16], 25], [36, 49]]"`; `treeMap((x) => x + 1, node(leaf(1), leaf(2)))`
renders `"[2, 3]"`.

## Map class

`A`: the book's nested-list tree-map recurses with a pair test over
cons cells; this edition pattern-matches the `Tree<A>` union's `_tag` instead.
