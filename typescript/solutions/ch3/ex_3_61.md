# Exercise 3.61: invert-unit-series

## Approach

The statement derives X = 1 - S_R * X by writing S = 1 + S_R, the part
after the constant term, and rearranging SX = 1 one line at a time.
Read as a coefficient recurrence, X is the constant 1 followed by the
negation of the product of S_R with X itself: `invertUnitSeries` conses
1 onto `negateSeries(mulSeries(streamCdr(s), invertUnitSeries(s)))`,
a self-reference inside the memoized thunk tail, so each requested
coefficient forces exactly the product coefficients below it.

## Pins

Computed by running the tests, precision 12.

- `invertUnitSeries(expSeries)`, first 6 coefficients: `1, -1, 1/2,
  -1/6, 1/24, -1/120` (measured 0.5, -0.16666666666666663,
  0.04166666666666663, -0.00833333333333331 for the fractional ones),
  exactly the series of e^-x = 1/e^x.
- `mulSeries(expSeries, invertUnitSeries(expSeries))`, first 6
  coefficients: `1, 0, 0, 0, 0, 0`, all exactly 0 past the constant
  term: the statement's SX = 1.

## Map class

T (translate: syntax changes only). The rearranged equation maps to
one `consStream` over a negated product; `mul-series` comes from
Exercise 3.60 and is restated with a pointer because exercise files do
not import from each other.

## Deviation

A local `negateSeries` carries the minus sign of X = 1 - S_R * X (and
normalizes negated zero to zero, keeping the unit check's zeros
exact); the book writes the negation inline. No other change.
