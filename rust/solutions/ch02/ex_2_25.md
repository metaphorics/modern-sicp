# Exercise 2.25: picking 7 with accessor chains

## Approach

The replacement keeps the exercise's skill: reading off car/cdr
combinations. The solution defines typed `car` and `cdr` over the
section's `Nest` (a leaf or an empty branch is a `SicpError`, not a
crash) and writes the three chains as `?`-linked steps. The paths: for
`(1 3 (5 7) 9)` cdr, cdr, car, cdr, car; for `((7))` car, car; for the
six-deep nesting the chain alternates cdr and car once per level, then
car onto the leaf. Writing the alternation out is itself the lesson:
cdr peels an element off the front, car steps into the sublist that
element names.

## Map class

`R`: SICP 2.25 is about quoting list structure into Scheme programs, so
the edition replaces it with accessor chains over the edition's tree
type; the number and the target data are unchanged.

## Deviation
