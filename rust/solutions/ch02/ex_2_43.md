# Exercise 2.43: Louis's swapped mapping order

## Approach

Both versions of `queen_cols` are instrumented with a call counter so
the exercise's "estimate" is measured rather than only argued. In the
correct order `queen_cols(k - 1)` is evaluated once per level; in
Louis's swapped order it is re-evaluated for every row candidate, so
the recursion tree gains a factor of `board_size` per level: `n + 1`
calls against `sum_{k<=n} n^k`-style growth, measured here as 6 against
3906 for `n = 5`. Scaling to the 8-by-8 board gives the promised answer,
about `T * 8^8`, roughly seventeen million times the correct program's
time.

## Map class

`T`: the statement translates directly; the demonstration is
instrumented rather than hand-waved.

## Deviation

The measurement uses `n = 5` to keep the test cheap; the rationale
extrapolates to `n = 8` as the statement asks.
