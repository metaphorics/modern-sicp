# Exercise 2.4 — procedural cons, car, cdr as closures (adapt)

The map class is `A`: the idea survives, but the statement changes
because Scheme's dispatch-on-argument `cons` needs a function record
in OCaml, and this alternative representation, a closure applying its
own selector argument, needs the selector's type spelled out as
`'a -> 'a -> 'a` rather than left untyped.

`cons x y` closes over `x` and `y` and waits for a selector `m`;
`car`'s selector picks the first argument, `cdr`'s picks the second.
`ex_2_04` checks both projections hold for a representative pair. The
substitution-model proof the book asks for is: `car (cons x y)`
reduces to `(fun m -> m x y) (fun p _q -> p)`, which reduces to
`(fun p _q -> p) x y`, which reduces to `x`.
