# Exercise 4.52: `if-fail` (T)

## Approach

`IfFail` exhausts the primary search and uses the fallback only when the
primary produces no answers. `Choose` still explores every alternative;
fallback behavior has its own search node.

## Map class

`T`.

## Sample answer

The fallback answers `42` after a failing primary. A primary that returns
answers keeps them and suppresses the fallback.
