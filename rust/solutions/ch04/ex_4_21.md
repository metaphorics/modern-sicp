# Exercise 4.21: recursion without define (T)

## Approach

Both expressions run on the base evaluator as written. The factorial passes the
procedure to itself through `(fact fact n)`; the completed `f` passes `even?`
and `odd?` to each other the same way, filling the holes with
`(od? ev? od? (- n 1))` and `(ev? ev? od? (- n 1))`.

## Map class

`T`.

## Sample answer

The self-application factorial at 10 is 3628800; `(f 10)` is `#t`.
