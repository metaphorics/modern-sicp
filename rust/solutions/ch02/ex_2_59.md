# Exercise 2.59: `union-set` for the unordered-list representation

## Approach

`union_set` recurses on `set1`: an element already in `set2` is
dropped (it will appear via `set2`), and an element not in `set2` is
kept and consed onto the recursive union of the rest with `set2`. The
base case returns `set2` itself. `[1, 2, 3]` union `[2, 3, 4]` keeps
`1` from `set1` (2 and 3 are already in `set2`) and appends `set2`
unchanged, giving `[1, 2, 3, 4]`.

## Map class

`T`: translates directly onto the section's `element_of_set`, which
`union_set`'s membership check reuses.

## Deviation

None.
