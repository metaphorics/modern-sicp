# Exercise 1.27

`fools_fermat_test` checks Fermat's condition exhaustively, `a^n congruent
a (mod n)` for every `a` from 1 up to `n - 1`, in place of the single
random witness `fermat_test` draws. All six Carmichael numbers, 561, 1105,
1729, 2465, 2821, and 6601, pass for every witness: the Fermat test alone
can never expose them as composite, no matter how many random `a` values
it tries, because they satisfy the congruence for every `a` coprime to
them and the ones that are not coprime still pass the test by construction
of these particular numbers. A non-Carmichael composite like 8 fails
immediately (`2^8 mod 8 = 0`, not `2`), showing the exhaustive check
correctly distinguishes an ordinary composite from a number built to fool
the test. The map class is `T`.
