# Exercise 5.38: open coding

Open coding compiles the operands of an open-coded operator into argument registers and folds them with one operation call, instead of building a full procedure application per call. The exercise compares an arithmetic-heavy expression's compiled size with the generic application sequence and keeps the answers identical: open coding is a code-shape optimization, never a semantic one.

The listing check reads the fold's presence off the compiled statements, and the closing design point is the book's: the compiler sees the arithmetic at compile time, which is exactly what a run-time dispatch can never do.
