# Exercise 2.23: for-each

## Approach

`forEach` walks the list left to right applying `f` and, unlike `map`,
builds nothing: the book's version returns something arbitrary, so this
one returns `true`. The walk is a while loop over the `Cons` tags, and
the generic `A` keeps the caller's collector typed.

## Numbers

Applying a collector to `[57, 321, 88]` leaves `[57, 321, 88]` in order
and returns `true`; the empty list applies nothing and still returns
`true`.

## Map class

`T`: the statement translates directly.

## Deviation

None.
