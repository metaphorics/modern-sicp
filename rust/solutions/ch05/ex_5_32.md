# Exercise 5.32: symbol-operator fast path (T)

## Approach

A call the checker resolves to a function id compiles to a direct `CallFun` transfer with no operator value built or dispatched. A call through a function pointer compiles to the indirect sequence that parks the callee across its argument and transfers through `CallValue`. Both answer identically; the streams show which path each took.

## Map class

`T`.

## Sample answer

The named call answers `36` with no indirect dispatch. The pointer call answers `42` through the indirect transfer on both engines.
