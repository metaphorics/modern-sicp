# Exercise 4.60: lives-near duplicates (T)

## Approach

The book's rule lists every same-town pair in both orders (eight
answers). The deduplicated rule keeps the pair whose first member
prints before the second, using a host `name<` predicate applied by
`lisp-value` -- the edition's form of the book's ordering hint.

## Map class

`T`.

## Sample answer

Four deduplicated pairs: Aull-Ben, Aull-Louis, Ben-Louis,
Fect-Hacker.
