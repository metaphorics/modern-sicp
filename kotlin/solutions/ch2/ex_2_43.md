## Exercise 2.43: swapped mapping order

Approach: interchange the loops — the map over rows becomes the outer
operation, so every candidate row re-derives the whole `(k - 1)`-column
board set. The answer set is unchanged, which the test asserts on the
4-solution n = 6 board. Class: T, direct translation. Deviation: the
timing question stays prose: no wall-clock test runs, per the edition's
test idioms; the rationale records the estimate — `queenCols(k)` now
performs board-size recursive calls where it made one, multiplying the
recursive work by board-size at each of the board-size levels, roughly
boardSize^boardSize (about 8^8, sixteen million) times the original's
linear-in-levels recursion.
