# Exercise 2.65: Θ(n) `union-set` and `intersection-set` for tree sets

## Approach

`union_set_tree` and `intersection_set_tree` compose three Θ(n) steps:
2.63's accumulator-based `tree_to_list` flattens each tree to its
(already sorted, by in-order traversal) element list; 2.62's
`union_set_ordered` (or the library's `intersection_set_ordered`)
merges the two lists in one pass; 2.64's `list_to_tree` rebuilds a
balanced tree from the merged list. Three Θ(n) stages compose to a
Θ(n) whole. The tree over `[1, 3, 5]` unioned with the tree over
`[3, 5, 7]` gives the tree over `[1, 3, 5, 7]`; their intersection
gives the tree over `[3, 5]`.

## Map class

`T`: translates directly, composing the section's and the two prior
exercises' already-Θ(n) building blocks.

## Deviation

None. `tree_to_list`, `list_to_tree`, and `union_set_ordered` are
copied locally rather than imported from exercises 2.63/2.64/2.62's
solution files, since solution modules are not a shared library
surface.
