# Exercise 4.1: operand evaluation order (A)

## Approach

The checked Rust source defines two effectful operands and calls them from
`add`. Rust fixes left-to-right operand evaluation, so the direct and analyzed
engines must both print `1` and then `2`. The explicit `let` version sequences
the same effects and shows that the order is specified rather than incidental.

## Map class

`A: host fixes order, reword premise`.

## Sample answer

Both source forms print `1\n2\n3\n` through `admit`, direct evaluation, and the
analyzer.
