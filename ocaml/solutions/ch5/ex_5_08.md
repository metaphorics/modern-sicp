# Exercise 5.8: one label naming two locations

The book asks the assembler to signal an error when the same label
name indicates two locations. In this edition the check sits in the
assembler's label scan (the shared reader's `parse_program`, which
builds the label table before any execution procedure exists), and a
duplicate is a typed failure: `Bad_instruction` rendering as
`bad instruction: the label again is used twice`.

`ex_5_08 ()` feeds the book's ambiguous controller (`here` written
twice) to the assembler and pins the report. Nothing is assembled and
the machine is never started, so the question the book asks (what
will register `a` hold at `there`?) has no answer to give: the
description is rejected before control can reach anything.
