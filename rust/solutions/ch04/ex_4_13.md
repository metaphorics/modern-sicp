# Exercise 4.13: make-unbound! removes a binding (T)

## Approach

Specification choice: remove from the first frame only, and error if the first
frame does not bind the name. Removing an outer binding from an inner scope
would break the shadowing rule, and the error names the choice instead of
silently unbinding a name the scope does not own. `WithUnbound` removes the
entry from the newest frame's table.

## Map class

`T`.

## Sample answer

After `(let ((x 2)) (make-unbound! x))`, the outer x (1) is visible again;
unbinding a name the first frame does not bind raises
`make-unbound!: not bound in the first frame: x`.
