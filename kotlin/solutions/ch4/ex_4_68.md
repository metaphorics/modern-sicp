# Exercise 4_68: the reverse rules

## Approach

A base rule for the empty list and a step rule recursing on the tail through append-to-form. Forward queries terminate; the backward query generates candidate lists forever.

## Answer

(1 2 3) reverses to (3 2 1) and (a b c d) to (d c b a); the unanchored (reverse ?x (1 2 3)) exhausts this engine's heap before a generated candidate survives the append filter, which the segment records honestly. Pinned in E4_68Test.

None.
