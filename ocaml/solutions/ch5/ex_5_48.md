Exercise 5.48: compile-and-run inside a session.

Each item is evaluated or compiled and run; compiling appends a
labelled block and the session continues in the reassembled machine,
keeping the global environment, so later interpreted items call the
compiled procedures. Compile-and-run is a host driver command folded
over the session, not a guest primitive: the subset has no quoted
source for a primitive to take, so interpreted code cannot invoke it through the 5.45 interface. Item source is checked
with the whole unit before the session starts. Pinned: the factorial
compiled and run, `double` evaluated, `double (factorial 5) -
factorial 5` answering 120.
