# Exercise 2.12a — endpoint and center-width interfaces agree (added by this edition)

This edition's tailored addition for section 2.1 (`docs/exercise-map.md`
records `chosen: ocaml` on row 2.12). Exercise 2.9 already proves
`width (add_interval x y) = width x +. width y`; the same argument
applied to `center` (an average of sums is the sum of the averages)
gives `center (add_interval x y) = center x +. center y`.
`add_interval_by_center_width` restates the sum directly from those
two facts, using the center-percent family's own vocabulary instead of
endpoints, so `ex_2_12a` is a direct comparison of the two interfaces
introduced in this section: the endpoint pair Alyssa started with, and
the center-and-tolerance pair the exercise built on top of it.

Unlike exercise 2.13's product formula, this comparison is exact, not
approximate (addition's width and center formulas hold for every
interval, not only small-tolerance ones), so `ex_2_12a` checks
agreement within `1e-9`, floating-point rounding rather than a
genuine approximation gap.
