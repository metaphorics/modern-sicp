# Exercise 1.37: continued fraction, both processes (translate)

The map class is `T`. Part a: `cont_frac n d k` builds the fraction
from the innermost term outward, `go k 0.` folding
`n i / (d i + result)` down to `i = 1`. With `n i = d i = 1.` this
approximates `1 / phi`.

Part b: `go` is already an iterative right-to-left fold (each call is
a tail call), so there is no separate recursive version to rewrite;
the section's `cont-frac` written the other way (accumulating outward
from `i = 1`) would need the whole unevaluated tail carried along,
which is exactly the linear-recursion shape `go` avoids.

`smallest_k_for_4_decimal_places` measures `|cont_frac k - 1/phi|`
against `0.00005` (half a unit in the fourth decimal place) for
increasing `k`, and returns the smallest `k` from which that bound
holds for every larger `k` too, not just the first `k` that happens to
land close by luck: `k = 9` and `k = 10` come within `0.000148` and
`0.000056`, both still over the `0.00005` bound, before `k = 11`
crosses it and the error decays monotonically from there. That
smallest stable `k` is 11, giving
`cont_frac 11 = 0.6180555555555556`, about `2.2e-5` from
`1 / phi = 0.6180339887498948`. `ex_1_37 () = (0.6180555555555556, 11)`.
