# Exercise 4.23: `analyze-sequence` comparison (T)

## Contract

Real `AnalyzedProgram.bodies` `Plan::Seq` data compared through two typed
sequence-analysis shapes.

## Lesson

The text version wraps one sequence in a combined execution procedure. The
Alyssa version keeps one procedure per analyzed statement and loops over
them at runtime. Both analyze the same `Plan::Seq`; the counters are derived
from that tree's statement and tail count, not from hand-written constants.

## Map class

`T`.

## Sample answer

For the one-expression body, both analysis counts are one and Alyssa's
runtime wrapper runs twice over two calls. For the two-expression body, the
analysis counts are one versus two and Alyssa's wrapper runs four times over
two calls, while the combined text version adds no sequence wrapper.
