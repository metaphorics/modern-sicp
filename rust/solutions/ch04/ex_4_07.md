# Exercise 4.7: `let*` as nested `let` (T)

## Approach

`let*` is rewritten into nested parallel bindings. Each initializer sees the
bindings made before it, so the sequential scope is visible in the derived
tree rather than hidden in the evaluator.

## Map class

`T`.

## Sample answer

With `x = 3`, `y = x`, `z = y`, the nested rewrite answers `3`.
