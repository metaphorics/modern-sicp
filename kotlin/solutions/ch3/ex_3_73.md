# Exercise 3.73: the RC circuit as a signal network

## Approach

`rc` returns the network as a closure: the resistor branch is
`scaleStream(i, r)` and reaches the output at once, the capacitor branch
is `integral(lazy { scaleStream(i, 1.0 / c) }, v0, dt)`, and the sum is
`addStreams` of the two, which is exactly `v = v0 + (1/c) integral(i dt)
+ r i`. The delayed integrand is what makes the network composable; the
closure captures the current stream once so both branches sample it in
step. Pins: `rc(5.0, 1.0, 0.5)` on a unit constant current with `v0 = 0`
gives `5.0, 5.5, 6.0, 6.5, 7.0, 7.5, 8.0, 8.5` (each step adds
`dt * i / c = 0.5` to the integral part while the resistor part stays at
5). A second pin drives a three-sample current 1, 2, 3 with `v0 = 2`
through the same circuit and gets `7.0, 12.5, 18.5`. Both lists were
probed from the compiled solution and re-derived in a python3 script
with the same operation order (`v_k = r * i_k + int_k`,
`int_{k+1} = dt * i_k + int_k`); the lists agree bit for bit.
