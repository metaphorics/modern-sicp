# Exercise 4.24: benchmark analysis versus execution (T)

## Approach

The host clock times both evaluators over the same `(fib 13)` workload with
five warmup runs before each thirty-run measurement. The analyzed evaluator
pays for analysis once up front and executes the pre-analyzed procedure per
call; the base evaluator re-analyzes every call. The measured fraction of
analysis is the difference in per-call time.

## Map class

`T`, with the map's note: host timer, warmup.

## Sample answer

The pre-analyzed execution beats the base evaluator per call (the test prints
the margin); the analysis share of one base call is the difference, and it
grows with how often a form executes.
