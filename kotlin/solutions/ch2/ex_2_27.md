## Exercise 2.27: deep tree reversal

Approach: `reverseTree` reverses only a node's direct children, while
`deepReverse` recursively reverses every child list. On the two-branch
sample, each branch and the root reverse independently. Class: A, per the
map; the exercise uses the sealed `Tree` model so each leaf and node has a
typed shape. Deviation: results are returned as `Tree` values rather than
rendered nested-list text.
