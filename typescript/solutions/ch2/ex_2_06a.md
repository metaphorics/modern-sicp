# Exercise 2.6a: arithmetic on three plus the successor function

## Approach

`three` is the direct numeral `(f) => (x) => f(f(f(x)))`. `succ` is the
book's `add1` under its arithmetic name: `(n) => (f) => (x) => f(n(f)(x))`,
one more application of the step. The encoded-decoding property is pinned
through `churchToInt(n) = n((x) => x + 1)(0)`: the numeral is applied to the
successor step and a zero seed, so decoding inverts the encoding and every
arithmetic identity becomes an ordinary numeric assertion.

## Numbers

The direct `three`, `succ(two)`, and `churchAdd(two, one)` all decode to 3;
`succ(three)` decodes to 4 and `churchAdd(three, three)` to 6; and
`succ(succ(one))` decodes to the same value as the direct `three`.

## Map class

Tailored addition, chosen for TypeScript in the map's 2.6 row ("arithmetic
on three plus successor"). The exercise is natural in this edition because
its numerals are plain function values: no wrapper machinery stands between
the arithmetic and the decoding.

## Deviation

`Church` and the `ex_2_06` numerals are imported rather than restated, so
the addition exercises the same type the section's solution defines.
