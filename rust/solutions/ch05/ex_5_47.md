# Exercise 5.47: compiled calls to interpreted procedures (T)

## Approach

Enable the compiler's `compound_calls` path, compile `f` to call `g`,
then define `g` in the interpreted environment and invoke `f`. For a
compound procedure, the emitted call sequence saves the continuation,
tests the procedure kind, and transfers through the evaluator's
`compound-apply` entry. This lets compiled code call an interpreted
compound procedure rather than only primitives or compiled entries.

## Map class

`T`.

## Sample answer

With `f(n) = g(n + 1)` compiled and interpreted `g(x) = 2x`, the call
`(f 5)` returns `12`. The assembled controller includes the
`compound-apply` path and saves `continue` for the cross-mode call.
