## Exercise 1.13: Fib(n) is the closest integer to phi^n / sqrt(5)

Approach (the proof): let `hat(n) = (phi^n - psi^n) / sqrt(5)`. Base cases:
`hat(0) = (1 - 1) / sqrt(5) = 0 = Fib(0)`, and
`hat(1) = (phi - psi) / sqrt(5) = sqrt(5) / sqrt(5) = 1 = Fib(1)`, since
`phi - psi = sqrt(5)` directly from their definitions. Inductive step:
assume `hat(k) = Fib(k)` for all `k <= n`. Both `phi` and `psi` are roots
of `x^2 = x + 1` (check: `phi^2 = phi + 1` and `psi^2 = psi + 1` follow
from the quadratic formula that defines them), so
`phi^(n+1) = phi^2 . phi^(n-1) = (phi + 1) . phi^(n-1) = phi^n + phi^(n-1)`,
and likewise `psi^(n+1) = psi^n + psi^(n-1)`. Subtracting and dividing by
`sqrt(5)` gives `hat(n+1) = hat(n) + hat(n-1) = Fib(n) + Fib(n-1) = Fib(n+1)`,
closing the induction. Since `|psi| < 1`, `psi^n / sqrt(5)` shrinks toward
0, so `hat(n)` is within `1/2` of `phi^n / sqrt(5)` for `n` large enough
that `Fib(n)` is the closest integer to it, which is what the exercise
asks to show.

Class: T (translate); the executable artifact is a numerical
corroboration, not a substitute for the proof above. `closedFormFib`
computes `hat(n)` in `Double` and rounds; `fibDirect` is the ordinary
iterative definition, kept as a second, independent implementation. The
property test in the solution's test file checks agreement for every `n`
from 0 to 40, the range where `Double` rounding still lands exactly on
the integer answer.
