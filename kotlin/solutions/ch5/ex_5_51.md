# Exercise 5.51: the evaluator translated into C

`ecevalC` translates the chapter 5.4 explicit-control evaluator to
C: its registers live in a machine struct, its `ev-` entries are
labels, `continue` stores label addresses, and one frame stack
implements saves and restores. The same artifact contains the guest
value model, heap allocation, environments, and an input reader.
The C reader and call-resolution pass check the entire input before
any guest effect; unsupported forms produce a diagnostic instead
of a fabricated result.

`translatedEvaluatorRuns` builds the artifact with `cc -O1` and
runs a Kotlin guest factorial session from a temporary source file.
The expected stdout is `120`; the run then compares it with the
chapter's explicit-control evaluator for the same source. The C
artifact has not yet been compiled under the integration gate.
