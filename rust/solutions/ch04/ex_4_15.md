# Exercise 4.15: the halting-problem diagonal, run (T)

## Approach

The probe runs under `Bounded`, a seam extension that spends one budget unit
per step and raises when the budget is gone. With `halts?` fixed to answer yes,
`(try try)` burns the budget: the program was still running, so `halts?` lied.
With the answer no, `(try try)` returns `halted`, contradicting the verdict.
Both outcomes violate the contract; the budget makes the diverging branch
finite.

## Map class

`T`, prose-lean with the probe running.

## Sample answer

Yes-verdict: `the step budget ran out: the program was still running`.
No-verdict: `halted`.
