# Exercise 2.48: directed line segments (translate)

The map class is `T`. A segment is the pair of the start and end
vectors: `make_segment` pairs them, `start_segment` and
`end_segment` select. `ex_2_48 ()` is the segment from `(1, 2)` to
`(3, 4)`; the tests check the selectors against it, and 2.49's
painters consume this representation through
`segments_to_painter`.
