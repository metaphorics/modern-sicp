# Exercise 5.12a: the per-type instruction census

This edition's extension of 5.12: the assembler also counts the
assembled instructions by type, in the book's listing order (assign,
test, branch, goto, save, restore, perform). The counts live in the
same `AssemblySummary` the 5.12 report renders, as its `countsByType`
field, and `renderAssemblySummary` prints them as the last line, so
the census rides along with the report instead of needing its own
assembly pass.

`E5_12a.kt` reads that line off the same fresh assembly of the gcd
controller: `gcdMachineCensus()` answers
`(by type test 1 branch 1 assign 3 goto 1)`, pinned by `E5_12aTest`.
The numbers cross-check the 5.12 summary: three distinct assign texts,
one test, one branch, one goto, no stack instructions, and the raw
counts agree with the instruction total the traced and counted runs
of 5.15 and 5.16 exhibit for the same controller.
