# Exercise 5.18: register tracing

A register is written by the host's `set_register` and by the
instructions `Assign`, `Assign_op`, and `Restore`. The monitor reads a
traced target register before such an instruction steps and again
after, so when a register's trace is on each write appends
`name: old -> new` to the machine's transcript, a write of an equal
word included.

`ex_5_18 ()` traces `n` and `val` through the factorial machine on
n = 3: the host's input load reports first (`n: unassigned -> 3`),
each level's decrement reports, the base case's `val` assignment
reports, and the restores report on the way out (`n: 1 -> 2`,
`n: 2 -> 3`), ending with `fact 3 = 6`.
