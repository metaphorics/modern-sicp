# Exercise 1.27 — Carmichael numbers fool the Fermat test (translate)

The map class is `T`. `fools_fermat n` checks `a ** n = a (mod n)` for
every `a` from 1 to `n - 1`, exhaustively — the exhaustive check the
exercise asks for, distinct from `Primality.fermat_test`'s single random
witness.

Run against the six Carmichael numbers below 100,000,000 that
@ref{Footnote 47} lists (561, 1105, 1729, 2465, 2821, 6601), every one
returns `true`: the Fermat test passes for every possible witness, not
merely for the ones a random draw happens to pick, confirming these
numbers really do satisfy the defining property of a Carmichael number
and not merely that they got lucky against a handful of random `a`'s.
The ordinary composite 100 fails almost immediately (`a = 2` already
breaks the congruence), confirming `fools_fermat` correctly distinguishes
the two cases.
