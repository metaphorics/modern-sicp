# Exercise 3.40: all values of concurrent x squared

## Approach

The squaring process is two reads and a write; the cubing process is
three reads and a write. The solution enumerates every interleaving
that respects each process's own order -- all ways to weave three P1
steps and four P2 steps, 35 schedules -- through a deterministic
simulator, and collects the sorted finals: {100, 1000, 10000, 100000,
1000000}. A read multiplies the current `x` into the process's private
product; the write stores the product. For the serialized program, the
same two processes run for real inside one `Serializer`, 50 trials,
and every trial lands on 1000000: with both bodies atomic, whichever
goes first reads the same 10 and the last writer stores the full
fifth power.

## Map class

`T`. The two processes and the value sets are the statement's own.

## Deviation

None. The enumeration is exhaustive over step interleavings, and the
serialized half is demonstrated by repeated real runs rather than by
argument alone.
