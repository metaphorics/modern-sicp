# Exercise 3.69: triples and the Pythagorean triples

## Approach

The head triple is `(S0, T0, U0)`. The rest interleaves the first-row
triples with the recursive triples over all three cdrs. The first-row
triples are the exercise 3.67 shape of the (T, U) plane, the module's
`pairs` of the tails, prefixed by S0, so every triple with
i < j <= k appears, the head carries i = j = k, and each level of the
recursion adds exactly one additional stream to the mix. The
Pythagorean stream is that triples stream of the integers read through
a filter on `i^2 + j^2 = k^2`. The filter skips nonmatching triples in
a loop and re-enters fresh at each hit, because the gaps between
Pythagorean triples run to tens of thousands of elements and a
per-element recursion would exhaust the call stack.

## Map class

T (translate: syntax changes only). `triples` mirrors the module's
`pairs` with one more stream and the filter is the statement's
`stream-filter`; the tests pin the statement's first five Pythagorean
triples by execution.

## Deviation

The enumeration does not produce the class `(i, i, k)` with k > i
(the plane is built over the shifted tails, so j > i there). That class
contains no Pythagorean triple, since `2 i^2 = k^2` has no positive
integer solutions, so the filtered stream is complete for the
statement's use. The module's `streamFilter` also recurses once per
skipped element; the local `filterTriples` skips iteratively and is
element-for-element the same filter.
