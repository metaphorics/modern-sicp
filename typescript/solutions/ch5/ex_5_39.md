# Exercise 5.39: lexical-address lookup

A lexical address is a frame count and a position: the data a variable reference carries instead of a name. The lookup operation walks that many frames out and reads that slot, and the set operation writes the same slot, so the machine reads and writes bindings without searching. The session runs the book's example through the evaluator, and the operations themselves are pinned on their own names and shapes.

The exercise is the run-time half of the compiler's lexical addressing: whatever the compile-time environment answers in exercise 5.41, these two operations consume at run time.
