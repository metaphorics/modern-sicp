# Exercise 5.41: finding lexical addresses

`findVariable` searches compile-time frames from innermost to outermost. Within
each frame it uses the variable's position as the displacement. Its returned
pair is therefore `(frame number, displacement)`, with both indexes starting
at zero; if no frame contains the name, it returns `null` to represent
`not-found`.

`findVariableLookups()` runs the book's three examples over
`((y z) (a b c d e) (x y))`. The test pins `c` to `(1 2)`, `x` to `(2 0)`, and
`w` to `not-found`. The first two results demonstrate both the outward frame
search and within-frame position; the last preserves the distinction between a
lexical binding and a name that is not present in the compile-time environment.
