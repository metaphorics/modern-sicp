# Exercise 4.26: `unless` as syntax versus procedure (T)

## Contract

`lazy-memo/1` over typed `LazyExpr::{If,Apply,Lambda,Force}` data.

## Lesson

The special form selects one arm directly. The procedure version binds all
three operands as delayed thunks, then forces the test and only the selected
arm. The effect log therefore distinguishes the chosen arm without turning
`unless` into host control syntax.

## Map class

`T`.

## Sample answer

Both forms emit only `taken`; the unselected `skipped` operand stays delayed.
