# Exercise 4.50a (this edition): seeded `ramb` (T)

## Contract

`SearchEngine::with_seed(2026).run_seeded(...)` with a deterministic
engine-held random choice policy.

## Lesson

The tailored addition pins the random order to the engine seed. Repeating the
seed repeats the exact answer order; changing it changes the order while the
answer set remains intact.

## Map class

`T`.

## Sample answer

Seed `2026` repeats exactly and differs from seed `2027` in order.
