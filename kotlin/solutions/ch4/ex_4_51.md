# Exercise 4.51: permanent assignment survives backtracking

## Lesson

An ordinary assignment rolls back with each failed trial, so every
answer shows the same count and the final count reads `0`. A
permanent write survives backtracking: the count accumulates across
failed trials -- the book's `(a b 2)`, `(a c 3)`, `(b a 4)` -- and the
final count `4` survives the exhausted search. The `ifFail` second arm
reports the count after exhaustion.

## Map class

`T` (map row 4.3: `setPermanent`; reversible versus permanent
assignment). The distinction is observed in answer streams, never in
driver prompts: engines emit none.

## Deviation

None. The delivered-count guard caps the answers at three; the budget
is untouched.

## Answer

- Permanent: `(a b 2)`, `(a c 3)`, `(b a 4)`, final `4`.
- Ordinary: `(a b 1)`, `(a c 1)`, `(b a 1)`, final `0`.
- Pin: `permanentSetTranscript() == "(a b 2)\n(a c 3)\n(b a 4)\n4\n"`
  and `setBangTranscript() == "(a b 1)\n(a c 1)\n(b a 1)\n0\n"`.
