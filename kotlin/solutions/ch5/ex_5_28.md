# Exercise 5.28: the tail recursion removed

`nonTailController` replaces the explicit-control evaluator's sequence
and compound-application branches. It saves each active sequence frame
on the machine stack before evaluating its next expression and restores
that frame after the expression returns. The compound-call return frame
also restores the caller's environment before unwinding to the pending
operand; return and break markers cross these frames through the same
restore paths. This removes the tail-position shortcut: each recursive
call inside a sequence retains a pending restore.

`nonTailRecursiveMeasurements` runs iterative and recursive factorial
for inputs 1 through 5 on this actual controller. The measured
maximum-depth rows and their growth verdicts come from the machine's
monitored stack, not the fixed counts of the book's different controller.
`nonTailAnswersAgree` checks that the altered evaluator still prints
the same factorial answer as direct execution.
