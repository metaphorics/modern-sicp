# Exercise 1.13: Fib(n) is the closest integer to phi^n / sqrt(5) (translate)

The map class is `T`. The exercise asks for a proof; the code carries
only an empirical check the proof predicts.

**Claim.** Fib(n) = (phi^n - psi^n) / sqrt(5), where phi = (1 + sqrt 5) /
2 and psi = (1 - sqrt 5) / 2.

**Proof, by strong induction on n.** Both phi and psi are roots of
x^2 = x + 1 (the golden ratio's defining equation, satisfied by
construction: phi and psi are exactly the two roots of x^2 - x - 1 = 0
by the quadratic formula), so phi^2 = phi + 1 and psi^2 = psi + 1.

Base cases: n = 0 gives (phi^0 - psi^0) / sqrt(5) = (1 - 1) / sqrt(5) = 0
= Fib(0). n = 1 gives (phi - psi) / sqrt(5) = sqrt(5) / sqrt(5) = 1 =
Fib(1), since phi - psi = sqrt(5) by their definitions.

Inductive step: assume the claim for n - 1 and n - 2. Then

    Fib(n) = Fib(n-1) + Fib(n-2)
           = (phi^(n-1) - psi^(n-1)) / sqrt(5) + (phi^(n-2) - psi^(n-2)) / sqrt(5)
           = (phi^(n-2)(phi + 1) - psi^(n-2)(psi + 1)) / sqrt(5)
           = (phi^(n-2) * phi^2 - psi^(n-2) * psi^2) / sqrt(5)
           = (phi^n - psi^n) / sqrt(5),

using phi + 1 = phi^2 and psi + 1 = psi^2 from the defining equation.
This closes the induction.

**Closest integer.** |psi| = (sqrt(5) - 1) / 2 is about 0.618, so
|psi^n| < 1 for every n >= 0, and psi^n / sqrt(5) has magnitude at most
1 / sqrt(5), under 1/2. Since Fib(n) = phi^n / sqrt(5) - psi^n / sqrt(5)
is an integer, phi^n / sqrt(5) lies within 1/2 of that integer, so
Fib(n) is indeed the closest integer to phi^n / sqrt(5).

`closed_form_fib` evaluates the right-hand side with `float` and rounds;
`fib_direct` is the book's tree-recursive `fib`, kept only for the check
and never called at large `n`. The test compares the two for every `n`
from 0 to 40 and pins `ex_1_13 10 = 55`.
