# Exercise 2.33 — map, append, length as accumulations (translate)

The map class is `T`, solved with a local `accumulate` in the book's
argument order (it is `List.fold_right`). The blanks: map conses
`f x` onto the recursion (`fun x y -> f x :: y`); append's initial
and sequence arguments are `seq2` and `seq1`, with plain cons as the
operator; length's operator ignores the element and adds one.

Samples: `ex_2_33_map (fun x -> x * x) [1; 2; 3] = [1; 4; 9]`,
`ex_2_33_append [1; 2] [3; 4] = [1; 2; 3; 4]`,
`ex_2_33_length [1; 2; 3; 4] = 4`.
