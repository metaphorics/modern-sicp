# Exercise 2.10 — divide by a zero-spanning interval (translate)

The map class is `T`. `div_interval` refuses a divisor `y` whose
bounds satisfy `lower_bound y <= 0.0 && upper_bound y >= 0.0`, the
condition for `y` to contain (or touch) zero, returning `Error
(Spans_zero (lower_bound y, upper_bound y))` instead of a silently
wrong or infinite interval.

Both Scheme and OCaml already agree here: `1.0 /. 0.0` is `infinity`
in each, an IEEE 754 float, not a raised error, so the exercise's
"signal an error if it occurs" genuinely needs Ben's explicit check in
either language; nothing about OCaml makes this harder or easier than
the book's own ask.

`ex_2_10 () = Error (Spans_zero (-1.0, 1.0))`, dividing `[1, 2]` by an
interval that spans zero.
