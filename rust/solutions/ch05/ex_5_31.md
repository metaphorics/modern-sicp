# Exercise 5.31: unnecessary evaluator saves (T)

## Approach

Compile each of the four applications with the default compiler and
filter the emitted instruction sequence for `save` and `restore`. The
quoted operands in `(f 'x 'y)` and `((f) 'x 'y)` need no evaluation
state to survive, so both produce no stack operations. In the nested
operand cases, evaluating `(g 'x)` can overwrite the live `proc` and
`argl` registers; `preserving` therefore saves and restores each, for
four instructions per case.

## Map class

`T`.

## Sample answer

The four cases, in the exercise's order, contain 0, 0, 4, and 4 save or
restore instructions. The last two preserve `proc` and `argl` around
the call to `g`; the first two need no saves because their operands are
quoted constants.
