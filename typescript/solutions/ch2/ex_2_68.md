# Exercise 2.68: encode-symbol

## Approach

`encodeSymbol` recurses from the root: at a leaf it answers the empty
bit list on a match and an error otherwise; at a branch it prefixes 0 to
the left search or 1 to the right search. `encode` is the book's given
procedure, threading the edition's error channel.

## Numbers

Encoding the exercise 2.67 result `(A D A B B C A)` under `sampleTree`
reproduces the original sample message bit for bit. A symbol outside the
tree (`E`) returns the error, and `encode` propagates it.

## Map class

T (translate).

## Deviation

The book says "signals an error"; this edition returns the error through
the section's `Result` type, as everywhere in chapter 2.
