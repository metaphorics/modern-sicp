# Exercise 5.2: the machine language description

The map class is `T`. Where 5.1 draws, 5.2 writes: the iterative
factorial machine of exercise 5.1 described in the register-machine
language. The transcription `factorialController` of
`solutions/ch5/E5_01.kt` is that description, and the exercise pins
what a reader extracts from the text: the instruction count, the
labels, and the label positions.

`assemblyReport` in `solutions/ch5/E5_02.kt` computes that report from
the transcription: five instructions (one `test`, one `branch`, three
`assign`-family steps: the two data-path buttons and the loop's
`goto`) around two labels. The label table shows the stop-address
convention the section establishes: each label names the position of
the instruction that follows it, and the trailing `fact-done`, the
label the branch uses as its exit, names position 5, one past the last
instruction, where reaching means the machine is done.

Method: the runs are the same hand model as exercise 5.1 (no
simulator exists in this unit; the machine of 5.2 is the machine of
5.1). `factorialAssemblyReport()` answers
`["5 instructions, 2 labels; fact-loop=0 fact-done=5", "120", "720"]`:
the assembly report and the hand model's runs on n = 5 and n = 6,
pinned in `E5_02Test`.
