## Exercise 2.46: the vector abstraction

Approach: the addition idea for this section ("vectors as a data class or
tuple") is the chosen tailored addition 2.46a, so this exercise's own
answer is the plain data class the book asks for: `Vect(x, y)` with
`makeVect`/`xcorVect`/`ycorVect` as the constructor and selectors, and
`addVect`/`subVect`/`scaleVect` built only from them. Because
`frameCoordMap` and the primitive `wave` painter need working vectors
before this exercise's file is reached, the representation lives in the
shared `Painters.kt` rather than being redefined here — the same forward
reference the book's own prose makes when it uses `add-vect` and
`scale-vect` in code shown well before exercise 2.46's statement. This
file's tests are the exercise's actual content: they check the
constructor/selector roundtrip, the three vector operations, and the
`frame-coord-map` example from the prose.

Class: T (a direct translation; Kotlin's data class is the natural
representation the book's own hint anticipates).
