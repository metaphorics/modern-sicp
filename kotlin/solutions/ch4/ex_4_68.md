# Exercise 4_68: the reverse rules

## Approach

The empty-list rule anchors reverse; the step rule reverses the tail
and appends its head. These are `QRule` values over the typed query
terms. The backward question uses a depth-eight bound to make a
finite query out of otherwise unbounded candidate generation.

## Answer

Hand-derived, unrun expectations (`E4_68Test`): `[1, 2, 3]` reverses
to `[3, 2, 1]`, `[a, b, c, d]` to `[d, c, b, a]`; the bounded backward
query also yields `[3, 2, 1]`. No heap-exhaustion run is claimed.

## Deviation

The depth bound replaces the unbounded reverse query.
