# Exercise 4.22: let in the analyzing evaluator

The map class is `T`. The analyzer handles a non-recursive `let` as the derived expression of 4.6: before analysis, every such `let` at every depth rewrites into its combination, so the analyzer sees only a function applied to the inits. The rewrite is syntactic and happens once.

Sample: `ex_4_22 ()` answers `["7 (1 lets before, 0 after)"; "5 (2 lets before, 0 after)"; "610 (1 lets before, 0 after)"]`.
