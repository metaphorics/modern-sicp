# Exercise 1.24

`random_below` replaces the book's `random`: rather than a `rand` crate or
a host PRNG, this edition draws every witness from `sicp_runtime::Random`,
the seeded `xorshift64*` generator every runtime in the project ships (see
1.2.6 and D31 of the technical plan), so a run is reproducible across
machines and across editions. `timed_fast_prime_test` wraps `fast_prime`
the same way `timed_prime_test` wrapped `is_prime` in exercise 1.22, with
`Instant` for the clock.

Run with 8 Fermat trials per number, the timed test reports all 12 primes
found in exercise 1.22 as prime. Since the Fermat test is `Theta(log n)`,
testing primes near 1,000,000 should take only a small constant multiple
longer than testing primes near 1000 (the ratio of `log(1,000,000)` to
`log(1000)` is 2), a far smaller gap than trial division's `sqrt(n)`
scaling; whether the measured wall-clock times confirm that on a given
machine depends on how much of the run is noise at this scale, which is
why the test checks the primality reports rather than the timings
directly.
