## Exercise 3.27: memoization over one shared table

Approach: `memoize` captures one `HashMap<Long, Long>` and returns a
function that looks its argument up before computing and stores fresh
results after: the book's memoizer, with the section's make-table
replaced by the host map. `makeMemoFib` applies it to the
self-recursive Fibonacci lambda, so every recursive level consults the
same table object. The self-reference is tied through a nullable local
`var` that `fibStep` reads only after `memoize` has returned; a plain
`val` cannot refer to itself in its own initializer, and the project's
rules rule out `lateinit`.

Why the diagram became a trace: the book asks for an environment
diagram of `(memo-fib 3)`. The Kotlin object is the same shape (one
table cell shared by every recursive level, one `fibStep` closure
capturing it) but the structure worth watching is a single hash map
that every level reads and writes, so the edition asks the reader to
trace consults over it instead. The trace is measurable, and the tests
measure it: instrumenting `fibStep` with a counter shows exactly 4
computes for `memoFib(3)` (the distinct arguments 3, 2, 1, 0), a
second call of `memoFib(3)` adding nothing, and exactly 21 computes for
`memoFib(20)`, one per distinct argument, `n` + 1, which is the
linear step count the exercise asks the reader to explain: the first
call of each level computes, and every later consult of that level
answers from the table.

Why `memoize fib` fails: the book's last question. Memoizing the plain
recursive `fib` memoizes only the top call: inside that one compute,
the recursion runs the unmemoized plain function, so the exponential
tree still gets walked once. The test pins it: `memoize(::fibPlain)`
at `n = 20` still makes over ten thousand plain calls, against the
memo-fib version's 21.

What the tests say: the book's numbers come back through the memoized
path up to `memoFib(50)` (12586269025, hopeless for plain `fib` in
practice), the 4-compute and 21-compute traces, and the
plain-fib-would-explode counter.

Class: `A` (the host map and the trace stand in for the book's local
table diagram; the statement says so).

Deviation: none.
