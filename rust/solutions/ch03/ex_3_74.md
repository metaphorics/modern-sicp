# Exercise 3.74: zero crossings via stream-map

## Approach

Eva Lu Ator's rewrite needs no recursion at all: the crossing stream is
the sign-change detector mapped over the sense data and the same data
delayed by one cell, with the initial previous value `0` consed onto
the front. The general two-stream map of exercise
3.50 (the module's `stream_map2`) does the pairing. The book's sense
data continues indefinitely on the page, so the port materializes the
thirteen printed values and extends them with a flat tail of the last
value 4: the walk never ends mid-way and every later comparison settles
at 0. The run pins the book's own rows: 0 everywhere but -1 at index 5
(the dip to -0.1) and +1 at index 10 (the recovery at 0.2).

## Map class

`T`. The statement translates whole. The one Rust wrinkle: the book
passes the first-order `sign-change-detector` straight to `stream-map`,
while the module's map hands the function references, so a one-line
lifting closure `|current, previous| sign_change_detector(*current,
*previous)` stands in for the direct pass.

## Deviation

None. The flat-tail extension of the page's "..." is the task brief's
own stated adapter and is documented where the sense data is built.
