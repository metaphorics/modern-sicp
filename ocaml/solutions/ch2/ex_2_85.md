# Exercise 2.85: drop projection (adapt)

The map class is `A`: the tower narrows to three levels (integer,
real, complex; the book's own three worked examples never need the
rational level) so `drop` can stay focused on those. `project` is
installed for `"real"` (round to the nearest integer, via
`Float.round`) and `"complex"` (drop the imaginary part), exactly the
two projections the exercise's footnote and text ask for. `drop v`
projects `v` one level down, raises the result back with
`raise_one_level`, and keeps going while raising back reproduces `v`
exactly (`value_equal`, the generic equality predicate the exercise
points to in Exercise 2.79): the project-then-raise equality test the
exercise specifies. A value with no `"project"` entry (the bottom,
`"integer"`) returns unchanged. `apply_generic_drop` is
`apply_generic`'s result, dropped: the "simplifies its answers"
rewrite the exercise's last sentence asks for.

`ex_2_85 ()` drops `1.5+0i`, `1+0i`, and `2+3i` to the type tag each
settles at (`"real"`, `"integer"`, `"complex"`; the exercise's own
three examples), then adds `(2, 3)` to `(-2, -3)` through
`apply_generic_drop` and reports the sum's settled tag, `"integer"`.
