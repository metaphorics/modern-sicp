## Exercise 2.59: union-set unordered

Approach: `unionSet` walks `set1`, keeping each element that is not
already in `set2` (dropping it otherwise since it would duplicate an
element `set2` already contributes), and appends `set2` itself at the
end. This is `Θ(n²)` for sets of comparable size, since every kept
element of `set1` pays an `elementOfSet` scan of `set2`.

Class: T, per the map — a direct translation of the book's own
recursive definition.

Deviation: none. This exercise's idea, "check `unionSet` against a
second, independently written implementation," is picked up by exercise
2.65a (this edition's chosen tailored addition), which cross-checks the
balanced-tree union against `java.util.TreeSet` instead.
