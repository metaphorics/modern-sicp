Exercise 5.36: operand evaluation order, measured.

The compiler evaluates operands left to right: its argument-list
constructor compiles operands in list order and appends each value
with `adjoin-arg`. The variant compiles them last to first and puts
each value in front with `prepend-arg`; the built list is the same.
A call printing each operand shows `123` against `321`, with identical
statement and step counts (154 and 166). The efficiency answer is
measured, not argued: each `adjoin-arg` copies the list it extends
while each `prepend-arg` allocates one cell, so the right-to-left
order builds n operands in linear rather than quadratic time.
