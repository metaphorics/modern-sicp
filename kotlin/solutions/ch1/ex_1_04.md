## Exercise 1.4: the operator picked by an if

Approach: the `if` evaluates to a function reference, `Long::plus` when
`b` is positive and `Long::minus` otherwise, and the call applies whichever
reference the test produced. The receiver-as-first-argument form `op(a, b)`
applies the picked reference directly, so the expression keeps the book's
one-line shape. `ex_1_04(2, -3)` is `5` because the operator becomes
subtraction and `2 - (-3) = 5`.

Class: A (the operator cannot be picked "via `+` itself" as in Scheme; the
adaptation picks it via a reference, which is the same point: an operator
position may hold any expression that evaluates to a function). Deviation:
the picked values are member function references of `Long`, not the bare
operators.
