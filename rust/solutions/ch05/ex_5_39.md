# Exercise 5.39: lexical-address operations (T)

## Approach

Enable lexical addressing, compile a lambda that mutates its `cell`
parameter, and execute it in an environment where `n` is global. The
runtime lookup and assignment operations use a lexical address to
select a frame and displacement; assignment updates the addressed
value cell. Lookup detects the `*unassigned*` marker and reports the
book's unassigned-variable error instead of returning it as an ordinary
value.

## Map class

`T`.

## Sample answer

The compiled machine contains both `lexical-address-lookup` and
`lexical-address-set!`. Starting with global `n = 10` and argument
`cell = 11`, the assignment changes `cell` to 110, so the final result
`n + cell` is `120`.
