# Exercise 4.8: named `let` as a recursive procedure

## Lesson

The named-let rewrite uses `GLetRec` to bind the loop procedure before its
first `GApp`. The book's iterative Fibonacci loop keeps `count`, `a`, and
`b` in one nested pair because the kernel procedure has one parameter.

## Map class

`T`; the recursive named binding preserves the exercise's objective.

## Deviation

The pair encodes the loop's three values for the kernel's single parameter.

## Answer

- Named-let Fibonacci computes `F(10) = 55`.
- The local recursive name returns `1` without changing the outer binding
  of `7`; ordinary `let` still returns `3`.
- Pins: `namedLetFibonacciTranscript() == "55\n"`,
  `loopNameLocalTranscript() == "1\n7\n"`, and
  `plainLetTranscript() == "3\n"`.
