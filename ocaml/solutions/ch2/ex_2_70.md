# Exercise 2.70 — encoding the rock song (translate)

The map class is `T`: only the syntax changes. The eight-symbol
alphabet and the song's thirty-six symbols are transcribed directly;
`generate_huffman_tree` and `encode` from Exercises 2.69 and 2.68 do
the rest. `fixed_length_bits` computes `ceil (log2 alphabet_size)`
bits per symbol, the number of bits a fixed-length code would need.

Sample: `ex_2_70 ()` is `(84, 108)`: the Huffman encoding of the song
needs 84 bits, and a fixed-length code over the eight-symbol alphabet
would need 108, a savings of just over 22%, matching the book's
"more than 20%" for the smaller worked example. The exercise's own
"how many bits" question is this pair's first component; the
"smallest number of bits... for a fixed-length code" question is its
second. See `ex_2_70a.md` for this edition's addition, which checks
the round trip these two rest on.
