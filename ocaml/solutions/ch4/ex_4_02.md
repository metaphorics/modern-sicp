# Exercise 4.2: Louis's reordered clauses and the call prefix (adapt)

Part (a) has no code in this edition: with the typed `Ast`, a
definition is a distinct `Definition` view, so a dispatch that checks
applications before assignments cannot mistake `(define x 3)` for an
application. Louis's premise dissolves, and the deliverable is part
(b): the call-prefix language.

The evaluator keeps the standard dispatch and replaces one clause: an
application whose operator is the variable `call` applies its first
operand to the rest, and any other application is the syntax error
`the application does not start with call`. The clause recurses
through itself, so the rule holds in nested operands and in procedure
bodies, which are only checked when they run.

Sample: `ex_4_02 ()` answers `["3"; "ok"; "42"; "Error: invalid form:
the application does not start with call"]`: a primitive call, the
definition of a two-parameter procedure in the call language, its
call, and the plain application the new syntax rejects.
