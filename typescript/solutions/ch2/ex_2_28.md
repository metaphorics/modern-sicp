# Exercise 2.28: fringe

## Approach

`fringe` gathers the leaves of a tree left to right into a list: a leaf
contributes its one-element list, and a node appends the fringe of each
subtree in order with the section's `append`. The book's doubled tree
shows the same leaves twice in a row.

## Numbers

`fringe(x)` for `x = ((1 2) (3 4))` prints `(1 2 3 4)`; the node holding
`x` twice fringes to `(1 2 3 4 1 2 3 4)`.

## Map class

`A`: the book's tree of nested pairs is the edition's `Tree` union, so
the leaves are gathered over a readonly subtree array with `append`
instead of `car`/`cdr` pairs.

## Deviation

None.
