# Exercise 4.16: scan out internal definitions (T)

## Approach

The rewrite collects a body's definitions, emits one unassigned placeholder
per name, then emits one assignment per initializer. A read of a placeholder
before its assignment is reported as the scan-out error. The transform happens
when the procedure is constructed.

## Map class

`T`.

## Sample answer

Mutual `even?`/`odd?` definitions receive placeholders first; `a` read before
its definition is rejected.
