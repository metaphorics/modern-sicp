# Exercise 4_79: environments instead of renaming

## Approach

Each rule application runs in a lexical layer of its own: the body's variables carry the application's layer id, references resolve to the innermost layer that owns the name, and a recursive application shadows its ancestors only inside the call -- the environment structure of a procedure call.
