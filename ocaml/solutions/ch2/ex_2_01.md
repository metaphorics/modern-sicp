# Exercise 2.1: sign-normalizing make-rat (translate)

The map class is `T`. `ex_2_01 n d` reduces `n` and `d` by the `gcd`
of their absolute values, as section 2.1.2's own `Rational.make`
already does, then multiplies both by `-1` when `d` was negative. A
positive rational therefore always carries two positive components,
and a negative one carries exactly one negative component, the
numerator, matching the exercise's stated rule.

This edition's `ex_2_01` also refuses `d = 0` with `Error
(Zero_denominator n)`, extending the book's ask by the same check the
main text's `Rational.make` already performs (section 2.1.2). The
book's own exercise says nothing about a zero denominator, but leaving
it unchecked here would silently produce a nonsensical pair (or, for
`n = 0`, a division by zero from `gcd 0 0`), which the main text
already treats as an error one section earlier.

Sample: `ex_2_01 (-4) (-6) = Ok (2, 3)`, `ex_2_01 4 (-6) = Ok (-2, 3)`,
`ex_2_01 3 0 = Error (Zero_denominator 3)`.
