# Exercise 4.10: a new syntax for an unchanged evaluator

The map class is `T`. The evaluator reads syntax only through `Ast.view`, so a different surface syntax needs only a translation into the checked syntax; `eval` and `apply` stay as they are. The new syntax is a small uniform term language with named binary operators, list sequences, and its own recursion form.

Sample: `ex_4_10 ()` answers `["720"; "new \"syntax!\""; "7"; "error: invalid form: unknown operator %"]`.
