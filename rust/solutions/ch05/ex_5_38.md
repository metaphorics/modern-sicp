# Exercise 5.38: open-coded primitive operations (T)

## Approach

Integer arithmetic is already inline `Arith` over the operand registers, while a helper call builds an argument list and transfers through `CallFun`. The direct program keeps its arithmetic inline with no transfer; the helper-routed version pays the transfer for the same values on both engines.

## Map class

`T`.

## Sample answer

Inline code prints `120`, `10`, `7` with no call transfer. Helper calls print `120`, `10` through real transfers on both engines.
