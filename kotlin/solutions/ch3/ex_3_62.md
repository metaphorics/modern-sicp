# Exercise 3.62: dividing power series, and tangent

## Approach

S1/S2 = (1/c) S1 (1/(S2/c)): scaling the denominator by 1/c makes its
constant term 1, `invertUnitSeries` (3.61) takes the reciprocal,
`mulSeries` (3.60) multiplies, and the outer 1/c factor restores the
constant. A denominator with a zero constant term cannot be scaled to
a unit series, so `divSeries` rejects it up front with an
`IllegalArgumentException`. `tangentSeries` is sin/cos; pinned exact
on ten terms: 0, 1, 0, 1/3, 0, 2/15, 0, 17/315, 0, 62/2835.
