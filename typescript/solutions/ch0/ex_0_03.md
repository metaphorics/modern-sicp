# Exercise 0.3: recursion floor, loop ceiling

## Approach

`sumToRecursive` adds after the recursive call returns, so every step
holds a stack frame and depth equals `n`. `sumToIterative` runs the
same process as a `for` loop that carries `total` and `k` in locals,
which costs a constant stack. `recursionDepth` descends through a
local function and catches the engine's refusal: the `catch`
discriminates `RangeError`, returns the last completed depth, and
rethrows anything else, because only the stack error is part of the
measurement.

## Proof

Both versions agree at `n = 100` (`5050`). At `n = 100_000` the loop
returns `5_000_050_000` while the recursion raises `RangeError`, which
the test asserts with `toThrow`; the depth probe returns a finite
number above 1000 frames on any engine this suite runs on, without
pinning an exact depth, since the ceiling is an engine fact, not a
language fact.

## Class and deviations

Chapter 0 exercises are original per edition. The Rust edition's
section 0.1 (checked factorial) and the Kotlin edition's section 0.3
prose teach the same stack fact; this exercise makes it measurable in
TypeScript, where no `tailrec`-style check exists. No deviation.
