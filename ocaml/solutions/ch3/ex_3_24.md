# Exercise 3.24 — table keyed by a same-key? predicate (adapt)

The map class is `A`: `make_table` takes a caller-supplied
`same_key : mobj -> mobj -> bool` and closes over it in a fresh
`local_table`, matching the book's constructor argument exactly; the
`lookup`/`insert` closures returned as a record stand in for the
book's `dispatch`. The one real design point is that `make_table`
uses ONE `same_key` predicate for both levels of a two-dimensional
table, so `near tol` — built for the statement's numeric tolerance —
must also match symbol keys exactly, or every second-level lookup
with a symbolic key would spuriously fail; it does so by adding a
`Sym, Sym` case rather than falling through to the catch-all `false`.
