# Exercise 4.01: the two operand orders

The map class is `T`. The book's statement already says the order is fixed by the written recursion rather than inherited from the host. Each version sequences its operand evaluations explicitly, since OCaml leaves a native application's argument order unspecified. Both are wired into real evaluators: the `Apply` clause evaluates the operator through `self`, the operands through the chosen order, and applies through `S.apply_with ~self`; every other node falls back on `S.open_eval ~self`.

Sample: `ex_4_01 ()` answers `["left right 7"; "right left 7"; "left error: division by zero"; "right left error: division by zero"]`: the printed words show which operand ran first, and the failing pair shows the first failure each order reaches.
