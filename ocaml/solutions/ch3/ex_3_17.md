# Exercise 3.17 — count distinct pairs with a visited history (adapt)

The map class is `A`: the fix for Ben's algorithm is a `visited`
auxiliary structure keyed by physical identity, and OCaml's standard
library has no identity-keyed set, so `count_pairs_distinct` carries a
hand-written `List.exists (fun c -> c == p) !visited` scan instead of
the book's `assq`-based one. Because the scan always compares the
underlying `mpair` record (via `pair_of`), not a freshly wrapped
`mobj`, it is immune to the double-allocation trap that exercise 3.15
warns about, and it doubles as a cycle guard: a pair already in
`visited` is never walked again, so the three-pair ring also answers
3 instead of diverging.

Sample: `ex_3_17 ()` answers `(3, 3, 3, 3)`.
