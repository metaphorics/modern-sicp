# Exercise 4.5: `cond` arrow clauses evaluate once

## Lesson

`(test => recipient)` binds the test value and applies the recipient
to it when true, falling through otherwise. The probe test counts its
own evaluations, pinning the single-evaluation contract on both sides:
a true test answers through the recipient with one evaluation, a false
test answers the rest with one evaluation.

## Map class

`A` (map row 4.1: derived forms desugar in guest code). The arrow is a
guest rewrite to the kernel application.

## Deviation

None. The recipient receives the bound test value, never a re-run.

## Answer

- True test: `42`, one evaluation.
- False test: the rest `7`, one evaluation.
- Pin: `arrowClauseTranscript() == "42\n1\n7\n1\n"`.
