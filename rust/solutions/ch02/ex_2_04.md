# Exercise 2.4: an alternative procedural representation of pairs

## Approach

`Cons<A, B>` holds both parts privately and sends them to a caller-supplied
selector. A Rust closure has a fixed return type, so a single closure
cannot support selectors returning both `A` and `B`. The solution uses
the generic method `Cons<A, B>::apply<R>(&self, selector: impl
FnOnce(&A, &B) -> R) -> R`. `car` calls `apply` with `|p, _q| p.clone()`
and `cdr` with `|_p, q| q.clone()`. `Cons`'s fields stay private, so
`apply` (and therefore the selector closure) is still the only way to
reach `x` or `y`. Callers cannot inspect the representation directly.
