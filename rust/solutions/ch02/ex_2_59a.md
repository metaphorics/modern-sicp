# Exercise 2.59a: `union-set` agrees with `HashSet` union (this edition's addition)

## Approach

`union_set` is a hand-written recursive procedure over `Vec<i128>`;
Rust's standard library already has a set type with its own `union`.
This addition proves the two agree, as sets, first on one probe pair
(`ex_2_59a`) and then across hundreds of generated no-duplicate integer
pairs of varying size via `proptest` (`union_set_matches_std_hashset`),
which is a stronger check than the book's exercise asks for and
exercises the deduplication and ordering edge cases a single example
cannot.
