# Exercise 3.5: Monte Carlo integration

## Approach

`estimate_integral` multiplies the fraction of random rectangle points
satisfying the predicate by the rectangle's area, with the experiment closure
built in place around the generator: the draws are two `random_in_range`
calls per trial, so `monte_carlo` from the section body is reused unchanged.
`random_in_range` scales the generator's 64-bit word into `[low, high)`. The
test measures the unit circle (radius 1, center (1, 1)) in the square from
(0, 0) to (2, 2) at 10,000 trials with the fixed seed and lands on 3.1228,
within 0.02 of pi.

## Map class

`T`: the statement translates directly; the generator is an explicit
parameter because the edition's seeded `Rand` is a value, not ambient state.

## Deviation

The book's `random-in-range` calls a decimal-valued `random`; this edition
scales whole 64-bit words, as the statement itself notes.
