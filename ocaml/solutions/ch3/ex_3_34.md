# Exercise 3.34 — Louis Reasoner's flawed squarer (translate)

The map class is `T`: Louis's proposed `squarer a b` is a bare
`multiplier a a b` — the same connector `a` wired into both factor
terminals — and the flaw is structural, so it translates directly
onto the existing `Constraints.multiplier`. Setting `b` alone can
never derive `a`, because the multiplier's propagation rule needs two
of its three connectors known to compute the third, and here both
factor terminals are the same unset connector, so "one factor known"
never actually holds. `a` must be forced by hand; once it is, the
network confirms consistency (`5 * 5 = 25`) without ever having
computed the square root itself.

Sample: `ex_3_34 ()` answers `(false, 5, 25)`.
