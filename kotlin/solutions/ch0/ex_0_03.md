## Exercise 0.3: a sealed tree and an exhaustive when

Approach: `depth` is a `when` expression over the sealed `Tree` with a case
per variant and no `else`, so the compiler guarantees the walker covers the
whole sum. Part two is a compile experiment, not a runtime assertion: the
reader adds a third variant (say `data class Fork(val kids: List<Tree>) :
Tree`) and the `when` in `depth` stops compiling with K2's
"'when' expression must be exhaustive, add necessary 'is Fork' branch or an
'else' branch" error; re-adding the case restores the build. That failure
is the exercise's point, so the solution test only pins the depth
arithmetic (leaf = 1, node = 1 + max of children).

Class: companion-added exercise (idiom-kotlin.md, Section 5, list item 0.3);
no map row. Deviation: none; the compile-failure step is documented here
rather than automated, because the gate must stay green.
