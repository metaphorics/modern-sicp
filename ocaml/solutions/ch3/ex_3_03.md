# Exercise 3.3: password-protected account (translate)

The map class is `T`. `make_account` still closes over one `int ref`
for the balance; the only new shape is the password gate, added as a
leading `string` argument compared unconditionally with
`String.equal`. Scheme's `((acc password op) amount)`, two nested
applications returning a procedure and then calling it, collapses
into `acc password message`, a single three-argument curried call,
since OCaml has no need for the intermediate procedure Scheme's
message-passing style returns.

Sample: `ex_3_03 ()` is `(Balance_response (Balance 60),
Incorrect_password)`, matching the statement's correct-password
withdrawal followed by a wrong-password deposit attempt.
