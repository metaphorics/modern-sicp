## Exercise 2.67: sample decode

Approach: `sampleTree` and `sampleMessage` are built directly from
`Huffman23.kt`'s given `makeLeaf`/`makeCodeTree`, matching the book's
tree and bit sequence exactly. Decoding by hand, bit by bit from the
root: `0` reaches leaf A; `1 1 0` reaches leaf D; `0` reaches A again;
`1 0` reaches B; `1 0` reaches B again; `1 1 1` reaches C; `0` reaches A
— giving the message `A D A B B C A`, which `decode` (given in
`Huffman23.kt`) reproduces exactly.

message into this section's types.
