## Exercise 2.87: zero, through a nested coefficient

Approach: [installPolyIsZero] installs `=zero?` for type `polynomial`:
a polynomial is zero exactly when every term's coefficient is zero,
tested by the same generic `=zero?` -- which recurses through the table
when a coefficient is itself a polynomial. `ex_2_87` checks a flat
zero polynomial, a polynomial nested one level whose every coefficient
is a zero polynomial, one nested polynomial that is not zero, and that
`adjoinTerm` actually drops a term whose nested-polynomial coefficient
is zero.

Class: T, per the map -- one more per-level `=zero?` install, following
the same pattern exercise 2.80 already established.

Deviation: none in substance.
