# Exercise 2.87 — polynomial =zero? (translate)

The map class is `T`: installing `=zero?` for `"polynomial"` is one
more table entry, the same shape as 2.80's installs for
`"scheme-number"`, `"rational"`, and `"complex"`. A coefficient here
is a plain number or a nested polynomial (`coeff = Flt of float | Poly
of poly`) — the representational fact behind "coefficients that are
themselves polynomials," which `is_zero_coeff` handles recursively: a
`Flt` is zero exactly when the float is, and a `Poly` is zero exactly
when its term list is empty (every term `adjoin_term` lets through
already has a nonzero coefficient, so an empty list is the only zero
polynomial). `adjoin_term` drops a term whenever
`is_zero_coeff term.coeff`, exactly as 2.5.3's narrative `adjoin_term`
does for plain numbers, which is what lets `adjoin_term` work for
polynomials with polynomial coefficients.

`ex_2_87 ()` adjoins two `x`-terms to an empty term list: one whose
coefficient is the empty (zero) polynomial in `y`, one whose
coefficient is a nonzero polynomial in `y`. Only the
nonzero-coefficient term survives, returning `(1, true)` — one
surviving term, and the empty `y`-polynomial reads as zero.
