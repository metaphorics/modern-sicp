# Exercise 5.12: the assembler's summary

The assembler already walks every instruction; while it pairs each one
with its execution procedure, `summarize` gathers the book's lists from
the same walk: the instructions grouped by type with duplicates removed,
the registers the controller names, the entry-point registers (the
`goto (reg r)` targets), the saved and restored registers, the assign
sources of each register, and the defined labels. Every list is in a
deterministic order: type groups and register groups in first-appearance
order, instruction texts and sources sorted, labels in definition order.

The test pins the rendered summary of the gcd machine: one instruction
apiece in the `test`, `branch`, and `goto` groups, three sorted
`assign` texts, the register list `a b t`, empty entry-point and stack
register lists (the gcd controller jumps by label and never saves), the
three assign sources with `t`'s operation call rendered in the nested
form, and the labels in definition order. The summary is computed from a
fresh assembly of the same controller the 5.7 machine runs.
