# Exercise 2.24: the structure of `[1, [2, [3, 4]]]`

## Approach

This edition builds the value and reads its structure back from the
printers: `showList` gives the printed form, the section's `length` the
outer count, and the tree interpretation is the `Tree` union value whose
`countLeaves` is the leaf count. The value is
`list(1, list(2, list(3, 4)))` and its tree reading is
`node(leaf(1), node(leaf(2), node(leaf(3), leaf(4))))`.

The box-and-pointer picture, in this edition's cells, is a two-element
spine whose second element is the spine of `[2, [3, 4]]`, and so on down:

```
[ 1 | • ]─→ [ • | / ]
            ↓
          [ 2 | • ]─→ [ • | / ]
                      ↓
                    [ 3 | • ]─→ [ 4 | / ]
```

The tree reading puts one leaf per number and one node per sublist:

```
node
├── leaf 1
└── node
    ├── leaf 2
    └── node
        ├── leaf 3
        └── leaf 4
```

## Numbers

The printed form is `[1, [2, [3, 4]]]`; the outer list has length 2; the
tree has 4 leaves.
