# Exercise 5.5: hand-simulate the factorial and Fibonacci machines (T)

## Approach

The section's hand model steps the two transcribed controllers
(the book's Figures 5.11 and 5.12) instruction by instruction and
records every save and restore with the stack contents at that
point. Inputs: n = 3 for both machines, the smallest input that
exercises recursive calls in both. The pinned traces are the answer:
one line per significant point, the stack rendered with its top on
the left.

## Map class

`T`.

## Sample answer

Factorial n = 3: val = 6, 27 instructions, 4 pushes against 4
restores, maximum depth 4. Fibonacci n = 3: val = 2, 51
instructions, 8 pushes against 8 restores, maximum depth 4; both
recursive calls of each level execute, including the n - 2 path.
