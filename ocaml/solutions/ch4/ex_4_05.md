# Exercise 4.05: arrow clauses

The map class is `T`. A plain clause pairs a Boolean test with a result; an arrow clause pairs a test answering an `option` with a recipient function receiving the `Some` payload, `None` falling through like a false test. The clauses derive into nested `if` and `match` nodes of the checked syntax, so each test runs exactly once. The payload's binder holds a space, which no source identifier can spell, so a recipient naming an outer variable of the same shape still reads the outer one.

Sample: `ex_4_05 ()` answers `["2"; "7"; "4"; "0"; "error: invalid form: Else must be the last clause"]` over an association-list lookup.
