# Exercise 2.10: `div-interval` signals an error when the divisor spans zero

## Approach

`div_interval_checked` tests `y.lower_bound() <= 0.0 && y.upper_bound()
>= 0.0` before dividing (an interval that touches zero at either bound
still makes the reciprocal infinite, so the check includes the
boundary), returning `SicpError::DivisionByZero` when it holds. This
replaces `ch02::sec_2_1::div_interval`'s undefined pre-fix result (an
infinity, a NaN, or a numerically plausible but meaningless finite
interval, all reachable without a panic) with a typed error. The test
checks both a valid division, `[6, 8] / [2, 4]`, and a rejected one,
dividing by `[-1, 1]`.

## Map class

`T`: Ben's fix translates directly; only the error-signaling mechanism
changes syntax, from Scheme's `error` to a typed `Result`.
