# Exercise 3.55: partial-sums combinator

## Approach

`partial-sums` answers S0, then the running totals S0 + S1, S0 + S1 +
S2, ... The compact stream form: cons the first element of S onto the
elementwise sum of the result stream with the tail of S. Each new total
is then one addition past the memoized total before it -- `sums` is
added to `source.tail()`, shifted by one place, so `sums[k + 1] =
sums[k] + s[k + 1]` by construction -- and the definition names its own
result under `self_stream`, the book's self-referential `define`. On
`integers` the partial sums are the triangular numbers 1, 3, 6, 10,
15, ..., the statement's own example, and the section module ships the
same combinator (it builds the text's pi stream), so the local
definition is cross-checked against it over a prefix.

## Map class

`T`. The statement translates whole. The one Rust wrinkle is the
self-referential `define` -- the result stream appears inside its own
tail -- served by `self_stream` with the name read in the tail thunk
only.

## Deviation

None. The section module already provides `partial_sums` for the
pi-stream text; the exercise-local definition stands on its own and the
test pins that both answer 1 3 6 10 15 over the prefix.
