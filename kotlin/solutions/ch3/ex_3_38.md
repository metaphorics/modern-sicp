# Exercise 3.38: interleavings of Peter, Paul, and Mary

## Approach

Each command is one read of the shared balance followed by one write
computed from that read, so the six steps live on three lanes. The
solution drives two kinds of evidence under `runTest`'s deterministic
scheduler. First, the six sequential orders run the processes
back-to-back and land exactly on {35, 40, 45, 50}. Second, targeted
launch orders with `yield()` injected between a process's read and its
write force each interleaved-only value: 50 (all three read before any
write, Mary's write last), 45 (Mary reads the 90 Paul left), 110
(Peter's write of his stale 100-read lands last), 90, 80, 55, and 60.
Finally the test enumerates all 90 interleavings with
`allInterleavings(2, 2, 2)` and asserts the outcome set is exactly
{30, 35, 40, 45, 50, 55, 60, 80, 90, 110}: the ten values the
interleaving semantics allows, no more.

## Map class

`T`. The commands and the two questions are the statement's own; the
enumeration machinery is this edition's answer to the JVM's
nondeterministic scheduler, as the section text states.

## Deviation

None. The step split (read step, write step per process) is the book's
own three-step analysis of the balance statement, made drivable.
