# Exercise 2.25: picking out the 7

## Approach

Each combination is a readonly tuple and each `car`/`cdr` pair becomes
one index: `car` is `[0]` and each `cdr` is `[1]`. `[1, 3, [5, 7], 9]` puts
7 at `first[2][1]`; `[[7]]` puts it at `second[0][0]`; and
`[1, [2, [3, [4, [5, [6, 7]]]]]]` sits six cdr-steps deep, so the chain is
`third[1][1][1][1][1][1]`. The tuple types are annotated level by level
so the chains typecheck.

## Numbers

All three chains return 7.

## Map class

`R`: the book's `car`/`cdr` chains over nested `cons` pairs become index
chains over the edition's readonly-array tuples.

## Deviation

The third chain in the batch design was written
`third[1][1][1][1][1][0]`, which indexes to 6; the chain that picks the
asserted 7 is `third[1][1][1][1][1][1]`, and the test pins 7.
