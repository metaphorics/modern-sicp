# Exercise 3.19: tortoise-and-hare constant-space detection (translate)

The map class is `T`: Floyd's algorithm is a direct translation (a
tortoise advancing one `cdr` per step and a hare advancing two, with
`==` in place of the book's `eq?` to test whether they have met) and
needs no auxiliary storage, so it needs no identity-keyed set at all.
The addition idea on this row ("shared suffix detection") is folded
into the fourth probe instead of made a separate exercise: two lists
that share a tail but never loop must NOT be flagged as cyclic, which
is exactly the case a naive "the hare passed here before" check could
get wrong if it compared list contents instead of pointers.

Sample: `ex_3_19 ()` answers `(false, true, true, false)`.
