# Exercise 4.23: analysis must build, never execute

## Lesson

Analyzing a sequence must build the combination without running it;
Alyssa's version evaluates every form during analysis, so the effects
land at analysis time and again at every run. The text version
answers nothing until run: the counters pin which analyzer ran what
when -- `0` then `30` for the text, `30` then `60` for Alyssa's.

## Map class

`A` (map row 4.1: analysis returns closures). The combination is a
kernel block either way; only the timing of effects differs.

## Deviation

None. The bug is reproduced exactly -- effects during analysis --
because the counters make the mistiming observable.

## Answer

- Text: nothing at analysis, `30` at the run.
- Alyssa: `30` at analysis, `60` after the run.
- Pin: `textSequenceTranscript() == "0\n30\n"` and
  `alyssaSequenceTranscript() == "30\n60\n"`.
