# Exercise 5.52: the compiler emits C

The exercise's emitter translates the compiler's typed instruction
sequence into C statements: machine registers become C globals,
instruction labels become C labels, and operations call the C
support layer keyed to the compiler's `compiled-*` vocabulary.
`runtimeC` contains values, environments, procedure entries,
arithmetic, and printing. `compiledCRuns` combines that support
with the emitted program, builds it with `cc -O1`, and runs a
recursive factorial that must print 120 and agree with `Direct`.

`CBackend.emitProgram` is a separate, complete reference C artifact
with closure entry and its own `main`. `compiledCVerdicts` compiles
and executes that reference artifact for comparison as well as
reporting structural properties of the exercise's emitted code.
The exercise's emitter and the reference backend are deliberately
not presented as the same implementation. The canonical
self-interpreter from exercise 5.50 remains the demanding kernel
target; its native execution is unverified pending integration.
