# Exercise 2.49 — the four primitive painters (translate)

The map class is `T`. All four are `segments_to_painter` over the
unit-square coordinates: (a) the four edge segments of the outline,
(b) the two diagonals of the ``X'', (c) the four side midpoints of
the diamond, and (d) a 20-segment wave (head, legs, tail, back)
standing in for the book's drawing; the statement only says "the
wave painter", so any fixed segment set that reads as the wave
satisfies it, and this edition's set matches the one the section's
main-text module renders.

The tests paint each into the unit frame: outline, X, and diamond
have 4, 2, and 4 segments with the endpoints the geometry predicts,
and every endpoint stays inside the frame.
