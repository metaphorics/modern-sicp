# Exercise 2.89: the dense term-list representation

## Approach

A dense polynomial stores only the coefficients, highest order first, so the
book's `x^5 + 2x^4 + 3x^2 - 2x - 5` is `(1 2 0 3 -2 -5)`. The order of a
term is the length of the list from its coefficient to the end, decremented
by one. The selectors and constructor keep the same order-coefficient
interface the sparse procedures are written against, so the section's
add-poly runs unchanged over dense lists.

## Numbers

The book's polynomial renders as `(1 2 0 3 -2 -5)`; adding it to itself
doubles every coefficient in place; and a polynomial read from the all-zero
coefficient list answers as the empty term list through `=zero?`.

## Map class

A (dense term lists as readonly arrays): the coefficient vector is a plain
readonly array, positions standing for orders.

## Deviation

None.
