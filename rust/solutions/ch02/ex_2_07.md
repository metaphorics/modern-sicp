# Exercise 2.7: the interval selectors that complete `make-interval`

## Approach

The exercise statement hands over the constructor directly,
`(define (make-interval a b) (cons a b))`, and asks only for the two
selectors. The solution reimplements this small trio locally
(`Interval::new`, `lower_bound`, `upper_bound`) as literal field
accessors, matching the book's assumption that callers already pass the
lower bound first. This duplicates the shape of
`ch02::sec_2_1::Interval`'s own constructor and selectors, which the
section's representative program already ships (see that module's doc
comment); the duplication is deliberate, so this exercise stays a real,
checkable answer rather than a call into code that was never withheld.
