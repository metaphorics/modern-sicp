# Exercise 5.44: open coding and shadowed names (T)

## Approach

Compile two lambdas with open coding enabled: one binds parameters
named `+` and `*`, and the other leaves those names free. Before
emitting direct machine arithmetic, the compiler checks the
compile-time environment. A name shadowed by a lambda parameter must
remain an ordinary procedure call; an unshadowed primitive can be
open-coded.

## Map class

`T`.

## Sample answer

The lambda that binds `+` and `*` contains zero open-coded `+` or `*`
operations. The lambda with free primitive names contains at least one.
This compiler check covers lexical shadowing; the implementation notes
that top-level rebinding is outside this analysis.
