# Exercise 3.78: solving a second-order equation with two integrals

## Approach

`solve2nd(a, b, dt, y0, dy0)` wires Figure 3.35: the acceleration stream
is `addStreams(scaleStream(dy, a), scaleStream(y, b))`, it feeds the
inner `integral` producing `dy` from `dy0`, and `dy` feeds the outer
`integral` producing `y` from `y0`. Both integrands are delayed and the
`dy` cell is tied before any tail can force it, so the loop closes.
Pins: with `a = -0.2`, `b = -1.0`, `dt = 0.01`, `y0 = 1.0`, `dy0 = 0.0`
the values at indices 100, 200, 300, 400 are
`0.5710853715751386, -0.2621361136816313, -0.7313719317259952,
-0.5064238606998512`. They were probed from the compiled solution and
re-derived in a python3 script with the same operation order
(`ddy = a*dy + b*y`, then `dy += dt*ddy`, then `y += dt*dy` with the old
`dy`); the doubles agree bit for bit. The decay envelope: the damped
period spans about 315 steps, so the maxima of `|y|` over successive
extremum windows `[0, 315)`, `[315, 630)`, `[630, 945)` are
`1.0, 0.7408645010200705, 0.5488697360170923`, strictly decreasing as
the resistor-free damping term bleeds energy.

## Deviation

The statement leaves `y0` and `dy0` open; the tests use `1.0` and
`0.0`. The envelope assertion walks 945 steps so it spans three extrema,
while the exact pins stay at or below the statement's 400 steps.
