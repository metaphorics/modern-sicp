## Exercise 2.66: tree lookup

Approach: `RecordTree` mirrors `Tree` (exercise 2.63/2.64) but stores a
whole `Record` at each node instead of a bare `Long`, comparing by
`Record.key`. `lookup` is `elementOfSetTree`'s exact shape with the
return value swapped from a `Boolean` to the matching `Record?`: equal
key returns the node's record, smaller recurses left, larger recurses
right, and an empty tree returns `null`.

Class: T, per the map; a direct translation, once "false" becomes
Kotlin's `null` for "no such record."

Deviation: `sampleDb` is a small hand-built database (five records)
rather than the book's unspecified "personnel files"; it is built
balanced by the same halve-and-recurse idea as `listToTree` (exercises
2.63/2.64), applied to `Record`s instead of `Long`s.
