# Exercise 2.35: count-leaves as an accumulation (adapt)

The map class is `A` (map row: "count-leaves over recursive tree
type"). The template asks for an accumulation over a map. In this
edition the enumeration stage is the tree's fringe: `ex_2_35` maps a
constant-one function over the leaves and accumulates with `+` from
0, i.e. `List.fold_left ( + ) 0 (List.map (fun _ -> 1) (fringe
tree))`. The `fringe` of 2.28 supplies the enumeration the Scheme
original got from `map` over the tree with a `pair?` test inside.

Sample: `ex_2_35` of the book's `((1 2) 3 4)` tree is 4, and of
`(list x x)` is 8.
