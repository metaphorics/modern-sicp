# Exercise 2.92: multi-variable polynomials (adapt)

The map class is `A`: `var_less` imposes the ordering the exercise
asks for on variables (plain string order, so `"x"` outranks `"y"`)
and `add_across_variables` adds two polynomials in different
variables by promoting the lower-priority one (by `var_less`) to a
degree-0 coefficient of the higher-priority polynomial's variable,
then adjoining it to that polynomial's own terms. A dominant-variable
term's coefficient is either a plain number or, once promoted, that
whole polynomial (`coeff = Num of float | Sub_poly of poly`). This
edition scopes the exercise down to the case with no collision:
`add_across_variables` refuses, rather than silently mis-combine, when
the higher-priority polynomial already carries its own degree-0 term,
since reconciling two same-order coefficients (one a number, one a
promoted polynomial) needs the full multivariate addition the
exercise itself calls "not easy."

`ex_2_92 ()` adds `x` (variable `x`, a bare first-order term) to
`3y + 2` (variable `y`): `"x"` outranks `"y"`, so the result is `x`'s
variable with two terms, order 1 (coefficient 1) and order 0
(coefficient the promoted polynomial `3y + 2`).
