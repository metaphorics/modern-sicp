# Exercise 4.06: let as a derived expression

The map class is `T`. `let x1 = e1 and ... and xn = en in body` rewrites into the combination `(fun x1 ... xn -> body) e1 ... en`. The inits are operands of the combination, so they run in the enclosing scope, which is exactly the scoping of a parallel `let`. A `let rec` is not a combination and is left to the standard dispatch.

Sample: `ex_4_06 ()` answers `["7"; "7"; "5"; "effect 1"; "120"]`: one `let` through the clause, the same lowered combination through the standard evaluator, a shadowing program whose inner inits see the outer binding, a `let _` that still runs its init, and a `let rec`.
