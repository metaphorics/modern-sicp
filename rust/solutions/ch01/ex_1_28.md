# Exercise 1.28

The Miller-Rabin `expmod` adds one check inside the squaring branch:
whenever a residue squares to 1 without itself being 1 or `m - 1`, it is a
nontrivial square root of 1, which can only exist modulo a composite
number (by Fermat's theorem, modulo a prime the only square roots of 1 are
1 and `p - 1`), so the function returns 0 and that 0 propagates up through
every remaining squaring, permanently spoiling the result of the whole
test for that witness.

Every prime below 100 passes for every witness from 1 up to `n - 1`: no
prime modulus ever exposes a nontrivial root, so the extra check never
fires and the test behaves like an ordinary Fermat check. Every one of the
six Carmichael numbers, which fool the plain Fermat test for every
witness, is rejected by at least one witness under Miller-Rabin: some
witness's computation passes through a nontrivial square root of 1 along
the way, which the plain `expmod` of exercise 1.27 has no way to notice.
The map class is `T`.
