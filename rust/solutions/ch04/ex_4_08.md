# Exercise 4.8: named iteration (T)

## Approach

The named loop is represented as a self-bound iterative procedure. The loop
name is bound before the body runs, so recursive calls refer to the same
iteration state. The implementation keeps the loop state explicit instead of
relying on a host tail-call guarantee.

## Map class

`T`.

## Sample answer

The named Fibonacci loop answers `55` for term `10`, with boundary terms `0`
and `1`.
