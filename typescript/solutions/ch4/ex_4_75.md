# Exercise 4.75: the unique special form (translate)

## Approach

The solution installs `unique` as a new query processor through the
engine's `put` hook, the book's extension mechanism for special
forms. A `unique` goal keeps its input frame exactly when the inner
query produces precisely one answer, looking at most two answers
deep so the check stays bounded on longer streams.

## Numbers

`(unique (job ?x (computer wizard)))` yields the single instantiated
answer; the programmer query (two answers) and a query with no
answers both yield nothing. The tests pin all three outcomes.

## Class and deviations

Translated row. No deviation: installed through the engine's own
special-form hook.
