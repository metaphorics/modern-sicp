# Exercise 2.66: lookup over a tree of records (translate)

The map class is `T`: only the syntax changes. `lookup` is
`element_of_set?`'s tree walk with the record's key standing in for
the tree entry: compare `given_key` against the current record's key,
and descend left or right depending on which side of it `given_key`
falls, stopping with `None` at an empty subtree.

Sample: `ex_2_66 ()`, `lookup 3` against a three-record tree, is
`Some {key = 3; name = "margaret"}`; looking up a key no record has
is `None`.
