# Exercise 2.77: nested apply_generic (adapt)

The map class is `A`: the two-level tag system is the same shape in
OCaml as in Scheme, so the fix is the same fix: install the generic
selectors themselves under `["complex"]`, so a value tagged `complex`
whose contents are still tagged `rectangular` reaches
`install_rectangular_package`'s entries through one more
`apply_generic` call. `install_alyssa_complex_fix` adds exactly that
one entry per selector; nothing about `apply_generic` itself changes.

To answer "how many times is `apply_generic` invoked," `apply_generic`
here increments a shared `call_count` ref on every call, so the count
is measured, not counted by hand from a trace. `ex_2_77 ()` calls
`magnitude z` on the rectangular `(3, 4)` tagged `complex` before and
after the fix: before, no `["complex"]` entry exists and
`apply_generic` raises; after, it answers `5.0` through exactly two
calls: one that strips `complex` and lands back in `apply_generic`
via the newly installed `magnitude`, one that strips `rectangular` and
computes the answer.
