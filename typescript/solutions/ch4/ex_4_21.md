# Exercise 4.21: recursion without define

## Approach

Everything runs on the engine, which needs no extension: the programs
themselves carry the recursion. The self-application trick binds a
procedure whose first parameter is the procedure itself, so the body
recurses by passing itself along. The typed guest spells that contract
with an interface — `Step { run(self, k) }` — so the self-application
is type-checked rather than duck-typed. Part (b) fills the template's
`⟨??⟩` holes: each recursive call must forward BOTH procedure
arguments it received — the pair itself plus the decremented count —
so the filled call is `peer.check(peer, self, n - 1)`.
