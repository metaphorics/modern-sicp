# Exercise 5.49: compiled read-execute loop (T)

## Approach

Build a driver that chains compiled entries with a prompt and result
printer after each one. The forms are compiled into blocks first; the
assembled machine then jumps through those entries, so user forms
execute as compiled code rather than through evaluator dispatch. This
is a host-driven realization of the read-compile-execute-print
behavior under the simulator's fixed-controller assembly model.

## Map class

`T`.

## Sample answer

The chained session defines `square`, prints `144` for `(square 12)`,
defines `twice`, and prints `882` for `(twice 441)`. Definitions
report `ok`.
