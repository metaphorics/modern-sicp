# Exercise 3.18: detecting a cycle in a list

## Approach

The book's answer walks the tails while remembering every pair it has
seen. JavaScript object identity carries the book's `eq?`, so the visited
set is the host `Set<object>`: membership on a pair object is identity,
which is why the map marks this row T for TypeScript where the other
editions' notes about missing identity sets do not apply here. `hasCycle`
walks tails, answering true at the first revisit and false at the empty
end.

## Pins

Computed by running. A plain three-item list answers false, the empty
list answers false, a two-pair ring (last tail back to the first pair)
answers true, a list whose last pair loops back to its own head answers
true, and two lists sharing a suffix (the map's shared-suffix idea, chosen
for another edition) both answer false: a shared tail is not a cycle.

## Map class

T (translate: syntax changes only). The map notes identity-keyed sets are
host facilities here, so the visited-set answer is a plain translation.
