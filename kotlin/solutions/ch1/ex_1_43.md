## Exercise 1.43: repeated application

Approach: `repeated(f, n)` is `f` itself at `n = 1`, otherwise `f`
composed with `repeated(f, n - 1)`, using exercise 1.42's `compose`;
generic over `T` so exercise 1.44 can reuse it at
`T = (Double) -> Double`, applying the *smoothing transformation*
repeatedly rather than a plain numerical function.
`repeated(square, 2)(5)` is `square(square(5)) = 625`.

Class: T (translate). Deviation: none. This section's chosen tailored
addition, 1.43a, extends this exercise with a logarithmic-time
`repeated` built by squaring; see `ex_1_43a.md`.
