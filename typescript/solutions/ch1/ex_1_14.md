# Exercise 1.14: the count-change tree and its orders of growth

## Approach

Every application of the reduction rule is one node of the tree, so the
instrumented `cc` in the solution counts nodes as it counts ways, and
tracks the depth of simultaneous calls - that depth is the space the
process needs. The tree for 11 cents, condensed (each node is
`cc(amount kinds)`):

```
                                     (11 5)
                    +................................+
                    |                                |          kind 50 never fits
                 (11 4)                            (11-50 4)  -> subtree of 0-ways
           +...............+                        ...
           |               |
        (11 3)          (6 3)                        <- a 10 leaves 1
     +........+        +........+
     |        |        |        |
  (11 2)   (1 2)    (6 2)     (1 2)                <- a 5 leaves 1 or 6
   ...      ...      ...      ...
  the (a 1) fringe: a chain of penny decisions, one node per cent left
  leaves: (0 k) -> 1 way   (a<0 k) or (a 0) -> 0 ways
```

## Numbers

Changing 11 cents counts `4` ways, over a tree of `55` nodes whose
deepest chain is `16` simultaneous calls. At amount 100: `15499` nodes,
depth `105`; at 200: `229589` nodes, depth `205`. The depth tracks the
amount (`maxDepth ~ n + 5`): space is `Theta(n)`. The node count divided
by `n^4` settles toward a constant (`55/11^4 ~ 3.8e-3`, `15499/100^4 ~
1.5e-4`, `229589/200^4 ~ 1.4e-4`): the number of steps is `Theta(n^4)`
for the five fixed denominations.
