# Exercise 2.58: differentiating infix notation (adapt)

The map class is `A`: the idea (change only the representation, not
`deriv`) survives, but infix notation needs a second variant layer
alongside `Deriv.expr`'s prefix one. Part (a)'s `infix` type
(`Num`/`Var`/`Plus`/`Times`) is the fully parenthesized case, and
`deriv` over it is a copy of `Deriv.deriv`'s two rules under the new
names. Part (b) drops the parenthesization requirement: `tok`
tokenizes standard notation, and `parse_standard` is a small
precedence-climbing parser (sums split at the top-level `+`, terms at
the top-level `*`) that reads any token list into the same `infix`
tree, so `deriv` needs no second version for the harder notation.

Samples: `ex_2_58_parenthesized ()`, the derivative of
`x + (3 * (x + (y + 2)))` with respect to `x`, and
`ex_2_58_standard ()`, the derivative of the un-parenthesized
`x + 3 * (x + y + 2)`, are both `Num 4`.
