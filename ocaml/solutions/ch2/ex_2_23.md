# Exercise 2.23: for-each (translate)

The map class is `T`. `ex_2_23` recurses down the list, applies
`proc` to the head as a statement (sequence before the recursive
call), and returns `()` at the end. The procedure is used for its
effect, so the tests capture the effect (an accumulator ref) and the
left-to-right order, not a return value.

Sample: `for_each print_int [57; 321; 88]` prints `57`, `321`, `88`
in order and returns unit.
