# Exercise 5.4: exponentiation machines

Both machines use `b` and `n` as inputs and return the answer in `val` (recursive) or `product` (iterative).

## Recursive design

Registers: `b`, `n`, `val`, `continue`. Operations: `=`, `-`, and `*`.

```text
expt-loop: test n = 0; if true goto base-case
           save continue; save n
           n := n - 1; continue := after-expt; goto expt-loop
after-expt: restore n; restore continue
            val := b * val; goto continue
base-case: val := 1; goto continue
expt-done:
```

The saved `n` is used by the multiply after the recursive call. The saved `continue` returns to the caller.

## Iterative design

Registers: `b`, `n`, `counter`, `product`. Operations: `=`, `-`, and `*`.

```text
counter := n; product := 1
expt-iter: test counter = 0; if true goto expt-done
           product := b * product
           counter := counter - 1
           goto expt-iter
expt-done:
```

The recursive and iterative descriptions are implemented as `exponentRecursive` and `exponentIterative`. Running either with `b = 3`, `n = 4` returns 81. The recursive controller reaches four stack levels; the iterative controller uses no stack.
