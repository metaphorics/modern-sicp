# Exercise 1.13: the Fibonacci closed form against the definition

## Approach

Proof by induction that `Fib(n) = (phi^n - psi^n) / sqrt(5)` where
`phi = (1 + sqrt(5))/2` and `psi = (1 - sqrt(5))/2`.

Base cases. `n = 0`: `(1 - 1)/sqrt(5) = 0 = Fib(0)`. `n = 1`:
`(phi - psi)/sqrt(5) = 1 = Fib(1)`, since `phi - psi = 1`.

Inductive step. Assume the formula for `n - 1` and `n - 2`. Since
`phi^2 = phi + 1` and `psi^2 = psi + 1` (each is a root of
`x^2 = x + 1`, the defining equation of the golden ratio from section
1.2.2),

```
phi^n - psi^n
  = (phi + 1)phi^(n-2) - (psi + 1)psi^(n-2)
  = [phi^(n-1) - psi^(n-1)] + [phi^(n-2) - psi^(n-2)]
  = sqrt(5) * (Fib(n-1) + Fib(n-2))
  = sqrt(5) * Fib(n).
```

So `Fib(n) = (phi^n - psi^n)/sqrt(5)`. Because `|psi| < 1`,
`|psi^n|/sqrt(5) < 1/sqrt(5) < 1/2`, so `Fib(n)` is the closest integer
to `phi^n / sqrt(5)` - which is also the bound used in section 1.2.2 to
read the exponential growth of the tree-recursive process off `phi`.

## Numbers

`closedFormFib(10)` is `55`; the rounded closed form equals the
iterated definition for every `n` in `0..40`. Beyond roughly `n = 71`
the floating-point evaluation of `phi^n` can no longer resolve the
nearest integer, which is exactly why exercise 1.19 moves this
computation to `bigint`.
