# Exercise 4.16: scan out internal definitions (translate)

The map class is `T`. The book's transformation translates directly:
`scan_out_defines` walks a body, collects the top-level defines in
both forms, and rewrites the body to one `let` that reserves every
name with the section's `*unassigned*` symbol, followed by the
assignments in source order; a body without defines is unchanged. The
statement's part (c) asks where to install the scan: this edition
scans at procedure creation, where a lambda or a function define
builds its `Value.compound` once, so every application runs the
already-rewritten body and nothing re-scans on each access. Part (a)
is the marker check in lookup: reading a name that still holds the
marker is an invalid form naming the variable.

Sample: `ex_4_16 ()` answers
`["#t"; "Error: invalid form: b is read before it is assigned"]`:
the text's mutual recursion runs under the scan-out, and reading `b`
inside `a`'s initializer is rejected.
