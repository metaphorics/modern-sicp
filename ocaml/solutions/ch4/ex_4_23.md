# Exercise 4.23 — Alyssa's analyze-sequence, counted (adapt)

The map class is `A`: the statement compares the text's
`analyze_sequence` with Alyssa's on sequences of one and two
expressions, and this edition makes the comparison a measurement. Two
otherwise identical analyzers run the statement's program —
`(define (f n) (begin (set! n (+ n 1)) (* n 2)))` built from `Ast`
constructors, then two calls of `(f 1)` — with a counter incremented
where the sequencing work happens. A one-expression sequence has no
sequencing to count in either version: the text's returns that
expression's own execution procedure, and Alyssa's loop runs a single
procedure.

The text's version combines the execution procedures into one chain
during analysis, so the counter rises once per analysis pass and never
at execution; two calls still cost one count. Alyssa's version analyzes
the individual expressions but loops over them at every execution, and
that walk is the work: each of the two calls counts once. This is Eva's
point made observable — although the individual expressions were
analyzed, the sequence itself was not.

Sample: `analysis_count_book ()` answers `1`,
`analysis_count_alyssa ()` answers `2`, and `ex_4_23 ()` answers
`["1"; "2"]`.
