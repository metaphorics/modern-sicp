# Exercise 4.10: new syntax by translation

## Lesson

A `defun` surface form lowers to a defining statement for a procedure
value; a `fun` surface form lowers to the procedure itself. Both
rewrites are guest functions over kernel data, so no new evaluation
rule and no foreign reader is involved: the lowering runs first, the
kernel evaluates what it already knows.

## Map class

`A` (map row 4.1: new syntax extends the sealed family, never a
parser). Surface lowers to statements and procedures the kernel has.

## Deviation

None. The lowered `defun` defines through the kernel's own defining
statement; application is unchanged.

## Answer

- The lowered `defun` defines the square: `49`.
- The lowered `fun` doubles `21`: `42`.
- Pin: `newSyntaxTranscript() == "49\n42\n"`.
