# Exercise 5.1: design the iterative factorial machine (T)

## Approach

Three registers (`n`, `counter`, `product`), two operation boxes
(`*` for the new product, `+` for the incremented counter), and the
`>` test that ends the loop. The data-path and controller diagrams
are carried in the solution module's documentation as ASCII art in
the book's notation, the edition's figure convention; the machine
itself is transcribed as controller data and run. The test pins the
iterative property directly: the stack is never touched.

## Map class

`T`.

## Sample answer

For n = 6 the machine leaves 720 in `product` after 34 executed
instructions, with zero pushes and zero pops.
