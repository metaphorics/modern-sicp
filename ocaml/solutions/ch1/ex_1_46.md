# Exercise 1.46 — iterative-improvement abstraction (translate)

The map class is `T`. `iterative_improve good_enough improve guess`
tests the guess, returns it if it passes, and otherwise recurses on
`improve guess`, exactly the book's pattern. `sqrt_via_ii` and
`fixed_point_via_ii` rewrite `Sec_1_1.Sqrt.sqrt` (@ref{1.1.7}) and
`Sec_1_3.Fixed_point.fixed_point` (@ref{1.3.3}) in these terms, as the
exercise asks.

`sqrt_via_ii 9. = 3.00009155413138`, bit-identical to
`Sec_1_1.Sqrt.sqrt 9.` — the same algorithm, restated. But
`fixed_point_via_ii cos 1. = 0.7390893414033927` is not bit-identical
to the section's own `fixed_point cos 1. = 0.7390822985224024`. This
is not a bug: `iterative_improve`'s `good_enough` tests whether the
*current* guess is already close to its own image under `f`, while
`fixed_point`'s `try_guess` compares two *consecutive* guesses and
returns the newer one. The two tests agree closely but not exactly,
and `iterative_improve` can settle one iteration earlier — a genuine,
documented difference between the two stopping rules the exercise
leaves unspecified, not a translation error.
