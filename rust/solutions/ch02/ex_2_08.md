# Exercise 2.8: `sub-interval`

## Approach

Reasoning analogous to `add-interval`: the smallest possible difference
`x - y` is `x`'s lower bound minus `y`'s upper bound (subtracting the
most `y` could be), and the largest is `x`'s upper bound minus `y`'s
lower bound. For any two well-formed intervals this pair is itself well
formed (`x.lower - y.upper <= x.upper - y.lower` follows from
`x.lower <= x.upper` and `y.lower <= y.upper`), so `Interval::new` never
rejects the result; the `Result` return type reflects
`Interval::new`'s own signature.

## Map class

`T`: the statement and the reasoning translate directly from
`add-interval`.
