# Exercise 5.42: lexical-address code generation (T)

## Approach

Two counters from one factory own independent frames, so advancing one leaves the other at its own count: after two calls the first answers `3` on its third call while the second answers `1` on its first. Both engines agree, which is lexical addressing made observable.

## Map class

`T`.

## Sample answer

Both engines print `3` then `1`.
