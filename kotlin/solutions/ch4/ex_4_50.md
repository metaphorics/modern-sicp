# Exercise 4.50: ramb

## Approach

`ramb` is `amb` behind a per-visit shuffle: the subclass reuses the
base choice point and overrides the visit order with a Fisher-Yates
pass driven by the runtime's seeded xorshift64*, whose seed the driver
threads in (D31). Fixed seed, fixed session. In Alyssa's generator the
ramb-driven word choices escape the first-alternative recursion, so
the first sentence already contains words the depth-first generator
never reached.

## Map class

`T` unchanged. The edition's seed discipline (D31) is what makes the
ramb pins reproducible; the OCaml sibling's ramb uses the same seed
value.

## Deviation

None.

## Answer

From the actual runs (`E4_50Test` pins both): under seed 20260925,

ramb-driven generator's first sentence is (sentence (simple-noun-phrase
(article a) (noun professor)) (verb lectures)).
