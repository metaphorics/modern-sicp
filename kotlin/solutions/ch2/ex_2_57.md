## Exercise 2.57: n-ary sums and products

Approach: `NaryExpr.Sum`/`Product` hold a `List` of two or more terms
instead of a fixed pair. `addend`/`multiplier` read the first element;
`augend`/`multiplicand` return the sum (respectively product) of the
rest, collapsing to the bare remaining element when exactly one is
left — the book's own hint, generalized. `derivN` is textually identical
to the base two-argument `deriv` (same four branches, same calls to
`addend`/`augend`/`multiplier`/`multiplicand`); only what those four
accessors return has widened, exactly as the exercise asks.

Class: A, per the map — the idea survives, but n-ary terms/factors widen
the constructors' shape from a fixed pair to a `List`.

Deviation: kept as its own local `NaryExpr`/`derivN`, not an edit to
`AlgExpr.kt`, so the running prose's two-argument `Expr` and exercise
2.58's parser (which targets that same two-argument shape) are
unaffected.
