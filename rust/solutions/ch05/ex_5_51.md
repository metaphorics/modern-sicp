# Exercise 5.51: translating the evaluator to C (T)

## Approach

Translate the 5.4 explicit-control evaluator into C, with controller
entries as labels and the evaluator registers as static state in the
`eceval` function. The `continue` register stores a label address and
computed goto implements indirect controller transfers. An explicit
array stack follows the machine's push/pop discipline; the C runtime
supplies Scheme values, pairs, symbols, environments, and primitives.
The solution writes the C source and sample program to a temporary
directory, builds with the system `cc`, and runs the result.

## Map class

`T`.

## Sample answer

The translated evaluator's sample session defines factorial and
returns `120` for `(factorial 5)`. The C implementation relies on the
system compiler's GNU computed-goto extension.
