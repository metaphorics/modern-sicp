# Exercise 1.7: relative tolerance for square roots

## Approach

The new end test watches the change in the guess and stops when
`|guess - previous|` is less than `0.001` times the guess, so the
tolerance scales with the radicand. The iteration keeps the section's
recursive shape with one extra parameter for the previous guess. The
fixed point `0` is handled outright: its change ratio is forever `1/2`,
so the relative test would never fire.

## Numbers

Small: the absolute test returns `0.03230844833048122` for
`sqrt(0.0001)` - three times too large; the relative test returns
`0.010000000025490743`. Large: for the radicand `1234567890123456800000`
the absolute test never fires - the ulp of the radicand is about
2.6e5, so `|guess^2 - x|` can never drop below `0.001`, and a capped run
fails to converge; the relative test returns `35136429551.74436` against
the host oracle `35136418288.20144`, a relative error of `3.2e-7`.
