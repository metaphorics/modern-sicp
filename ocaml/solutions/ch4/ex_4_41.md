# Exercise 4.41: an ordinary program (A row, reworded)

The statement asks for an ordinary program in the reader's working
language; this edition reads that as OCaml, so the solution is a plain
host function: `permutations` over the five floors, filtered by the
puzzle's restrictions. No evaluator, no search machinery. The
permutation enumeration answers exactly one solution,
`((baker 3) (cooper 2) (fletcher 4) (miller 5) (smith 1))`, which is
the amb evaluator's answer too: the exercise's point that the
nondeterministic program buys notation, not power.
