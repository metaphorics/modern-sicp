## Exercise 3.28: the or-gate as a primitive function box

Approach: the or-gate is built exactly like the section's `andGate`,
and the file's KDoc says so where it matters. One action closure serves
both input wires; it reads both signals and schedules the output to
take their logical or one `orGateDelay` later. Because the same closure
is attached to both inputs, either input changing is enough to
re-evaluate the gate, and the gate never needs to remember which input
changed: the action recomputes from the wires' current state every
time.

The conversion itself is `logicalOr`, one line: 1 when either input is
1, else 0. The book leaves the analogous `logical-and` to the reader's
imagination; this edition defines both conversions as one-line guards
over the wire discipline that keeps signals at 0 or 1, and
`logicalNot` in the support file throws for anything else so a
corrupted signal cannot silently compute a wrong answer.

One naming note: the section's gate constructors are members of
`Simulation`, but this exercise's deliverable lives in its own file and
Kotlin cannot declare a member of an existing class from outside it, so
`orGate` is an extension on `Simulation` with the same call shape as
the members. `sim.orGate(a, b, out)` reads and compiles the same way in
the book's session. The support file needs no or-gate to compile (
`halfAdder` and `fullAdder` resolve the extension from this exercise)
so nothing else in the section had to move.

What the tests say: `E3_28Test.kt` drives the truth table over all four
input pairs (fresh simulation per pair, one propagate, final output
checked against the arithmetic), pins the delay by probing the output
wire (the settled print lands at exactly `orGateDelay` = 5), and checks
that a second input change which cannot alter the output schedules
nothing: the probe log stays at two lines because `setSignal` never
calls the actions for an unchanged value.

Deviation: none. The gate is the book's definition with the message
`or-gate` spelled as the extension `Simulation.orGate`.
