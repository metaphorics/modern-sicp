# Exercise 4.73: why flattenStream delays

## Approach

The engine flattens by interleaving each inner stream with the
deferred flattening of the rest. Over two supervisor streams the
delayed flatten surfaces Louis second overall, while eager append
defers Hacker's whole branch last. The eager variant from the
statement would additionally force the outer tail before yielding
any inner head — the same starvation shape as 4.71, one level up.

## Numbers

Four frames in both orders; Louis sits at index 1 flattened
versus index 3 appended. The tests pin both orders exactly.

## Class and deviations

Translated row. No deviation: both orders run through engine
exports over real assertion streams, with the outer stream built
as a stream literal. The unbounded-outer consequence is explained,
not executed.
