# Exercise 5.52: the compiler emits C

The backend translates each compiler instruction sequence into the
statements of a single C function: registers are globals, labels are
C labels, `continue` and procedure entries hold label addresses, and
every machine operation is one C dispatch. Constants are emitted
inline as constructors because they are immutable values the machine
only reads, which removes the constant table the OCaml edition needs.
`extend-environment` keeps its parameter shape through a
comma-joined name list. The run-time support mirrors the 5.50
machine: values, id-tabled environments, the primitive table with the
environment procedures, and a driver that prints the final value.

`compiledInterpreterRuns()` compiles the adapted metacircular source
(the 5.50 provision plus the object call) to C, builds it with
`cc -O1`, and runs the object factorial through the C-compiled
interpreter. The run answers 120, pinned by the test.
