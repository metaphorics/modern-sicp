# Exercise 3.53: predict self-referential doubling stream

## Approach

`s` is 1 consed onto `(add-streams s s)`, and adding a stream to itself
doubles every element -- elementwise `s[k] + s[k]`. So by induction:
`s[0] = 1` from the cons, and each later element is twice the one at
the same position one step in, giving 2, 4, 8, ... -- `s[k] = 2^k`, the
powers of two. The self-reference is the book's `(define s (cons-stream
1 (add-streams s s)))`: the name is read only inside the tail thunk,
which runs after the definition is complete, and because the two
summands share the one memoized spine, each element computes once and
the doubling never re-runs work.

## Map class

`T`. The statement translates whole. The one Rust wrinkle is the
self-referential `define`: a Rust definition cannot name itself, so the
body runs under `self_stream` and reads `s.stream()` inside the tail
thunk only, which is exactly the discipline the book's `define`
enforces.

## Deviation

The statement asks to describe the elements without running; the
description is the powers of two, and the test pins the first eight
elements as its verification.
