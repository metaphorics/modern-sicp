# Exercise 5.40: compile-time environment threading

The compile-time environment describes the lexical frames surrounding
an expression. Searching the innermost frame first yields a frame
distance and a slot for each bound name; an absent name is not
assigned a lexical address.

`compileTimeEnvironmentDump` uses the same frame-list model as
exercises 5.39 and 5.41. It looks up `product`, `counter`, `n`,
and `missing` in two nested frames and reports either the
frame/offset pair or `unbound`. The printed traversal describes
the model, not a compiler tracing callback.
