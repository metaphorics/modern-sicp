# Exercise 2.27: deep-reverse

## Approach

`deepReverse` is the tree version of `reverse`: reverse the sequence of
subtrees and recurse into each; a leaf is its own deep reverse.
`shallowReverse` is the contrast case the book's `x` motivates: only
the outermost subtree order flips, so the inner pairs stay `(1 2)` and
`(3 4)` untouched. Both copy the subtrees with a spread before
`reverse` because a node's subtree array is readonly.

## Numbers

For `x = ((1 2) (3 4))`: `showTree(x)` is `((1 2) (3 4))`,
`shallowReverse(x)` is `((3 4) (1 2))`, and `deepReverse(x)` is
`((4 3) (2 1))`; the deeper `(1 (2 3))` deep-reverses to `((3 2) 1)`.

## Map class

`A`: the book's lists-of-lists become the edition's `Tree` union, so
both reversals operate on a node's readonly subtree array instead of
`car`/`cdr` pair structure.

None.
