# Exercise 5.15a: a budget on the instruction count (tailored)

## Approach

Added by this edition and extending 5.15. The counting machine
gains `set_instruction_budget`: `None` runs unbounded, `Some(n)`
halts a run that is due to execute an instruction past n with the
typed `BudgetExceeded { count, pc }`. The map's idea cell asks for
an alert when the count exceeds a budget; halting with a typed
fault at the boundary is that alert, made inspectable: the count
and the program counter name exactly where the run stood.

## Map class

Tailored addition, `chosen: rust` recorded by the parent; no map
edit made.

## Sample answer

fib(6) with budget 10 faults `BudgetExceeded { count: 10, pc: 3 }`
(pc 3 is the loop's assign); with 280 it faults at count 280, pc
19; with 281 it finishes. The halted machine continues after the
budget is cleared and accounts 281 instructions in total.
