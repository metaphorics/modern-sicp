# Exercise 4.23a: count analysis invocations with a counter (this edition; extends 4.23)

## Approach

`Counting` instruments the analyzer seam: it counts `analyze` invocations, and
its sequence execution procedures count their own runs. Two one-expression
bodies, each executed twice: the analysis counts agree between the styles (the
same single pass), the text-style sequence wrapper never runs (for one body
there is no wrapper at all), and Alyssa's wrapper runs once per body execution,
four times.

## Map class

Tailored addition, chosen for Rust in the map's idea cell (D30).

## Sample answer

Text style 0 sequence-execution runs, Alyssa style 4; analysis counts equal.
