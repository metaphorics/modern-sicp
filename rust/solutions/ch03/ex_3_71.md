# Exercise 3.71: Ramanujan numbers via weighted pairs

## Approach

The Leiserson trick the statement names: order the pairs `(i, j)` of
the integers by the weight `i*i*i + j*j*j`, and every number written as
a sum of two cubes in two ways appears as a run of equal weights --
adjacent, because the weighted merge emits in nondecreasing weight
order and a tie holds one pair per merged side. A local grouping
combinator folds the ordered stream into maximal runs of equal weight,
each run answering `(weight, count, witness pairs)`, walked eagerly
because a run is bounded by the number of representations the weight
has; the runs of length two or more are the Ramanujan numbers. The
first six runs answer 1729 and the next five the statement asks for:
`1729, 4104, 13832, 20683, 32832, 39312`, each carrying its two witness
pairs, `(1,12)` and `(9,10)` for 1729.

## Map class

`T`. The statement translates whole: the stream of pairs weighted by
`i^3 + j^3` per exercise 3.70, the search for two consecutive pairs
with the same weight, the first such number 1,729, and the next five.
The one Rust wrinkle: the same eager-recursion hygiene as 3.69 does not
bite here -- the qualifying runs arrive within a few hundred pairs, so
the grouping walk stays shallow and instant.

## Deviation

None. The statement's "next five" are pinned alongside 1729 and 4104,
so the task sketch's two-number pin is contained in the answer.
