# Exercise 4.13 — make-unbound! removes the newest binding (translate)

The map class is `T`. The statement is underspecified on purpose; the
solution completes it by removing the binding from the newest frame
only. Removing from every frame would punch holes through enclosing
scopes and destroy bindings the caller never saw; removing from the
newest frame alone makes the previous binding of the name visible
again, which is the useful reading of unbinding in a lexically scoped
language. `make_unbound_` answers whether it removed one. The frames
are the association lists of 4.11, so the removal is one
`remove_assoc` on the newest frame's list.

Sample: `ex_4_13 ()` answers
`["2"; "#t"; "Error: unbound variable x"; "9"; "#t"; "1"; "#f"]` —
two defines leaving a single replaced binding that the removal takes
away for good, then over a shadowing frame the removal uncovering the
outer binding, and `#f` for a name the newest frame never bound.
