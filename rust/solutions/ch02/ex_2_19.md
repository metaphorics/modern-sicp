# Exercise 2.19: change-counting with a coin list

## Approach

The three helpers are one line each over `List`: `no_more` is
`is_empty`, `except_first_denomination` is the `cdr`, and
`first_denomination` is the `car`. `cc` keeps the 1.2.2 tree recursion
and now receives the currency as data, which is the exercise's point:
the same recursion counts the ways for any coin list passed in.

## Map class

`T`: the statement translates directly, with one representation note:
amounts are integer pence, so the book's half-pound coin would be the
value 50 and duplicate the existing 50-pence coin in `uk-coins`; this
edition lists `(100 50 20 10 5 2 1)` and says so in the section.

## Deviation

The `uk-coins` literal drops the book's 0.5 entry for the pence reason
above; the `cc 100 us-coins` answer of 292 is unchanged, and the test
additionally pins the `uk-coins` count (4563).
