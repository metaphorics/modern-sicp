# Exercise 1.18

The invariant is `a * b + c`, unchanged from state to state: doubling `a`
and halving `b` preserves `a * b`, so `c` is untouched; decrementing `b`
and adding `a` into `c` accounts for the one unit of `b` that decrement
removed. `c` starts at 0 and holds the full product once `b` reaches 0.
`fast_times_iter(7, 5) = 35`, `fast_times_iter(17, 33) = 561`, and
`fast_times_iter(0, 9) = 0`.

The map class is `A`, the same reason as exercise 1.16: this is exercise
1.16's technique combined with exercise 1.17's doubling and halving, and
Rust needs the loop spelled out rather than a tail-recursive `fn` that
depends on an optimization the compiler does not guarantee.
