# Exercise 2.57: sums and products of arbitrary numbers of terms

## Approach

`Sum` and `Product` widen from two fixed fields to a `Vec<Expr>` of
terms. `deriv` itself is byte-for-byte the two-term version, still
calling `addend`/`augend` and `multiplier`/`multiplicand`; only those
four functions change, exactly as the book asks: the addend (multiplier)
is the first term, and the augend (multiplicand) is the second term
when there are exactly two, or the sum (product) of the rest when
there are more. `x * y * (x + 3)` differentiates to
`(+ (* x y) (* y (+ x 3)))`, the same answer 2.3.2's two-term version
gives for the equivalent nested `(* (* x y) (+ x 3))`.

## Map class

`A`: n-ary sums and products change the expression enum's shape,
matching the map's Rust class for this row.
