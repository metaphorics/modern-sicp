# Exercise 3.35: squarer as a primitive constraint (translate)

The map class is `T`: the fix for exercise 3.34 is a genuinely new
primitive constraint, `squarer a b` with `a.in * a.in = b`, built the
way `adder`/`multiplier`/`constant` are built in the main text: a
`me` dispatch handling `I_have_a_value` and `I_lost_my_value` and
using `connect` on both connectors. Setting `b` computes `a` as
`isqrt b`; setting `a` (after a forget) computes `b` as `a * a`; and
because a negative product has no real square root, `isqrt` raises
`Invalid_argument` rather than silently returning nonsense, which
`negative_raises` confirms directly.

Sample: `ex_3_35 ()` answers `(7, 36)`, and `negative_raises ()`
answers `true`.
