# Exercise 0.1: three Scheme sessions in TypeScript

## Approach

Each session translates line by line, in order, into the body of one
function: session 1 is five arithmetic expressions, session 2 binds
`a` and `b` with `const` and evaluates the five conditionals, and
session 3 defines `square` and calls it three times. The numeric
responses collect into one list, so a single `toEqual` pins the whole
transcript; the `(= a b)` response is `false` and lives in the
conditional of session 2 rather than the numeric list.

The conditional expressions map to TypeScript's conditional operator:
`if` is a statement here, so `(if (and (> b a) (< b (* a b))) b a)`
becomes `b > a && b < a * b ? b : a`. The `cond` of the last
arithmetic line nests its clauses in the else position, in the same
order Scheme tries them.

## Numbers

Every response matches Scheme's exactly: `486, 100, 12, 1, 6` from
session 1, then `19, false, 4, 16, 6, 16` from session 2, then `441,
49, 81` from session 3. All are small integers, well inside the 2^53
exactness bound of section 0.2's number model, so no `bigint` is
needed.

## Class and deviations

Chapter 0 exercises are original per edition (see the header note in
`docs/exercise-map.md`); the exercise mirrors Kotlin edition exercise
0.1, which sets the same task for the same three sessions. No
deviation.
