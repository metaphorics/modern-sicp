# Exercise 4.3: data-directed dispatch in eval

## Approach

The special-form dispatch becomes a table keyed by the node `tag`, one
operation per form: assignment, logical connectives, conditionals,
arrows, binary and unary operations, and templates, each installed with
`put` and fetched with `get`, as in the data-directed differentiation of
exercise 2.73. The book's parenthetical now says node tag, not `car`:
the typed syntax carries its dispatch key in the node itself.
Self-evaluating literals and variables carry no form, so they bypass the
table; a `call` node whose tag is not installed runs the application
path; any other uninstalled data tag runs the ordinary evaluator's case.
The installed operations take the expression and the environment
directly — the book's shape — so one table serves every environment and
the old spine adapter disappears. Subexpressions and the expression
forms of procedure bodies recurse through the same dispatch; the
statement forms `while`, `for-of`, `switch`, `throw`, and `try` run the
engine's statement evaluator inside bodies.

## Numbers

`square(6) * square(7)` is `1764`. `1 === 2 ? 111 : 222` is `222`. After
`let n = 1`, `n = 5` writes `5` and `n` reads `5`. Assigning a `const`
binding is `error:bad-operand` and leaves `x` at `10`. `((x: number):
number => x * 2)(21)` is `42` and `(() => { 1; 2; return 3; })()` is
`3`. Nested forms in a body classify `-5` as `"neg"` and `5` as `"pos"`.
An uninstalled `call` runs the application path: `square(9)` is `81`;
an uninstalled data tag runs the ordinary evaluator: `[1, 2, 3]` renders
`[1, 2, 3]`. One more `put` installs the unary form as `4242`.

## Class and deviations

Translated row. The premise's own re-cut moves the dispatch key from the
operator symbol (`car`) to the node `tag`. Deviation removed: the old
solution wrapped the spine's primitive-typed `OpTable` per environment;
the typed table stores operations over expressions directly, so there is
no adapter and no per-environment cache. The body statement forms listed
above are the only cases that leave the table dispatch, and that boundary
is named here rather than hidden.
