## Exercise 1.19: Fibonacci in a logarithmic number of steps

Approach: expand `T_pq(T_pq(a, b))`. One application gives
`(bq + aq + ap, bp + aq)`; feeding that pair back through `T_pq` and
collecting terms in `a` and `b` gives a new pair whose coefficients match
`T_p'q'(a, b)` exactly when `p' = p^2 + q^2` and `q' = q^2 + 2pq`. This
lets `fibIterLog` halve the exponent on every even step (squaring the
transform) and fold one factor on every odd step, the same halve/fold
pattern as exercises 1.16 and 1.18, giving Theta(log n) steps overall.

Class: A (adapt). Every four editions' map row calls out that a fixed
integer width forces a choice here: `Fib(93)` already exceeds
`Long.MAX_VALUE`, so a `Long`-typed `fibLog` would silently wrap well
inside the range this exercise is meant to explore. This edition states
`fibLog` and `ex_1_19` over `java.math.BigInteger` throughout, so `Fib(n)`
is correct for every `n`, including `Fib(1000)` (209 digits), the
showcase the tailored addition 1.19a probes for the exact boundary where
a checked-`Long` version would give up.
