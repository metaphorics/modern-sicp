# Exercise 2.6: Church numerals `one`, `two`, and `+`, defined directly

## Approach

`one` applies its step exactly once; `two` applies it exactly twice; and
`church_add(a, b)` builds a numeral that applies `a`'s composition of `f`
and then `b`'s, in sequence, by cloning `f` (via `Step`'s `Clone`) so both
compositions can use it. None of the three goes through
[`church_succ`](../../crates/ch02/src/sec_2_1.rs), matching the
exercise's requirement that they be direct, not built from repeated
`add-1`. The section's `Church`/`Step` wrapper-struct trick (needed to
break the type cycle a bare `type` alias for a self-referential function
type cannot express) is reused as-is, through the public `from_fn`/
`apply` methods added for exactly this purpose; only the three numerals
and the addition operator are this exercise's own work.

## Map class

`A`: the idea (numerals as functions counting applications) survives,
but the statement changes, since expressing "a numeral is a function
that applies `f`, `n` times" needs the wrapper-struct trick rather than a
bare closure type.
