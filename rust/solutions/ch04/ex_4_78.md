# Exercise 4.78: the query language on the amb evaluator (T)

## Approach

The query evaluator uses the 4.3 search process with frames. A simple
query pushes one choice frame containing the data-base matches and rule
applications. `and` threads continuations, `or` pushes its branches,
and `not` probes under a private stack. The driver returns one answer
per `try-again`.

## Map class

`T`.

## Sample answer

The book's `or` example answers depth-first -- Hacker, Fect, Tweakit,
Reasoner -- where the stream engine interleaves: Hacker, Reasoner,
Fect, Tweakit. The married cycle answers Minnie repeatedly, every
derivation route landing on the same pair.
