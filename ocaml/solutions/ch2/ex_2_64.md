# Exercise 2.64: list-to-tree, partial-tree returning a tuple (adapt)

The map class is `A`: the idea (`partial_tree` builds a balanced tree
over the first `n` elements and returns what is left) survives, but
the book's `cons` pair, holding the tree in its `car` and the
remaining elements in its `cdr`, becomes an OCaml tuple
`tree * int list`, since OCaml has no single `cons`-cell type that
both a tree and this pairing share. `partial_tree` puts roughly half
of the `n` elements (`(n - 1) / 2`) in the left subtree, takes the
next element as the entry, and puts the rest in the right subtree,
so the tree stays balanced by construction; each of the `n` elements
is visited once, so `list_to_tree` runs in `Theta(n)`.

Sample: `ex_2_64 ()`, `list_to_tree [1; 3; 5; 7; 9; 11]`, is
`Node (Node (Empty, 1, Node (Empty, 3, Empty)), 5, Node (Node (Empty,
7, Empty), 9, Node (Empty, 11, Empty)))`.
