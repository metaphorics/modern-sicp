# Exercise 2.27: `deep-reverse`

## Approach

`deep_reverse` mirrors the tree's structure in its own recursion: a
leaf is its own answer, and a branch is rebuilt by walking its children
back to front, deep-reversing each child on the way. Exercise 2.18's
`reverse` supplies the shallow rotation, and the same cons-onto-front
walk reappears one level of type depth down.

## Map class

`A`: the book's nested lists become the recursive `Nest` type, which is
exactly what the map's class prescribes for this exercise; the reverse
logic is unchanged.

## Deviation

None beyond the recursive type the map calls for.
