# Agents

- Before adapting prose, examples, or exercises, follow the conventions
  in `docs/plan/technical-modern-sicp-editions.md` (the decision register
  D1 to D36, the unit contract, the exercise policy), the per-language
  notes in `docs/plan/idiom-<language>.md`, the per-exercise tracking in
  `docs/exercise-map.md`, and the layout rules in `docs/decisions/`. [Tony Hoare]
- Before declaring a change done, run the gates the root `justfile` and
  the edition's `justfile` define. The canonical command list is the
  "Quality gates and CI" table in
  `docs/plan/technical-modern-sicp-editions.md`. [John Carmack]
