# Exercise 3.75: buggy smoothing detector fix

## Approach

Alyssa's plan extracts crossings from the signal that averages each
sense value with the previous RAW value, so the detector must compare
each new average against the previous AVERAGE. Louis's verbatim
translation shows the defect: he computes `avpt` = (head + last_value)/2,
compares it against `last_value`, and then passes `avpt` back as the
next `last_value` -- so his first comparison pits an average against the
raw seed 0, and from the second cell on his "average" blends the raw
current value with his own previous output instead of the adjacent raw
pair. The pinned ladder makes it concrete: his second average is
(2 + 0.5)/2 = 1.25 where the plan gives (2 + 1)/2 = 1.5, and the blend
leaks each old average forward forever (1.25, 1.375, 1.1875, 0.84375,
0.371875, ...), an exponential tail rather than a smoother. The fix
keeps his structure and adds the hint's third argument:
`make_zero_crossings_fixed(input, last_value, last_avpt)` computes the
same `avpt` from the raw previous value, compares it against
`last_avpt`, and recurses with the raw head and the average carried
separately. On the sense data Louis detects -1 at index 6 and +1 at
index 11, one step later than Alyssa's raw answer (5 and 10); the fixed
form answers the smoothed crossings from the correct adjacent-pair
ladder (first negative at (x5+x6)/2 = -1.05 against 0.2, first positive
at (x10+x11)/2 = 1.6 against -0.15).

## Map class

`T`. The statement translates whole. The one Rust wrinkle: the
`let`-bound `avpt` becomes a plain binding recomputed per cell, and the
recursive call clones the input stream into the tail thunk -- the
module's own persistent-spine idiom, not a data copy.

## Deviation

On this clean data Louis's crossing positions happen to coincide with
the fixed form's (6 and 11); the versions part ways in the averaging
ladder, so the test pins that ladder directly. This is a property of
the chosen sense data, not a change to the exercise: the shift against
3.74's raw answer is the visible symptom here, and the ladder pin is
the general one.
