# Exercise 3.71: Ramanujan numbers via weighted pairs

## Approach

The cube-weighted pairs of the integers, weight `i^3 + j^3`, come from
exercise 3.70's `weighted-pairs`. Because equal weights drain out of
the weighted merge consecutively, a number expressible as a sum of two
cubes in two ways shows up as two consecutive pairs of equal weight.
The scan walks the weighted stream one element at a time, and when the
weight ties with its predecessor it emits the number together with
both representations, the statement's "two consecutive pairs with the
same weight".

## Pins

Computed by running. The first six Ramanujan numbers, with their two
representations as the scan produced them:

- `1729 = 1^3 + 12^3 = 9^3 + 10^3`
- `4104 = 2^3 + 16^3 = 9^3 + 15^3`
- `13832 = 2^3 + 24^3 = 18^3 + 20^3`
- `20683 = 10^3 + 27^3 = 19^3 + 24^3`
- `32832 = 4^3 + 32^3 = 18^3 + 30^3`
- `39312 = 2^3 + 34^3 = 15^3 + 33^3`

The hits strictly increase, and in each hit both representations sum
to the same cube weight with `i <= j` in each pair.

## Map class

T (translate: syntax changes only). The mechanism is the statement's:
generate the stream of pairs weighted by the sum of two cubes, then
search for two consecutive pairs with the same weight.

## Deviation

Exercise 3.70's `merge-weighted` and `weighted-pairs` are restated in
this file because exercise files do not import from each other. The
scan reports overlapping windows, so a number with three
representations would be emitted twice; none of the first six has
more than two, so the pin list is unaffected.
