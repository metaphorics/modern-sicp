## Exercise 3.20: trace state in a procedural pair

Approach: `proceduralPair` returns an object whose methods close over two
mutable slots. `val alias = x` refers to the same object, so
`alias.setFirst(Whole(17L))` changes the value returned by `x.first()`.

Why a fresh object differs: another call to `proceduralPair` creates new
captured slots. Its initial first and second values do not change when an
earlier object is mutated.

What the tests say: mutation through an alias is visible through the
original reference. A fresh pair keeps its initial values and is not the
same object as `x`.

Class: R (the closure's captured mutable slots are the state being traced).

Deviation: the host API uses first/second selectors and mutable slot methods.
