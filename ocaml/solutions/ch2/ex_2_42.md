# Exercise 2.42: eight queens (translate)

The map class is `T`. Positions are `(row, column)` pairs, so
`empty_board` is `[]`, `adjoin_position` conses `(row, column)`, and
`safe k` finds the queen in column `k` and checks every other queen
for different row and different diagonal (`abs (r - row_k) <> abs (c
- column_k)`), which also excludes the same column case. `queens`
keeps the book's shape: filter the flatmap of adjoin-position over
rows and the recursive `queen_cols (k - 1)`.

Samples: `ex_2_42 8` has length 92, the classic count of eight-queens
solutions; `ex_2_42 6` has 4.
