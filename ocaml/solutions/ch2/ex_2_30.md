# Exercise 2.30 — square-tree (adapt: recursive tree type)

The map class is `A` (map row: "recursive tree type replaces nested
lists"). `ex_2_30_direct` squares leaves and recurses over the child
list with a `fold_right` cons, with no higher-order procedure doing
the recursion for it. `ex_2_30_map` is the second shape of the main
text: map a function over the children that squares a leaf and
recurses on a node. Both produce the statement's
`Node [Leaf 1; Node [Leaf 4; Node [Leaf 9; Leaf 16]]; Leaf 25; Node
[Leaf 36; Leaf 49]]` on the book's input.
