# Exercise 4.73: `flatten-stream`'s explicit `delay` (translate)

The undelayed `flatten-stream` the exercise proposes computes
`flatten-stream` of the input's `stream-cdr` as an ordinary argument,
so it must unroll the whole input stream of streams before the first
output element exists. The delayed base evaluator keeps the rest behind the
thunk of `interleave_delayed` and serves the head stream immediately.

The solution realizes both on the base evaluator's stream layer. On a
finite input the two agree element for element: the delay changes
demand, not order (`delayed_finite_first4` and
`undelayed_finite_first4` both `1 2 3 4`). On the infinite frame
streams that recursive rules produce, the undelayed flatten diverges
before answering anything. A hanging query cannot be pinned, so the
layer demonstration makes the demand observable with a sentinel: the
input stream of streams `[1; <divergent rest>]` raises a local
`Divergent_rest` when its second tail is forced. The delayed
`flatten_stream` serves `1` without touching that tail; the undelayed
flatten raises before any element exists: the raised sentinel marks
exactly the computation that would loop in vivo. The real-engine
demonstration runs the delayed system on an `and` whose first conjunct
is 4.72's infinite swap-rule stream, so the second conjunct's
`stream-flatmap` genuinely faces an infinite input stream of streams;
the delayed engine answers (pinned below), and the undelayed twin of
this very query is the case that would hang.

Asserted pins:

```
delayed_and_first4
(and (loves (Minnie Mouse) (Mickey Mouse)) (job (Hacker Alyssa P) (computer programmer)))
(and (loves (Mickey Mouse) (Minnie Mouse)) (job (Hacker Alyssa P) (computer programmer)))
(and (loves (Minnie Mouse) (Mickey Mouse)) (job (Fect Cy D) (computer programmer)))
(and (loves (Minnie Mouse) (Mickey Mouse)) (job (Hacker Alyssa P) (computer programmer)))
delayed_finite_first4=1 2 3 4
undelayed_finite_first4=1 2 3 4
finite_orders_agree=true
delayed_sentinel_first=1
undelayed_diverged_before_first_answer=true
```

Deliberate deviation: the sentinel raise stands in for an infinite
loop, which no test suite can pin; the rationale states this
explicitly rather than hiding it. The fourth `delayed_and_first4` row
repeats the first matching: the interleaved combination serves
frame-streams round-robin, and the pinned order is the engine's.
