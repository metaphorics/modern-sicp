# Exercise 5.10: a new surface syntax behind the datum seam (T)

## Approach

The new syntax keeps the instruction keywords but drops the
wrappers: bare symbols name registers, bare numbers and booleans
are constants, `test` and `perform` name their operation bare in
head position (`(test = b 0)`), `branch` and `goto` take a bare
label (`(goto test-b)`), an assign whose head-of-source is a bare
operation name (`(assign t rem a b)`) is an operation application,
and a lone bare symbol source (`(assign n val)`) stays a register.
Label sources keep the wrapped `(label l)` form, and register
targets of `goto` keep `(reg r)`, so the grammar stays
unambiguous. A translator in the solution module turns the new
lines into the book's datums and hands them to
`make_machine_from_datums`; the assembler and machine are
untouched, which answers the book's structural question.

## Map class

`T`.

## Sample answer

The translation of the new-syntax GCD controller equals the
book-syntax controller datum for datum; the translated GCD answers
2 on 206 and 40, and the full Fibonacci controller in the new
syntax answers 8 on 6.
