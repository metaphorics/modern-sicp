# Exercise 5.31: which evaluator saves are superfluous

The analysis walks one compiled program and pairs each save with its restore, then asks the liveness question the compiler's needs and modifies sets answer: does the protected region rewrite the register before the restore? A save whose register is untouched across its region keeps the old value alive for nothing, and that is the superfluous one the exercise asks about.

The report gives one line per save with its verdict, and the tests pin both verdicts appear: the classification is computed from the compiled statements, not asserted from a list.
