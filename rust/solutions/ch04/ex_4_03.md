# Exercise 4.3: data-directed dispatch in eval (T)

## Approach

`TableDriven` keys the crate's `OpTable` registry by operation `eval` and the
expression's head symbol; the element type is a clause that receives the
expression, the environment, and the dispatcher, which the runtime `Handler`
cannot carry. Self-evaluating forms and variables stay as residual tests (they
dispatch on the datum, not a tag, exactly the 2.73 lesson); everything else
looks up the table, and a miss is the leftover application clause. A new form
`unless` installs at runtime with no edit to the dispatcher.

## Map class

`T`, with the table on the crate's put/get registry shape (D19).

## Sample answer

`(quote (a b))` gives `(a b)`, the table-dispatched `if` gives 42, the defined
call gives 49, and the installed `unless` gives `ran`.
