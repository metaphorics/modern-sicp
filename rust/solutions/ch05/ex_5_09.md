# Exercise 5.9: forbid labels as operation operands (T)

## Approach

The operand grammar for operation inputs admits `(reg r)` and
`(const c)` only; a `(label l)` input is refused at assembly time
with the typed `LabelOperand`, naming the operation and the label.
Assign sources keep their own `(label ...)` case, since a label is
a legitimate assign source. The check runs per input while the
execution procedure is built, so a bad operand stops the machine
before it can start.

## Map class

`T`.

## Sample answer

`(op +)` over `(reg b)` and `(reg c)` still answers 5; `(op +)
(reg b) (label there)` fails with `an operation input of "+" is a
register or a constant, not the label "there"`.
