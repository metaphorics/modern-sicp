# Exercise 4.49: sentence generation (T)

## Approach

Alyssa's change is one procedure: `parse-word` ignores `*unparsed*` and
answers `(list (car word-list) (an-element-of (cdr word-list)))` -- the
tag with an ambiguous word. The parsing programs then generate, and the
driver's `try-again` walks the sentences in search order. The footnote's
"boring" recursion is visible in the sample: the search retries the
rightmost choice (the verb) first because its frame sits deepest, so
the leftmost choice (the article) barely varies.

## Map class

`T`.
