# Exercise 5.40: threading the compile-time environment (T)

## Approach

Each closure and block extends the environment with its own frame, so the factory's parameter wins inside the closure while the outer binding stays visible outside. The adder closes over `3` and ignores the outer `100`; the outer `x` still reads `100` after the call on both engines.

## Map class

`T`.

## Sample answer

Both engines print `7` then `100`.
