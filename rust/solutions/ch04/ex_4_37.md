# Exercise 4.37: Ben's triple generator efficiency (T)

## Approach

The book's program chooses `i`, `j`, and `k`, applies `i <= j <= k`, then
tests whether the legs and hypotenuse form a Pythagorean triple. Its
`candidate` events count ordered triples that reach that final test.

Ben chooses only `i` and `j` with `i <= j`, computes `k = sqrt(i² + j²)`,
and accepts it only when the root is exact and within the bound. For
positive legs, `k >= j` follows automatically. Both programs therefore
produce the same triples, but Ben tests fewer candidates because he does
not enumerate `k`.

## Map class

`T`.

## Sample answer

The answer sets match. The number of `candidate` events is smaller for Ben's
program.
