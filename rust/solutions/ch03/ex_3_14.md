# Exercise 3.14: mystery reverses in place

## Approach

The book traces `mystery` over `v = (a b c d)` and asks for `v` and
`w` afterward. The Rust solution runs `reverse_in_place` and prints
both names after the call: `w` is `(d c b a)`, and `v`, which still
names the first cell of the old chain, is `(a)`. The walk takes each
cell's `cdr` one at a time and rewrites it to point backward, so the
four cells survive with their pointers turned around. The tests add
the one-element case, where the loop answers the same cell it was
given.

## Map class

`A: in-place pair mutation via RefCell`. Every rewrite is a
`set-cdr!` on a shared `Rc` cell, and the contrast between the two
printed answers is the mutation seen from the two handles that name
its two ends.

## Deviation

None. The book's interaction and both answers are kept exactly.
