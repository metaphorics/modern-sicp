# Exercise 3.80: the series RLC circuit as coupled integrals

## Approach

`rlc(r, l, c, dt)` returns the state-builder closure: the capacitor
voltage integrates `- iL / c` (the integrand stream is
`scaleStream(iL, -1.0 / c)`) from `vC0`, and the inductor current
integrates `(vC - r iL) / l` (a `zipStream` pairing `vC` with `iL` and
mapping `(v - r * i) / l`) from `iL0`. The two loops close together
because each integrand is tied before any tail can force it, the same
tie-before-force discipline as `solve2nd`. Pins for the book's circuit
`r = 1, c = 0.2, l = 1, dt = 0.1, vC0 = 10, iL0 = 0`: `vC` at steps
5, 10, 20, 30, 50 is `5.5955, -3.5160605800000004, -2.547583716974599,
4.59751360693207, 0.15526261365409222` and `iL` is `3.6461,
2.750945989, -2.691268933365921, 0.9857934876496868,
-1.2231501590473282`, probed from the compiled solution and re-derived
bit-identically in a python3 same-order script (`vc += dt * ((-1/c) *
il)` and `il += dt * ((vc - r*il)/l)`, each step reading the old pair).
The oscillation decays: the maxima of `|vC|` over successive
extremum-aligned windows are `10.0, 4.59751360693207, 1.6854674625828383`,
strictly decreasing as the resistor dissipates energy.

## Map class

`T` (map row 3.80: two coupled integral loops returning a pair).

## Deviation

The integrand orders follow the contract's phrasing, `(vC - r iL) / l`
as one division and the capacitor scaling as a single multiply by
`-1/c`, rather than the figure's separate `1/L` and `-R/L` scaler boxes;
the python3 check mirrors the chosen order exactly.
