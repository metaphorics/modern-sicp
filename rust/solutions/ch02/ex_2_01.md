# Exercise 2.1: a sign-normalizing `make-rat`

## Approach

The reference solution builds on `Rational::new`, which already reduces
its arguments to lowest terms with `gcd` (the fix given earlier in
2.1.1), but does not normalize which part carries a negative sign. This
exercise's `make_rat` calls `Rational::new`, then checks the reduced
denominator: if it is negative, both the numerator and the denominator
are negated (with `checked_neg`, since `i128::MIN` has no positive
counterpart), moving the sign onto the numerator. The test checks all
four sign combinations of `1 / 2`.

## Map class

`T`: the statement translates directly (build a rational number whose
sign lives on the numerator), and the solution is a straightforward
extension of the section's own `gcd`-reducing constructor.

## Deviation

None. `ch02::sec_2_1::Rational::new` deliberately ships without the sign
fix, so this exercise's contribution is real rather than pre-solved by
the main text.
