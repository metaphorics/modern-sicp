# Exercise 4.43: yacht puzzle (T)

## Approach

Each daughter draws a father with `amb`; the five assignments must be
distinct. Melissa's father is Sir Barnacle (the story states it).
When the puzzle gives Mary Ann's surname, her father is Mr. Moore.
The program requires all five yacht namings to be distinct. The story
fixes four: Moore the Lorna, Downing the Melissa, Hall the Rosalind,
and Barnacle the Gabrielle. Parker's yacht draws the one daughter
name left. The closing sentence
-- Gabrielle's father owns the yacht named after Dr. Parker's daughter
-- is one final `require` comparing the naming table with the father
table. Efficiency follows 4.40's lesson: the program requires each
stated fact before the search descends.

## Map class

`T`.

## Sample answer

Told Mary Ann's surname: one solution, Lorna's father is Downing. Not
told: two solutions, Downing and Parker.
