Exercise 1.44 (translate): `smooth(f, dx)` averages `f` at the point and its two neighbors; the n-fold smoothed function is built by repeatedly wrapping an owned `Rc<dyn Fn(f64) -> f64>`, the same construction `repeated` uses in exercise 1.43, since "smooth the smoothed function" is again a composition of procedures with each other rather than of numbers. Smoothing a linear function changes nothing (`f(x - dx) + f(x) + f(x + dx)` averages back to `f(x)` when `f` is linear); smoothing `x^2` twice adds `4 dx^2 / 3` at every point, because each application of `smooth` adds `2 dx^2 / 3` to a quadratic and the two applications add independently. No deviation.
