Exercise 5.47: compiled code calls interpreted procedures.

Every non-saturated-primitive call goes through the runtime's
`compiled-apply`, which knows only primitives and compiled procedures.
The modified runtime adds the third branch: a closure is handed to the
evaluator's `apply-entry`, which saves `continue` and enters
`apply-dispatch` as an interpreted call, returning through `continue`.
The book routes the entry through a `compapp` register because its code
is assembled apart; here the runtime shares the controller and jumps to
the label. Without the branch the session errors (`not applicable:
closure is not a procedure`); with it `apply_twice add6 0` answers 12,
interpreted `add6` or fully compiled alike.
