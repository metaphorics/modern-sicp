# Exercise 5.43: scanning out internal definitions (T)

## Approach

Compile the same procedure with the ordinary compiler and with the
`scan_out` option. The latter rewrites the body's internal definitions
as unassigned local bindings followed by assignments, instead of
emitting runtime `define-variable!` operations within the body. Run the
rewritten program to check that its definitions still provide the
expected values.

## Map class

`T`.

## Sample answer

The procedure defining `a = 1` and `b = 2` returns `3`. In the scanned
instruction text, the bindings are initialized to `*unassigned*` and
then assigned, and there is no compiled `define-variable!` operation
for those internal definitions.
