# Exercise 2.45 — the split combinator (adapt: polymorphic
combinator)

The map class is `A` (map row: "split returns polymorphic
combinator"). `ex_2_45_split combine sub_combine painter n` recurses
on `combine painter (sub_combine smaller smaller)`, so
`ex_2_45_split beside below` is `right_split` and
`ex_2_45_split below beside` is `up_split`. The tests pin both
identities structurally: the split instances produce the same
segment lists as the direct definitions when painted into the unit
