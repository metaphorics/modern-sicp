# Exercise 1.38: Euler's e expansion

## Approach

Euler's denominators are 1 everywhere except at indices `i = 2, 5, 8, ...`
(every third, starting at 2), where the value is `2, 4, 6, ...` - that is,
`D_i = 2(i + 1)/3` when `(i + 1)` is divisible by 3, and `1` otherwise. The
fraction runs through the loop `contFracIter` of exercise 1.37 with all
numerators 1, and `e = 2 + fraction`.

## Numbers

`eApprox(5)` is `2.71875` (three correct digits), `eApprox(13)` is
`2.718281828735696` (nine correct digits), and `eApprox(20)` is
`2.718281828459045` - the very double `Math.E` holds, so the test can assert
equality with the host constant.
