# Exercise 3.6: rand with generate and reset messages

## Approach

The book's two symbols become the variants of `Command`: `Generate` advances
the hidden word with `rand_update` and answers the new value, `Reset(v)`
overwrites the word and answers nothing. The generator is a small struct, so
the reset genuinely reaches the same state that `Generate` advances — the
reachability the exercise is about. The test checks the replay property
(three draws, reset to the seed, three draws: identical) and the contrast
(reset to a different word changes the continuation), then pins the exact
mechanism: the first draw after `Reset(x)` is `rand_update(x)`.

## Map class

`T`: the statement translates directly, with message-passing expressed as an
enum handled by `match`.

## Deviation

The book's `((rand 'reset) new-value)` returns a procedure; here one message
carries the new value directly, which the enum makes natural.
