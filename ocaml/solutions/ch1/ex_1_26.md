# Exercise 1.26: Louis's doubled expmod calls (translate)

The map class is `T`; the argument about call-tree branching applies
identically to OCaml.

Eva is right. The section's `expmod` computes `expmod base (exp / 2) m`
once on an even exponent and squares the result; Louis's version calls
`expmod base (exp / 2) m` twice and multiplies the two calls together.
Each of those two calls is itself a full recursive evaluation, not a
reused value, so at every even level of the recursion the number of
live branches doubles. Over the `Theta(log n)` levels the recursion
passes through, that doubling compounds: `2^(Theta(log n))` is
`Theta(n)`. Louis has turned a call tree with one path from root to leaf
into a call tree with exponentially many, one for every combination of
branch choices. Squaring turns a `Theta(log n)`-deep chain into a
`Theta(n)`-sized tree.

`expmod_square_calls 4 64 97` counts 8 calls (the section's version, one
recursive call per level down a tree with `exp` a power of 2); `
expmod_double_calls 4 64 97` counts 191 (Louis's version). Both compute
the same value, 35, at wildly different cost, a call-count ratio of
about 24, growing without bound as `exp` grows, which is exactly the
`Theta(n)` versus `Theta(log n)` gap the argument predicts.
