# Exercise 4.19: internal-definition scoping debate (T)

## Approach

The sequential model evaluates `b` after `a` is already visible; the scan-out
model evaluates `b` before the later `a` assignment can run. Each position is
implemented separately so the disagreement is an observable result rather than
a prose preference.

## Map class

`T`.

## Sample answer

Sequential evaluation answers `16`; scan-out reports that `a` is read before
its definition runs.
