# Exercise 2.69: successive merge

## Approach

`successiveMerge` repeatedly merges the first two (smallest-weight)
elements of the ordered set with `makeCodeTree` and reinserts the merged
node by weight with the section's weighted `adjoinSet`, until one tree
remains. The ordered set does all the work: no searching, just the
front of the list.

## Numbers

For the book's pairs `[[A, 4], [B, 2], [C, 1], [D, 1]]`, the leaf set comes out
`[[D, 1], [C, 1], [B, 2], [A, 4]]`: `makeLeafSet` adjoins the last pair
first, and equal weights insert after. The merges then rebuild the
book's sample tree exactly: `{D C}` under B, the result under A. The
test asserts the generated tree deep-equals exercise 2.67's
`sampleTree`.

## Map class

T (translate).

## Deviation

Empty input returns an error through `Result` instead of the book's
undefined behavior on the empty set.
