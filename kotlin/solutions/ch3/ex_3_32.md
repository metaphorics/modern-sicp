## Exercise 3.32: why a segment's actions must run first in, first out

Approach: the pinned order, straight from the code: two actions added
to one agenda segment at time 5 run as `["first", "second"]`, because
`ActionQueue.insert` appends at the rear and `delete` removes from the
front: the 3.3.2 queue's two-pointer discipline, so the oldest
scheduled action in a segment is always the next one run.

Why the order must be FIFO: an action's output depends on the wire
state it observes when it runs, and actions scheduled into the same
segment are responses to changes that all land at the same simulated
instant. They must run in the order their causes happened, oldest
first, so each action sees the accumulated state of all the changes
scheduled before it. The exercise's and-gate trace makes the failure
mode concrete: inputs a1, a2 at 0, 1 change to 1, 0 in the same time
segment. Each change runs the gate action the moment it lands,
and the gate reads the wires as they stand then: the a1 change sees a2
still at 1 and schedules `out = and(1, 1) = 1` at t + 3, first in the
segment; the a2 change, second in, schedules `out = and(1, 0) = 0`.
Run FIFO, the gate applies 1 then 0 and settles at the and of the
inputs' actual final values: 0, correct. Run LIFO (a plain list,
added and removed at the front), the a2 response would run first and
the a1 response second (the order of causes reversed), so the
update computed from the stale reading (1, 1) is the one that lands,
and the output is left at the gate's superseded value, 1. The agenda
is the simulator's notion of causality; LIFO would run effects before
their causes within an instant.

What the tests say: `E3_32Test.kt` pins the two-action same-segment
order, then pins the full deletion order across two segments (time 3's
pair before time 5's, each pair FIFO): `propagate` drains segments in
time order and hands each segment's actions back oldest-first, ending
with the agenda empty. The gate demonstration is `fifoResult()` and
`lifoResult()`: the section's own and-gate wired over the book's
scenario (settle the inputs at (0, 1), move both inside one segment
) settles at 0, while the identical circuit over a LIFO comparison
agenda leaves 1, the superseded value. That is the whole discipline:
time orders the segments, the queue orders the actions inside one.

Deviation: none.
