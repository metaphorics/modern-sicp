# Exercise 4.10: new syntax, unchanged eval (T)

## Approach

Surface forms are desugared before dispatch. `Defun` and `Fun` both become a
core definition; `Apply` becomes a core call. The core evaluator only sees its
own typed forms, so a raw surface spelling is not a hidden evaluator feature.

## Map class

`T`.

## Sample answer

Desugaring `Defun(square)` followed by `Apply(square, 7)` answers `49`; a core
call to `defun` remains unbound.
