# Exercise 4.33: quote produces lazy lists (T)

## Approach

With the 4.2.3 procedural `cons`/`car`/`cdr` defined, the plain evaluator's
quoted lists are ordinary data: the procedural `car` messages its argument and
`(a b c)` is not applicable. The fix reroutes quote handling on the same seam: a
quotation of a non-empty proper list lifts into the `cons` chain of its quoted
elements, so the driver's quoted lists are true lazy pairs; atoms, the empty
list, and dotted tails stay ordinary.

## Map class

`T`.

## Sample answer

Plain: `(car '(a b c))` -> "not a procedure: (a b c)". Lifted: `(car '(a b c))`
-> a, `(car (cdr '(a b c)))` -> b, `(list-ref '(a b c d) 3)` -> d.
