# Exercise 4.22: let in the analyzed evaluator (T)

## Approach

`LetAnalyzer` implements the analyzer seam: a let analyzes into the analysis of
its combination, so the rewrite runs once at analysis time and the base
analyzer is untouched. The base analyzer rejects `let` (it falls into the
application clause and the operator lookup fails), which is what the extension
fixes. A lambda whose body holds a let analyzes once and answers correctly on
every call.

## Map class

`T`.

## Sample answer

`(let ((x 3) (y 4)) (+ x y))` is 7; `(g 2)` with an internal let is 5 on both
calls.
