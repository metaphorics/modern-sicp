# Exercise 1.43 — n-fold repeated application (translate)

The map class is `T`. `repeated f n` follows the book's hint, folding
`n` copies of `f` together with exercise 1.42's `compose`, starting
from the identity function so `repeated f 0` is the identity. `square`
applied twice raises its argument to the 4th power, so
`(repeated square 2) 5 = 5^4 = 625`, matching the book's own
`((repeated square 2) 5) => 625`. `ex_1_43 () = 625`.

The map's tailored addition 1.43a (compose by squaring for logarithmic
repeated application) was claimed by the Kotlin edition; this
edition's one addition is 1.46a instead.
