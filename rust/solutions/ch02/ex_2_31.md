# Exercise 2.31: `tree-map`

## Approach

`tree_map` takes the leaf operation as a function parameter and keeps
the traversal from 2.30; `square_tree` is then a one-line call. The
operation parameter is `Copy` because the recursive calls carry it down
unchanged, and the squaring closure captures nothing.

## Map class

`A`: generic tree map over the recursive type.

## Deviation

None.
