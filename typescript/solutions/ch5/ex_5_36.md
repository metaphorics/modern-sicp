# Exercise 5.36: operand evaluation order in the compiler

The operand list of a call is built by one construction, and the exercise writes both readings of it: the book's default evaluates the operands right to left, the last operand initializing the argument list and the earlier one adjoining onto it; the alternative goes left to right, adjoining each argument at the end. The two constructions are the same size statement for statement, which is the measurement the exercise asks for.

The shipped compiler's own listing for the two-operand call is printed beside them, so the order can be read off real compiled code rather than assumed.
