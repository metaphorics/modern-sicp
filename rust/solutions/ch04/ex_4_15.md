# Exercise 4.15: halting-problem diagonal (T)

## Approach

A bounded typed machine gives the diagonal argument an observable witness. A
verdict that says the diagonal halts sends the program into the diverging
branch and exhausts the budget; the opposite verdict reaches the halting
branch. Neither verdict can satisfy its own contract.

## Map class

`T`, with the bounded probe carrying the proof.

## Sample answer

The optimistic verdict reports budget exhaustion; the pessimistic verdict
returns normally.
