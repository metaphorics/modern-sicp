# Exercise 2.49: primitive painters

## Approach

The outline is the four sides of the unit square; the X is its two
diagonals; the diamond joins the four side midpoints; and the wave is
`wave_segments` fed through `segments_painter`, the construction the
exercise asks for. Each painter is a frame-to-segment function, so all
four work under any frame transformation for free. The test pins the
segment counts (4, 2, 4, 18), and a freshness test compares each
painter's SVG rendering byte for byte against the checked-in figure the
example generator wrote under `book/figures/generated/chap2/`.

## Map class

`T`: the statement translates directly; the map's "painter output as
SVG strings" idea is the edition's main-text convention (2.2.4 draws to
SVG rather than a graphics terminal), not a tailored addition.

## Deviation

The wave's segment list is this solution's own hand-drawn set, distinct
from the spine's given `wave`, so the exercise is not pre-solved by the
main text.
