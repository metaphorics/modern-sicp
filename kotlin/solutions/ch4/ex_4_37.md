# Exercise 4.37: Ben's generator

## Approach

Ben computes instead of choosing: `hsq >= ksq` prunes each (i, j)
branch before any third choice point, and the exact integer-square-root
test replaces the k choice outright (the square root is computed, not
chosen). The counts use the edition's backtrack metric: one per failure
resumption that delivers an alternative, counted to the first answer.
The object-language helpers stay deterministic, so the search trees are
identical to any other realization of the two programs.

## Map class

triple, roughly a ninth of the work) with this engine's own counts.

## Deviation

`isqrt-or-false`; float square roots would make the integrality test
clippy, and the deterministic check leaves the search tree unchanged.
