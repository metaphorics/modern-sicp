# Exercise 1.45: n-th roots, repeated damping (translate)

The map class is `T`. `nth_root n n_damps x` searches for a fixed
point of `y -> x / y^(n - 1)`, average-damped `n_damps` times via
`repeated average_damp n_damps` (exercise 1.43's `repeated`, folded in
locally); at `n_damps = 0` this is the undamped search the section
shows diverging for square roots.

`damps_needed n` runs the experiment the exercise asks for: starting
from `1` damp, it tests whether `nth_root n damps 2.` lands within
`0.001` of a genuine `n`th root of `2.` (checked by raising the result
back to the `n`th power), and returns the first damp count that
passes. Measured this session at `x = 2.`, `guess = 1.`:

| n | damps needed | n | damps needed |
|---|---|---|---|
| 2 | 1 | 9 | 3 |
| 3 | 1 | 10 | 3 |
| 4 | 2 | 11 | 3 |
| 5 | 2 | 12 | 2 |
| 6 | 2 | 13 | 3 |
| 7 | 2 | 14 | 3 |
| 8 | 1 | 15 | 2 |
| 16 | 4 | | |

This tracks the well-known `floor(log2 n)` guideline loosely (`n = 4`
needs 2, `n = 16` needs 4) but not exactly: `n = 8` converges with a
single damp and `n = 12` and `n = 15` with fewer damps than
`floor(log2 n)` predicts, for this particular `x` and starting guess.
`floor(log2 n)` is a sufficient bound, not a tight one; a different `x`
or guess can shift the exact count the book's "some experiments" turn
up, which is the honest result of actually running the search rather
than asserting the textbook figure.
