# Exercise 4.32: lazy lists versus streams (T)

## Approach

Lazy pairs are explicit `Pair` data with delayed tails. `First` and `Rest`
demand only the part they need, so a list can be built and inspected
selectively without forcing the whole structure.

## Map class

`T`.

## Sample answer

The first element is `1`; forcing only the rest leaves the second thunk
unevaluated.
