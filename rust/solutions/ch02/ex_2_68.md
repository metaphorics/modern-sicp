# Exercise 2.68: `encode-symbol`

## Approach

`encode_symbol` walks toward the leaf holding `symbol`: `false` for a
left turn, `true` for a right turn, checking at each node which
branch's symbol set contains the target and erroring if neither does
(a symbol absent from the whole tree). `encode` accumulates
`encode_symbol`'s bits for every symbol of a message, matching the
book's given definition. Encoding exercise 2.67's decoded message
(`A D A B B C`) reproduces the original `sample_message` bit string
exactly, and encoding an absent symbol (`Q`) is an error rather than
silently doing nothing.

## Map class

`T`: translates directly; the book gives `encode`'s shell and asks for
`encode-symbol`.

## Deviation

This exercise keeps its own local `HuffmanTree`/`make_leaf`/
`make_code_tree`, independent of the section library's already-working
`encode_symbol` (which the library needs so its own `encode` listing
compiles and runs), so the exercise's actual contribution (writing
`encode-symbol`) is real code, not a re-export.
