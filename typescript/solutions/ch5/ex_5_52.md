# Exercise 5.52: the compiler emits C

The C backend walks the compiler's typed instruction stream in order, label markers included, and emits each statement over the backend runtime: registers are globals, a continue register holds label-address words, operation calls nest recursively as C expressions, and MachineValue constants map onto the runtime's constructors with double numbers. The emitted forms are appended after the runtime file and the whole translation unit builds to the guest interpreter in C.

The guest self-interpreter source is the edition's checked guest evaluator source; the compiler compiles it, the backend emits it, and the built interpreter answers the same session the direct evaluator answers, so the comparison is against engine-observed output and never a handwritten expectation. No generated JavaScript and no host eval stand in for the teaching compiler.
