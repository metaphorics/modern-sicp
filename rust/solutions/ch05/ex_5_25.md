# Exercise 5.25: normal-order evaluation in the controller (T)

## Approach

The strict slice expresses laziness with explicit thunks: a boxed closure whose body runs only when called. The chooser forces exactly one branch, so the never-used division never runs while the demanded branch answers. Forcing the same division directly traps, proving laziness defers the failure instead of removing it.

## Map class

`T`.

## Sample answer

Both engines print `42` and `7` with no trap. The forced division traps on both engines.
