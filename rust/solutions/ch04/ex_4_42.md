# Exercise 4.42: liars puzzle (T)

## Approach

Each girl makes one true and one untrue statement, so each pair of
claims is an exclusive or. The program defines `one-true` as
`(if p (not q) q)`, assigns the five examination places with `amb`,
requires the places distinct, and requires one girl's letter per
`require`, in letter order. The search keeps the single assignment
where every letter holds.

## Map class

`T`.

## Sample answer

`((betty 3) (ethel 5) (joan 2) (kitty 1) (mary 4))`, then exhaustion.
