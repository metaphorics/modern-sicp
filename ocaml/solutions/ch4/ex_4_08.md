# Exercise 4.08: named let

The map class is `T`. A named `let` binds its name, within its body, to a procedure over the binding names, then calls it on the inits, which run in the enclosing scope. It derives into `(let rec name p1 ... pn = body in name) e1 ... en`; a named `let` with no bindings takes one unit parameter applied to `()`. `let_to_combination` extends the 4.6 transformation to both `let` forms.

Sample: `ex_4_08 ()` answers `["55"; "12"; "7"; "10"]`: the book's iterative Fibonacci at 10, a plain `let`, a named `let` whose init names an outer variable shadowed by its parameter, and the empty named `let`.
