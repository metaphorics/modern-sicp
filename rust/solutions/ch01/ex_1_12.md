# Exercise 1.12

`pascal(row, col)` translates the book's rule directly: the edges of each
row (`col == 0` or `col == row`) are 1, and every interior element is the
sum of the two elements above it, `pascal(row - 1, col - 1) + pascal(row -
1, col)`. Counting from zero, row 4 is `1 4 6 4 1`, so `pascal(4, 2) = 6`;
row 6 is `1 6 15 20 15 6 1`, so `pascal(6, 3) = 20`; row 0 is just `1`, so
`pascal(0, 0) = 1`. The map class is `T`: the recursive definition survives
the translation unchanged, only `define` becomes `fn`.
