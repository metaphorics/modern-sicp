# Exercise 4.32a (this edition): lazy tree, selective forcing (T)

## Contract

`lazy-memo/1` over explicit `LazyExpr::{Pair,Thunk,Force,Apply}` tree data.

## Lesson

The tree's two children are thunks carrying independent effects. Selecting
and forcing the left child emits only `root-left`; the right thunk remains
delayed because the branch was never visited.

## Map class

`T`.

## Sample answer

The effect log is exactly `root-left`; `root-right` never appears.
