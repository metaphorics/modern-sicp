# Exercise 5.15: instruction counting

The counting machine is the first use of the per-instruction seam:
`makeCountingMachine` passes an `onInstruction` hook that advances a
counter before each executed instruction, transfers included. The
counter is read after the run, the way Alyssa's monitor would report
it, and the exercise pins the gcd machine at 26 instructions for
gcd(206, 40) and the figure 5.11 factorial at 49 for n = 5.

The same hook counts the figure 5.12 Fibonacci machine, and the test
pins the boundary behavior: the base case runs 5 instructions (the
initial assign, the test, the branch, the base assign, and the return
goto), so fib(0) and fib(1) each count 5, while the whole computation
runs 28 for fib(2), 51 for fib(3), and 281 for fib(6).

The book's print-and-reset message exists as `printInstructionCount`:
it appends the count to the machine's transcript, returns it, and
zeroes the counter. The test pins a factorial(3) run: the message
answers 27, the transcript carries the single line "27", and the
counter reads 0 afterwards, so a later count measures only later runs.
