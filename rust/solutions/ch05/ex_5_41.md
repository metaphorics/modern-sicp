# Exercise 5.41: finding lexical addresses (T)

## Approach

Search the compile-time environment from its innermost frame outward.
A found address is the zero-based frame distance and the variable's
zero-based position within that frame; names absent from all frames
return `not-found` for global-lookup fallback.

## Map class

`T`.

## Sample answer

For `((y z) (a b c d e) (x y))`, `c` has address `(1 2)`, `x` has
address `(2 0)`, and `w` returns `not-found`.
