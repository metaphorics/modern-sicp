# Exercise 1.42: function composition

## Approach

`compose(f, g)` returns `x => f(g(x))`: `g` first, then `f`, per the
statement's "f after g".

## Numbers

The statement's example holds: `compose(square, inc)(6)` is `49`. Reversing
the arguments gives `compose(inc, square)(6) = 37`, and the identity function
is neutral on both sides.
