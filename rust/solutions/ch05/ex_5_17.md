# Exercise 5.17: labels announced in the trace (T)

## Approach

Each assembled slot keeps the labels that immediately precede it
(retained at `extract-labels` time), and the tracer prints those
label lines before the instruction text. The work happens beside
the count, so the instruction count of 5.15 is untouched.

## Map class

`T`.

## Sample answer

The label-traced fib(3) run: 63 transcript lines, 51 instruction
lines and 12 label lines; the label sequence is fib-loop three
times, immediate-answer, afterfib-n-1, fib-loop,
immediate-answer, afterfib-n-2, afterfib-n-1, fib-loop,
immediate-answer, afterfib-n-2, and the count is still exactly
51.
