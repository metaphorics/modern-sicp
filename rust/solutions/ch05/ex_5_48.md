# Exercise 5.48: adding `compile-and-run` (T)

## Approach

Install `compile-and-run` as a runtime primitive in the evaluator. It
compiles its quoted expression with return linkage and records the
resulting code block. Because this machine assembles a fixed controller
before execution, the exercise then builds a machine containing that
block and runs it through the evaluator controller.

## Map class

`T`.

## Sample answer

Calling `compile-and-run` on the factorial definition returns `ok`.
Running the compiled definition on the second evaluator returns `120`
for `(factorial 5)`.
