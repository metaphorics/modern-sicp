# Exercise 2.41: ordered triples summing to s

## Approach

Three nested range enumerations produce every ordered triple of
positive integers up to `n`; a filter keeps the triples with distinct
components, and a second filter keeps those summing to `s`. It is the
`unique-pairs` pattern one dimension deeper, which is the direction the
section's nested-mapping subsection points.

## Map class

`T`: the statement translates directly.

## Deviation

The test uses `n = 4`, `s = 9`, whose six solutions are the
permutations of 2, 3, and 4.
