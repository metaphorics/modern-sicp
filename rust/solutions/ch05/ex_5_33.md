# Exercise 5.33: compiling the alternative factorial (T)

## Approach

Compile the book's recursive factorial and `factorial-alt`, whose
multiplication places `n` before the recursive call. The code summaries
count emitted statements and save sites; separate `compile-and-go`
runs check the results. Moving the recursive call changes which
operand value must remain live while that call executes, so the
compiler's save and restore sequence can differ even though the
mathematical recurrence is equivalent.

## Map class

`T`.

## Sample answer

Both `(factorial 5)` and `(factorial-alt 5)` produce `120`. The ordinary
factorial compilation has 79 statements. The alternative's statement
and save-site counts are generated from its compiled sequence, rather
than pinned as constants, because the point is to inspect the
register-liveness difference.
