# Exercise 5.49: a read-compile-execute-print loop

`readCompileExecutePrintRuns` owns one `Compiler.session()` and
submits two source forms. The first defines `square` and runs a
zero-argument entry that prints 144. The second defines `twice` and
runs another entry that calls both `twice` and the **previously
defined** `square`; it prints 882.

`appendAndRun` admits the cumulative source before allowing the new
form's effects, appends only its new machine instructions at a
halted boundary, and returns only this turn's printed output.
The solution retains the first turn's `session.machine` and verifies
identity with the second turn's machine. Definitions, registers,
stack and environment are therefore live across the two turns rather
than reconstructed by rerunning an accumulated source program.
