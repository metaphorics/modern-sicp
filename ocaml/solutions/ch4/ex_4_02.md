# Exercise 4.02: dispatch order and the call language

The map class is `T`. Part (a) is Louis's reordered dispatch, testing for an application first by asking only whether the node has subexpressions, the analogue of testing for a pair. A binding such as `let x = 3 in x` is then read as the application of `3` to `x`, which fails with an unbound variable. Part (b) is the deliverable: an evaluator in which only an application headed by the variable `call` applies, every other application being an invalid form. Guest programs stay typed OCaml by defining `let call f = f`.

Sample: `ex_4_02 ()` answers the three Louis misreadings, then `"42"`, `42`, `120`, and the rejection of a plain application.
