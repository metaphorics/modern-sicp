## Exercise 0.1: three Scheme sessions in Kotlin

Approach: each session becomes a private function that evaluates the
session's expressions in order and collects the numeric results; the Boolean
`(= a b)` line is asserted separately in the test rather than coerced into
the `List<Long>`. The solution shows the three regimes the session teaches
in Kotlin: plain arithmetic literals, `val` names with `if`/`when`
conditionals, and a local `fun square` applied to its own result.

Class: this is a companion-added exercise (idiom-kotlin.md, Section 5, list
item 0.1); there is no exercise-map row, since the map does not cover
chapter 0. Deviation from SICP exercise 1.1: none in content; the expected
transcript values are the same numbers SICP prints, and the exercise asks
for the Kotlin rendering with D29-style result comments.
