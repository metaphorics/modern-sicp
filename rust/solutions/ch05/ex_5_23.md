# Exercise 5.23: derived expressions via transformer operations (T)

## Approach

The host slice has no `cond` or `let` surface; its derived forms are the `if`/`else` chain, `match` over a closed enum, and closure application for local bindings. Each lowers to the core control transfers, so the rest of the evaluator never knows the forms existed. One source runs on the explicit-control evaluator and the compiler with their transcripts compared.

## Map class

`T`.

## Sample answer

The `if`-chain and the `match` answer `12`, `9`, `0`, `10`, and `70`; the closure application answers `42`. Both engines print every line identically.
