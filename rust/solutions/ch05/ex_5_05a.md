# Exercise 5.5a: annotate each restore with its matching save (tailored)

## Approach

Added by this edition; extends exercise 5.5. The hand model already
carries the provenance each restore needs: the step of the save it
pops, the age of the value (instructions between that save and the
restore), and the count of older saves of the same register left
beneath. The pinned annotated trace of the n = 3 Fibonacci run is
the answer, and the annotations make exercise 5.6's analysis
mechanical: a restore whose value the very next save of the same
register pushes back unchanged is a pure round-trip, removable
together with that save. The test counts those round-trips: one per
internal call, two at n = 3.

## Map class

`T` (tailored addition, `chosen: rust` in the map's idea cell).
