?middle-manager ?boss) (supervisor ?staff-person ?middle-manager))`. The
recursion now runs before the supervisor test, so every rule application
enters `outranked-by` with both variables still unbound: each level's first
disjunct re-enumerates the whole `supervisor` data base and the `and` spawns
the next level before any test can prune. Worse, for the anchored query the
trailing test can never pass at all: `(supervisor (Bitdiddle Ben)
?middle-manager)` passes only frames whose middle-manager value is Warbucks
Oliver, while the recursion fills every frame's staff slot from the data
base's staff-side names; Warbucks appears only in boss slots. The filter
therefore consumes the endless regeneration forever without emitting a
second answer.

edition's `stream_take` forces one tail cell past the element it collects,

driver's answer-stream head: `run` + `Streams.stream_car`. Non-termination
