# Exercise 2.20 — same-parity (adapt: variadic rest arguments)

The map class is `A` (map row: "variadic rest arguments replace
dotted-tail notation"). OCaml functions have fixed arity, so the
dotted-tail pattern of the statement becomes the rest-argument idiom:
`ex_2_20 first rest` takes the first integer normally and the
remaining integers as one list. The body conses `first` onto the
filter of `rest` by parity with `first`, computed with `mod 2`
equality.

Sample: `ex_2_20 1 [2; 3; 4; 5; 6; 7] = [1; 3; 5; 7]`,
`ex_2_20 2 [3; 4; 5; 6; 7] = [2; 4; 6]`.
