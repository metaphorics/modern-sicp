# Exercise 4.76: merging frames for and (T)

## Approach

The merging `and` evaluates each conjunct against the input stream.
`merge-frames` combines compatible frame pairs by folding one frame's
bindings into the other through `extend-if-consistent`. Filtering
conjuncts (`not`, `lisp-value`) run in series: merging has no meaning
for a filter, so the prefix/suffix split applies filters in series
after the merge.

## Map class

`T`.

## Sample answer

Supervisors-with-jobs return identical answers (8) with 8 x 9 = 72
compatibility checks. Supervisees-with-addresses return identical
answers (8) with 8 x 8 = 64 checks. The probe measures the factor-of-k
saving analyzed in the exercise. Applying filters in the suffix keeps
the rule bodies correct.
