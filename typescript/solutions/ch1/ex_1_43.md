# Exercise 1.43: n-fold repeated application

## Approach

`repeated(f, n)` is `f` itself at `n = 1`, otherwise `f` applied to the
`(n - 1)`-fold application of `f`, spelled as the composition the
statement suggests from exercise 1.42 but written inline so the solution
stays self-contained like its neighbors. The nesting puts the innermost
application first, exactly the statement's apply-f-n-times shape.

## Numbers

`repeated(square, 2)(5)` is `square(square(5)) = 625`, the statement's
own example. `repeated(square, 5)(2)` is `2^32 = 4294967296` (still
below 2^53, so an exact double); `repeated(inc, 100)(0)` is `100`. At
`n = 1` the function is `f` itself, and the order test confirms
`repeated(x => inc(square(x)), 2)(3)` is `((3^2) + 1) + 1 = 11`.

## Class and deviations

Translated row, per the map. Recursion depth is `n`, which stays tiny
in this section's uses (1.44 and 1.45 fold it over damps and smoothings
in the single digits); this edition's no-tail-call concession would
only matter for large `n`. The logarithmic `repeated` by repeated
squaring is another edition's 1.43a and is not attempted here. No other
deviation.
