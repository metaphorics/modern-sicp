## Exercise 2.33: accumulate-based map, append, length

Approach: define `accumulateList` first, then fill the book's blanks: cons
each mapped head onto the mapped rest for `map`, accumulate the first list
onto the second for `append`, and count `1` per element for `length`.
`filterViaAccumulate` is included as a bonus fourth operation, since the
book poses it earlier in 2.2.3 with the same accumulate shape.
`flatMapSeq` (the book's `flatmap`, introduced later in 2.2.3) lives here
too because 2.40 to 2.43 need it. Class: T, direct translation. Deviation:
the four operations are long-specific; the shared `accumulateList` and
`flatMapSeq` are generic.
