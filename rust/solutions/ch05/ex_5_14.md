# Exercise 5.14: pushes and maximum depth of the factorial machine (T)

## Approach

The exercise's augmented controller performs
`(op initialize-stack)` on entry and
`(op print-stack-statistics)` at `fact-done`; both are installed
machine operations. The measurements run n = 1..=7 and the answers
are checked against the host product.

## Map class

`T`.

## Sample answer

Both total-pushes and maximum-depth are 2n - 2 for n > 1 (0, 2, 4,
6, 8, 10, 12 for n = 1..=7): each of the n - 1 non-base levels
pushes twice and the base level pushes nothing. The n = 6 run
prints `(total-pushes = 10 maximum-depth = 10)`.
