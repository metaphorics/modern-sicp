# Exercise 4.14: host map as primitive (T)

## Approach

The typed procedure value distinguishes primitive operations from compound
procedures. A host-style map accepts only primitives; applying a compound
procedure must go back through the evaluator's apply seam.

## Map class

`T`.

## Sample answer

Primitive `square` maps `[1, 2, 3]` to `[1, 4, 9]`; the same host map rejects a
compound procedure, while apply answers `15` for the compound call.
