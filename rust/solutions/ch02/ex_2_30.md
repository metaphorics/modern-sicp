# Exercise 2.30: `square-tree`

## Approach

The direct version is `count-leaves`'s recursion with a multiplication
at the leaf. The `map`-and-recursion version regards a branch as a
sequence of sub-trees, maps over it, and recurses only where a mapped
element is itself a tree; on `Nest` the `match` is the `pair?` test.
Both render identically, which the test pins through the printed form.

## Map class

`A`: recursive tree type replaces nested lists, supplied by `Nest`.

## Deviation

None.
