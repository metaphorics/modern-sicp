# Exercise 4.29: memoization and forcing counts (T)

## Approach

The same delayed effect is demanded twice under each named mode. Recompute
evaluates the thunk twice; memo evaluates it once and reuses the stored
result. The difference is the forcing count, not a host speed trick.

## Map class

`T`.

## Sample answer

`lazy-recompute/1` emits twice; `lazy-memo/1` emits once.
