# Exercise 4.18: the alternative scan-out strategy (T)

## Approach

`WithScanOutAlt` rewrites with an inner let: `(let ((u *unassigned*) ...) (let
((init-0 e1) (init-1 e2)) (set! u init-0) ...) rest)`. The initializers now
evaluate while every defined name is still unassigned, so the strategy enforces
the restriction the text's strategy only states. The 3.5.4 `solve` fails under
it (y is read while unassigned) and works under the text's strategy (the set!s
run in order and `delay` defers the read) -- argued in prose because streams
belong to 4.2.

## Map class

`T`; both strategies run and their difference is shown.

## Sample answer

Text strategy: `(f)` with `(define u 5) (define v (* u 2))` gives 10. The
alternative raises `the variable u is read before its define runs`.
