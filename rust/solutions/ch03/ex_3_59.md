# Exercise 3.59: integrate-series, exp sin cos

## Approach

`integrate-series` is the termwise integral minus its constant term:
each coefficient divided by its 1-based index, written as the book's
`stream-map / s (integers-starting-from 1)` over the module's
`stream_map2`. With it, `exp-series` is `1` consed onto the integral
of itself (`d(e^x) = e^x` fixes the constant at 1), closing a single
`self_stream` loop. Sine and cosine are mutually defined -- sine is 0
consed onto the integral of cosine, cosine is 1 consed onto the
integral of minus sine -- which is one name too many for a single
`self_stream`. The translation keeps both the book's defines and one
shared spine: two `Rc<RefCell<Option<Stream>>>` slots act as the two
names, the constant terms are consed eagerly, and each integral tail
thunk reads the other slot only when forced -- after both definitions
are complete, the same rule the book's `define` network satisfies.
Pinned prefixes: `e^x` gives 1, 1, 1/2, 1/6, 1/24, 1/120; sine gives
0, 1, 0, -1/6, 0, 1/120; cosine gives 1, 0, -1/2, 0, 1/24, 0, -1/720,
each within 1e-12.

## Map class

`T`. The statement translates whole. The Rust wrinkle is that the
crate's `self_stream` binds one name, while sine and cosine name each
other; the two-slot construction above is the direct extension of the
same define-completes-then-tails-run discipline.

## Deviation

None. `integrate-series` is defined exercise-local with a note, since
the section module deliberately leaves it to this exercise.
