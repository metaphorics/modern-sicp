# Exercise 1.21

`find_divisor` tests successive integers from 2 upward against `n`,
stopping at the first divisor found or at `n` itself once the test divisor
passes `sqrt(n)`. 199 and 1999 are both prime, so `find_divisor` runs all
the way to `n` and each returns itself. 19999 factors as `7 * 2857`, so
`smallest_divisor(19999) = 7`. The map class is `T`: nothing about the
statement changes for Rust.
