# Exercise 2.64: list to tree

## Approach

The book's `partial-tree` pair becomes the tuple
`[TreeSet, List<number>]`: the first component is the balanced tree over
the first n elements, the second the untouched remainder. The left
subtree takes `floor((n - 1) / 2)` elements, the entry is the next one,
and the right subtree takes the rest, so every node splits its range
almost exactly in half.

## Numbers

`listToTree([1, 3, 5, 7, 9, 11])` is the tree with 5 at the root,
`[1, [], 3]` on the left and `[9, [7], [11]]` on the right, the book's
drawing. (b) Every element is read once and every node is built once:
Theta(n).

## Map class

A (adapt): the pair is a two-element tuple, per the map's row.

## Deviation

None.
