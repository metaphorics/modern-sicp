# Exercise 4.67: the loop detector (T)

## Approach

The detector installs as the simple-query fallback: each frame's key is
the pattern instantiated under the frame with every unbound variable a
wildcard (renamed rule variables collapse to the shape of the request).
A frame whose shape is already in the history dies there. The caller
clears the history between top-level queries.

## Map class

`T`.

## Sample answer

The married cycle terminates with the one genuine answer
`(married Mickey Minnie)`; supervisor and wheel queries answer
normally under the same detector.
