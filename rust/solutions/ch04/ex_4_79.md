# Exercise 4.79: environments instead of renaming (T)

## Approach

Rule application binds the conclusion's parameters fresh. The new
bindings shadow the frame's old formal bindings, and `unify_match`
writes this application's parameter bindings against the pattern.
When the pattern leaves a parameter untouched, the parameter is re-linked
to the binding it replaced. This keeps writes through an argument
variable in the body visible to the enclosing query. The evaluator
collects answer vectors, so this implementation covers bounded
queries only.

## Map class

`T`.
