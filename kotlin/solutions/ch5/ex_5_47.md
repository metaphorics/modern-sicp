# Exercise 5.47: compiled code calls interpreted procedures

The interpreter constructs a closure over a lexical `increment`
binding and returns it from a checked guest program. Another
checked program declares `interpreted(x: Long)` and compiles
`compiledCaller`, which calls that declaration. The compiler's
`interpretedBindings` interface substitutes the interpreter-created
closure for the declaration's machine binding before execution.

`mixedCallsRun` executes the compiled caller once with its compiled
declaration, then with the interpreted closure installed. The
different answers, 141 and 42, prove that the mixed call actually
crosses the compiled-to-interpreted boundary. The declaration's
matching signature is checked before either run.
