# Exercise 2.96: pseudoremainder (adapt)

The map class is `A`. Part (a): `integerizing_power c exponent` is `c`
raised to `exponent`, building the integerizing factor
`c^(1+O1-O2)` the text describes; `pseudoremainder_terms` is
`remainder_terms` with the dividend first scaled by that factor, so
the division that follows never introduces a fraction, and `gcd_terms`
is redefined to use it, fixing the noninteger-coefficient problem
Exercise 2.95 exhibited. Part (b): `coefficients_content terms` is the
integer GCD of every (rounded) coefficient in `terms` (`0` for the
empty list), and `reduce_content` divides every coefficient by it,
removing the redundant integer factor pseudodivision leaves behind;
`gcd_terms_reduced` and `gcd_poly_reduced` compose the pseudo-gcd with
this cleanup.

`ex_2_96 ()` reruns Exercise 2.95's `Q1`/`Q2` example (built from
`P1`, `P2`, `P3`) through `gcd_poly` (now using `pseudoremainder_terms`)
and confirms every coefficient of the raw result is already an
integer, then reports `coefficients_content` of `gcd_poly_reduced`'s
result: `1` once part (b)'s cleanup has divided out the redundant
factor.
