# Exercise 5.21: count-leaves machines

`countLeavesRecursive` follows the recursive definition. It counts the car, saves that answer while it counts the cdr, then adds the two results. `countLeavesIterative` carries its count in n through both subcalls, so it does not save a partial answer. Both controllers run on the 5.2 simulator with the section's list operations installed over the same vector-memory model.

`plantTree()` builds each tree by allocating its list cells through `cons`. `countLeavesRuns()` compares both machine answers with the host definition and prints the simulator's actual stack statistics. On `(1 2 (3 (4 5)))`, both return 5. The recursive controller pushes 21 times and reaches depth 14; the explicit-counter controller pushes 14 times and reaches depth 10. The smaller `((7))` and empty-tree rows pin the nested and base cases as well.
