# Exercise 5.37: disabling `preserving` (T)

## Approach

Compile the recursive factorial definition with `preserving` enabled
and disabled. Count both total emitted statements and save sites, then
run factorial 5 with unconditional save and restore generation. Without
register-use analysis, every sequence boundary gets stack operations,
including cases where the following sequence never needs the saved
value.

## Map class

`T`.

## Sample answer

The default factorial compilation has 79 statements. Turning off
`preserving` increases both the statement count and the number of save
sites, yet the compiled factorial still returns `120`. The extra
operations are the cost of blindly preserving registers rather than
only values that remain live.
