# Exercise 5.37: preserving disabled

`preserving` is what keeps a register's value alive across the compilation of a subexpression that might rewrite it. With it disabled, every register is saved and restored around every nested compilation, and the waste is visible as statement traffic around code that never touches those registers.

The exercise compares the shipped discipline with an indiscriminate wrapper on the same source: the answers are unchanged, the stack traffic is not. The comparison is stated as counts and code shape, the observable cost of the optimization.
