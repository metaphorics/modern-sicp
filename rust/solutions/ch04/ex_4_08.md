# Exercise 4.8: named let (T)

## Approach

`named_let_to_combination` rewrites `(let name bindings body)` to
`((lambda (name) (set! name (lambda bindings body)) (name inits)) '*ok*)`.
The set!-based form is required: a loop procedure evaluated before the wrapper
applies would not capture the frame that binds `name`, and the recursive
self-call would be unbound. The book's named-let Fibonacci gives 55.

## Map class

`T`.

## Sample answer

`(fib 10)` with the named-let `fib-iter` is 55.
