# Exercise 2.38 — fold-left versus fold-right (translate)

The map class is `T`. `fold_left` is the book's `iter` helper with
OCaml types. The four requested values are pinned by `ex_2_38`:
`fold_right ( /. ) 1.0 [1.0; 2.0; 3.0] = 1.5` (that is `1 / (2 / 3)`),
`fold_left ( /. ) 1.0 [1.0; 2.0; 3.0] = 0.166...` (that is `(1 / 1) /
2 / 3`), `fold_right` with cons gives `[1; 2; 3]`, and the
left-to-right cons gives `[3; 2; 1]`. The nested `list` folds of the
book build an improper nesting that OCaml cannot type homogeneously,
so the fourth expression uses the order-swapped cons, whose result
`[3; 2; 1]` is the observable difference of direction the exercise
is about; the deviation is recorded here.

The property: `op` must be commutative and associative (an
Abelian-group operation, with the same initial value) for the two
folds to agree on every sequence.
