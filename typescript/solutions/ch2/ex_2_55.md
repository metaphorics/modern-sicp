# Exercise 2.55: the double quote, built by hand

## Approach

The map classifies 2.55 as R: the puzzle is the reader's `''`
abbreviation, which has no analogue here. The solution builds the value
the book's interpreter computes, `(quote (quote abracadabra))` with one
layer evaluated away, as `qlist(qsym("quote"), qsym("abracadabra"))`,
takes its head, and explains which layer plays which quote mark.

## Answer

`(car ''abracadabra)` is the symbol `quote`: the reader expands the typed
expression to `(quote (quote abracadabra))`; evaluation performs the
outer quote, leaving the list `(quote abracadabra)`; `car` of that is the
symbol `quote`. In the hand-built datum the outer `qlist` is the outer
quote mark, and the `qsym("quote")` element is what the inner mark left
behind.

## Map class

R (replace): the exercise is about the reader; the hand-built value
teaches the same section material.

## Deviation

None.
