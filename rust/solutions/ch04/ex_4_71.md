# Exercise 4.71: explicit delay in simple-query (T)

## Approach

Louis's undelayed `simple-query` and `disjoin` are implemented as table
processors and compared against the delayed engine under a fuel-bounded
fallback. The measured finding for this edition: a Rust stream value is
already a lazy structure -- every recursion point sits behind a
`cons-stream` tail or a boxed thunk -- so the eager Scheme argument
evaluation that makes the undelayed definitions diverge at construction
has no counterpart here; the undelayed engine answers the same first
answer, and the observable regress shows up only while hunting deeper
answers, where both engines exhaust the same fuel line.

## Map class

`T`.

## Sample answer

Both engines answer `(outranked-by (Bitdiddle Ben) (Warbucks Oliver))`
first; both exhaust the fuel hunting a second. The undelayed `or`
chains into the regress one branch earlier.
