# Exercise 3.64: stream-limit convergence helper

## Approach

`stream_limit` walks the approximation stream with two witnesses: it keeps
each element until the next arrives, and answers the earlier of the first
consecutive pair whose difference is below `tolerance` in absolute value --
exactly the statement's "second of the two elements" wording, read as the
first element whose successor no longer moves it by more than the tolerance.
The test applies it to the module's Newton streams: `sqrt_stream(2.0)` and
`sqrt_stream(5.0)` at tolerance `1e-6`, and checks each answer against
`f64::sqrt` of the same argument to machine precision -- the Newton
iteration from 1.0 reaches the `f64` fixed point, so the limit is the
hardware square root itself -- and pins the decimal forms and the
limit-squared self-consistency the statement's tolerance implies.

## Map class

`T`. The statement translates whole.

## Deviation

None. The tolerance is absolute, matching the statement's "differ by less
than the tolerance" wording.
