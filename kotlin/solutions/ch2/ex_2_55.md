## Exercise 2.55: double quote (replaced)

Approach: apply the reader-expansion rule by hand instead of running a
reader. A single quote `'x` is sugar for `(quote x)`; nesting it once
more, `''abracadabra` is sugar for `(quote (quote abracadabra))`, built
directly as `vlist(VSym("quote"), vlist(VSym("quote"), VSym("abracadabra")))`.
That value is a two-element list whose first element, its `car`, is
the symbol `quote`, and whose second element is the one-element list
`(quote abracadabra)`. The `car` is `quote`, not `abracadabra`, because
the doubled quotation mark expanded a symbol-shaped mark into a real
list element sitting in front of the payload; the interpreter never
"sees through" a quote mark to the word after it, it only ever sees the
list `(quote abracadabra)` that the mark stands for, and `car` of that
list is the `quote` symbol itself.

Class: R, per the map; the exercise is about Scheme's reader, which
this edition does not have, so the replacement asks the reader's own
expansion rule to be applied by hand, keeping the number and the
section's one piece of underlying material (the reader-abbreviation
rule stated in the main prose).

Deviation: none.
