# Exercise 1.3 — sum of squares of the two larger numbers (translate)

Map class `T`. The procedure takes three integers and returns the sum of
the squares of the two larger ones. The solution finds the smallest of the
three with `min` and squares the other two; this avoids the book's six-way
case analysis while keeping the definition total.

Ties deserve a test: when two or three values tie for smallest, exactly
one smallest value is dropped, which is the same answer the book's
wording gives (`1 1 2` yields `5`, `2 1 2` yields `8`, `3 3 3` yields
`18`). Negative inputs exercise the same logic; squares make the sign
irrelevant.

The integer type is the section convention for exact arithmetic; the
contract is pinned by `int -> int -> int -> int` in both the scaffold and
the solution.
