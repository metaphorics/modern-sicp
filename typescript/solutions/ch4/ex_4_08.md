# Exercise 4.8: named let

## Approach

Following the book's shape, the named binding is a local named function
over the group's names, called on the initializers: `let loop((v1 e1),
...) body` derives to `(() => { function loop(v1, ...) { body } return
loop(e1, ...); })()`. The function declaration binds the loop name in
the local frame before the body runs, so recursive calls in the body
resolve to the loop itself; the trailing call starts it with the
initializers. The parameter list is the group's names, so each binding
becomes one loop argument. Plain grouped bindings remain in the same
evaluator through the derivation of exercise 4.6.

## Numbers

`(let loop((k 10)) ...)` computing Fibonacci answers `55`. A factorial
loop `(let loop((n 5) (acc 1)) ...)` answers `120`. The transformation
of `let loop((n 0)) n` is structurally the local-function form above —
equal after erasing spans. Plain let still evaluates: `x = 3, y = 4`
over `x + y` is `7`, and a named let inside a procedure body recurs
through its name to `55`.

## Class and deviations

Translated row. Deviation: the old solution followed the book's `set!`
hint and needed a throwaway initial actual (`'ok` standing in for
`*unassigned*`); the local named function needs no uninitialized
placeholder at all, so that deviation disappears — the binding is the
function declaration, and recursion is ordinary lexical scope.
