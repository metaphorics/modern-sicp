# Exercise 4.2: dispatch order and call-prefixed applications (T)

## Approach

Typed `Form` data separates definitions, assignments, applications, and
call-prefixed calls. The application-first dispatcher rejects a definition
before it can reach the special-form clause; the ordered dispatcher checks
special forms first and treats a call-prefixed application as an application
without extra checks.

## Map class

`T`.

## Sample answer

`application_first(Definition)` is an error; `special_first(Definition)`
accepts the definition; `special_first(PrefixedCall(20, 22))` answers `42`.
