# Exercise 2.54: recursive equality over a symbol tree (adapt)

The map class is `A`: the idea survives (define `equal?` recursively
over the primitive equality of atoms), but the statement changes
because OCaml has no single type that is "either a symbol or a
list". The exercise introduces `datum = Sym of string | Seq of datum
list`, the smallest variant that can hold what the book's quoted
lists hold, and `equal_datum` matches the book's recursive
definition one case at a time: two symbols are equal when their
names are, two sequences are equal when they hold the same number of
elements and those elements are pairwise `equal_datum`, and anything
else is unequal.

Sample: `equal_datum (words ["this";"is";"a";"list"]) (words
["this";"is";"a";"list"])` is `true`; the same two words nested one
level differently, mirroring the book's second example, is `false`.
