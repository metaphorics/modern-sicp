# Exercise 3.10: let desugaring adds a frame

## Approach

The book's two versions differ by an inner `let` frame; the question is
whether they behave alike and how the structures differ. The Rust
replacement keeps the question and makes it measurable. The solution
implements the let-shaped `make_withdraw_let` beside the section's
parameter-captured `make_withdraw`, runs the book's interaction on
both, and measures each closure with `std::mem::size_of_val` through a
small generic helper. Both measurements come out equal to
`size_of::<i128>()`: the closure captures the variable it names, so the
extra `let` built no extra structure, and the balance lives inside the
closure object in both versions. In Scheme the difference was an extra
frame; in Rust the extra name is flattened at compile time, and the
test pins that.

## Map class

`R: trace closure capture of balance`. The trace is the size
measurement plus the behavior parity, both asserted.

## Deviation

The measurement uses `size_of_val` on the unnameable closure types
through a helper generic over `FnMut(i128) -> Reply`, so the test
compares against `size_of::<i128>()` without naming the closures.
