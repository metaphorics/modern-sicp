# Exercise 4.18: source order against initializers-first

## Lesson

The text strategy assigns in source order, so each initializer sees
the bindings before it; the alternative evaluates every initializer
first and assigns after, so an initializer that reads a fellow
definition finds the reservation still empty. The probe is the book's
shape: `dy` defers its value behind a procedure, and `y`'s
initializer applies it.

## Map class

`A` (map row 4.1: internal definitions). The two orders are two guest
evaluation functions over the same names and inits.

## Deviation

None. The alternative is simultaneous evaluation with a new name, so
its failure mode is honest: the fellow name is simply unbound there.

## Answer

- Source order serves the fellow read: `3`.
- Initializers-first leaves it empty: failure.
- Pin: `textStrategyTranscript() == "3\n"` and
  `altStrategyTranscript() == "error\n"`.
