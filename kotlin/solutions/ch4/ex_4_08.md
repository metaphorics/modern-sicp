# Exercise 4.8: named `let` as a recursive procedure

## Lesson

A named loop is a recursive procedure bound around its first call,
which is exactly the kernel's tie-the-knot binder. The kernel binds
one parameter, so the countdown carries its state -- remaining count
and running total -- in one pair, read through the kernel's member
form. Five steps sum to `15`.

## Map class

`A` (map row 4.1: recursion and closures). The loop name, parameter,
and call map onto `GLetRec`, `GLam`, and application.

## Deviation

None. The pair state stands in for multiple parameters, which the
curried kernel has no form for.

## Answer

- The five-step countdown sums to `15`.
- Pin: `namedLetTranscript() == "15\n"`.
