# Exercise 4.78: the query language on backtracking search (translate)

## Approach

Rebuilding the language on the amb evaluator would subsume much of
the stream machinery under choice points with try-again, but the
search order changes: depth-first search runs each `or` branch's
whole subtree before the next, where the stream engine interleaves
them. The solution exhibits the difference on the book's `or`
example over Microshaft: the stock engine interleaves, while an
appending disjoin installed through the engine's `put` hook runs
depth-first, which is the order the amb engine would produce.
