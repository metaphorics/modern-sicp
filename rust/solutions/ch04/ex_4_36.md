# Exercise 4.36: unbounded Pythagorean triples (T)

## Approach

Substituting `an-integer-starting-from` for `an-integer-between` in place
never completes: the second choice wanders upward forever before the
third is drawn, so no triple is ever finished. The edition's fair
enumeration rule: grow exactly one bound -- the hypotenuse `k` -- through
`an-integer-starting-from`, and search each finite `k` completely with
the bounded generator of 4.35. Repeatedly typing `try-again` therefore
walks `k = 1, 2, 3, ...` and, for each `k`, every `(i, j)` below it, so
every Pythagorean triple appears after finitely many requests.

## Map class

`T`.

## Sample answer

First six: `(3 4 5)` (k=5), `(6 8 10)` (k=10), `(5 12 13)` (k=13),
`(9 12 15)` (k=15), `(8 15 17)` (k=17), `(12 16 20)` (k=20).
