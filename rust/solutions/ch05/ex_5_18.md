# Exercise 5.18: per-register tracing (T)

## Approach

The machine has a single store path (`store`), so tracing a
register is one check there: a traced store appends
`name: old -> new`. `trace_register` and `untrace_register` are
the machine interface the exercise asks for, and the host's own
`set_register` reports like any assign because it goes through the
same path.

## Map class

`T`.

## Sample answer

The factorial machine on n = 3 with `n` and `val` traced reports
eight lines, from `n: *unassigned* -> 3` through `val: 2 -> 6`;
after untracing `val`, only the five `n` lines remain and the
answer is still 6.
