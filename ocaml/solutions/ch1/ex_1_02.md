# Exercise 1.2: the fraction as pure nested calls (replace)

Map class `R`: the SICP exercise asks the reader to translate an infix
fraction into Scheme's prefix notation, which is a lesson about Scheme
itself. Per the edition's signpost, the number is kept and the material is
retargeted: the reader takes the book's expression tree and writes it as
pure nested calls, the shape the original exercise was driving at, in a
language whose operators are normally infix.

The four combinators `add`, `sub`, `mul`, and `div` are one-line wrappers
over the `float` operators; the answer uses no infix operator at all, so
the nesting mirrors the expression tree one node per call. Working in
`float` is the section convention: the fraction contains `4/5`, which has
no integer value.

The value is `14.8 / -60 = -37/150`, pinned to `-0.24666666666666667` with
a `1e-6` tolerance against `-37.0 /. 150.0`. The test fails if a call
lands on the wrong subtree, because the nesting then computes a different
rational.
