# Exercise 5.34: compiling iterative factorial (T)

## Approach

Compile factorial with its local tail-recursive `iter` and run the
compiled entry at inputs 3, 4, and 5 under a driver that reports stack
statistics. The recursive call is in tail position, so compilation
transfers directly to the compiled procedure entry instead of saving a
new continuation. The maximum simulated stack depth stays the same
across the three inputs, although total pushes can grow.

## Map class

`T`.

## Sample answer

The generated tail transfer is `(assign val (op
compiled-procedure-entry) (reg proc))` followed by `(goto (reg val))`.
The measured maximum depths for n = 3, 4, and 5 are equal. No specific
depth value is pinned by this solution.
