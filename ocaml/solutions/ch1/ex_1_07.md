# Exercise 1.7 — the tolerance test at the extremes (translate)

Map class `T`. The solution provides both programs: `ex_1_07_sqrt` is the
section's square root with the fixed absolute tolerance `0.001`, and
`ex_1_07_sqrt_improved` replaces the end test with one that watches the
change from the previous guess and stops when the change is less than one
thousandth of the guess.

The small-number failure is tested numerically. For a radicand of
`0.0001` the absolute test stops near `0.032`, more than twice the true
root `0.01`, yet comfortably inside the tolerance, because the tolerance
is measured against `x` rather than against the answer's scale. The test
pins that the original misses by more than `0.005` while the improved
version lands within `1e-6` for the same input.

The large-number failure is about representation, not accuracy: once the
guesses approach the true root, the spacing of adjacent `float` values
near `x` exceeds `0.001` (near `1e12` it is about `0.0001`, near `1e16`
it is `2`), so `square guess - x` can stop shrinking before it drops
below the tolerance and the loop never terminates. A test cannot run a
nonterminating program, so the large-number proof is the improved
version converging on `1e12` within a relative hair of `1e6`, and the
ulp arithmetic above. The improved program guards `x = 0.0` by
returning `0.0`; without the guard its relative test iterates forever on
a radicand whose root is zero, a small deviation from the book's
statement recorded here.
