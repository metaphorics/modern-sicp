# Exercise 4.74a: the flatmap frame measurement (this edition's addition)

Both evaluators of 4.74 run one shared query each with a frame counter
attached to the flatmap under test.

Counting rule, precisely: **a frame is counted when it is emitted into
the flatmap's output stream**: one increment per frame delivered on
the flatmap's output, once per frame, in emission order. The counter
is a wrapper stream around the flatmap's result (the base evaluator's
interleave-based `stream_flatmap` for the book side; `stream-map` of
`stream-car` over `stream-filter` of the non-empty element streams for
Alyssa's side), adding one cell per delivered frame. Counting at
interior cons construction would be wrong: the swap-based
`interleave_delayed` builds an interior node for each `delayed_s2 ()`
evaluation whose head is served again by the outer cons, so
construction counts frames the output never contains. The pinned
queries are finite and read to the end, so the delivered-frame total
is exactly the flatmap's output size.

The shared query is 4.4.1's
`(and (supervisor ?x ?y) (not (job ?x (computer programmer))))`: the
`find_assertions` flatmap emits 8 frames (one per supervisor
assertion, all matching) and the `negate` flatmap emits 6 (the
non-programmers). A second run covers the third replaced path with
`(and (salary ?person ?amount) (lisp-value > ?amount 30000))`: 9
`find_assertions` frames plus 5 `lisp-value` survivors.

4.74b's observation, measured: the counts coincide because
`negate`, `lisp-value`, and `find-assertions` produce at most one
frame per input frame (the empty stream or a singleton), so Alyssa's
first-survivor selection keeps exactly the frames the interleaving
would have emitted, and nothing else about the engine changes.

Asserted pins:

```
query=(and (supervisor ?x ?y) (not (job ?x (computer programmer))))
old_frames=14
simple_frames=14
answers_equal=true
counts_equal=true
lisp_query=(and (salary ?person ?amount) (lisp-value > ?amount 30000))

lisp_simple_frames=14
lisp_answers_equal=true
lisp_counts_equal=true
```
