# Exercise 1.16 — iterative fast exponentiation (translate)

The map class is `T`; OCaml's tail calls make the iterative shape here
exactly as constant-space as the book's Scheme.

`fast_expt_iter a b n` holds the invariant `a * b^n` across every state.
On an even `n`, `(b^2)^(n/2) = b^n`, so squaring `b` and halving `n`
preserves the invariant; on an odd `n`, folding one factor of `b` into
`a` and decrementing `n` preserves it, since `(a * b) * b^(n-1) = a *
b^n`. Starting from `a = 1` the invariant reads `b^n`, the goal; when `n`
reaches 0 it reads `a`, the answer. Each step at least halves `n` (or
halves it after one odd step), so the process runs in `Theta(log n)`
steps and, since the self-call is always the whole result, `Theta(1)`
space.

The test pins `ex_1_16 2 10 = 1024`, matching `fast_expt`, and checks an
odd exponent (`ex_1_16 3 13 = 1594323`) and the `n = 0` base case
(`ex_1_16 5 0 = 1`).
