# Exercise 5.1: iterative factorial machine

## Data paths

```text
n ---------------------+----------------+
                       |                v
counter -----> [ > ] --+--> control: done when counter > n
   ^         [ + 1 ] <---+
   |                      |
product <--- [ * ] <--- counter
   |                      |
   +---- output            |
```

The registers are `n`, `counter`, and `product`. The operations are `>`, `+`, and `*`. The controller initializes `product` and `counter` to 1, tests `counter > n`, and otherwise multiplies the product and increments the counter.

## Controller

```text
(assign product (const 1))
(assign counter (const 1))
test-counter
(test (op >) (reg counter) (reg n))
(branch (label factorial-done))
(assign product (op *) (reg counter) (reg product))
(assign counter (op +) (reg counter) (const 1))
(goto (label test-counter))
factorial-done
```

The TypeScript transcription is `factorialIterative` in the section module. Executing it with `n = 5` returns `product = 120`.
