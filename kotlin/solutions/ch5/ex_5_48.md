# Exercise 5.48: compile-and-run inside the evaluator

`compileAndRunReport` admits a recursive factorial program, compiles
it, runs its emitted instructions on `Compiler.machine`, and
independently compares the compiler's public run result with a
`Direct.run` of the same checked source. Both programs print 120.

The exercise's original primitive compiled a quoted expression
inside an interactive evaluator. This Kotlin guest subset instead
exposes a two-phase compiler API; the compile-and-run boundary is
real, but there is no guest-visible `compile-and-run` primitive.
