# Exercise 4.53: permanent-set! with if-fail (T)

## Approach

The program visits every prime-sum pair from the two lists. It
prepends each answer to `pairs` with `permanent-set!`, which
backtracking cannot undo. The trailing `(amb)` fails the branch, so
the search advances to the next pair. When no pairs remain, the first
expression's search has failed. `if-fail` catches that failure and
returns the accumulated list, newest pair first because each prepend
occurs on the way down.

## Map class

`T`.

## Sample answer

`((8 35) (3 110) (3 20))`, then the search runs dry -- the pairs are
the three prime-sum pairs in discovery order, reversed by the prepends.
