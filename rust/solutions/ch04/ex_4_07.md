# Exercise 4.7: let* as nested lets (T)

## Approach

`let_star_to_nested_lets` folds the bindings right to left into nested `let`s.
Adding the one clause is sufficient, and the seam makes that literally true:
each nested `let` re-enters `step`, so a `let*` inside another's body is
handled too.

## Map class

`T`.

## Sample answer

The book's example is 39 (x=3, y=5, z=11, x*z); a `let*` nested in another's
body answers 5.
