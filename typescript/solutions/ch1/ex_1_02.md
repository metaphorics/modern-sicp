# Exercise 1.2: the fraction as pure nested calls

## Approach

The fraction is written as one nested application of the four statement
primitives `add`, `sub`, `mul`, `div`, with every operator a call and no
infix operator anywhere outside them. The call nesting mirrors the
expression tree: `div` at the root; the numerator is
`add(5, add(4, sub(2, sub(3, add(6, div(4, 5))))))`; the denominator is
the product of three factors, `mul(3, mul(sub(6, 2), sub(2, 7)))`.

## Numbers

The value is `-0.24666666666666667`, the float form of `-37/150`
(numerator 14.8, denominator -60). The test also pins that the nested
application and the plain infix expression agree bit for bit.

## Class and deviations

Replaced row: SICP exercise 1.2 asks for a translation into Lisp's
prefix form, which is about Scheme's notation itself. The replacement
keeps the number and teaches the same material - seeing an expression as
a tree of operations - in the opposite direction: the fraction is easy
to write with infix operators, so the exercise rebuilds it from pure
calls, the way the section's prefix combinations look.
