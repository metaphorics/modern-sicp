# Exercise 2.32 — subsets (translate)

The map class is `T`. The blank in the template maps `car ::` over
`rest`: with `s = car :: cdr`, the subsets of `s` are the subsets of
`cdr` together with every one of those subsets with `car` added. The
explanation the statement asks for: `subsets cdr` already produces
all subsets not using `car`, and mapping the cons produces exactly
the ones that do, so the union is the full power set, of size 2^n.

Sample: `ex_2_32 [1; 2; 3]` has the 8 subsets, `[]` first.
