# Exercise 5.12: the assembler's summary

While assembling, the assembler can gather data about the controller,
and this edition does: `assemble` builds an `AssemblySummary` beside
the instruction sequence. The summary carries the book's census, in
the order the exercise lists it: the instructions with duplicates
removed and grouped by type, the registers the controller names
overall, the entry-point registers (the `goto (reg r)` targets), the
registers the stack instructions use, each register's assign sources,
and the defined labels. Every list is in a deterministic order
(instruction texts and sources alphabetically, registers
alphabetically, labels in definition order), so the report is
reproducible.

`E5_12.kt` assembles the gcd controller once more (the same
`gcdController` the 5.7 machine runs) and renders the summary with
`renderAssemblySummary`. `gcdMachineSummary()` answers the six report
lines pinned by `E5_12Test`: one deduplicated instruction per type
(`assign` groups `a`, `b`, and the `rem` line), `(registers a b t)`,
empty entry-point and stack register lines (the gcd machine never
saves, restores, or jumps by register), the three assign sources, and
the two labels.
