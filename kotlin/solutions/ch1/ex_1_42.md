## Exercise 1.42: compose

Approach: `compose(f, g) = { x -> f(g(x)) }`, generic over `T`.
`compose(square, inc)(6)` is `square(inc(6)) = square(7) = 49`.

Class: T (translate). Deviation: none. The solution's test
property-checks `compose(f, g)(x) == f(g(x))` for generated inputs, in
addition to the book's own example.
