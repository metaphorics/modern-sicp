# Exercise 4.6: `let` as a derived expression

## Lesson

A one-binding `GLet` lowers to `GApp(GLam(name, body), value)`. The
application evaluates the initializer in the current frame, then evaluates
the body in a frame containing the new binding. Nested lets apply the same
rewrite at each level.

## Map class

`T`; the derived binding and its teaching objective are unchanged.

## Deviation

None. The single-binding application makes the initializer and body scopes
explicit.

## Answer

- Ordinary and derived bindings both answer `7`.
- An initializer reading outer `x = 5` binds `x = 7`; the body reads `7`.
- Nested bindings answer `3`.
- Pins: `letEquivalenceTranscript() == "7\n7\n"`,
  `letBodyTranscript() == "7\n"`, and
  `letNestedTranscript() == "3\n"`.
