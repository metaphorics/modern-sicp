# Exercise 2.17: a `last-pair` for lists

## Approach

`last_pair` cdrs down the list until the rest of the current cell is the
empty list, then wraps that cell's `car` back up as a one-element list,
exactly the recursive plan the statement sketches. The empty list has no
last pair, so the function reports `SicpError::TypeMismatch` there
instead of panicking; the test's sample list is nonempty, so the result
is the book's `(34)`.

## Map class

`T`: the statement translates directly onto the runtime's persistent
`List`, whose `car`/`cdr` accessors mirror the book's selectors.

## Deviation

None. The empty-list case is a typed error rather than a crash, per the
edition's error convention.
