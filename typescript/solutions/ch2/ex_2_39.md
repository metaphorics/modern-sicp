# Exercise 2.39: reverse via fold-right and fold-left

## Approach

Fold-right meets the first element first, so reversing conses nothing in
front: each element `x` must instead be appended behind the already
reversed rest, `(x, y) => append(y, list(x))`. Fold-left meets the
elements in order and conses each onto the front of the accumulated
result, `(x, y) => cons(y, x)`, the natural shape for reverse. The
fold-left version imports exercise 2.38's `foldLeft` rather than
redefining it, and the module's accumulate stands in for the book's
fold-right.

## Numbers

Both `reverseViaFoldRight(list(1, 4, 9, 16, 25))` and
`reverseViaFoldLeft(list(1, 4, 9, 16, 25))` render `"(25 16 9 4 1)"`.

## Map class

`T`: the book's two definitions translate directly over the edition's
lists.

## Deviation

None.
