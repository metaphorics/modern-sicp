# Exercise 4.5: cond arrow clauses (translate)

The reader delivers `(test => recipient)` as a clause whose action
list is the variable `=>` followed by the recipient, so the cond
dispatch detects that shape: the test is evaluated once, and when it
holds, the recipient is evaluated and applied to the test's value
through `apply`, so a compound recipient works like any procedure.
Plain clauses and the trailing `else` behave as before.

Sample: `ex_4_05 ()` answers `["2"; "(x c)"; "missing"]`: the
statement's `assoc` example returning the entry's `cadr`, an arrow
clause whose recipient is a lambda, and a failing test falling
through to the `else`.
