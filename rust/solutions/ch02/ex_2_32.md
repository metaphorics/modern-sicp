# Exercise 2.32: `subsets`

## Approach

The completed definition: the subsets of `s` are the subsets of its
`cdr` (omitting the first element) together with those same subsets
each extended by the first element at the front (including it). The
empty set's subset list is the list containing the empty set, which is
the base case `list(nil)`. The count doubles per element, hence `2^n`
subsets, and the printed order matches the book's.

## Map class

`T`: the statement translates directly onto `List<List<i128>>`, whose
`Display` prints the nested parentheses.

## Deviation

None.
