# Exercise 4.13: removing a binding

The map class is `T`. `make_unbound` removes a name from the first frame only. An outer frame is shared by every procedure created in it, so removing a name there would change code that never asked for it; removing the first frame's binding can only uncover an outer binding of the same name.

Sample: `ex_4_13 ()` removes a shadowing `x` and shows the global `x` reappear, refuses the global `y` through a call frame while another call still sees it, and removes a defined `w`.
