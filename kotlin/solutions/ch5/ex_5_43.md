# Exercise 5.43: scanning out internal definitions

The compiler can make a procedure body's bindings explicit before compiling it.
With `scanOut` enabled, `scanOutDefines` collects definitions directly in the
body, creates a `let` binding for each name initialized to the quoted
`*unassigned*` symbol, then places corresponding `set!` forms before the
remaining body expressions. The quoted marker is a value, not a variable lookup.
If the option is disabled, the body is compiled without this transformation.

`scanOutShapes()` compares the compiled forms for a body that defines `a` and
`b`. The test pins the plain body as containing a definition operation but no
unassigned marker, and the scanned body as containing the marker but no
`define-variable!` operation. It also runs the scanned procedure through the
compiled evaluator; the pinned result is `ok`. These checks cover the emitted
shape and the execution path exercised by this example, not every possible
placement or dependency among internal definitions.
