## Exercise 2.77: closing the gap `magnitude` fell through

Approach: `Complex(Rect(3.0, 4.0))` is a two-level number (the outer
`complex` tag, then `Rect`/`Polar` underneath), and the complex package
installs `add`/`sub`/`mul`/`div` but none of the four selectors, so
`magnitude` on it misses with `GenError.NoMethod`. Alyssa's fix: install
`real-part`/`imag-part`/`magnitude`/`angle` at the complex level too,
each forwarding to `RepTable`'s representation-level procedure.
[DispatchCounter] instruments the call so `ex_2_77` can show `magnitude`
dispatching twice (once through the complex-level generic table, once
through the rectangular-level one underneath), matching the book's own
account of the two-tag structure.

Class: A, per the map; the exercise itself just asks to install four
procedures, but proving "dispatches twice" needs an observable trace,
which the closed Scheme call stack does not offer for free; the counter
is this edition's way of making that claim checkable.

Deviation: none in substance.
