# Exercise 3.17a: counting distinct nodes

## Approach

The edition addition on the 3.17 row extends the distinct-pair count
to the count of distinct nodes: a box-and-pointer diagram draws the
atoms too. `countNodes` keeps two host sets, pairs by identity
(`Set<object>`) and leaf atoms by value (a value `Set`), and walks
head and tail from the root. A pair reachable by two routes counts
once; equal atom values count once.

## Pins

Computed by running on the 3.15 structures: countNodes(makeZ1) is 5:
the root, the two pairs of the shared (a b) spine, and the atoms a
and b. countNodes(makeZ2) is 7: the root, four pairs across the two
distinct (a b) copies, and a and b. For the unshared tree built as
(mlist (mlist a b) c d) the count is 9: five pairs, three in the
spine and two in the inner list, plus a, b, c, d. Equal atoms count
once: (a a b) is 5. The empty list is 0. These are the run's values;
a count that skipped the root pair would read 4, 6, and 8, which is
not what the function computes, and the three-element spine has
three pairs, not two.
