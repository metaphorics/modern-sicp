# Exercise 4.9 — a while construct as a derived expression (adapt)

The statement asks for designed iteration constructs; this edition
adds `while`, carried as a shape of test and body because the reader
has no while form. The lowering is the named-let expansion of 4.8
with a nullary loop: `(define %while-loop (lambda () (if test (begin
body ... (%while-loop)) #f)))` followed by `(%while-loop)`. The
nullary recursion answers the false object at exit and discards body
values, so the construct communicates through the environment it
mutates. A second construct, `until`, would be the same loop with the
branch polarity swapped, unimplemented.

Sample: `ex_4_09 ()` answers `["ok"; "ok"; "#f"; "15"]` — the
accumulator and counter definitions, the exit value, and the sum
`1 + 2 + 3 + 4 + 5` read back from the environment.
