# Exercise 2.94: polynomial gcd

## Approach

A `term_lists` module restates exercise 2.91's `div_terms` for this exercise to build on, and then `gcd_terms` is Euclid's algorithm with term lists in place of integers: an empty divisor leaves the dividend as the answer, and otherwise the gcd of `a` and `b` is the gcd of `b` and the remainder of dividing `a` by `b`, where the remainder is the second half of `div_terms`'s `(quotient, remainder)` pair. Errors are whatever `div_terms` raises along the way.

The probe computes `gcd(x^2 - 1, x - 1)`. The first division comes out even, `x^2 - 1 = (x - 1)(x + 1)` with remainder 0, so the recursion reaches an empty divisor after one step and returns `x - 1` itself. The test asserts the term-list form `[(1, 1), (0, -1)]`, which is `x - 1`, matching the book's worked computation.

A `generic` module then installs the operation the exercise asks for: `gcd_poly` takes the bare pair of polys `apply_generic` has already stripped, checks the variables agree (signalling `UserRaised` when they differ, mirroring the section's `add_poly`/`mul_poly`), runs `gcd_terms` on their term lists, and rebuilds the answer through `make_polynomial`. `install_greatest_common_divisor` puts that handler under `(polynomial polynomial)` and a plain Euclid handler under `(scheme-number scheme-number)`, both keyed by the operation name `greatest_common_divisor`; the exported `greatest_common_divisor(table, x, y)` is a one-line `apply_generic` call, so the book's "install in the system a generic operation" clause is a real table entry, not just term-list arithmetic below it.

The book's own test — `p1 = x^4 - x^3 - 2x^2 + 2x`, `p2 = x^3 - x` — runs through the installed operation and prints `(polynomial (x (2 -1) (1 1)))`, i.e. `-x^2 + x`. By hand, `p1 = x(x-1)(x^2-2)` and `p2 = x(x-1)(x+1)`, so `x^2 - x` (or its negative) is the GCD; the probe checks this the way the exercise asks, by dividing both `p1` and `p2` by the answer and confirming the remainder is empty, rather than by string-matching a sign Euclid's algorithm does not fix.

## Map class

`A`: gcd needs division loop over term lists. The solution is that loop in its plainest form, with the division's remainder half doing all the representational work and the recursion carrying Euclid's structure over unchanged. Installing the generic operation is the same table-`put` shape the section already uses for `add`/`mul`/`=zero?`, applied to one more operation name.

## Deviation

None of substance. Euclid's algorithm fixes the polynomial GCD only up to a constant factor, so this run's answer is the negative of the book's displayed `x^2 - x`; the probe verifies the by-hand property the exercise names (the answer divides both inputs exactly) instead of asserting the particular sign.
