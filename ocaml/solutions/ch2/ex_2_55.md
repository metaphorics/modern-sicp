# Exercise 2.55 — quote in edition AST terms (replace)

The map class is `R`: Eva Lu Ator's puzzle is about how Scheme's
reader expands the quote abbreviation, which has no OCaml
counterpart (OCaml has no reader that turns source text into data at
run time). The replacement teaches the same lesson using the shared
Scheme subset's own `Ast`/`Reader` from `sicp_common`: `Reader.read`
turns `'x` into a `Quote` node wrapping the datum `(quote x)`, so
`''abracadabra` reads as the quote of the two-element list `(quote
abracadabra)`. Taking the `car` of that datum and reading its symbol
name recovers `quote`, the same answer the book's interpreter prints,
now derived from the edition's own AST rather than asserted about
Scheme's reader from outside it.

Sample: `ex_2_55 ()` is `"quote"`.
