# Exercise 2.18: a `reverse` for lists

## Approach

Cdring down the list, each element is consed onto the front of the
answer built so far. Because `List::cons` places its element in the head
cell, a front-to-back walk with front insertion lands the elements back
to front, which is the whole trick. The loop form is Rust's spelling of
the book's iterative `reverse-iter` with an accumulator.

## Map class

`T`: the statement translates directly; the accumulator pattern is the
same, and the language needs no tail-call guarantee because the loop is
explicit.

None.
