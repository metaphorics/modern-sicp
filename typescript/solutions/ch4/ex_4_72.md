# Exercise 4.72: interleave versus append (translate)

## Approach

`disjoin` and `stream-flatmap` interleave where a plain append would
do, so that an infinite first stream cannot starve the later
alternatives. The solution demonstrates both combinators on the
core's own streams: an infinite naturals stream against a finite
two-element stream, taking six.

## Numbers

Appending yields `[1, 2, 3, 4, 5, 6]`: the finite stream never
surfaces. Interleaving yields `[1, 100, 2, 200, 3, 4]`: the later
stream's elements appear in turn. The tests pin both prefixes.

combinators.
