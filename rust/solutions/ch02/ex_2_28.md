# Exercise 2.28: `fringe`

## Approach

A leaf contributes a one-element list; a branch contributes the
concatenation of its children's fringes, left to right, built with the
section's `append`. The section later renames this procedure
`enumerate-tree` and ships it in the spine (2.2.3), so the solution's
fringe and the spine's enumerate_tree agree by construction; this file
keeps its own definition so the exercise's contribution is real.

## Map class

`A`: recursive tree type required, supplied by `Nest`.

## Deviation

None. The append-based composition is the book's plan and stays
quadratic in leaf count, which is irrelevant at book scale.
