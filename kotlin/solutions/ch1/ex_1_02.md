## Exercise 1.2: the fraction as pure nested calls

Approach: the four primitives `sum`, `diff`, `prod`, `quot`, each of type
`(Double, Double) -> Double`, stand in for the operator positions, and the
fraction is one `quot` of two nested-call trees. The value is `-247/1000`
to machine precision: `-0.24666666666666667`, identical to the infix form
`14.8 / -60.0` because both perform the same double operations. The
denominator's real division is why the primitives are `Double`-typed.

Class: R (the SICP exercise teaches Scheme's prefix notation itself; this
edition replaces it with the pure-call rendering, keeping the number and
the prefix-versus-infix lesson). Deviation: the statement names the four
primitives explicitly so the nested form is writable.
