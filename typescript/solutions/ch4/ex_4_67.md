# Exercise 4.67: the loop detector (translate)

## Approach

The evaluator stores active rule calls as the stable rule index and the
instantiated conclusion arguments in each immutable frame. Frame
extensions preserve that branch-local history. The rule-application
path rejects a repeated call and removes its entry from result frames
when the rule body returns, so completed sibling deductions remain
available.

## Numbers

The predicate pins are: same pattern with identical bindings against
itself is a repeat; the same pattern with one binding changed is not;
a different pattern is not. The tests pin all three verdicts plus the
branch-local wording of the summary.

## Class and deviations

The exported `repeatsActiveCall` predicate retains its original
string-pattern and binding-record behavior. The evaluator independently
applies the same active-call principle to actual rule applications.
