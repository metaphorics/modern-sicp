# Exercise 1.44: smoothing and n-fold smoothing (translate)

The map class is `T`. `smooth f x` averages `f` at `x`, `x -. dx`, and
`x +. dx`; `n_fold_smoothed f n` is `repeated smooth n f`, exactly the
book's hint ("using `smooth` and `repeated`"), with `repeated` from
exercise 1.43 folded in locally.

`noisy x = x *. x +. 0.01 *. sin (1000. *. x)` is a clean parabola with
a small, fast wobble layered on, a synthetic stand-in for a measured
signal with noise. `noisy 2. = 4.0093003950441615`, about `0.009` off
the true `4.`; `n_fold_smoothed noisy 5 2. = 4.009298845427903`, closer
to `4.` by roughly an order of magnitude in the error, since averaging
neighbors cancels the fast oscillation while leaving the slow-varying
`x *. x` term almost untouched.
