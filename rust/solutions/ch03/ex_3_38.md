# Exercise 3.38: enumerate interleaved balance outcomes

## Approach

The solution checks which balances Peter, Paul, and Mary can leave
behind. It executes the six sequential orders over a fresh $100
balance, then sorts the distinct final values and gets the four the
text enumerates (35, 40, 45, 50). For the concurrent case, Peter runs
on a spawned thread while Paul and Mary run on the calling thread,
200 times. Every observed outcome belongs to the seven-value set:
the four sequential balances plus the lost updates 80, 90, and 110.
The test samples concurrent outcomes, not all schedules, so it asserts
membership in the possible set rather than one particular schedule.

## Map class

`T`. The three transactions, the six orders, and the outcome sets are
the statement's own.
