# Exercise 2.61 — adjoin-set for ordered lists (translate)

The map class is `T`: only the syntax changes. By analogy with
`element_of_set`, `adjoin_set` can stop scanning as soon as it passes
the point where `x` belongs, needing on average about half as many
steps as the unordered representation's unconditional scan.

Sample: `ex_2_61 ()`, `4` adjoined into `{1, 3, 6, 10}`, is
`[1; 3; 4; 6; 10]`.
