# Exercise 1.22

`Instant::now()` and `Duration` replace the book's `runtime` primitive:
`Instant::now()` reads the machine's monotonic clock at the start of the
test, and `Instant::elapsed()` reports how long has passed since. The map
class is `A` for exactly this reason: Scheme's `runtime` primitive has no
Rust equivalent, so the statement is reworded around the standard library's
timing API instead of translated word for word.

`search_for_primes` walks consecutive odd integers from a starting point
and keeps the first three that pass `is_prime`. Run above each of the four
boundaries the statement asks for, it finds 1009, 1013, and 1019 above
1000; 10,007, 10,009, and 10,037 above 10,000; 100,003, 100,019, and
100,043 above 100,000; and 1,000,003, 1,000,033, and 1,000,037 above
1,000,000, twelve primes in all. Since `smallest_divisor` tests divisors up
to `sqrt(n)`, the search near 10,000 should take about `sqrt(10)` times as
long per prime as the search near 1000, and so on for each `10x` step in
the input; whether a given run's wall-clock timings actually bear this out
depends on the machine's noise floor for a microsecond-scale measurement,
which is why the test asserts on the primes found rather than on elapsed
time.
