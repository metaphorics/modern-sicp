## Exercise 1.15: how many times is p applied?

Approach (part a): `p` runs once per level of the recursion that divides
the angle by 3 until it is within 0.1 radians. `12.15 / 3 = 4.05`,
`/ 3 = 1.35`, `/ 3 = 0.45`, `/ 3 = 0.15`, `/ 3 = 0.05`, which is finally at
most 0.1 in magnitude; that is 5 divisions, so `p` runs 5 times, each
wrapping the recursive call to `sine` on the way back out. A closure
counter incremented inside `p` measures this directly rather than
counting by hand.

Part b (growth, carried here since it has no return value to assert): the
number of divisions needed to bring an angle `a` under 0.1 radians is the
smallest `k` with `|a| / 3^k <= 0.1`, so `k` grows as `log3(|a|)`; both
the number of steps and the depth of the pending `p` applications (hence
the space) grow as Theta(log a).

Class: T (translate). Deviation: none for part (a); part (b) is answered
in prose because it asks for an order-of-growth statement, not a value.
