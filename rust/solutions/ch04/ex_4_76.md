# Exercise 4.76: merging frames for and (T)

## Approach

The merging `and` evaluates each conjunct against the input stream and
merges compatible frame pairs, `merge-frames` folding one frame's
bindings into the other through `extend-if-consistent`. Filtering
conjuncts (`not`, `lisp-value`) stay series: merging has no meaning for
a filter, so the prefix/suffix split applies filters in series after
the merge.

## Map class

`T`.

## Sample answer

Supervisors-with-jobs: identical answers (8), 8 x 9 = 72 compatibility
checks; supervisees-with-addresses: identical answers (8), 8 x 8 = 64
checks. The factor-of-k saving the exercise analyzes is measured, and
the filters-in-suffix rule keeps the rule bodies correct.
