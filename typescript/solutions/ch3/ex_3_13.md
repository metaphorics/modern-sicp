# Exercise 3.13: make-cycle builds a ring

## Approach

The book's `make-cycle` uses `last-pair` from Exercise 3.12 and
rewrites the final pair's tail with `set-cdr!` so it points at the
first pair. The edition imports `lastPair` from ex_3_12 and calls
`setCdr`, so the ring is the very argument, mutated in place. The
structure has no `mnil` end, so `showMList` on it never terminates:
the demo and the tests pin the ring by identity only, walking tails
and comparing objects, and never print it.

## Pins

For z = make-cycle over (a b c): the first head is a, the second b,
the third c, and the third pair's tail is the first pair again
(Object.is true). Walking three tails from z lands on z.
make-cycle returns its argument (Object.is true), the in-place
mutation the book draws. The book's closing question, what happens
if we compute (last-pair z): the walk has no empty end, so it never
returns; that is pinned here as a fact about the structure, never
run.
