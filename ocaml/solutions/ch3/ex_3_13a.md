# Exercise 3.13a: cycle-safe printing (this edition's addition)

SICP numbers stop at 3.13; this edition adds 3.13a because exercise
3.13 raises a question the book never answers in code: once a
structure can be circular, what does printing it safely even mean?
`show_cycle` remembers every pair it has visited by physical identity
in an association list and prints `#cycle` the moment it revisits one,
so a genuinely infinite structure still yields a finite string. A
`fuel` budget guards against structures that are merely very large
rather than cyclic, raising instead of hanging. The design mirrors
`count_pairs_distinct` from exercise 3.17: the same "seen by `==`"
pattern that counts pairs here renders them, which is the point the
addition makes.

Sample: `ex_3_13a ()` answers
`("(a b c . #cycle)", "(a b . #cycle)", "(a b)")`.
