# Exercise 1.11 — recursive and iterative f (translate)

The map class is `T`. `f_recursive` translates the piecewise rule
directly: one call per term, a tree-recursive process exactly shaped
like `Fibonacci.recursive`.

`f_iterative` slides a three-value window forward, mirroring
`Fibonacci.iterative`'s two-value window: state variables `a`, `b`, `c`
hold `f(k+2)`, `f(k+1)`, `f(k)`, and each step computes
`a + 2b + 3c` (the next value) and shifts `a` into `b` and `b` into `c`.
Starting the window at `(f(2), f(1), f(0)) = (2, 1, 0)` and running it
`n - 2` times lands on `f(n)` for `n >= 3`; `n < 3` returns `n` directly,
matching the base case.

`f(5) = 25` and `f(10) = 1892`, computed by hand from the rule and
confirmed by both procedures agreeing. The test checks the two processes
against each other over a range and pins the two named values.
