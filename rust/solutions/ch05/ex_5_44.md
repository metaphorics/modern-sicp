# Exercise 5.44: open coding and shadowed names (T)

## Approach

A rebound name stays an ordinary binding resolved innermost-first: the inner block's `x` feeds both uses of the inner expression while the free function name still reaches its definition. No special case distinguishes the two; the environment order decides both on both engines.

## Map class

`T`.

## Sample answer

Both engines print `3` then `200`.
