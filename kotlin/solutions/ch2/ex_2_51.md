## Exercise 2.51: below, two ways

Approach: `belowViaTransform` mirrors `beside`'s construction exactly,
splitting on the vertical edge instead of the horizontal one, so the
first painter fills the bottom half of the frame and the second fills
the top; this is the same construction the shared `Painters.kt` already
carries as `below` (needed there so earlier listings such as `wave4` and
`cornerSplit` can run), restated here as the exercise's own answer.
`belowViaRotation` takes the book's hint: rotate both painters 270
degrees (turning "left of" into "below"), place them beside each other,
then rotate the whole assembly 90 degrees, which undoes the per-painter
rotation while keeping the bottom/top placement the `beside` step
produced. The tests prove all three constructions agree, segment for
segment, on two different painter pairs, and separately confirm which
half of the frame each painter's segments land in.

Class: A. The map's note is that `below` needs the painter function
type; both constructions are ordinary higher-order functions once
painters are plain `(Frame, StringBuilder) -> Unit` values.
