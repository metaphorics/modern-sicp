# Exercise 4.53: permanent-set! with if-fail (T)

## Approach

The program walks every prime-sum pair of the two lists; each answer is
prepended to `pairs` by a `permanent-set!` no backtrack can undo, and
the trailing `(amb)` fails the branch so the search advances to the
next pair. When the pairs run dry the whole first expression's search
has failed, `if-fail` catches it, and the alternative answers with the
accumulated list -- newest pair first, because each prepend landed on
the way down.

## Map class

`T`.

## Sample answer

`((8 35) (3 110) (3 20))`, then the search runs dry -- the pairs are
the three prime-sum pairs in discovery order, reversed by the prepends.
