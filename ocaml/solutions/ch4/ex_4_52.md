# Exercise 4.52: if_fail (translate)

`if_fail` is a clause added to the search evaluator by open recursion.
It makes a choice point of two alternatives: the first expression, and
the fallback, which the search tries only after every branch of the
first has failed. This matches the book's `if-fail`, whose fallback runs
as the failure continuation of the first expression.

When every element is odd, the first expression has no answer and the
program answers `all-odd`. When 8 is present, it answers `8`. Because
the experiment searches to exhaustion, `all-odd` follows once the first
expression's branches run out, which the book reaches with
`try-again`.
