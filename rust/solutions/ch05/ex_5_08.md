# Exercise 5.8: duplicate label detection in the assembler (T)

## Approach

The book's first question is answered by the as-written semantics:
`lookup-label` is an `assoc` over a scan-order table, so the first
`here` wins and `a` holds 3 when control reaches `there`. The
solution pins that reading two ways: `lookup_label` over a
hand-built ambiguous table returns 0 for `here`, and the
deduplicated controller (first block kept) runs to `a` = 3. The
repair: `extract_labels` rejects a repeat on sight, so the whole
controller fails assembly with the typed `DuplicateLabel`, naming
the label; nothing runs.

## Map class

`T`.

## Sample answer

As written, `a` = 3 at `there`; with the fix the assembly of the
book's controller fails with `the label "here" is used twice`.
