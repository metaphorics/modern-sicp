# Exercise 3.17: counting distinct pairs with a visited set

## Approach

The book's hint: traverse the structure, keeping an auxiliary record
of the pairs already counted. The edition uses a host `Set<object>`,
whose membership test on objects is reference identity, the book's
`eq?`. `countPairsCorrect` walks head and tail, adds each pair to the
set on first sight and counts it then, and returns 0 on `mnil` or on
anything already seen, so sharing collapses and rings terminate.

## Pins

countPairsCorrect returns 3 on all three structures of Exercise
3.16: plainX3, sharedX2, and sharedX3. Where Ben's count returns 4
and 7, the correct count returns 3 and 3, the true number of
distinct pairs; on the unshared structure the two counts agree, both
3. On the three-pair ring built by make-cycle over (a b c), the
correct count is 3: the visited set ends the walk. Ben's count is
never run on the ring; it would not return.
