# Exercise 4.22: analyzing `let` once, running often

## Lesson

Analysis translates the form once into the kernel application the
evaluator already runs; execution runs that translation on demand.
The analysis counter climbs when the form is analyzed, the run
counter climbs per execution: one analysis serves two runs, each
answering `7`.

## Map class

`A` (map row 4.1: analysis returns closures). Analysis is translation
plus a counting effect; execution is evaluation plus a counting
effect, and the counters tell them apart.

## Deviation

The counters are instrumentation, labeled as such; the analyzed form
is the plain derivation, unchanged.

## Answer

- Two executions answer `7` and `7`.
- Analyses: `1`. Runs: `2`.
- Pin: `analyzedLetTranscript() == "7\n7\n1\n2\n"`.
