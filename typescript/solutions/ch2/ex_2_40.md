# Exercise 2.40: unique-pairs

## Approach

The nested mapping inside prime-sum-pairs - for i from 1 to n, for j
from 1 to i-1, generate the pair - is not specific to primes, so it
becomes `uniquePairs`: a flatmap over i whose inner map produces
`list(i, j)`. With the pair generation named, prime-sum-pairs reads as
its composition: `filter` by `primeSum`, then `map` with `makePairSum`,
with no pairing detail left in the program body. All four sequence
operations come straight from the module.

## Numbers

`uniquePairs(4)` renders `"((2 1) (3 1) (3 2) (4 1) (4 2) (4 3))"`, and
`primeSumPairsSimplified(6)` renders exactly the module
`primeSumPairs(6)` string - the test compares the two displays.

## Map class

`T`: the book's unique-pairs refactor translates directly.

## Deviation

The batch spec's test sketch rendered `uniquePairs` by mapping
`showList` over the pairs, but this edition's `showList` double-quotes
string elements, which would wrap every pair in quotes. The test
displays the pair list itself, printing the same unquoted string the
sketch specified; the solution code is unchanged.
