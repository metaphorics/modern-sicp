# Exercise 1.4: the operator chosen by a conditional (translate)

Map class `T` for OCaml. The Scheme exercise observes that a combination's
operator may itself be a compound expression: `((if (> b 0) + -) a b)`.
The map flags Rust as an adaptation because its operators are not values;
OCaml needs no adaptation, because `( + )` and `( - )` are ordinary
function values, so the translation is direct and the exercise stays a
`T`.

`ex_1_04 a b = (if b > 0 then ( + ) else ( - )) a b` reads exactly like
the book's line: the conditional yields the operator function, and the
result is applied to `a` and `b`. The `if` is an expression in OCaml, so
the operator position holds a conditional expression without ceremony.

The tests cover both operators plus the `b = 0` edge, which takes the
subtraction branch (`>`, not `>=`), and a negative `a` to show the
operator applies to the arguments rather than precomputing a sign.
