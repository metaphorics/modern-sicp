# Exercise 1.26: counting the cost of Louis's explicit multiplication

## Approach

The section's `expmod` computes one subproblem of half the exponent and
squares the result. Louis wrote the squaring as a product of two
independent self-calls. In an eager host the two arguments of `*` are
both evaluated before the multiplication runs, so every even exponent
now spawns **two** half-size subproblems, each of which spawns two
quarter-size ones, and so on: the call tree doubles per level of the
exponent's binary representation. The number of calls for a power-of-two
exponent `2^k` follows `T(2^k) = 1 + 2*T(2^(k-1))`, which is `2^(k+2) -
3`; the square-based version makes `k + 2` calls. The instrumented
variants count calls for base 2 mod 561 and turn Eva's claim into two
rows of numbers.

## Numbers

At `exp = 1024`: the square version makes `12` calls, Louis's `3071`.
At `exp = 2048`: `13` against `6143`. Doubling the exponent doubles
Louis's work and adds one call to the original - `Theta(n)` against
`Theta(log n)`, exactly as Eva says. The values agree (both compute the
same remainder), which is what makes the slowdown so misleading to
debug by output.

## Class and deviations

Translated row. The statement's prose survives with `fastPrime` and
`isPrime` renamed; the answers are pinned as measured call counts
instead of asserted prose, so a regression back to one subproblem (or a
mistaken third) fails the test.
