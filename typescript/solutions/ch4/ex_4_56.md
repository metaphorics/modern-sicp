# Exercise 4.56: compound queries

## Approach

Three combinations over the shared database, plus addition 4.56a:

1. `superviseesWithAddresses` conjoins the supervisor pattern with the
   address pattern; frames flow left to right, so answers keep database
   order.
2. `lowerSalaries` conjoins two salary patterns with a `lisp-value`
   host predicate. Salaries are stored as texts, so the predicate
   narrows to strings and compares numerically — the narrowing is the
   typed-data analogue of the book's numeric comparison.
3. `supervisedOutsideComputer` conjoins supervision with negation as
   failure over a computer-headed dotted job pattern, then reads the
   supervisor's job. Negation never binds: the dotted tail renders as
   the unbound `?division-rest` in every answer line.
4. Addition 4.56a (`nonProgrammersSupervisedByBen`) negates one exact
   job pattern, keeping only Tweakit.

## Numbers

Three supervisee addresses; six salaries below Ben's 60000 (Hacker,
Fect, Tweakit, Reasoner, Cratchet, Aull — Warbucks, Scrooge, and Ben
himself are excluded); four people supervised outside the computer
division (Bitdiddle, Scrooge, Cratchet, Aull); one non-programmer
supervisee. The tests pin the rendered lines exactly.

## Class and deviations

Translated row. Deviations: queries are typed data (no query text);
strings render double-quoted; negation leaves its pattern variables
visibly unbound. The `lisp-value` predicate is a typed host function
over instantiated values.
