## Exercise 2.48: the segment abstraction

Approach: same situation as exercise 2.46. `Segment`, `makeSegment`,
`startSegment`, and `endSegment` live in the shared `Painters.kt` because
`segmentsToPainter` and the primitive `wave` painter need them before
this exercise's file is reached; this file's own contribution is
`segmentLength`, built only from the two vector selectors, demonstrating
that the abstraction barrier holds (nothing here inspects `Segment`'s
fields directly).

Class: T (a direct translation of a constructor-plus-two-selectors data
abstraction into a Kotlin data class).
