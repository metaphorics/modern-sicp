# Exercise 5.50: compile the metacircular evaluator

`metacircularEvaluatorSource` is the 4.1 evaluator as object-language
source, the class-A provision both 5.50 and 5.52 build on: the
environment procedures ride behind machine words, the list accessors
and the arithmetic the primitive table names ride in the runtime
support, and `factorial` is defined inside the object world by the
session, never at machine level.

`compiledMetacircularRuns()` compiles the definitions into one block,
then drives three object-level calls: the object factorial twice
around the book's tick pair. The block's own final form, the object
`define` of factorial, answers the first `ok`, and the driver answers
120, `(tick tick tick)`, and 120. The test pins `answers: ok, 120,
(tick tick tick), 120`. Landing this run fixed two real defects: the
`cond->if` transform read the test from the wrong list slot so every
`cond` took its first consequent, and the 5.5 machine lacked the
runtime list, display, and arithmetic primitives the object program
names.
