# Exercise 0.1: three TypeScript interaction sessions

## Approach

Each session is written as TypeScript expressions in order inside one
function: session 1 is five arithmetic expressions, session 2 binds
`a` and `b` with `const` and evaluates five conditional expressions,
and session 3 defines `square` and calls it three times. The numeric
responses collect into one list, so a single `toEqual` pins the whole
transcript; the equality comparison in session 2 answers `false` and
stays in the conditional rather than the numeric list.

The conditional expressions use TypeScript's conditional operator. The
nested conditional of the last arithmetic line keeps the source order
in its `else` position.

## Numbers

Every response is `486, 100, 12, 1, 6` from session 1, then `19,
false, 4, 16, 6, 16` from session 2, then `441, 49, 81` from session
3. All are small integers, well inside the 2^53 exactness bound of
section 0.2's number model, so no `bigint` is needed.

## Class and deviations

Chapter 0 exercises are original per edition (see the header note in
`docs/exercise-map.md`); the exercise mirrors Kotlin edition exercise
0.1, which sets the same task for the same three sessions. No
deviation.
