Exercise 1.43 (translate): `repeated(f, n)` builds an `Rc<dyn Fn(f64) -> f64>` in a loop, one composition per application of `f`, since the returned procedure must outlive the call and a generic `impl Fn` return cannot represent "compose with myself again" across loop iterations. `repeated(square, 2)(5)` is 625; repeated `inc` by 7 starting from 0 is 7, checking the statement's other reading.
