# Exercise 4_72: interleave versus append

## Approach

If an infinite disjunct comes first, appending the finite branch
after it never reaches that branch. The engine's `QOr` interleaves
its branch streams. The solution takes four answers from the
interleaved disjunction of the unbounded `loves` cycle and the
supervisor facts, then four answers from the two branch runs
appended with `Sequence.plus`, and counts the supervisor answers in
each prefix.

## Answer

Expectations (`E4_72Test`), cross-checked against an independent
SICP stream-evaluator model: the interleaved prefix alternates
Minnie/Mickey, Hacker/Ben, Mickey/Minnie, Fect/Ben (two supervisor
answers); the appended prefix repeats the `loves` pair and holds
zero supervisor answers, as would any longer prefix.

## Deviation

The appending counterfactual is assembled in host code from two
driver runs rather than as an alternative engine.
