# Exercise 2.55: the quotation name, built by hand

## Approach

The map classifies 2.55 as R: the puzzle is the abbreviation that writes
the quotation operation twice in a row, which has no analogue in this
edition's notation. The solution builds the value that abbreviation
computes - the list whose first item is the symbol `quote` and whose
second item is the symbol `abracadabra` - as
`listDatum(symDatum("quote"), symDatum("abracadabra"))`, takes its head,
and explains which layer of the construction plays which of the two
quotation marks.

## Answer

Applying the quotation-name datum to the symbol `abracadabra` and then
taking the head answers the symbol `quote`: the doubled mark abbreviates
a quotation of a quotation, so evaluating it once leaves the two-element
list `[quote, abracadabra]`, and the head of that list is the symbol
`quote`. In the hand-built datum the outer `listDatum` stands for the
outer quotation mark, and the `symDatum("quote")` element is what the
inner mark left behind.

## Map class

R (replace): the exercise is about the reader; the hand-built value
teaches the same section material.

## Deviation

None.
