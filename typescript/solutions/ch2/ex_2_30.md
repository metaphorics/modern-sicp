# Exercise 2.30: square-tree, directly and via map

## Approach

`squareTreeDirect` recurses over the edition's two tree constructors: a
leaf squares its value, a node squares each of its subtrees and rebuilds
the branch. `squareTreeViaMap` is the book's alternative: map a squaring
function over the subtrees, with the leaf-or-branch decision made inside
the mapping function, exactly the cond-within-lambda the book shows.
Like the book's version, the map spelling treats the root as a branch
holding the sequence of its subtrees. Both produce a new tree of the
same shape with every leaf squared.

## Numbers

For `node(leaf(1), node(leaf(2), node(leaf(3), leaf(4)), leaf(5)), node(leaf(6), leaf(7)))`
both versions render `"[1, [4, [9, 16], 25], [36, 49]]"` - leaves 1 through 7
squared in place.

## Map class

`A`: the book's nested-list tree becomes the edition's `Tree<A>` union,
so the recursion pattern-matches on `_tag` instead of testing for pairs.

## Deviation

None.
