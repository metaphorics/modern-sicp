# Exercise 5.13: registers derived from the controller text (T)

## Approach

`registers_in` scans the datums and names every register the
controller mentions: assign targets, `(reg ...)` sources and
inputs, save and restore names, and `(goto (reg ...))` registers.
`make_machine_with_derived_registers` feeds that set to the
normal constructor, so no register list is required. The machine's
own `flag` is never derived because no controller names it.

## Map class

`T`.

## Sample answer

The GCD controller derives `{a, b, t}` and answers 2 on 206/40;
the Fibonacci controller derives `{continue, n, val}` and answers
8 on 6. A controller naming no register derives the empty set and
still runs its constant instructions.
