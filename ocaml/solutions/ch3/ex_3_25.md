# Exercise 3.25: table under an arbitrary number of keys (adapt)

The map class is `A`: `lookup`/`insert` take an `mobj list` of keys
and descend one `Table` subtable per key, building any missing
subtable on the way down with `T.make_table ()` and linking it in with
`set_cdr`, mirroring the book's recursive generalization of the
two-dimensional table. The test scenario deliberately avoids letting
one key path be both a leaf and a prefix of a longer path (for
example inserting under `[a]` and under `[a; b]` at once). That case
needs a node representation with a distinct "value here" slot the
book's own sketch does not specify, so the demonstration instead uses
sibling paths of consistent depth per prefix, which the book's stated
contract already supports cleanly.

Sample: `ex_3_25 ()` answers
`(Some 1, Some 2, Some 3, Some 4, None, Some 5, Some 2)`.
