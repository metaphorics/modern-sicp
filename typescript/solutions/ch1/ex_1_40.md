# Exercise 1.40: cubic for Newton's method

## Approach

`cubic(a, b, c)` closes over the three coefficients and returns
`x |-> x^3 + ax^2 + bx + c`, exactly the shape `newtonsMethod(cubic(a, b,
c), guess)` needs. The Newton machinery (deriv, newtonTransform, fixedPoint)
is the section's own 1.3.4 code restated locally.

## Numbers

`cubic(1, 2, 3)(2)` is `21`. For `cubic(-6, 11, -6) = (x-1)(x-2)(x-3)`
started at `1.5`, Newton's method lands on `3` (one Newton step reaches
`3.0` exactly and the finite-difference derivative keeps it there, so the
recorded root is `3.0000000000001608`, within `1.7e-13`). For
`cubic(0, -2, -3)` started at `1.0` the method finds `1.8932891963046012`,
and the residual `|g(root)|` is below `1e-6`.
