# Exercise 2.26: append, cons, and list on two lists (replacement)

## Approach

The replacement keeps the exercise's trio and asks what type and what
printing each produces. `append(x, y)` is a flat `List<i128>` and
prints `(1 2 3 4 5 6)`. `list(x, y)` is a `List<List<i128>>` and prints
`((1 2 3) (4 5 6))`. `cons(x, y)` is the instructive case: Scheme
pairs the list `x` with the list `y`, mixing element types in one
structure, which no single homogeneous Rust `List<T>` can hold; the
edition's tree type `Nest` is its home, and it prints exactly the
book's `((1 2 3) 4 5 6)`.

## Map class

`R`: SICP 2.26 is about the Scheme interpreter's printed answers, so
the edition replaces it with a prediction over the edition's collection
printing; the number and the two lists are unchanged.

## Deviation

The `cons` case is answered in the tree type, since the typed edition
has no improper pairs; the printed shape matches the book's.
