# Exercise 4.67: the loop detector (T)

## Approach

The detector installs as the simple-query fallback. For each frame, it
instantiates the pattern, treats every unbound variable as a wildcard,
and uses the result as a key. Renamed rule variables then have the
request's shape.
The detector rejects a frame whose shape already appears in the
history.
The caller clears the history between top-level queries.

## Map class

`T`.
