# Exercise 4.9: `while` and `until` as derived loops

## Lesson

`while` repeats its body while the test holds; `until` repeats until
it holds. Both lower to a self-calling one-argument procedure bound
around its first call: the test picks the body block or the done
value, and the block ends by invoking the loop again. The kernel has
equality but no inequality, so the `until` probe exits on equality.

## Map class

`A` (map row 4.1: derived forms, sequencing). Iteration is recursion
over blocks; the loop value is unspecified by design.

## Deviation

None. The dummy operand feeds the single-parameter procedure; the
pins read the accumulated cells, not the loop value.

## Answer

- `while` under `n < 4`: `n` is `4`, the total is `10`.
- `until` on `m == 3`: `m` is `3`, the doubled total is `12`.
- Pin: `loopsTranscript() == "4\n10\n3\n12\n"`.
