# Exercise 2.3: two rectangle representations

## Approach

`RectangleCorners` stores two opposite corners; `RectangleDims` stores
one corner plus a width and a height. Both representations expose
`width()`/`height()` (or plain fields), and the shared `perimeter` and
`area` functions take only `width` and `height`, never a representation
directly, so they sit above the abstraction barrier exactly as the book
intends: "the same perimeter and area procedures work using either
representation." The test builds the same 4-by-3 rectangle both ways and
checks all four numbers agree.

## Map class

`T`: two constructor/selector pairs behind one shared pair of
procedures, translated directly.
