# Exercise 5.52: compiling the evaluator to C (A: object-language evaluator source)

## Approach

Compile each top-level form of the provided object-language
metacircular evaluator with the chapter 5 compiler, then translate the
emitted controller statements into C. Registers become C globals,
labels become C labels, and computed gotos implement indirect
transfers. A runtime supplies the machine operations and values; the
backend initializes constants, emits each compiled form and prints its
value, then invokes the system C compiler and runs the result.
