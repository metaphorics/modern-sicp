# Exercise 4.25: `unless` under lazy application (T)

## Approach

The lazy experiment represents `unless` as `If(test, exceptional, normal)`.
With the false test, the failing exceptional thunk is never demanded, so the
delayed arm stays delayed and `120` comes back. The eager counterpart uses a
typed application whose body demands both operands; forcing the failing
operand answers no value.

## Map class

`T`.

## Sample answer

The delayed `unless(false, 120, failing-thunk)` answers `120`; the eager
application that demands both operands answers no value.
