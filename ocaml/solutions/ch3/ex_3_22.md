# Exercise 3.22 — queue as a message-passing closure (adapt)

The map class is `A`: the book's `dispatch` on a quoted message
becomes a record of closures, `q_empty`/`q_front`/`q_insert`/
`q_delete`, each closing over the same pair of local `front`/`rear`
cells that `make_queue_object` allocates fresh per call. Two calls to
`make_queue_object` never share state, matching the book's claim that
each queue built this way is independent; `ex_3_22` confirms it by
building a second queue and showing its own insert and empty check
are unaffected by the first queue's traffic.

Sample: `ex_3_22 ()` answers `("b", false, "c", false)`.
