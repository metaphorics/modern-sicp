# Exercise 3.72: sums of two squares thrice

## Approach

The same ordered-pairs route as exercise 3.71 with the weight
`i*i + j*j`: pairs ordered by that weight emit equal weights
adjacently, and the local grouping combinator folds the stream into
maximal runs of equal weight carrying their witness pairs. The runs of
length three or more are the numbers the statement asks for, with the
three pairs that show how they are so written: `325 = 1^2 + 18^2 =
6^2 + 17^2 = 10^2 + 15^2`, `425 = 5^2 + 20^2 = 8^2 + 19^2 =
13^2 + 16^2`, and `650 = 5^2 + 25^2 = 11^2 + 23^2 = 17^2 + 19^2`. The
runs arrive within a few hundred weighted pairs -- the third number's
weight is 650, so the scan ends just past it -- and each run is walked
eagerly, bounded by the number of representations the weight has.

## Map class

`T`. The statement translates whole: the stream of all numbers written
as a sum of two squares in three different ways, showing how, built in
the way of exercise 3.71. The one Rust wrinkle is shared with 3.71: the
grouping combinator is exercise-local because the section module ships
no run-forming helper.

## Deviation

None.
