# Exercise 4.77: delayed filtering for not (T)

## Approach

The promised filters extend the frame with a `*promise*` binding
holding the tagged query when its variables are unbound, and the
fulfillment pass discharges every promise once the rest of the
conjunction has run. Deferred/fulfilled counters pin the machinery.

## Map class

`T`.

## Sample answer

The book's 4.4.3 wrong-answer cases come out right: the `not` query
answers the six supervisors outside programming (one promise deferred,
eight fulfillments) and the `lisp-value` query answers the five
salaries above 30000 (one promise deferred, nine fulfillments), where
the naive filters give an empty stream and an unknown-variable error.
