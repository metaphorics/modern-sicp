# Exercise 2.73a: the atan rule (this edition's addition)

## Approach

Adds `Atan(Box<Expr>)`, a new expression variant, and installs its
derivative rule under `("deriv", "atan")` in the same table 2.73 built:
`d(arctan u)/dx = du/dx / (1 + u^2)`, represented without a division
operator as `du * (1 + u^2)^-1` using the exponentiation constructor
already in scope. Differentiating `(atan x)` with respect to `x` folds
to `(** (+ 1 (** x 2)) -1)`; differentiating `(atan (+ x 3))` carries
the chain rule through `du = 1` unsimplified until the outer product
folds it away, landing on `(** (+ 1 (** (+ x 3) 2)) -1)`. No rule
already installed changes, and no match arm in `deriv` changes: the
addition is exactly the table entry plus the variant that names it,
which is the section's own point about data-directed additivity made
concrete on a rule the book did not give.
