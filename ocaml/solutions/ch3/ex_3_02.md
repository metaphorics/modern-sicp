# Exercise 3.2: monitored procedure (translate)

The map class is `T`. Scheme's `mf` mixes three unrelated answer
shapes (a count, an unspecified reset value, and `f`'s own result)
in one untyped return position, and mixes the two control symbols
into `f`'s own argument domain. OCaml closes both opens: `'a message`
separates `How_many_calls`, `Reset_count`, and an ordinary `Input x`;
`'a response` separates the three possible answers. The counter
itself is a captured `int ref`, incremented on every `Input` and
reset to zero on `Reset_count`.

Sample: `ex_3_02 ()` is `(Value 10., Count 1)`, matching the
statement's `(s 100)` then `(s 'how-many-calls?)` over
`(make-monitored sqrt)`.
