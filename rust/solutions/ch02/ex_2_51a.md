# Exercise 51a: the below-via-rotate composition check (this edition's addition)

## Approach

Exercise 2.51's equivalence check runs on one tiny probe pair. This
addition re-proves the identity on the real wave painter at the SVG
level: the direct and rotated constructions must produce byte-identical
documents. It also tests a case the identity does not cover for free.
Stacking wave over the X painter must put the wave's segments in the
bottom half and the X's in the top half. This catches the
argument-order bug that equality on a symmetric example would hide.
The picture-language example generates the figure pair
`below_direct.std.svg` and `below_rotate.std.svg`, then verifies them
against these painters byte for byte.
