# Exercise 5.11: three save and restore disciplines, and a pruned Fibonacci (T)

## Approach

`RestoreDiscipline` is a three-way typed switch set before a run:
Plain pops the top entry into the named register (the book's
behavior), Tagged faults with `MismatchedRestore` when the popped
entry was saved from another register, and PerRegister keeps one
stack per register. The book's probe `(save y)(save x)(restore y)`
pins all three: y = 8, a typed fault naming y and x, and y = 7.
Part (a) exploits the plain discipline in `afterfib-n-2`: a plain
`(restore n)` picks up the value saved from `val`, so the pair
`(assign n (reg val))` plus `(restore val)` collapses into that one
instruction. The pruned machine matches the host on n = 0..=10.
Under the other disciplines the same controller is refused
(Tagged: `MismatchedRestore` at step 52; PerRegister: `n`'s stack
runs dry at step 93), which is exactly the point of the exercise.

## Map class

`T`.

## Sample answer

Pruned fib(6) runs 269 instructions against the original's 281
(twelve internal calls, one instruction shorter each), with pushes
unchanged at 48 and peak depth 10; the answer stays 8.
