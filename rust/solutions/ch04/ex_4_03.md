# Exercise 4.3: data-directed dispatch in eval (T)

## Approach

The solution keeps an operation table keyed by the expression head. Each
handler is a typed operation value, and a new operation can be installed while
the table is live. Dispatch is therefore data lookup, not a chain of syntax
predicates in the evaluator.

## Map class

`T`.

## Sample answer

`square(7)` is `49`; a missing head answers `None`; installing `double` makes
`double(7)` answer `14` without changing the dispatch code.
