# Exercise 5.43: scanning out internal definitions (T)

## Approach

Internal definitions become ordered local bindings: each `let` initializes its cell before the next reads it. Reading a name before its binding exists never reaches evaluation — admission rejects the program before any effect, the way the scan rejects an unassigned variable.

## Map class

`T`.
