# Exercise 4.38: multiple dwelling minus the Smith-Fletcher clause (T)

## Approach

The book's procedure with the requirement
`(require (not (= (abs (- smith fletcher)) 1)))` omitted. The test pins
the count two independent ways: the amb search enumerates the solutions
one `try-again` at a time, and a plain host loop over all 120 floor
assignments applies the remaining restrictions, so the count does not
rest on the evaluator alone.

## Map class

`T`.

## Sample answer

Five solutions, in search order:
`((baker 1) (cooper 2) (fletcher 4) (miller 3) (smith 5))`,
`((baker 1) (cooper 2) (fletcher 4) (miller 5) (smith 3))`,
`((baker 1) (cooper 4) (fletcher 2) (miller 5) (smith 3))`,
`((baker 3) (cooper 2) (fletcher 4) (miller 5) (smith 1))`,
`((baker 3) (cooper 4) (fletcher 2) (miller 5) (smith 1))` -- the last
but two being the book's original answer.
