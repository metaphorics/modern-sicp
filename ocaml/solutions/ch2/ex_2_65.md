# Exercise 2.65 — Theta(n) union and intersection for tree sets (translate)

The map class is `T`: only the syntax changes. Built from Exercise
2.63's `tree_to_list_2` and Exercise 2.64's `list_to_tree`,
`union_set` and `intersection_set` convert both trees to ordered
lists, merge or intersect the lists in `Theta(n)` the way the
ordered-list representation does, and convert the result back to a
balanced tree. Every step is `Theta(n)`, so the whole operation is
too, an improvement over doing set algebra directly on unbalanced
trees.

Sample: `ex_2_65 ()`, the union and the intersection of the tree of
`{1, 3, 5, 7}` and the tree of `{3, 4, 5}`, are the balanced trees of
`{1, 3, 4, 5, 7}` and `{3, 5}`.
