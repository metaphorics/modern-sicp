# Exercise 5.45: comparing factorial stack use (T)

## Approach

The recursive factorial runs two ways at n = 5 and 10: the counted compiler run and the special-purpose Figure 5.11 machine. The hand-tuned machine parks exactly `2n - 2` pushes with depth never exceeding the compiled run's, and every implementation answers correctly, so the rows compare control, not arithmetic.

## Map class

`T`.

## Sample answer

Answers are `120` and `3628800` everywhere. Machine pushes are exactly `2n - 2` with depth at or under the compiled run's.
