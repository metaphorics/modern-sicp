# Exercise 5.22: append and append! machines

`appendController` walks x recursively, saving each car and continuation. At the base case it points z at y; the return path allocates a fresh cons cell for each saved car. For x = `(1 2 3)` and y = `(4 5)`, z is p7, the original x remains p2 and unchanged, and free advances from p5 to p8.

`appendBangController` walks to the last pair of x and performs `set-cdr!` with y. It does not allocate a result cell: x remains the answer pointer p2, its list now reads `(1 2 3 4 5)`, and free stays p5. The tests pin both memory drawings and use the section's `eq?` word comparison to distinguish a copied result from the in-place splice.
