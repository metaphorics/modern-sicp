# Exercise 5.36: operand evaluation order (T)

## Approach

Calls and nested operands evaluate left to right, as in Rust. Two operand functions announce themselves as they run, so the transcript records the order while the combined value proves the argument list keeps source order. Both engines must print the same three lines in the same order.

## Map class

`T`.

## Sample answer

Both engines print `first`, then `second`, then `12`, with the recording positions strictly ordered.
