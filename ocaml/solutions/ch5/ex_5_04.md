# Exercise 5.4 — the two exponentiation machines

The map class is `T`. The statement asks for controller sequences for
the recursive `(expt b n)` and its iterative reformulation.

The recursive controller follows the 5.1.4 discipline with one
economy the section itself anticipates ("whether there are other
registers that need to be saved depends on the particular machine"):
only `continue` is saved around the recursive call. The subproblem
clobbers `n` (decrementing it) but never `b`, so `b` needs no save;
each returning level multiplies `b` into `val` once. The register set
is `b`, `n`, `val`, `continue`; the sequence is the
`expt_recursive_controller` text of `solutions/ch5/sec_5_4.ml`.

The iterative controller is the 5.1 pattern again: registers `b`,
`counter`, `product`, a single test `(op =)` against `(const 0)`, and
no stack and no `continue` at all — the state is wholly in the
registers.

Running both, `ex_5_04 ()` answers `["1024"; "243"; "1024"; "243"]`:
recursive on (2, 10) and (3, 5), then iterative on the same inputs —
identical answers, different machinery. The stack the recursive machine
uses is exactly `n` levels deep (one `continue` per level), the
observation 5.5 and 5.6 measure for the factorial and Fibonacci
machines.
