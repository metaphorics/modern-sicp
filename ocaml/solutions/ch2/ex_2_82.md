# Exercise 2.82: multi-argument coercion (adapt)

The map class is `A`: `apply_generic_n` generalizes `apply_generic` to
any number of arguments by trying the strategy the exercise names:
coerce every argument to the type of each argument in turn, stopping
at the first type for which every coercion succeeds and an operation
entry exists. `coerce_all_to target args` tries to coerce every
argument to `target`'s type, answering `None` if any argument has no
path there.

`ex_2_82_a ()` is the case where the strategy works: `"add3"` is
installed for three `"real"` arguments plus a
`"rational" -> "real"` coercion, and coercing every argument
to the first argument's type finds the installed entry.
`ex_2_82_b ()` is the exercise's hint made concrete: an operation
installed only for `["a"; "b"]` with no `a -> b` or `b -> a` coercion
in either direction, so trying to coerce every argument to one common
type never finds it, even though the exact mixed-type entry exists,
the situation the exercise asks for an example of.
