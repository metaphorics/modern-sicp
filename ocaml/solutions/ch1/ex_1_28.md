# Exercise 1.28 — Miller-Rabin test (translate)

The map class is `T`. `miller_rabin_expmod` behaves exactly as `expmod`
except that at each squaring step it also asks whether the value about
to be squared is a nontrivial square root of 1 modulo `m` — not equal to
1 or `m - 1`, yet its own square is 1 modulo `m`. If so, it returns 0 as
the hint directs, and since 0 can never equal 1, the outer
`miller_rabin_test` (which checks the whole power equals 1 modulo `n`)
rejects `n` immediately.

For a genuine prime `n`, no such nontrivial root exists (this is exactly
the fact the book states as the reason Miller-Rabin cannot be fooled), so
the signal never fires and `miller_rabin_expmod a (n - 1) n` is the
ordinary Fermat power, equal to 1 by Fermat's Little Theorem. For an odd
composite `n`, at least half of the witnesses `a` reveal a nontrivial
root somewhere in the squaring chain, so the signal fires far more often
than the Fermat test alone would ever catch — including on Carmichael
numbers, which fool the plain Fermat test for every witness.

`ex_1_28 ()` runs 30 rounds of `miller_rabin_prime` against the six
Carmichael numbers exercise 1.27 confirmed fool the Fermat test; every
result here is `false` — Miller-Rabin correctly rejects all six, where
the plain Fermat test cannot. The test also checks `miller_rabin_prime`
accepts the ordinary prime 97 and rejects the ordinary composite 100.
