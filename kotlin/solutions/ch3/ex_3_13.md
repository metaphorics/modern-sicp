## Exercise 3.13: make a cycle in a linked pair chain

Approach: `makeCycle` assigns the original head to the last `PairCell`'s
`second` field. The resulting graph has three cells, and the last one links
back to the first.

Why the search no longer terminates: `lastPair` stops at `Empty`; after the
mutation, the chain has no such terminator. A linear walk repeats the same
three cells forever.

What the tests say: one test follows three links and checks that the cursor
returns to the exact original head. Another walks nine steps and checks that
the cursor never reaches `Empty`. These assertions pin both the cycle's
shape and why a last-cell search cannot finish.

Class: T (the cycle uses mutable host data and object identity).

Deviation: the linked structure is observed directly, not through a list
printer.
