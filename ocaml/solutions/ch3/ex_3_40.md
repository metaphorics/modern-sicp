# Exercise 3.40: all values of concurrent x squared and cubed (translate)

The map class is `T`. Unsynchronized, each read of `x` on either side
is its own event, so the solution enumerates every interleaving of the
squaring process's read-read-write with the cubing process's
read-read-read-write and simulates them; whatever values a write's
side actually saw are what it multiplies together. The enumeration
yields the five powers 10^2 through 10^6. Serialized, the two
statements cannot interleave at all, so both sequential orders run,
and they agree here because squaring and cubing commute:
`(x^2)^3 = (x^3)^2 = x^6 = 1000000`. The live sampler only has to stay
inside the enumeration.

Sample: `ex_3_40 ()` answers
`([100; 1000; 10000; 100000; 1000000], [1000000])`.
