# Exercise 2.56: exponentiation added to the expression variant (adapt)

The map class is `A`: the idea (extend `deriv` with one more case
and two more smart constructors) survives, but adding a case to a
Scheme list-tagged representation is adding a fourth `cond` clause,
while adding a case to an OCaml variant is adding a constructor,
`Power of expr * expr`, that the compiler then forces every match to
handle. `make_exponentiation` builds in the book's two rules
(anything to the 0 is 1, anything to the 1 is itself) the same way
`Deriv.make_sum`/`make_product` build in theirs, and `deriv`'s new
case is the power rule `d(u^n)/dx = n u^(n - 1) du/dx` written
directly with `make_product` and `make_sum`.

Sample: `ex_2_56 ()`, the derivative of `x^3`, is `Prod (Const 3,
Power (Var "x", Const 2))`.
