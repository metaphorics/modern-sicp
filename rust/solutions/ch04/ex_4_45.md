# Exercise 4.45: five parses of the ambiguous sentence (T)

## Contract

Typed grammar parses compiled into `search-depth-first/1` paths with guarded
token transitions and rendered-tree `Success` answers.

## Lesson

The recursive grammar accepts only complete sentence spans. Each accepted
`Tree` is compiled into one `Search` path that guards `unparsed` at every
consumed word, sets the next position, and ends with a full-input guard before
success. The search engine returns five distinct rendered trees; a malformed
input has no grammar parse and therefore no search path.

## Map class

`T`.

## Sample answer

`SearchEngine` returns five unique `S(...)` tree renderings and no answer for
the malformed input.
