# Exercise 4.23a (this edition): counting analysis invocations (T)

## Contract

Instrumented analysis over the real `Plan` returned by `ch04::sec_4_1::analyze`,
plus retained execution through `run_analyzed_program`.

## Lesson

The counter is attached to the analyzer seam and counts each returned sequence
procedure. A one-expression body analyzes once under either shape; executing it
twice gives the text version no sequence wrapper and gives Alyssa's per-step
wrapper two runtime calls. The checked source's retained plan is run separately
to prove the same transcript.

## Map class

`T`.

## Sample answer

Analysis calls are `1` and `1`; runtime sequence work is `0` and `2`; the
retained analyzed program prints `7\n7\n7\n7\n`.
