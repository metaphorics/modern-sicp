# Exercise 3.4 — lockout after seven bad passwords (translate)

The map class is `T`. A second captured `int ref` counts consecutive
incorrect passwords; a correct password resets it to zero before the
requested operation runs, matching "consecutive" in the statement
literally (an intervening correct access clears the count). Once the
count exceeds seven, the account answers `Police_called` instead of
`Incorrect_password`.

Sample: `ex_3_04 ()` is a list of eight responses to eight consecutive
wrong-password withdrawals: the first seven are `Incorrect_password`
and the eighth is `Police_called`, since "more than seven" is
violated starting at the eighth attempt.
