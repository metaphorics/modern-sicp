# Exercise 3.59a: the derivative of a coefficient stream

## Approach

The derivative of a0 + a1 x + a2 x^2 + ... has coefficients a1,
2 a2, 3 a3, ..., so `differentiateSeries` is the tail of the stream
zipped with `integers`, each coefficient multiplied by its new
one-based index. Because every coefficient is an exact `Rat`, the
derivative identities hold by equality: D(exp) = exp, D(sin) = cos,
D(cos) = -sin, each pinned on a six-to-eight term prefix.

## Map class

`T` (map row 3.59a: direct translation, same coefficient streams).

## Deviation

The suggested pin "D(integrateSeries(s)) = s minus its constant
term" is not an identity of the streams themselves: the book's
integrate output is shifted, its element j being the coefficient of
x^(j+1), so differentiating that shifted stream directly scales
element j by (j+1)/(j+2) (the probe returns 1/2, 0, -1/8, ... for
sin, not the sine coefficients). The statement's own rule is to cons
the constant on first, and under that contract the identity is exact:
D(0 : integrateSeries(s)) = s, verified for exp, sin, and cos. The
tests pin that form.
