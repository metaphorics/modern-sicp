# Exercise 3.18: detect a cycle in a list (adapt)

The map class is `A`, for the same reason as exercise 3.17: OCaml has
no built-in identity-keyed set, so `contains_cycle` carries its own
`visited` list compared by `==`. It walks the `cdr` chain, and answers
`true` the moment it revisits a pair already seen. The four probes
build a plain acyclic list, the closed ring of exercise 3.13, a
single self-pointing pair, and the empty list, each built as its own
fresh chain, since aliasing two of these bindings to the same
underlying pairs would make closing one also close the other and
falsify the "plain list" case.

Sample: `ex_3_18 ()` answers `(false, true, true, false)`.
