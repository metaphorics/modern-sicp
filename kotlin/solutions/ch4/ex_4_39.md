# Exercise 4.39: does the order of the restrictions matter?

## Approach

The book order and a Fletcher-first reorder answer the same assignment;
the expected guest-side count to the first answer is 1470 failed
requirements under both orders. This is not a measurement of the old
evaluator's internal backtrack resumptions. In the book's program,
every restriction is checked only after all five floors are
chosen, so an assignment fails at the same innermost choice point
whichever requirement rejects it first, and reordering the requires
cannot change the search tree. Reordering pays only when a requirement
moves ahead of a choice: 4.40's pruned program, 210 backtracks.

## Map class

`T` unchanged. Reordering requirements after all choices does not
change the number of failed assignments; moving a requirement ahead
of a choice does, as the 4.40 pruning example demonstrates.

## Deviation

None.
