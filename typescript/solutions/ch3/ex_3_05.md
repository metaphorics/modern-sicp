# Exercise 3.5: Monte Carlo integration

## Approach

The experiment draws a point from the rectangle with the book's
`randomInRange` and runs the predicate; the section's `monteCarlo`
turns `trials` into the fraction inside the region; the estimate
multiplies the fraction by the rectangle's area. Randomness is an
`Effect<number>` argument (the section's seeded `makeRand`), so the
whole exercise is reproducible instead of hostage to `Math.random`,
and the tests pin exact computed estimates.

## Numbers

Seed 42, 10000 trials: the unit circle over the square (-1, -1) to
(1, 1) estimates `3.104` (off pi by about 0.038); the book's radius-3
circle at (5, 7) over the rectangle (2, 4) to (8, 10) estimates
`27.936` against the true `9*pi` of about 28.274. A predicate that is
everywhere true estimates the rectangle's exact area (12 for the 3 by
4 rectangle), everywhere false estimates 0. The same seed reproduces
the same estimate exactly.

## Map class

T (plain port; rust holds the tailored 3.5a addition, the seeded
stream snapshot).

## Deviation

The book's `random-in-range` sits on MIT Scheme's `random`; the
edition draws uniform 32-bit values from the section's xorshift
generator and scales them into the range, which is what makes the
estimate pinnable.
