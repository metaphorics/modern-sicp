# Exercise 5.51: the evaluator translated into C

`ecevalC` is the 5.4 explicit-control evaluator translated into C:
the registers are globals, every `ev-` entry point is a label in one
function, `continue` holds label addresses through the computed-goto
extension, and the stack is an array with the same push/pop
discipline. Pairs, symbols, frames, and the primitive table are the
run-time support the exercise requires. The port corrects three
accessor paths the OCaml edition's C miswired (`cadr`, `caddr`,
`cddr` each read one link too many); a runtime check with nested
accessors confirms 20, 30, and `(30)`.

`translatedEvaluatorRuns()` writes the translation and the book's
factorial session to a scratch directory, builds with `cc -O1`, runs
the binary, and answers the stdout lines, pinned by the test as `ok`
and 120. The stack counters print to stderr (147 pushes at depth 28
for this build) and stay out of the pin.
