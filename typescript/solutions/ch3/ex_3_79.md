# Exercise 3.79: the general second-order solver

## Approach

The statement generalizes `solve-2nd` to any second-order equation
`d^2y/dt^2 = f(dy/dt, y)`: where exercise 3.78 summed the two scaled
taps, this network feeds an arbitrary function of the two state
signals into the derivative integrator. The solution keeps the
statement's argument order, so `f` receives the derivative first and
the position second, spelled `f(dy, y)`; the body is the exercise
3.78 pair of coupled `integralDelayed` loops with the sum replaced by
`streamMap2((d, yy) => f(d, yy), dy, y)`.

## Pins

Computed by running. Argument-order check: `solveGeneral((d) => d, 1,
2, 0.25)` solves `y'' = y'` and gives the exact dyadic sequence
`[1, 1.5, 2.125, 2.90625, 3.8828125]`, the discrete growth of a
derivative integrating itself; with the arguments swapped the loop
would integrate the position instead and diverge on a different
curve. The undamped case through an `f` closure, `(d, yy) => -yy`
from `y0 = 0`, `dy0 = 1`, `dt = 0.01`, reproduces exercise 3.78's
values bit for bit: `0.8456705645316805`, `0.918463576916705`,
`0.14335314503859142` at indices 100, 200, 300, with the same errors
`0.0041995797237840415`, `0.009166150091023284`,
`0.0022331369787242095` against `Math.sin`. The damped case through
`(d, yy) => -0.1 * d - yy`, from `y0 = 1`, `dy0 = 0`, `dt = 0.01`,
reproduces the first five values `1 1 0.9999 0.9997001 0.9994004099`
and the envelope pins `0.18510721623125634` at index 500 versus
`-0.09990880783812048` at index 4000, decay included.

## Map class

T (translate: syntax changes only). The row has no tailored idea

## Deviation

The task shorthand described `f` as taking `y` then `y'`; the
statement's own signature is `f(dy/dt, y)`, and the statement's order
wins, so `f` receives the derivative first. The deviation is
documented on the `SecondDerivative` type and exercised by the
`y'' = y'` order check, which fails under the swapped convention.
