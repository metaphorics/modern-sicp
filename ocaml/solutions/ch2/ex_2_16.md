# Exercise 2.16: equivalent expressions, different answers (translate)

The map class is `T`. Equivalent algebraic expressions differ under
interval arithmetic because every appearance of an interval variable
is evaluated as though it names an independent quantity; an expression
that repeats a variable therefore accumulates uncertainty an
algebraically equivalent, non-repeating expression does not, the same
mechanism exercises 2.14 and 2.15 exhibit for division and `par1`
versus `par2`.

`ex_2_16 () = sub_interval a a` for `a = [2, 4]`, giving `[-2, 2]`
rather than the algebraically exact `[0, 0]`.

Devising a package free of this shortcoming is, as the book warns,
essentially impossible while intervals stay bare pairs of bounds: that
representation has already discarded which sub-expressions share a
source variable, and no amount of cleverness in `sub_interval` or
`div_interval` can recover information the representation never kept.
A genuinely different representation, one that carries a dependency
record alongside each interval's bounds, could track shared sources
and compute tighter answers, but that is a new, richer abstraction,
not a patch to this one.
