# Exercise 2.20: `same_parity` with a rest slice

## Approach

`same_parity(first, rest)` takes a fixed `i128` followed by a `&[i128]`
slice. It filters that ordered sequence by the first value's parity and
collects the survivors into a `List`. The slice keeps the remaining
arguments homogeneous without macros or a variadic calling convention.

## Map class

`A`: the variadic-mechanism part of the statement uses a Rust slice;
the parity-filtering objective is unchanged.

## Deviation

None beyond the mechanism substitution the map prescribes.
