# Exercise 5.27: stack behavior of the recursive factorial

The recursive factorial runs through the same monitored evaluator over n = 1 to 6. Every level defers work across the recursive call, so the counters again grow linearly, at this process's own per-level steps. The comparison the exercise asks for is between the two processes: the recursive level pushes at least as much as the iterative one for the same factor, which the test pins as the first-step comparison plus each table's constant step.
