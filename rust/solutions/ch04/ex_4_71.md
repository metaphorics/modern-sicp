# Exercise 4.71: explicit delay in simple-query (T)

## Approach

The implementation represents Louis's undelayed `simple-query` and
`disjoin` as table processors. The fuel-bounded fallback compares them
with the delayed engine. In this edition, a Rust stream value is already
lazy -- every recursion point sits behind a `cons-stream` tail or a
boxed thunk -- so the eager Scheme argument evaluation that makes the
undelayed definitions diverge at construction has no counterpart here.
The undelayed engine returns the same first answer. The observable
difference appears only while searching for deeper answers; both
engines exhaust the same fuel.

## Map class

`T`.

## Sample answer

Both engines answer `(outranked-by (Bitdiddle Ben) (Warbucks Oliver))`
first; both exhaust the fuel hunting a second. The undelayed `or`
chains into the regress one branch earlier.
