# Exercise 4.13: `make-unbound!` removes one frame's binding

## Lesson

Removal touches the first frame only -- the reading that keeps unbind
a frame operation, symmetric with `define`, which also binds one
frame. An absent name removes nothing and still answers `ok`, so
unbind is idempotent; the shadow probe shows the outer binding visible
again after the shadow is removed, and the global never touched.

## Map class

`A` (map row 4.1: frames as data, mutable maps). Removal is the
map's own operation over kernel frames.

## Deviation

None. The form takes the operand name unevaluated in spirit: the
guest helper takes the name as data.

## Answer

- Unbind the global: `3`, `ok`, then failure.
- Unbind the shadow: the outer `1` shows through, the global stays `1`.
- Absent names answer `ok`.
- Pin: `unboundTranscript() == "3\nok\nerror\n"`,
  `unboundShadowTranscript() == "1\n1\n"`,
  `unboundAbsentTranscript() == "ok\n"`.
