# Exercise 4.21: recursion without `define` (T)

## Contract

Typed procedure values passed as ordinary arguments.

## Lesson

Factorial passes itself to itself. Fibonacci passes the same self-function
through its accumulator state. The even/odd pair is a typed procedure bundle:
each step receives the other procedure explicitly, so the recursive knot is
data rather than a top-level environment mutation.

## Map class

`T`.

## Sample answer

`factorial(10) = 3628800`, `fibonacci(10) = 55`, and the mutual pair answers
`even(10) = true` and `odd(7) = true`.
