# Exercise 1.40: cubic for Newton's method (translate)

The map class is `T`. `cubic a b c` partially applies three
coefficients and returns the one-argument function
`x -> x^3 + a x^2 + b x + c`, exactly the shape
`newtons_method (cubic a b c) guess` expects, matching the book's
`(newtons-method (cubic a b c) 1)`.

(`a = -6`, `b = 11`, `c = -6`), `newtons_method (cubic (-6.) 11.
(-6.)) 1.` converges to `1.`, the nearest of the three real roots to
the starting guess. `ex_1_40 () = 1.`.
