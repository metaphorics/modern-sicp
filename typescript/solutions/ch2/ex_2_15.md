# Exercise 2.15: is Eva right that `par2` is a "better" program?

## Approach

Eva's diagnosis, restated: a formula that mentions an uncertain variable
fewer times produces tighter error bounds, because the system cannot
recognize that two occurrences of the same variable are correlated.
`par1` names `r1` and `r2` twice each; `par2` names each once. Reusing
exercise 2.14's two 5-percent resistors, the test checks both the numbers
(5.0 percent against 14.9 percent) and the containment (`par2`'s bounds
sit inside `par1`'s), so "better" is pinned as tighter, not merely
different. The honest scope: better *under this system's
independent-occurrence model* - a smarter package (exercise 2.16) could
make both formulas agree.
