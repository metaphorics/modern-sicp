Exercise 5.47: compiled calls to interpreted procedures.

The `compound_calls` configuration adds the third branch to every
procedure call: `compound-procedure?` hands the call to the
evaluator's `compound-apply` through the `unev` register, whose value
is dead at a call site. The book's `compapp` register has no name in
this machine's fixed register set, so the entry point rides in `unev`
instead -- the recorded deviation. The compound branch sets
`continue` exactly as the compiled branch would for all four
target/linkage combinations. The pinned session is the book's:
compile-and-go `f`, define `g` interpreted at the driver, then
`(f 5)` answers 10 through `compound-apply`.
