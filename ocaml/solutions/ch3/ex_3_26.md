# Exercise 3.26 — binary-tree table records (adapt)

The map class is `A`: records replace the book's ordered-tree pairs,
with `left`/`right`/`value` as mutable fields a lookup or insert
rewrites in place rather than a `set-car!`/`set-cdr!` pair surgery.
`insert` walks from the root, comparing keys with `key_compare`
(numeric or symbolic, never mixed), and rebuilds only the spine of
pointers from the insertion point back to the root — a constant
number of writes per level, matching the book's O(log n) claim for a
balanced tree. Unlike exercise 2.66's tree built once from immutable
pairs, this table stays a live mutable object across repeated
inserts, including overwriting an existing key.

`("ten thirty fifty seventy eighty", "new", None)`.
