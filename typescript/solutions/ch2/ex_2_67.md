# Exercise 2.67: the sample decode

## Approach

Define the book's sample tree and the 13-bit sample message with the
section's constructors and run `decode`.

## Answer

`decode(sampleMessage, sampleTree)` is `[A, D, A, B, B, C, A]`: the bits split
as 0 | 110 | 0 | 10 | 10 | 111 | 0 against the codes A = 0, B = 10,
D = 110, C = 111.
