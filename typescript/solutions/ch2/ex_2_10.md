# Exercise 2.10: division checked against a zero-spanning divisor

## Approach

`divIntervalChecked` tests `y.lo <= 0 && y.hi >= 0` before dividing - the
boundary is included, since an interval that only touches zero makes the
reciprocal infinite all the same - and returns the typed error
`ZeroSpan` carrying the offending bounds. On the success side it computes
the section's reciprocal multiplication. This replaces the undefined
pre-fix result (an infinity, a NaN, or a numerically plausible but
meaningless finite interval) with a value the caller must handle, per the
edition's no-throw errors rule for chapters 1-2.

## Numbers

`[6, 8] / [2, 4]` asserts the interval `[1.5, 4]`; dividing by `[-1, 1]`
asserts `ZeroSpan`, as do the two touching cases `[0, 1]` and `[-1, 0]`.

## Map class

`T`: Ben's fix translates directly; only the error-signaling mechanism
changes, from the original's `error` to a typed error value.

## Deviation

None.
