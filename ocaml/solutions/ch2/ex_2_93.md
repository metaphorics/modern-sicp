# Exercise 2.93: generic rational functions (adapt)

The map class is `A`: `rational_function` bundles a numerator and a
denominator, both polynomials, kept exactly as given;
`make_rational_function` does not call a reduction step the way
2.1.1's `make_rat` did, per the exercise's explicit instruction.
`add_rational_function rf1 rf2` cross-multiplies: `n1*d2 + n2*d1` over
`d1*d2`, with no reduction step, using the generic `add_poly` and
`mul_poly` this section already built.

`ex_2_93 ()` builds `p1 = x^2 + 1`, `p2 = x^3 + 1`, `rf = p2/p1`
(matching the exercise's `make-rational` call), and adds `rf` to
itself, returning the sum's numerator and denominator term lists as
`(order, coeff)` pairs. Since nothing reduces, the denominator is
`p1^2`, not `p1`: the exercise's own observation about this addition
procedure.
