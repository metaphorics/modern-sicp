# Exercise 4.16: scan out internal definitions (T)

## Approach

`scan_out_defines` collects a body's top-level defines into names and values
(function forms become set! of a lambda) and rebuilds the body as
`(let ((name (quote *unassigned*)) ...) (set! name init) ... rest)`. The
installation point is `make_named_procedure` and the lambda clause -- the
procedure is scanned once when made, not once per call, which is the better
answer to part (c). The evaluator's variable clause raises on a read of the
unassigned marker, giving the scan-out error its own message.

## Map class

`T`.

## Sample answer

The mutually recursive `f` answers `#t`; `(g)` where a's value reads b answers
`the variable b is read before its define runs`.
