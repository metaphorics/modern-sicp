## Exercise 1.28: Miller-Rabin is not fooled by Carmichael numbers

Approach: `squareModCheckingRoot` returns 0 in place of a squared value
whenever that value is 1 modulo `n` but the number squared was neither 1
nor `n - 1` — a nontrivial square root of 1, which is impossible modulo a
prime. `millerRabinExpmod` threads this check through every squaring
step while computing `a^(n-1) mod n`; `millerRabinTest` accepts only when
the result is exactly 1. Run 30 times each with the shared seeded
generator (decision 0001, seed 42), all six Carmichael numbers fail
Miller-Rabin, unlike the plain Fermat test of exercise 1.27, which they
fool for every possible `a`.

Class: T (translate). Deviation: none in the algorithm; `random` becomes
the shared seeded generator, the same substitution exercise 1.24 makes,
so the classification is reproducible rather than dependent on an
unspecified host `random`.
