# Exercise 3.29: the or-gate from inverters and an and-gate

## Approach

The book builds `or` from De Morgan's identity, `a or b` equals
`not (not a and not b)`, and asks for the compound gate and its
delay. The Rust solution wires two inverters onto the inputs, an
`and_gate` onto their negations, and a final inverter onto the
conjunction, so the output is the identity's result. The solution
drives the four input combinations through one agenda run and
reports the settled outputs `0, 1, 1, 1, 0`. The delay is the sum
along the path: the input negations run in parallel, then the
conjunction, then the final negation, for `2 * INVERTER_DELAY +
AND_GATE_DELAY`, which is 7 with the section's constants. The tests
pin the transcript, the delay, and the identity itself.

## Map class

`T`. The identity, the construction, and the delay question are the
statement's own, carried out over the translated primitives.

## Deviation

None. The compound gate uses only the section's primitives, as the
statement requires.
