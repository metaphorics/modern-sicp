# Exercise 2.9 — interval width algebra (adapt)

The map class is `A`: the algebra survives, but stating it forces this
edition to settle an invariant section 2.1's narrative left open,
namely that `width` needs no more than the pair `interval` already
provides (a lower and upper bound), so it is written once against the
book's plain pair representation rather than against a richer interval
type.

`width (add_interval x y) = width x +. width y` follows algebraically
from `add_interval`'s definition (shown in the `.ml` comment);
`sub_interval` is the same argument with a sign flip. `ex_2_09`
exhibits the counterexample for multiplication: `a1 = [1, 3]` and `a2
= [5, 7]` share width 1, but multiplying each by `b = [10, 12]` gives
`ex_2_09 () = (13.0, 17.0)`, two different product widths from two
equal-width factors, because the product interval's width depends on
where the factors sit, not only on how wide they are.
