# Exercise 4.8 — named let (translate)

The 4.6 rewrite extends to the named form: `(let name ((v init) ...)
body)` becomes `(begin (define (name v ...) body) (name init ...))`,
built with the typed definition, sequence, and application
constructors. The call finds the definition in the defining
environment, so the body recurses through `name`. The shared reader
has no named let, so shapes arrive through the typed interface, and
the lowering needs nothing beyond the base evaluator.

Sample: `ex_4_08 ()` answers `["ok"; "55"; "10"]` — the binding of
`n` to 10, the statement's fib-iter named let at `n = 10`, and a
second named let summing `0 + 1 + 2 + 3 + 4`.
