# Exercise 5.46: comparing Fibonacci stack use (T)

## Approach

Repeat the factorial stack comparison for tree-recursive Fibonacci at
n = 5, 6, and 7. For each input, measure pushes and maximum depth in
the explicit-control evaluator, compiled code, and the special-purpose
Fibonacci machine. The code presents per-input measurements rather
than extrapolating a limiting ratio from a short range.

## Map class

`T`.

## Sample answer

The implementation returns three rows, one for each input, with
push/depth pairs for all three machines. Tree recursion creates two
recursive calls at each non-base case, so total work and stack behavior
grow with the call tree; these small-input measurements do not
establish a limiting ratio.
