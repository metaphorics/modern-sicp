# Exercise 2.47: frames as lists and as pairs

## Approach

Exercise 2.46's vectors supply the arguments of the two frame
constructors the book proposes. In the list representation a frame is
the three-element list `[origin, edge1, edge2]` and the selectors walk
down it; in the pair representation a frame is `[origin, [edge1, edge2]]`
and the selectors index the tuple. Because `frame-coord-map` only ever
calls selectors, the same coordinate-map arithmetic built on either
representation maps `(0.5, 0.5)` to `(0.5, 0.5)` on the unit frame -
the interchangeability the data abstraction is there to guarantee.

## Numbers

For origin `(0, 0)`, edges `(1, 0)` and `(0, 1)`: both representations'
selectors assert the same three vectors, and a coordinate map built on
each representation asserts `(0.5, 0.5)` for input `(0.5, 0.5)`,
matching the module's record-frame `frameCoordMap` on the same frame.

## Map class

`T`: both book representations with their selectors, translated into
this edition's List and tuple types.

## Deviation

None.
