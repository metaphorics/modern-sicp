# Exercise 2.42: eight queens

## Approach

The representation is one row index per occupied column, so a position
set is a `Vec<usize>` and adjoining a queen appends the row: the
edition's stand-in for the book's set of row-column pairs, where the
column index carries the column. `empty_board` is the sequence with one
empty placement, `safe?` compares the new queen's row and diagonals
against the earlier columns only, and the `queens` skeleton follows the
book's filter/flatmap shape over the placements. The test checks the
92 solutions of the 8-by-8 board and re-validates every solution for
conflicts independently of the solver's own `safe?`.

## Map class

`T`: the statement translates directly; the map's idea column suggests
column-index positions, which is the natural representation this
solution takes without being a tailored addition.

## Deviation

None.
