# Exercise 3.81: the request-driven rand stream

## Approach

Exercise 3.6 added a reset message to the generator so sequences
could be made repeatable; this exercise asks for the same service as
a stream process, with no assignment. The seed is carried as a value
instead of in a hidden state cell: each request answers with the
value the generator emits, `randUpdate(seed)` for `generate` or the
requested `seed` itself for `reset`, and that emitted value doubles
as the seed passed to the recursive tail. The generator's state
therefore lives in the stream of emitted numbers, which is exactly
why a reset makes everything after it a replay of a fresh start. The
starting seed defaults to the module's `randomInit` (the book's
`random-init`), and the recursion's second argument is internal
plumbing, not a different mode.

## Pins

Computed by running. The xorshift chain from 42 is `11355432`,
`2836018348`, `476557059`. Requests `generate generate reset(42)
generate` answer `[11355432, 2836018348, 42, 11355432]`: the reset
emits the new seed itself, and the `generate` after it repeats the
first number of a fresh start, whose first two generates are
`[11355432, 2836018348]`, so the post-reset output equals the fresh
sequence element for element. Three generates from `randomInit`
match the module's `randomNumbers` at indices 1, 2, 3 (its index 0
is the seed 42 itself): `[11355432, 2836018348, 476557059]`. Requests
`generate reset(7) generate generate` answer
`[11355432, 7, 1892583, 470389255]`, and two runs of the same
request stream answer identical streams, the replayability the
exercise exists to provide.

## Deviation

This edition spells the request stream as the union of the string
`"generate"` and `{ kind: "reset", seed }` records, the shapes of the
book's `(generate)` and `(reset <new-value>)` messages. The reset
case emits the new seed itself rather than a filler value, matching
exercise 3.6's convention that the generator answers the value it
resets to; the task's pins (reset visible in the output, post-reset
sequence equal to a fresh start) pin exactly that behavior.
