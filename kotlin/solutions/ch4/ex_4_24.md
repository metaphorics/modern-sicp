# Exercise 4.24: saved analyses, counted

## Lesson

What analysis saves is measured in counters instead of wall-clock
time. Re-analyzing before every call climbs both counters together;
analyzing once and running three times climbs the run counter alone.
The same analyze-once program runs under both engines, and both agree
on every answer and counter: the lesson is the saved analyses, and
the engines concur on them.

## Map class

`A` (map row 4.1: analysis returns closures; timing by counters). The
cross-engine agreement is pinned, not assumed.

## Deviation

The `Analyzed.run` call shape mirrors `Direct.run` per the engine
contract; the gate run confirms the surface.

## Answer

- Re-analyzed: three `7`s, three analyses, three runs.
- Once: three `7`s, one analysis, three runs.
- Analyzed engine: the once-program verbatim.
- Pin: `analysisSavingsTranscript() ==
  "7\n7\n7\n3\n3\n7\n7\n7\n1\n3\n"` and
  `analyzedEngineTranscript() == "7\n7\n7\n1\n3\n"`.
