# Exercise 2.45: `split`, a general splitting combinator

## Approach

`split` takes the two painter combinators (how to join the painter with
the pair, and how to join the pair internally) and returns the split
procedure. Scheme's self-referential lambda becomes a named private
recursive driver that the returned closure calls, since a bare closure
cannot refer to itself by name. `right_split_via_split = split(beside,
below)` and `up_split_via_split = split(below, beside)` reproduce the
hand-built definitions, which the test verifies by exact segment-set
equality against the spine's.

## Map class

`A`: split returns a generic higher-order constructor, realized as a
closure factory over painter combinators.

## Deviation

None.
