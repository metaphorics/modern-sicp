# Exercise 2.34: Horner's rule

## Approach

Horner's rule rewrites a0 + a1*x + ... + an*x^n as
a0 + x*(a1 + x*(a2 + ... + x*an)), which is a right fold over the
coefficient list ordered from the constant term up: at each step the
accumulated value of the higher terms is multiplied by x and the next
coefficient added. That is exactly `accumulate` with the combining
function `(thisCoeff, higherTerms) => thisCoeff + x * higherTerms` and
initial 0, whose zero supplies the absent constant of the x^n term.

## Numbers

`hornerEval(2, list(1, 3, 0, 5, 0, 1))` evaluates
1 + 3*2 + 0*4 + 5*8 + 0*16 + 1*32 = 1 + 6 + 40 + 32 = 79, the book's
answer.

## Map class

`T`: the book's accumulate-based definition translates verbatim.

## Deviation

None.
