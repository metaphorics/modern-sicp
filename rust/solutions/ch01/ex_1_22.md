# Exercise 1.22

`Instant::now()` and `Duration` replace the book's `runtime` primitive:
`Instant::now()` reads the machine's monotonic clock at the start of the
test, and `Instant::elapsed()` reports how long has passed since. The map
class is `A` for exactly this reason: Scheme's `runtime` primitive has no
Rust equivalent, so the statement is reworded around the standard library's
timing API instead of translated word for word.

`search_for_primes` walks consecutive odd integers from a starting point
and keeps the first three that pass `is_prime`. The three smallest primes
above 1000 are 1009, 1013, and 1019; above 1,000,000 they are 1,000,003,
1,000,033, and 1,000,037. Confirmed by trial division at each boundary
(1000, 10,000, 100,000, and 1,000,000) matches those computed by the
program. Since `smallest_divisor` tests divisors up to `sqrt(n)`, the
search near 10,000 should take about `sqrt(10)` times as long per prime as
the search near 1000, and so on for each `10x` step in the input; whether a
given run's wall-clock timings actually bear this out depends on the
machine's noise floor for a microsecond-scale measurement, which is why
the test asserts on the primes found rather than on elapsed time.
