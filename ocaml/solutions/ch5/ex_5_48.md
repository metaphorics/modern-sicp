Exercise 5.48: the compile-and-run primitive.

`compile-and-run` is a machine operation: it takes the quoted
expression, compiles it at run time, records the controller block,
and answers `ok`. The edition's controller is parsed text, so the
book's live patch of a running machine is reproduced as the next
assembled machine carrying the block, with the same operations and a
continued session; the concatenated transcript is the book's session
(ok, then `(factorial 5)` = 120). Recorded deviation: the define
executes on the second assembly, not inside the first machine's
run.
