# Exercise 2.19 — currency as a list (translate)

The map class is `T`. The three helpers are one-line views on the
list: `first_denomination` is `List.hd` with the empty-list case
named, `except_first_denomination` is `List.tl` totalized, and
`no_more` tests for `[]`. `cc` keeps the book's tree-recursive shape
unchanged; only its access to the coin list goes through the helpers.

Coin values are floats because the British list carries a half-penny;
the statement's amount `100.0` and every subtraction of coin values
stay exactly representable, so the integer-valued result count is
exact. The order of `coin_values` does not affect the answer: each
recursion either drops a denomination entirely or spends one coin of
it, so the set of ways counted is the same whatever order the
denominations are visited in (only the tree's shape changes).

Sample: `ex_2_19 () = 292`, the book's `(cc 100 us-coins)`.
