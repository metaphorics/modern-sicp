# Exercise 4.28: forcing the operator (T)

## Approach

`((id +) 2 3)` is the demonstration: `id`'s body answers a thunk whose
expression is `+`, so the application clause must run `actual-value` on the
operator before `apply` can dispatch. The negation proves the point: a variant
evaluator whose application clause calls `eval` on the operator, with everything
else the section's, hands the thunk itself to `apply`.

## Map class

`T`.

## Sample answer

Forced: 5. Unforced variant: "not a procedure: #[thunk]".
