# Exercise 4.9: design iteration constructs (T)

## Approach

`While` and `Until` are typed loop values carrying a condition and a step
function. The runner keeps the state explicit and tests the condition before
each step, which is the host-safe form of the book's iteration design.

## Map class

`T`.

## Sample answer

The `while` loop stops at `5`; the `until` loop stops at `13`.
