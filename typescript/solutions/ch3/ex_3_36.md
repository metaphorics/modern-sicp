# Exercise 3.36: the connector's environment, as a trace

## Approach

The book evaluates `(define a (make-connector))`,
`(define b (make-connector))`, `(set-value! a 10 'user)` and asks for
the environment in which the connector's local
`(for-each-except setter inform-about-value constraints)` runs. The
edition's connectors are closures over exactly that local state, so
the environment is real: each `makeTracedConnector` closure holds the
value, the informant, and the constraint list, and the traced
builders register the module's adder, multiplier, and constant
dispatches under labels so the connectors can name who they talk to.
Every message becomes one `TraceEvent` line: a setter claiming a
value (`setValue`), the value and no-value notices the connector's
`forEachExcept` sends to every constraint except the requester, and
the catch-up notice a late `connect` sends. The test wires the
module's celsius topology from traced parts, sets C = 25 as `user`,
and pins the log.

## Pins

Wiring the network logs six events, the three constants claiming
their connectors: const-9 to w, const-5 to x, const-32 to y, each
followed by the connector's notice to its multiplier or adder (w to
mul-cwu, x to mul-vxu, y to add-vyf). Setting C = 25 as user logs
seven more, in this measured order: user to C (setValue), C to
mul-cwu, mul-cwu to u (setValue), u to mul-vxu, mul-vxu to v
(setValue), v to add-vyf, add-vyf to F (setValue), and F reads 77.
Forgetting C as user logs exactly three lost notices down the spine
(C to mul-cwu, u to mul-vxu, v to add-vyf) and drains it: C and F
have no value, because the user's forget cleared C itself. Setting C
= 25 again logs the seven value arrows once more and F reads 77.

## Map class

`R: trace connector observer wiring`. Each trace line is one arrow
the book's environment diagram drew: the `for-each-except` call the
exercise asks about is the line from the changed connector to each
constraint its closure holds.

## Deviation

The book's drawing of the two connectors, their environment frames,
and the live `for-each-except` expression is replaced by the event
log, per the map's note; the connector interface and the message
discipline are the module's, unchanged.
