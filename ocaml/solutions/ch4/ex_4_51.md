# Exercise 4.51: permanent-set! (translate)

`permanent-set!` assigns without installing the undo trail, so the
trial that eventually fails still leaves its count behind. In the
statement's example the first answer is `(a b 2)` (the rejected `x=a,
y=a` trial raised the counter and survived), and `try_again` reports
`(a c 3)`; the same program under plain `set!` reports `(a b 1)` and
`(a c 2)`, because each rejected trial's assignment is undone before
the next alternative is tried. The demonstration pins all four answers
and the surviving counter value `3`.
