# Exercise 4.60: lives-near duplicate names (translate)

## Approach

The `lives-near` and `same` rules are the book's text. Two people live
near each other when their addresses share a town and they are not the
same person. Because the rule is symmetric, every pair is derived in
both orientations; the solution adds a canonical-direction query that
keeps one orientation per pair with a `lisp-value <` comparison over
formatted person names.

## Numbers

The raw query yields eight answers over four unordered pairs:
Alyssa-Cy in Cambridge, and Ben-Louis, Ben-DeWitt, Louis-DeWitt in
Slumerville, each in two orientations. The ordering-filtered query
yields four, one per pair, each answer carrying the `lisp-value`
literal. The tests pin the eight, the four, both orientations of the
Alyssa-Cy pair, and the canonical survivor.

## Class and deviations

Translated row. Deviation: the duplicate-removal direction uses a host
string comparison registered through `setPredicates`; the book leaves
the filtering mechanism open.
