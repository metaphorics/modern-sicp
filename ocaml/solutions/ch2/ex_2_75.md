# Exercise 2.75: make-from-mag-ang in message-passing style (adapt)

The map class is `A`: message passing is a closure returning a
closure in Scheme, and OCaml's closures play the same role directly,
so the "adaptation" is naming the operation set as a variant instead
of leaving it as an open set of symbols matched with `eq?`.
`op = Real_part | Imag_part | Magnitude | Angle` names exactly the
four operations `apply-generic` can send; `t = op -> float` is a
message-passing complex number, and `apply_generic op z = z op`
sends the message.

`ex_2_75` is `make_from_mag_ang` written the way the book's own
`make_from_real_imag` is written above it: given `r` and `a`, return
a `dispatch` closure that answers each of the four operations from
`r` and `a` directly, the same way `make_from_real_imag`'s closure
answers each of the four from `x` and `y` directly. No call goes
through the other constructor; each representation computes every
operation from its own two numbers.

Sample: `ex_2_75 5.0 0.0` answers `Real_part` as `5.0`, `Imag_part`
as `0.0`, `Magnitude` as `5.0`, and `Angle` as `0.0`: the polar
number `(5, 0)`, which is the real number 5.
