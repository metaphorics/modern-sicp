# Exercise 2.37: matrix operations

## Approach

`dot_product` is the book's given accumulate-of-products, with the
footnote-78 multi-sequence `map` rendered as `zip`. `matrix_star_vector`
dots each row with the vector. `transpose` runs `accumulate-n` with a
prepend, which mirrors the book's cons fill: `accumulate` is a right
fold, so each new column element enters its row accumulator from the
far end. `matrix_star_matrix` transposes `n` and dots every row of `m`
against every column.

## Map class

`T`: the statement translates directly; matrices are `Vec<Vec<i64>>`
and the map's "static shapes" idea stays an untaken idea.

## Deviation

None. The test pins the dot product, the vector product, the
transpose, and the square of the book's example matrix.
