# Exercise 5.15: instruction counting

The counting machine is a subclass that overrides the one execution
loop: `CountingMachine.execute()` advances `instructionCount` before
each execution procedure runs, transfers included, and the driver
reads the counter after the run, the way Alyssa's monitor would
report it. Nothing else in the simulator changes; the counter is a
property of the loop, not of the instructions.

`gcdInstructionCounts()` pins one run each of the two section
machines. The gcd machine on gcd(206, 40) executes 26 instructions:
four full passes over the five-line loop (test, untaken branch, the
rem assign, the two register shuffles, goto) plus the final test and
the taken branch, one pass per division step and one extra test that
observes b = 0. The factorial machine on n = 5 executes 49. Both
numbers are pinned verbatim by `E5_15Test`, and the gcd count
cross-checks the traced run of 5.16, which lists exactly those 26
instructions.
