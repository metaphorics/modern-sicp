# Exercise 4.11: frames as association lists (T)

## Approach

Each frame is an ordered list of typed name/value bindings. Lookup scans from
the newest binding outwards, define appends, and assign replaces the matching
cell. This keeps shadowing and mutation visible in the frame representation.

## Map class

`T`.

## Sample answer

The inner `x` shadows the outer one, `y` is assigned to `20`, and `z` remains
unbound.
