# Exercise 5.50: compile the metacircular evaluator

The canonical Kotlin corpus program
`spec/host-subsets/kotlin/corpus/selfinterp/evaluator.kt` is a guest
evaluator. Its own `main` builds a target program in the guest
value model and evaluates it to 120.0. `metacircularEvaluatorSource`
loads this one source file for both this exercise and the C backend
of exercise 5.52; no forked evaluator string is maintained here.

`compiledMetacircularRuns` admits and checks the kernel, then
executes it through `Direct`, `ExplicitControl`, and the compiled
machine. Each result's `mainValue` records the guest evaluator's
answer. Their agreement demonstrates that machine code can
execute a guest evaluator which itself executes another program.
No claim of observed native or compiled success is made until
the full integration run exercises this path.
