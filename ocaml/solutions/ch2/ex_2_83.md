# Exercise 2.83 — raise operation (adapt)

The map class is `A`: the tower of Figure 2.25 becomes a four-case
`value` variant (`Int`, `Rat`, `Real`, `Cpx`), and `install_raise`
installs `"raise"` for `"integer"`, `"rational"`, and `"real"`, each
one step up the tower; `"complex"` has no supertype, so it gets no
entry, matching the exercise's "for each type (except complex)."
`raise_one_level` looks the tag up in the table and applies whatever
`"raise"` procedure is installed for it.

`ex_2_83 ()` raises the integer 3 to the top of the tower one step at
a time, returning the type tag after each step (`"rational"`,
`"real"`, `"complex"`) and the final complex pair `(3.0, 0.0)`.
