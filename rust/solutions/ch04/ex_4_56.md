# Exercise 4.56: compound queries (T)

## Contract

Typed `Database`/`Term`/`Query` data evaluated by `ch04::sec_4_4::qeval`.

## Lesson

The exercise builds all three requested compound queries over Microshaft:
Slumerville address retrieval, salary comparison against Ben's salary with
`Query::Value`, and a delayed `not` filter for supervisors outside the
computer division. Assertions and rules are typed terms, answers are ordered
substitutions, and rule variables are renamed apart per application.

## Map class

`T`.

## Sample answer

The address query answers Ben, Louis, and Aull. The salary query includes
Louis and every answer's salary is below Ben's. The supervisor query answers
Ben, Scrooge, Cratchet, and Aull.
