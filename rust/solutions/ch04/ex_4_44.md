# Exercise 4.44: eight queens (T)

## Approach

Each row chooses a column through `ChooseRange`. Column conflicts use `Ne`,
and diagonal conflicts use the typed `DiffEq` predicate against explicit row
differences. The search therefore carries the board geometry in its guards.

## Map class

`T`.

## Sample answer

The first four-row solution is columns `3 1 4 2`.
