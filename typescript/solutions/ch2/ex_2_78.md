# Exercise 2.78: the tower's bare base case

## Approach

The book asks for `attach-tag`, `type-tag`, and `contents` that treat ordinary
numbers as themselves. A bare `bigint` names itself `scheme-number`:
`typeTag` answers `"scheme-number"` for a bare bigint and the datum's tag
otherwise; `contents` answers the bigint itself; and the ordinary-number
`attach-tag` is the identity. The implementation builds no pair wrapper for the
tower's base level, which is exactly the book's point.

## Numbers

`typeTag(7n)` and `typeTag` of the tagged form both answer `"scheme-number"`;
`contents(7n)` and `contents` of the tagged form both answer `7n`; the
identity `attach-tag(7n)` is `7n`; and `add(3, 4)` through the section table
still answers `7`.

## Map class

A (untagged numbers need a union with a bare case): the datum union gains the
bare `bigint` member, and every consumer narrows with `typeof` instead of
unpacking a pair.

## Deviation

The section module was retrofitted to this spelling, so every later exercise
(2.79 on) builds on bare bigints rather than on tagged pairs.
