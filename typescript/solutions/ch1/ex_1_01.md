# Exercise 1.1: evaluate a sequence of expressions in order

## Approach

The sequence becomes the body of one main-style script: five arithmetic
expressions, two `const` declarations, then six more expressions that use
`a` and `b`. Each expression contributes the value it produces, and the
two declarations contribute nothing of their own - they only bind names.
A script that prints each value in order prints exactly the returned
list, one value per line; the test pins the whole transcript with one
`toEqual`.

## Numbers

The eleven values in order: `10, 12, 8, 3, 6, 19, false, 4, 16, 6, 16`.
The seventh response is `false` (`a === b` with `a = 3`, `b = 4`), the
run's only non-numeric value. Every numeric response is a small exact
integer, far inside the 2^53 bound of the number model.

## Class and deviations

Adapted row: the original statement asks what the interpreter prints; the
TypeScript host has no standard read-eval-print loop, so the statement
asks for the values of the sequence evaluated in order in a script that
prints each one. No other deviation.
