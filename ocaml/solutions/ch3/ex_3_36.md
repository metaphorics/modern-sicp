# Exercise 3.36 — environment diagram of connector wiring (replace)

The map class is `R`: the SICP exercise asks for the environment
diagram showing how `(set-value! a 10 'user)` reaches a constraint's
local state, which only a Scheme evaluator's frame structure can draw.
This edition's replacement traces the same call graph as a flat list
of dispatch labels instead: setting a connector's value runs
`set_value`, which calls `for_each_except` to reach every attached
constraint's `me` dispatch with `I_have_a_value`, in turn calling
`process_new_value`; forgetting reaches the same constraints with
`I_lost_my_value`, calling `process_forget_value`. The trace makes the
exact same fan-out the diagram would draw, in the order the network
actually executes it.

Sample: `ex_3_36 ()` answers two nonempty traces, one per dispatch
path.
