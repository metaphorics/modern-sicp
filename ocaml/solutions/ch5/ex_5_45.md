Exercise 5.45: stack ratios for the factorial.

All three machines run under the same monitored stack: the interpreted
factorial on the 5.4 evaluator, the compiled one on the 5.5.7 interface
machine (evaluator fragments plus labelled blocks plus the shared
runtime, with a compiled-procedure branch in `apply-dispatch`), and
the Figure 5.11 machine. At n = 5: interpreted 105/18, compiled 10/10,
special 8/8; at n = 10: 220/33, 20/20, 18/18. Open coding brings the
compiled code within two pushes of the hand machine ($2n$ against
$2n-2$), where the $2$ shared by every measurement is the call item's
own `env`/`argl` setup; the old book numbers (144/28 interpreted, 31/14 compiled)
belong to the un-open-coded compiler and are superseded here.
