# Exercise 3.15 — set-to-wow diagrams show sharing (adapt)

The map class is `A`: the book's box-and-pointer diagrams become a
direct physical-equality check. `z1_of x` builds `(cons x x)` by
constructing the wrapped `mobj` for `x` exactly once and storing that
same value in both the `car` and `cdr` fields — reusing a fresh
`Pair (pair_of x)` expression for each field would allocate two
distinct boxes over the same underlying pair, which is not what the
book means by "the same pair in both slots" and would make `==`
report false. `z2` uses two separately built `(a b)` lists, so its
slots are never physically equal. `set_to_wow` then shows the
consequence: mutating through the shared slot changes both readings
of `z1`, while `z2`'s two copies diverge.

`(true, false, "((wow b) wow b)", "((wow b) a b)")`.
