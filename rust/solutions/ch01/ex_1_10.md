# Exercise 1.10

Ackermann's function is translated directly: three named cases plus the
recursive fallback, matching the Scheme `cond` line for line. `A(1, 10) =
1024`, `A(2, 4) = 65536`, and `A(3, 3) = 65536`.

The three named procedures compress to closed forms. `f(n) = A(0, n) = 2n`
because `A(0, y)` is the base case `2y` directly. `g(n) = A(1, n) = 2^n`:
unwinding `A(1, n) = A(0, A(1, n - 1))` doubles the previous value at every
step, starting from `A(1, 1) = 2`. `h(n) = A(2, n)` is a power tower:
`h(0) = 0`, `h(1) = 2`, and `h(n) = 2^h(n - 1)` for `n >= 2`, since
`A(2, n) = A(1, A(2, n - 1)) = 2^A(2, n - 1)`. The map class is `T`: nothing
about the statement changes for Rust, only the `define`-to-`fn` syntax.
