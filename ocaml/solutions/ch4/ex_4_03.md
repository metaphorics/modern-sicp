# Exercise 4.03: data-directed dispatch

The map class is `T`. Each syntax kind has a name, the analogue of the operator symbol heading a compound expression. A table maps kind names to handlers and `eval` looks the kind up before falling back on the standard dispatch, which plays the part of the application and self-evaluating clauses. The table is a value passed to `eval`, not global state. Installing a handler changes the evaluator without editing `eval`.

Sample: `ex_4_03 ()` answers `["120"; "if handled 6 times"; "true"]`: `fact 5` through a counting `if` handler, then one connective expression through a standard table.
