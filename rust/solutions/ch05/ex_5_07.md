# Exercise 5.7: test the exercise 5.4 machines on the simulator (T)

## Approach

Both controllers of exercise 5.4 are transcribed as controller text
and assembled with `make_machine`. The recursive machine counts `n`
down, saving `continue` per level and multiplying on return; the
iterative machine keeps `counter` and `product` and never saves. The
tests sweep b = 2..5, n = 0..9 against the host's `i128::pow` and
check the stack discipline: pushes and depth are both `n` for the
recursive machine, both 0 for the iterative one.

## Map class

`T`.

## Sample answer

2^10 = 1024 and 3^5 = 243 on both machines (pinned literally). The
recursive machine's stack peaks at depth 10 for 2^10; the iterative
machine never pushes.
