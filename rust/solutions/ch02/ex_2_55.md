# Exercise 2.55: quote in edition AST terms (replacement)

## Approach

Quotation is explicit symbolic data in this edition: a quoted form is
the two-element `Quoted` list whose first element is the symbol
`quote` and whose second is that form. The doubly quoted word denotes
`list2(sym("quote"), list2(sym("quote"), sym("abracadabra")))`, whose
outer `Pair` is the outer quotation; the value that quotation yields is
the inner two-element list `list2(sym("quote"), sym("abracadabra"))`.
That list's `car` is its outer `Pair`'s first element, the symbol
`quote`: not `abracadabra`, and not a further quote form. The solution
builds this value directly as a tiny local `Quoted` AST (symbol, pair,
or empty list), since quotation disappears into constructors in this
edition, and reads off both the printed value and its `car`.

## Map class

`R`: SICP 2.55 asks the reader to explain the Scheme reader's own
double-quote behavior, so the edition replaces it with the same
explanation carried out over the edition's own AST terms; the number
and the underlying puzzle (what does one `car` strip off a
twice-quoted symbol) are unchanged.

## Deviation

None.
