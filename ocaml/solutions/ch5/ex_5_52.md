Exercise 5.52: the compiler emits C.

The back end translates typed instruction sequences statement by
statement: registers are global words, labels are dispatch cases
reached by `goto`, `continue` and procedure entries are label numbers.
Syntax constants become C data: names become strings, operators become
codes, parameter lists and binding groups become name arrays, patterns
become trees built at start-up. Compiling `with_guest` of the 5.50
factorial yields a C evaluator answering `120`. Agreement is
enforced: the C output, the machine output, and the native output must
be byte-identical (`"120\n"`), else an error quoting all three; the
counter answers 3. The generated C
is a few thousand lines for the metacircular unit.
