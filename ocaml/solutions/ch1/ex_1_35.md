# Exercise 1.35 — golden ratio as a fixed point (translate)

The map class is `T`. Algebraically, phi satisfies `phi = 1 + 1/phi`
(multiply both sides of `phi^2 = phi + 1` by `1/phi`), so phi is a
fixed point of `x -> 1 + 1/x`. Running the section's `fixed_point`
search from a guess of `1.` gives `1.6180327868852458`, within the
search's `0.00001` tolerance of the closed form
`(1 + sqrt 5) / 2 = 1.618033988749895`.

`golden_ratio` uses a local `fixed_point`, not
`Sec_1_3.Fixed_point.fixed_point`: this chapter's exercises and
solutions libraries depend only on `sicp_common`, matching every
earlier section's convention of a self-contained answer per exercise
rather than a shared runtime library.
