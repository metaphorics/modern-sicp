# Exercise 3.46 — test-and-set race window (translate)

The map class is `T`. The statement asks for a timing diagram in which
two processes acquire the mutex at the same moment through a
`test-and-set!` written as an ordinary procedure. The solution replays
that diagram step by step — one process reads the free cell, a second
completes a whole test-and-set, the first resumes and sets the cell
too — so the double acquisition is constructed, not hoped for from a
race. A stress harness then lets two real domains fight over the naive
cell and counts the rounds where both believed they were inside; the
count is a measurement of one batch and changes run to run. The same
harness against the host's `Mutex`, which is atomic, always measures 0,
which is the comparison the exercise builds toward.

Sample: `ex_3_46 ()` answers `(true, n)`, where `n` is one batch's
measured double-acquire count (1573 on one run, never claimed to be
reproducible).
