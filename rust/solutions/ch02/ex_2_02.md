# Exercise 2.2: line segments built from points

## Approach

`Point` and `Segment` are small structs with private fields, built and
read only through `Point::new`/`.x`/`.y` and `Segment::new`/`.midpoint()`.
`midpoint` uses `f64::midpoint` on each coordinate pair, matching the
book's "average of the coordinates of the endpoints." `print_point`
renders `(x,y)` exactly as the book's `print-point` displays it (minus
the leading newline, which has no equivalent in a returned `String`).

## Map class

`T`: constructors and selectors translate directly into a pair of small
structs; nothing about the statement changes.
