# Exercise 4.50: ramb random choice (T)

## Approach

The engine's second choice form: `ramb` collects its alternatives as
ordinary data, shuffles them with Fisher-Yates over the evaluator's
seeded xorshift64* draw, and pushes the shuffled frame -- the same
search machinery as `amb`, a different order. The seed is threaded
through the driver's construction, so a `ramb`-driven program is
reproducible. Alyssa's generator under `ramb` no longer opens with the
leftmost alternatives: the sampled sentences leave the deterministic
recursion the footnote complains about.
