# Exercise 5.18: register tracing

Every write to a register goes through one store path (the host's
`set_register`, the `assign` execution, and `restore` all meet there),
so tracing hangs off that single point: when a register's trace is on,
each write appends `name: old -> new` to the machine's transcript.

`ex_5_18 ()` traces `n` and `val` through the factorial machine on
n = 3: the host's input load reports first (`n: *unassigned* -> 3`),
each level's decrement reports, the base case's `val` assignment
reports, and the restores report on the way out (`n: 1 -> 2`,
`n: 2 -> 3`), ending with `fact 3 = 6`.
