# Exercise 5.10: a new surface syntax, the simulator untouched

The new syntax strips the keywords the old syntax repeats: bare names
are registers (`(test = b (const 0))`, `(assign a b)`), an operation
call writes its operation in head position (`(rem a b)`), and branch
and goto targets are bare labels (`(branch gcd-done)`,
`(goto test-b)`).

`read_syntax` is a reader over the same S-expression text producing
the same typed program (labels resolved, duplicates rejected, stop
index for a trailing label), and `make_machine_from_program` assembles
it. The book's question: can the new syntax be installed without
changing any part of the simulator except the syntax procedures? Yes.
In this edition the answer is structural: the syntax layer's output is
the typed `program` record, and everything below it is unchanged.
`ex_5_10 ()` runs the GCD machine in both syntaxes (both answer 4) and
prints one compiled instruction from each: both are
`(assign t (op rem) (reg a) (reg b))`, the same typed instruction.
