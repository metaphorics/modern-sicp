# Exercise 4.33: quotes under the lazy regime

## Approach

With the section's lazy lists installed, the ordinary data literal --
this edition's quote, built from the collection constructors -- is not a
lazy list: the lazy `car` cannot walk it, and the typed checker says so
before anything runs. The fix lifts the quote: `quoted()` builds the same
list from lazy cells, so quoted lists ARE lazy lists, and the list
operations of the section (`car`, `listRef`) run on them one demand at a
time.

## Map class

`T`; the objective (what quotation must build for the lazy list
operations to consume it) is unchanged. Quotation is a constructor
lesson in this edition (there is no reader), so the "lifted quote" is the
constructor that builds lazy cells.

## Deviation

The quote-lifting evaluator hook is replaced by the constructor itself;
the failure case is an admission rejection (a data literal where a lazy
list is required) instead of a runtime not-a-procedure fault.

## Answer

- `plainQuoteCarTranscript() == "Error: <rejection category>\n"`: the
  data literal is not a lazy list.
- `lazyQuoteCarTranscript() == "a\n"`: a lifted quote answers its head.
- `lazyQuoteListRefTranscript() == "d\n"`: the section's list operations
  run on quoted lists.
