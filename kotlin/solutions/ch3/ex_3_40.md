# Exercise 3.40: all values of a concurrent square and cube

## Approach

P1 reads x twice and writes the product; P2 reads x three times and
writes the product. The test enumerates all 35 interleavings of the
seven accesses with `allInterleavings(3, 4)` and asserts the value set
is exactly {100, 1000, 10000, 100000, 1000000}: 10^2 through 10^6,
where 10^k for k = 4, 5 comes from one process's write landing between
the other's reads. With both bodies inside one serializer each, the
two launch orders both answer 10^6, since the only two orders are
square-then-cube and cube-then-square.

## Map class

`T`. Statement unchanged; the enumeration is the section's
determinism machinery.

## Deviation

None. The five-value answer matches the standard solution.
