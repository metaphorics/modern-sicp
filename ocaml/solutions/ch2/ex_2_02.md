# Exercise 2.2 — line segments from points (translate)

The map class is `T`. A point is a pair of floats; a segment is a
pair of points, built the same way rational numbers were built from a
pair of integers in section 2.1.1. `midpoint_segment` reuses
`start_segment`/`end_segment`/`x_point`/`y_point` exclusively, never
the underlying tuple representation directly, matching the section's
abstraction-barrier discipline one level up.

`print_point`, given by the book to try these procedures, prints
`"(x,y)"` with `%g` formatting (the shortest round-tripping decimal),
since the exercise never pins a fixed number of digits.

`ex_2_02 () = (2.0, 3.0)`, the midpoint of the segment from `(0, 0)`
to `(4, 6)`.
