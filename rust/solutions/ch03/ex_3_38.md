# Exercise 3.38: enumerate interleaved balance outcomes

## Approach

The book asks which balances Peter, Paul, and Mary can leave behind.
The solution runs the question instead of drawing it. The six
sequential orders are executed over a fresh $100 balance, and the
sorted distinct finals come back as exactly the four the text
enumerates (35, 40, 45, 50). For the concurrent half, Peter runs on a
spawned thread against Paul and Mary on the calling thread, 200 times,
and the sorted distinct outcomes all land in the seven-value set: the
four sequential balances plus the lost updates 80, 90, and 110. The
concurrent set is sampled, not enumerated -- the test asserts
membership in the possible set, never one particular schedule.

## Map class

`T`. The three transactions, the six orders, and the outcome sets are
the statement's own.

## Deviation

None for the base exercise.
