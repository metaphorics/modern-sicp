# Exercise 5.39: lexical-address operations (T)

## Approach

A closure owns the bindings it captures: calling it with `FnMut` runs the body against the same cells, so the accumulator's update persists the way addressed assignment persists across lookups. Starting at 10, adding 11 answers 21, then adding 99 answers 120, identically on both engines.

## Map class

`T`.

## Sample answer

Both engines print `21` then `120`.
