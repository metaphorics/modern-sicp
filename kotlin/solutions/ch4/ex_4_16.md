# Exercise 4.16: scan out internal definitions

## Approach

Alyssa's transformation runs at the parsed-body level: `scanOutDefines`
collects the top-level `DefineE` nodes of a body and, when there are any,
rewrites the body to one `LetE` that reserves every defined name with the
section's `*unassigned*` marker, followed by the `set!` assignments in
source order and the remaining body expressions; a body without internal
defines passes through untouched. Nested lambdas keep their own defines:
each is scanned when its own procedure is made. Part (b)'s installation
point is `makeProcedure`: the scan runs once per procedure creation, so
every application executes the already-rewritten body, while an `apply`-side
scan would re-transform the same body on every call. Part (c) is the
reservation check in `lookupVariable`: reading a name still holding the
marker raises the typed fault `TypeMismatch`: the binding demonstrably
exists (a plain `Unbound` lookup would mean something else) and what failed
is the read of a value no proper operation accepts.

## Map class

`T` (map row 4.16: Kotlin T).

## Deviation

The book's `scan-out-defines` works on raw data; this edition scans the
parsed body (`List<Expr>`), because the installation point `makeProcedure`
receives parsed bodies and the internal defines already arrive as typed
`DefineE` nodes, so the transformation needs no datum-level shape matching.

## Answer

From the actual runs (`E4_16Test` pins each transcript exactly):

- The statement's mutual even?/odd? recursion under the scan-out:
  `(f 10)` => `#t`.
- The premature read, `(define b (+ a 1))` before `(define a 5)`:
  => `Error: type mismatch: a is read before it is assigned`.
- The same program on the base evaluator (sequential rule):
  => `Error: unbound variable: a`, the contrast that shows the scan
  turned a silent out-of-order read into a located, typed fault.
- The structural pin: `scanOutDefines` of a body defining `b` then `a`
  yields one `LetE` reserving `["b", "a"]` with the marker, then
  `(set! b 1)`, `(set! a 2)`, then the original tail.
