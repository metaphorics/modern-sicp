# Exercise 2.88: polynomial subtraction (adapt)

The map class is `A`: the exercise's own hint is a generic negation
operation, so `negate_terms` negates every coefficient in a term
list, and `sub_terms l1 l2` is `add_terms l1 (negate_terms l2)`; subtraction
subtraction needs no new merge logic, only negation plus the addition
already on hand. `sub_poly` checks the two polys share a variable and
delegates to `sub_terms`, the same shape as `add_poly`.

`ex_2_88 ()` subtracts `x^2 + 1` from `x^2 + 3x + 1`, returning the
result's term list as `(order, coeff)` pairs; the `x^2` terms cancel,
leaving `[(1, 3.0)]`, i.e. `3x`.
