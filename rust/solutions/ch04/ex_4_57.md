# Exercise 4.57: the can-replace rule (T)

## Approach

The rule composes two `job` rows through `same`/`can-do-job` and
excludes self-replacement with `(not (same ...))`. Query (b) adds
salary comparisons with `lisp-value <`.

## Map class

`T`.

## Sample answer

Eight replacement pairs; the paid-more query answers Fect replacing
Hacker (35000 < 40000) and Aull replacing Warbucks (25000 < 150000).
