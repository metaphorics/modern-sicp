# Exercise 4.20: `letrec` as a derived expression (T)

## Approach

`letrec` is rewritten into unassigned bindings followed by explicit
assignment. Mutual recursion works because every name exists before any
initializer runs; a premature read still fails loudly.

## Map class

`T`.

## Sample answer

The mutually recursive bindings resolve after the assignments; a premature
read reports the unassigned error.
