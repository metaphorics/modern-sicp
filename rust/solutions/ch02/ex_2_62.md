# Exercise 2.62: a Θ(n) `union-set` for ordered-list sets

## Approach

`union_set_ordered` walks both lists with two indices, taking the
smaller head at each step, or the shared head once while advancing
both when they agree, then appends whatever remains of the longer
list. Every element of both lists is visited exactly once, so the
merge is genuinely `Θ(n)`, built in a single forward pass rather than
recursive calls that each re-copy an already-built result (which the
book's shared-`cons` recursion avoids for free and a `Vec`-returning
recursive translation would not). `[1, 3, 6, 10]` union `[2, 3, 7]`
merges to `[1, 2, 3, 6, 7, 10]`.

## Map class

`T`: translates directly onto the ordered-list walk pattern already in
the section (`element_of_set_ordered`, `intersection_set_ordered`).

## Deviation

None.
