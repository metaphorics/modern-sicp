# Exercise 2.23: `for-each`

## Approach

The implementation is the left-to-right loop the borrowing iterator
yields: the action sees each element exactly once, in order, and the
function returns `()`, standing in for the book's arbitrary return
value. The test drives it with a closure that records the elements it
was shown, reproducing the book's print-probe without printing.

## Map class

`T`: the statement translates directly.

## Deviation

None. The action parameter takes `&T` because observing needs no
ownership.
