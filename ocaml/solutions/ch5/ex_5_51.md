Exercise 5.51: the explicit-control evaluator in C.

The C program is the 5.4 controller as one function: registers are
locals, labels are dispatch cases, `continue` holds a label number,
the stack is an array with the same discipline and monitors. The
run-time support is tagged values, chained environments with `let rec`
cells, pattern matching, and the printing/array primitives. Source is
checked by `Check` and handed over as a serialized syntax tree; floats
and records report unsupported before anything runs. The system C
compiler builds it: factorial 120, list length 3, counter `5 12`, each
agreeing with the direct evaluator, with the C stack statistics (110
pushes/21 depth for factorial) beside them.
