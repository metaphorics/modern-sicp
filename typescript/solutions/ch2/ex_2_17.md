# Exercise 2.17: the last pair

## Approach

`lastPair` cdrs down the list until it reaches the cell whose tail is the
empty list and returns that cell. With the edition's `List` union the
book's `null?` test is a tag check: keep recursing while the cell is a
`Cons` whose tail is also a `Cons`, which leaves the last `Cons` (or the
empty list itself, the degenerate case the book leaves to `cdr`'s error).

## Numbers

`lastPair` of `(23 72 149 34)` prints `(34)`; the single-element list
`(34)` is its own last pair.

## Map class

`T`: the statement translates directly: the "is the cdr the empty list"
test becomes a tag check on the edition's list union.

## Deviation

None.
