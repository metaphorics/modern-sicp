# Exercise 1.38: Euler e expansion (translate)

The map class is `T`. Euler's denominators 1, 2, 1, 1, 4, 1, 1, 6, 1,
1, 8, ... place a `2 * (i + 1) / 3` exactly where `i + 1` is a multiple
of 3 (indices 2, 5, 8, 11, ...) and `1` everywhere else; `euler_d`
reads directly off that pattern. `e_approx k` is `2. + cont_frac (fun _
-> 1.) euler_d k`, reusing exercise 1.37's `cont_frac` (redefined
locally, per this chapter's one-file-per-answer convention).

`e_approx 20 = 2.718281828459045`, identical at print precision to
`Float.exp 1.`; `ex_1_38 () = e_approx 20`.
