# Exercise 4.14: the host map as a primitive fails (T)

## Approach

The diagnosis becomes concrete in the typed runtime. Louis's `louis-map` is a
plain primitive whose handler calls its procedure argument with `Value::call` --
which only applies primitives. Eva's `eva-map` is an object-language procedure,
applied by the evaluator itself. Applying a `Closure` through a bare handler is
exactly the failure: procedure values are not host closures, and the primitive
receives evaluated arguments.

## Map class

`T`.

## Sample answer

Louis's map fails with `not a procedure` on a compound procedure; Eva's map
answers `(1 4 9)`.
