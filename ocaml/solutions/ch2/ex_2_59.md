# Exercise 2.59: union-set for unordered lists (translate)

The map class is `T`: only the syntax changes. `union_set` folds
`set1` into `set2`, keeping an element only when `set2` does not
already carry it and adding every element of `set2` unconditionally,
since `set2` itself carries no duplicate.

Sample: `ex_2_59 ()`, the union of `{1, 2, 3}` and `{3, 4, 5}`, is
`[1; 2; 3; 4; 5]`.
