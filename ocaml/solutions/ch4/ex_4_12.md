# Exercise 4.12: one traversal for the three operations (translate)

The map class is `T`. The common pattern of lookup, set, and define is
the newest-first frame walk; `traverse` is that walk, applying an
inspection to each frame's association list and answering the first
`Some`. Lookup inspects with `assoc`; set inspects with a rewrite that
mutates the frame in place, so the walk stops at the nearest binding;
define writes the newest frame through the same frame abstraction. The
frames are the association lists of 4.11, so the demonstration can
also show the traversal reaching a binding in an outer frame past a
newest frame that does not bind it.

Sample: `ex_4_12 ()` answers
`["10"; "42"; "7"; "99"; "Error: unbound variable z"]`: the shadowing
lookup, the nearest-binding set seen through lookup, the fresh
binding, a set of an outer-frame binding through an empty newest
frame, and the unbound-variable error.
