# Exercise 2.53: predicting printed values (replacement)

## Approach

Each sub-question is answered by building the edition's equivalent
value and reading its printed form. `list(a, b, c)` and
`list(list(george))` print exactly as the book's lists do. `cdr`/`cadr`
of the two-pair nested list follow the same accessor chains as 2.2.
`car(a, short, list)` is never a pair, and this edition answers that
by the type itself: a `List<Symbol>`'s `car` is a `Symbol`, which
cannot be a compound value, so no runtime `pair?` check exists to call.
`memq('red, '((red shoes) (blue socks)))` is `false` because the outer
list holds sublists, never the bare symbol `red`; the solution proves
this by searching for the leaf `red` among `Nest::Sub` elements, which
never matches. `memq('red, '(red shoes blue socks))` finds `red` at
the front and returns the whole list.

## Map class

`R`: SICP 2.53 is about the Scheme interpreter's printed answers, so
the edition replaces it with a prediction over the edition's own
printing and `memq`; the number and the seven expressions are kept.

## Deviation

None. The `pair?` sub-question is answered by the type system rather
than a runtime predicate, which this edition has no need for.
