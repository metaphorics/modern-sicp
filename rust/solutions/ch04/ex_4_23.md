# Exercise 4.23: analyze-sequence comparison (T)

## Approach

Both versions run on the seam. The text's version folds the analyzed
expressions with `sequentially`, so for a one-expression body it returns the
expression's own execution procedure; Alyssa's `AlyssaAnalyzer` overrides
`analyze_sequence` to collect the procedures and loop at execution time, which
always adds a wrapper. The analysis invocation counts are equal -- the
difference is where the sequencing work runs, which 4.23a counts.

## Map class

`T`.

## Sample answer

Both versions analyze a one-expression body in one pass and answer the same
values: 7 and 7 for one-expression bodies, 3 and 3 for two-expression bodies.
