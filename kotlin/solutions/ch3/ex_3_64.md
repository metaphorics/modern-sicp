# Exercise 3.64: limits of convergent streams

## Approach

`streamLimit` walks the stream one pair at a time and returns the
second element of the first pair closer than the tolerance; a stream
that runs dry first never converged, so that path raises
`IllegalStateException` (covered by an empty stream and by a finite
diverging one). `sqrtByLimit` applies it to the section's guess
stream. Pins, all as computed: tolerance 1e-8 returns
1.414213562373095, within 2.2e-16 of the machine square root (bound
asserted at 1e-9); tolerance 0.1 stops one step earlier at
1.4166666666666665; tolerance 0.001 returns 1.4142135623746899. The
three convergences are pinned as exact doubles and are distinct.
