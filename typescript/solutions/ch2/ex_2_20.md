# Exercise 2.20: same parity

## Approach

`sameParity` keeps the first argument, filters the rest by its parity,
and conses the first back on. The test `x % 2 === first % 2` compares
residues, which agree exactly for same-parity integers, and the module's
`filter` is the book's nested `cond`.

## Numbers

`(same-parity 1 2 3 4 5 6 7)` prints `(1 3 5 7)`; with first 2 the
answer is `(2 4 6)`; a lone first argument returns `(7)` for 7.

## Map class

`A`: the statement's dotted-tail parameter list becomes the edition's
rest parameter `...rest: ReadonlyArray<number>`, and the rest arguments
become a list for `filter` to walk.

## Deviation

None.
