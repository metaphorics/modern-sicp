# Exercise 3.19: constant-space cycle detection

## Approach

The book redoes 3.18 with a constant-space algorithm: Floyd's
tortoise-and-hare. `hasCycleConstantSpace` keeps two locals, advancing the
tortoise one tail per step and the hare two; on a ring the hare laps the
tortoise and the two meet at the same pair object (identity), on a finite
list the hare reaches the empty end first. No visited set, no per-pair
memory: the constant-space bound is what the exercise asks for.

## Pins

Computed by running. The same case set as 3.18 answers identically: a
plain list and the empty list are false, a two-pair ring is true, a list
whose last pair loops back to its own head is true, and shared-suffix
lists are false for both. A long run of pairs into a two-pair ring is
still caught: the hare closes the gap one tail per step inside the ring
whatever the tail's length.
