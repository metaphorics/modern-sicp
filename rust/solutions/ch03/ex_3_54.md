# Exercise 3.54: mul-streams and factorial stream

## Approach

`mul-streams` is `add-streams` with the product in place of the sum --
one `stream_map2` call combining heads by multiplication and recursing
on the tails. The statement's two holes in the `factorials` definition
fill with `integers` and the stream's own tail: `factorials` is 1
consed onto `integers * factorials`. The head of that product is
1 * 1 = 1, its next element is 2 * 1 = 2, then 3 * 2 = 6, 4 * 6 = 24:
each element multiplies the previous factorial by its 1-based index, so
the stream reads the factorials from 0! up, with the consed 1 serving
as both 0! and 1!. The self-reference reads the stream's name inside
the tail thunk only, under `self_stream`, as the book's `define` does.

## Map class

`T`. The statement translates whole. The one Rust wrinkle is the same
self-referential `define` as 3.53 -- `self_stream` with the name read
in the tail thunk -- plus a local `mul_streams`, since the section
module ships only the additive twin `add_streams`.

## Deviation

None. The test pins the first eight elements 1 1 2 6 24 120 720 5040
and the element at index 10, 3628800 = 10!.
