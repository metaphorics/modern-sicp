# Exercise 3.30 — ripple-carry adder composition (translate)

The map class is `T`: `ripple_carry_adder` strings `n` `full_adder`s
together exactly as the book's recursive construction does, chaining
each stage's carry-out into the next stage's carry-in and terminating
the least-significant stage with a `0` carry-in. `bits_of`/`value_of`
convert between an integer and its most-significant-bit-first bit
list so the harness `add` can drive plain integers onto the wires and
read a plain integer back off, which is also what the section 3.3
"representative program" idiom-doc note asks this section to
foreground: the adder built and exercised end to end, not just
described.

Sample: `ex_3_30 ()` answers `((8, 0), (14, 0), (0, 1))` — 15 + 1
overflows four bits, wrapping to 0 with a carry.
