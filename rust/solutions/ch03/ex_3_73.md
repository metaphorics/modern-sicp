# Exercise 3.73: RC circuit signal processor

## Approach

The circuit is wired exactly as Figure 3.33 draws it: the current stream
is scaled by 1/C and run through the section's implicit `integral`,
seeded with the initial capacitor voltage v0, while a parallel path
scales the current by r; the adder combines both, so element k answers
v0 + (1/C)*dt*sum_{j<k} i[j] + r*i[k]. The module's `integral` is the
self-referential `int` of the text (the memoized feedback loop), so the
processor is three combinators and no recursion. The test injects the
constant unit current (an infinite `ones`-style stream) with r = 0.5,
c = 1, dt = 0.2, v0 = 0: the integrator contributes 0.2*k at index k and
the resistor path adds 0.5 at every index -- including index 0, where
the initial-value path meets the resistor term in the adder -- so the
run pins v[k] = 0.2*k + 0.5: 0.5, 0.7, 0.9, 1.1, 1.3, 1.5.

## Map class

`T`. The statement translates whole. The one Rust wrinkle: `rc` answers
a closure, and everything the closure's stream thunks capture must be
`'static`, so the current stream arrives by reference and is cloned into
the combinators -- a clone that shares the one memoized spine, which is
the book's shared name, not a copy.

## Deviation

The parent's mid-flight correction replaces the brief's minus sign with
the book's Figure 3.33 formula, whose resistor term is +R*i; the build
above follows the corrected sign. The 1/C scale sits on the integrand
ahead of the integrator rather than after it, so the initial-value path
keeps v0 unscaled exactly as the figure's formula v = v0 + (1/C)*INT i
dt + R*i reads; at the test's c = 1 the two placements answer
identically. All pins are from the actual run.
