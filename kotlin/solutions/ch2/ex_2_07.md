## Exercise 2.7: completing the interval abstraction

Approach: `Interval` is a data class of `lowerBound` and `upperBound`, so
declaring it this way already gives both selectors as ordinary
properties; there is no separate selector body left to write, unlike the
book's Scheme answer, which still has to define two one-line procedures
around `car` and `cdr`. `makeInterval(6.12, 7.48)` is
`Interval(6.12, 7.48)`.

Class: T, a direct translation, though it becomes closer to a formality
than a puzzle once the host language has real records; the exercise still
earns its place because a reader has to notice that a data class already
supplies both selectors. Deviation: `addInterval`, `mulInterval`, and
`divInterval`, the main text's own given operations, are reproduced in
this file rather than the exercise's own; they are needed by name in
exercises 2.9 through 2.16, which reuse them from this same compiled
module the way exercise 1.43a reused exercise 1.42's `compose`.
