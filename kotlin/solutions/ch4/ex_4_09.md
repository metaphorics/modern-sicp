# Exercise 4.9: `while` and `until` as derived loops

## Lesson

`while` and `until` lower to a `GLetRec` procedure whose test chooses
between a body block and the done value. The block ends with a recursive
`GApp`. The evaluator executes those calls recursively on the host stack.

## Map class

`T`; the exercise designs derived iteration forms over the existing kernel.

## Deviation

The loops use a dummy argument because the kernel procedure takes one
parameter. Tests observe the mutated state, not the loop's unspecified value.
No constant-stack claim is made.

## Answer

- `while` sums from `1` through `5` to `15`.
- An initially false `while` and an already-satisfied `until` skip their
  bodies.
- `until` multiplies `8` through `12` and stops at `13`, producing `95040`.
- Nested loops produce `6`.
- Pins: `whileSumTranscript() == "15\n"`,
  `untilProductTranscript() == "95040\n13\n"`, and
  `nestedLoopsTranscript() == "6\n"`.
