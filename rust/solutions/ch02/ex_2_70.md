# Exercise 2.70: encoding a rock song's lyrics

## Approach

`generate_huffman_tree` (exercise 2.69's algorithm, reproduced
locally) builds a tree from the eight-symbol alphabet's frequencies.
Encoding the 36-word lyric line against that tree takes 84 bits. A
fixed-length code for 8 symbols needs `⌈log₂ 8⌉ = 3` bits per symbol,
so 36 symbols need `3 × 36 = 108` bits. The Huffman code saves 24
bits, about 22%, because the most frequent symbol (`NA`, 16
occurrences) sits at the top of the tree while the rare symbols
(`BOOM`, `WAH`, one occurrence each) sit at the bottom.
