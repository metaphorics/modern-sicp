# Exercise 4.6: let as a derived expression (T)

## Approach

`let_to_combination` rewrites `(let ((x 3) (y 4)) (+ x y))` to
`((lambda (x y) (+ x y)) 3 4)`, and `WithLetDerived` evaluates the rewrite at
every nesting depth. The inits evaluate in the outer environment: with `x`
bound to 5 outside, `(let ((x 3) (y x)) y)` is 5, not 3. The grammar carries
plain `let` in the base (the metacircular corpus program reads it), so the
exercise re-derives it through the seam and pins the scoping rule.

## Map class

`T`.

## Sample answer

Rewrite `((lambda (x y) (+ x y)) 3 4)`, value 7; the scoping probe answers 5.
