# Exercise 3.72: sums of two squares in three ways

## Approach

The same machinery as exercise 3.71 with the weight `i^2 + j^2`: the
square-weighted pairs of the integers ordered by weight, scanned for a
window of three consecutive pairs of equal weight. Each hit reports
the number and its three representations, the statement's "showing how
they can be so written".

## Pins

Computed by running. The first four numbers with three
representations as a sum of two squares, exactly as the scan produced
them:

- `325 = 1^2 + 18^2 = 6^2 + 17^2 = 10^2 + 15^2`
- `425 = 5^2 + 20^2 = 8^2 + 19^2 = 13^2 + 16^2`
- `650 = 5^2 + 25^2 = 11^2 + 23^2 = 17^2 + 19^2`
- `725 = 7^2 + 26^2 = 10^2 + 25^2 = 14^2 + 23^2`

The hits strictly increase, and in each hit all three representations
sum to the same square weight with `i <= j` in each pair.

## Map class

T (translate: syntax changes only). The statement says "in a similar
way to exercise 3.71", and the construction is that scan widened from
two consecutive equal weights to three.

## Deviation

Exercise 3.70's `mergeWeighted` and `weightedPairs` are restated in
this file because exercise files do not import from each other. The
three-wide window reports overlapping windows as separate hits, so a
number with four representations would be emitted twice; none of the
first four has more than three. Numbers with exactly two
representations, such as `50 = 1^2 + 7^2 = 5^2 + 5^2`, are skipped.
