# Exercise 3.65: three convergences to ln 2

## Approach

The summands 1, -1/2, 1/3, -1/4, ... are mapped over the integers
with an alternating sign, and this file carries its own private
`partialSums` twin (a tie-before-force cell over `add-streams`), so
the exercise stands on its own rather than importing 3.55's answer.
`ln2Raw` is the running sum, `ln2Euler` its Euler transform, and
`ln2Accelerated` the first column of the tableau of repeated
transforms. Indices are zero-based `stream-ref` positions. Measured
and pinned, all exact doubles: raw element 10 = 0.7365440115440116,
error 4.340e-2 (bound 5e-2); Euler element 5 = 0.6928571428571428,
error 2.900e-4 (bound 4e-4); accelerated element 5 =
0.6931471806635636, error 1.036e-10 (bound 2e-9). The tests also
assert the ordering: each acceleration stage is strictly closer to
ln 2 than the one before.

## Map class

`T` (map row 3.65: direct translation).

## Deviation

None. Independent check: a python3 script recomputing the partial
sums, the Euler correction s2 - d21^2/(d21 + d01), and the tableau in
the same operation order reproduces all three pinned doubles exactly.
