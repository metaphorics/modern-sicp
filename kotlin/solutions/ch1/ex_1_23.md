## Exercise 1.23: skipping even test divisors

Approach: `next` returns 3 immediately after 2 and otherwise adds 2, so
`findDivisorFast` walks 2, 3, 5, 7, 9, ... instead of every integer.
Since no even number greater than 2 can be the smallest divisor of a
number that already survived a test against 2, this never changes the
answer, only the number of candidates tried; the solution's test checks
this by comparing `ex_1_23` against a naive one-at-a-time search across
primes, a small composite, and a Carmichael number.

Timing discussion (not asserted by the test): halving the number of test
divisors suggests roughly half the elapsed time, but the observed
speedup is typically less than 2x in practice, because `next` itself does
one extra comparison and branch per step that the plain `+ 1` version
does not pay, an overhead the book's own asymptotic argument does not
model.

Class: A (adapt); the clock-comparison half of the exercise is the same
`System.nanoTime` adaptation as exercise 1.22.
