# Exercise 2.34: Horner's rule (translate)

The map class is `T`. The blank is `higher_terms * x + this_coeff`:
each step takes the value accumulated from the higher-order terms,
multiplies by `x`, and adds the current coefficient. The coefficient
sequence is arranged `a_0` first as the statement prescribes.

Sample: `ex_2_34 2 [1; 3; 0; 5; 0; 1] = 79`, the book's
`1 + 3x + 5x^3 + x^5` at `x = 2` (`1 + 6 + 40 + 32`).
