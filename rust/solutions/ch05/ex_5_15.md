# Exercise 5.15: instruction counting, and the budget (T + tailored)

## Approach

The machine counts every executed instruction, transfers included.
The print-and-reset message exists twice: as the direct method
`print_instruction_count` (returns the count, appends it to the
transcript, resets to zero) and as the machine operation
`print-instruction-count`, so a controller can perform it. 5.15a,
added by this edition, extends the counting machine with
`set_instruction_budget`: a run due to execute an instruction past
the budget halts with the typed `BudgetExceeded`, carrying the
count (the budget itself) and the program counter of the
instruction that would have run. The exact demand finishes
cleanly, and the halted machine stays inspectable and continuable.

## Map class

`T` (plus the tailored 5.15a, `chosen: rust` in the idea cell).

## Sample answer

fib(0) and fib(1) run 5 instructions, fib(2) 28, fib(6) 281. With
a budget of 280 the fib(6) run faults at count 280, pc 19; clearing
the budget and proceeding completes the run, val = 8, total 281.
