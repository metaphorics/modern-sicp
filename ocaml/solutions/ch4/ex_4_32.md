# Exercise 4.32 — chapter 3 streams versus lazy lists (translate)

The map class is `T`. The difference the statement asks for is the
laziness of the `car`: a chapter 3 `cons-stream` evaluates its first
argument at construction time and delays only the tail, while the text's
procedural `cons` delays both, so no element of a lazy list is produced
until something forces it. The demonstration arms the skipped elements
with a division by zero. `(car (cdr (cons (/ 1 0) (cons 42 '()))))`
answers 42 under the lazy lists — the first element is never produced.
The same construction with the chapter 3 behavior — `cons-stream` in the
applicative-order evaluator, where the `car` is computed when the pair
is built — dies in the division before the list exists. The armed tail
of `(cons (/ 1 0) (cons 7 (/ 1 0)))` is skipped just as freely, which is
the advantage the extra laziness buys: an element costs nothing unless
it is actually needed, so delayed versions of general structures —
Hughes's lazy trees among them — fall out of the same non-strict `cons`.

Sample: `ex_4_32 ()` answers
`["42"; "Error: division by zero"; "7"]`.
