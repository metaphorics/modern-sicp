# Exercise 2.3: two rectangle representations (translate)

The map class is `T`. `Rectangle` names the one thing `perimeter` and
`area` actually need, `width` and `height`; `Perimeter_area` is a
functor written once against that signature and applied twice, so the
compiler (not just the reader's eye) confirms that the same
`perimeter`/`area` code works against either representation, which is
exactly what the exercise's closing question asks for.

`Two_corners` stores two opposite, axis-aligned corners and derives
`width`/`height` from the coordinate difference; `Corner_and_dims`
stores one corner plus the width and height directly. `ex_2_03`
builds the same 3-by-4 rectangle both ways and returns both
`(perimeter, area)` pairs: `((14.0, 12.0), (14.0, 12.0))`.
