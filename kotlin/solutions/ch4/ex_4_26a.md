# Exercise 4.26a: `when` as a derived expression

## Lesson

The derivation is macro-style: one rewrite to forms the evaluator
already has. `(when condition body ...)` lowers to `(if condition
(begin body ...) false)`, the `false` standing where the missing
alternative stands. The rewrite runs in guest code over the sealed
family, so it composes with the kernel's own dispatch; the trace pins
that the name is unbound before the derivation and answers after it.
The lazy mirror leaves the unchosen arm unforced.

## Map class

`A` (map row 4.1: derived forms). The 4.26 `unless` mirror for the
affirmative side.

## Deviation

None. The multi-expression body sequences through the kernel block.

## Answer

- Before: the name is unbound.
- After: a true condition answers `yes`; a false one answers the
  derived `false`; three bodies answer the last, `3`.
- Lazy mirror: `42`, the division never forced.
- Pin: `whenBeforeTranscript() == "error\n"`,
  `whenAfterTranscript() == "yes\n"`,
  `whenNoElseTranscript() == "false\n"`,
  `whenBodySequenceTranscript() == "3\n"`,
  `whenLazyTranscript() == "42\n"`.
