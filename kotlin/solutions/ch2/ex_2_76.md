## Exercise 2.76: adding types versus operations

Approach: the same `(realPart, magnitude)` pair of `(3, 4)` is computed
through explicit dispatch (`RepZ`, a sealed hierarchy with a `when` per
operation), data-directed style (`RepresentationTable`, a local
`put`/`get` table sharing 2.4.3's discipline), and message passing
(exercise 2.75's `ComplexObject`), then compared for agreement.

Adding a new type:
- Explicit dispatch: a new `RepZ` variant plus a new arm in every
  existing `when` (`edRealPart`, `edMagnitude`, and any operation added
  since) — every operation's code is touched once.
- Data-directed: one new `install*Representation` function calling only
  `RepresentationTable.put` — nothing existing changes, confirmed here by
  the pointer-identity test: the rectangular package's `real-part`
  handler is the exact same object reference before and after the polar
  package installs.
- Message passing: one new object constructor, analogous to an existing
  one — nothing existing changes either.

Adding a new operation:
- Explicit dispatch: one new total function with a `when` arm per
  existing type — one new definition, no existing one touched.
- Data-directed: one new `put` per already-installed representation — as
  many small additions as there are representations, but no existing
  entry is edited.
- Message passing: every existing object's dispatch needs a new branch —
  every object touched once, the mirror image of adding a type.

So explicit dispatch and message passing trade places depending on which
axis grows: explicit dispatch pays per type added, message passing pays
per operation added, and the table's `put`/`get` discipline is the only
one of the three that never edits an existing definition either way — the
cost of a new combination is additions, not edits, in every direction.
Rust's closed `enum` and this edition's sealed `RepZ` share the same
trade-off: the compiler proves every `when` exhaustive, which the open
table cannot, at the price of an edit per new type.

Class: A, per the map — the idea survives (three strategies, the same
comparison), but the statement gains executable code demonstrating the
claim rather than leaving it as prose, since a typed language can
actually build and run all three and check they agree.

Deviation: none in substance.
