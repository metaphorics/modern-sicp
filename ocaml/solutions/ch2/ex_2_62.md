# Exercise 2.62 — Theta(n) union-set for ordered lists (translate)

The map class is `T`: only the syntax changes. `union_set` merges the
two ordered lists the way a merge sort's merge step does: advancing
whichever list carries the smaller head, and advancing both when the
heads are equal, so no element is compared more than a constant
number of times and the whole merge is `Theta(n)` rather than the
unordered representation's `Theta(n^2)`.

Sample: `ex_2_62 ()`, the union of `{1, 3, 5, 7}` and `{2, 3, 6, 7}`,
is `[1; 2; 3; 5; 6; 7]`.
