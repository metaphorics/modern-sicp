# Exercise 5.32: symbol-operator fast path (T)

## Approach

The evaluator's application controller tests whether the operator is a
symbol. If so, it looks up the procedure directly in `env`, bypassing
the general recursive evaluation path; compound operators still use
the ordinary path. A monitored driver compares the original and
modified controllers on the same recursive factorial, recording stack
pushes and maximum depth. The fast-path transcript also exercises both
a named procedure and a lambda operator.

## Map class

`T`.

## Sample answer

The original controller uses 144 stack pushes for factorial 5 at a
maximum depth of 28; the symbol fast path uses 108 pushes at the same
depth. Both compute `120`. The reduction is the operator-side `env`
save/restore pairs the fast path skips. It also evaluates `f` applied
to 6 as 36 and a lambda application to 41 as 42.
