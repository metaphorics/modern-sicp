# Exercise 2.66: tree lookup

## Approach

`lookupTree` mirrors the section's `elementOfSetTree` over records
carried at the nodes: compare the given key with the node's key and
descend left or right.

## Numbers

Over the test data base built by successive adjoins, keys 5, 1, and 12
are found with their values; keys 4 and 99 return nothing. One key
comparison per level: Theta(log n) for a balanced tree.

## Map class

T (translate).

None.
