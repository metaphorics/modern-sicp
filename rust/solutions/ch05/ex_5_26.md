# Exercise 5.26: the iterative factorial on the monitored stack (T)

## Approach

The section-5.1 loop machine never touches the stack: every iteration reuses the same registers. Six runs from n = 1 to 6 check the answers against the running factorial with pushes and depth pinned at zero. The same loop as a guest program runs on both engines for the interpreted/compiled agreement later exercises build on.

## Map class

`T`.

## Sample answer

Machine answers `1, 2, 6, 24, 120, 720` with zero pushes at zero depth throughout. The guest loop prints the same six lines on both engines.
