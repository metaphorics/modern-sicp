# Exercise 5.29: stack formulas for the tree-recursive Fibonacci

The tree-recursive Fibonacci runs through the monitored evaluator for n = 2 to 6. The depth follows the longest chain of deferred work and steps uniformly from row to row; the pushes count the whole recursion tree, so each row's increment grows with the tree. The test pins both shapes: one constant depth step and strictly growing push increments, the exercise's two stack formulas read off the machine's own counters.
