# Exercise 0.1 — five Scheme interactions in OCaml

The five interactions come from section 1.1 of the book: one arithmetic
combination, the `square` definition plus a call, an `if`, and an anonymous
`lambda` applied on the spot. Each translation is a top-level binding, so the
inferred type shows up in the scaffold's `.mli` and in the REPL's `val` line —
the types the exercise asks the reader to report are exactly the signatures
here.

Notes per interaction:

- `(+ 2 (* 4 6))` becomes `2 + (4 * 6)`: prefix combination trees flatten to
  infix, and parentheses keep the book's grouping instead of relying on
  precedence.
- `(define (square x) (* x x))` becomes `let square x = x * x`. The call
  `(square 7)` is `square 7` — no parentheses around arguments.
- `(if (> 4 11) 4 11)` becomes `larger 4 11` through `let larger a b = if a > b
  then a else b`. OCaml's `if` is an expression, so the definition and the
  Scheme form have the same shape.
- `((lambda (x) (* x x)) 5)` stays an application of a literal function, value
  `25`.

The test pins the numeric answers (26, 49, 11, 25) and that `larger` works in
both argument orders; the types are pinned by the `.mli` itself, which the
compiler checks against the implementation.
