# Exercise 1.16

The invariant is `a * b^n`, unchanged from state to state: when `n` is
even, squaring `b` and halving `n` keeps `b^n` the same (`(b^2)^(n/2) =
b^n`), so `a` does not need to change; when `n` is odd, folding one factor
of `b` into `a` and decrementing `n` keeps the product exact. `a` starts at
1 (so the invariant equals `b^n` from the start) and the loop ends when `n`
reaches 0, at which point `a * b^0 = a` is the answer. `fast_expt_iter(2,
10) = 1024` and `fast_expt_iter(3, 7) = 2187`, matching `fast_expt`.

The map class is `A`: the book's version is a tail-recursive procedure
(`expt-iter` in 1.2.1's model, generalized here to squaring), and Scheme
would run it in constant space forever. Rust gives no such guarantee to a
recursive spelling, so the exercise asks for the loop directly instead of
a `fn` that calls itself in tail position.
