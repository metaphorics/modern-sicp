# Exercise 2.59: union of unordered sets

## Approach

Walk `set1`, keeping each element that is new to `set2` in front of it.
Element order follows `set1` first, then `set2`'s remainder, matching the
representation's no-order promise.

## Numbers

`union((1 3 5), (4 3 6))` is `(1 5 4 3 6)`: 1 adjoined, 3 skipped as
present, 5 adjoined, then `set2`'s `(4 3 6)`. Operation count: one
`elementOfSetUnordered` scan of `set2` per element of `set1`, so
Theta(n1 * n2) (Theta(n^2) for two sets of size n), the same growth as
the representation's intersection.

## Map class

T (translate).

## Deviation

None.
