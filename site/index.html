Structure and Interpretation of Computer Programs

Four editions: Rust, OCaml, TypeScript, Kotlin

Harold Abelson and Gerald Jay Sussman with Julie Sussman wrote Structure and Interpretation of Computer Programs (second edition, 1996); this project adapts the book, with its section and exercise numbers kept one to one, into four modern editions. How the editions differ

Every edition keeps SICP's section and exercise numbers and solves all 356 exercises in its own language. Three sections are re-cut because the host language changes the lesson: 3.2 (the environment model, redrawn for each language's closures), 3.4 (concurrency, on each language's own primitives), and 4.3 (nondeterministic evaluation, rebuilt on each language's own search mechanism). The full list of tailored additions and replacements is in the exercise map.

How to read

Each edition opens with a Chapter 0 primer that teaches only the language subset the book uses. Section 0.8, Reading this book, explains the interaction convention used in every listing and how exercise numbers map to SICP's; start there: Rust · OCaml · TypeScript · Kotlin.
