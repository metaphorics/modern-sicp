# Exercise 2.27: deep-reverse (adapt: recursive tree type)

The map class is `A` (map row: "deep-reverse needs recursive
nested-list type"). Scheme reverses a list whose items may be lists;
OCaml's `'a list` cannot nest, so the operation runs over the
section's `tree` variant. `ex_2_27` reverses every `Node`'s children
(`List.rev (List.map ex_2_27 children)`) and leaves leaves alone.

Sample: `ex_2_27 (Node [Node [Leaf 1; Leaf 2]; Node [Leaf 3; Leaf 4]])
= Node [Node [Leaf 4; Leaf 3]; Node [Leaf 2; Leaf 1]]`, the book's
`((4 3) (2 1))`.
