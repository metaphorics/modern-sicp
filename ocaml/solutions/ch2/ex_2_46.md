# Exercise 2.46 — the vector abstraction (translate)

The map class is `T`. The record `vect = { x : float; y : float }`
is the pair of coordinates the statement asks for; `make_vect`,
`xcor_vect`, `ycor_vect`, `add_vect`, `sub_vect`, and `scale_vect`
are the constructor, the selectors, and the three operations, with
float arithmetic explicit per the edition conventions. `ex_2_46`
applies the three operations to one fixed set of inputs for the
tests: add gives `{ x = 4; y = 6 }`, subtract gives `{ x = 2; y = 2
}`, scale gives `{ x = 2; y = 4 }`.
