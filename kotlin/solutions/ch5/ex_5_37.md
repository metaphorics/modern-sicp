# Exercise 5.37: disabling `preserving`

Preservation keeps a register's old value across an instruction
sequence only when later instructions still need it. Saving a
register already dead at that point uses stack space needlessly.

`preservingWaste` compiles the same nested-call program using
`CompilerOptions(preserving = ...)` in its three available modes:
`LIVENESS`, `ALWAYS`, and `NEVER`. It reads the actual save pairs
from each compilation and reports how many saved values were not
clobbered by the enclosed sequence. The final verdict checks that
every save in each listing has a corresponding later restore; no
runtime behavior is inferred from an unrun mode.
