# Exercise 4.7: `let*` as nested `let`s

## Lesson

Each init sees the earlier bindings, so the lowering folds right to
left: every binding but the last wraps the lowering of the rest. The
kernel's single-binding `GLet` is exactly the node the fold builds.
The sequential pin reads its predecessors; shadowing still binds
inward.

## Map class

`A` (map row 4.1: derived forms). Sequential binding is nested
single lets, no new evaluation rule.

## Deviation

None. The fold is total over matched name/init lists.

## Answer

- Sequential inits: `7`.
- Shadowed inner: `2`.
- Pin: `letStarTranscript() == "7\n2\n"`.
