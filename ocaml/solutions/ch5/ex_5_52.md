Exercise 5.52: the compiler emits C.

The C backend translates the compiler's instruction sequences one
statement at a time into a single C function: registers are globals,
labels are C labels (dashes become underscores), `continue` and
procedure entries hold label addresses, and the machine's operations
are one C dispatch mirroring the compiled operations table. The
runtime is 5.50's object world in C. Compiling the adapted
metacircular source produces a Scheme interpreter in C that runs its
object program: `(m-eval '(factorial 5) ...)` answers 120, built and
run by the system compiler.
