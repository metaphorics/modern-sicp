# Exercise 3.59: integrate-series and the elementary series

## Approach

The statement's part (a) fixes the integral rule: coefficient `a_n` of
`x^n` becomes `a_n / (n+1)` of `x^(n+1)`, with the constant term left
for the caller to cons. `integrateSeries` therefore zips the input
with 1, 2, 3, ... and divides. Part (b) builds the three series from
their derivative facts, each as a constant consed onto the integral of
another series: exp from `d/dx e^x = e^x` with constant `e^0 = 1`;
sine from `d/dx sin = cos` with constant `sin(0) = 0`; cosine from
`d/dx cos = -sin` with constant `cos(0) = 1`, integrating negated
sine. The self-references sit in memoized thunk tails, so each series
is a value that unfolds on demand.

## Pins

Computed by running the tests, precision 12.

- `integrateSeries(ones)`: `1, 1/2, 1/3, 1/4, 1/5` (harmonic), the
  statement's `a0, a1/2, a2/3` shape on the simplest input.
- `expSeries`, first 6: `1, 1, 1/2, 1/6, 1/24, 1/120`.
- `cosineSeries`, first 7: `1, 0, -1/2, 0, 1/24, 0, -1/720`.
- `sineSeries`, first 8: `0, 1, 0, -1/6, 0, 1/120, 0, -1/5040`.

## Map class

T (translate: syntax changes only). Coefficients are JS numbers rather
than exact rationals, so the tests compare with `toBeCloseTo` at
precision 12; integer coefficients compare with `toBe`.

## Deviation

The map row's tailored idea (differentiate a series termwise) is
marked "chosen: kotlin", so TypeScript owes only the plain T row of
the statement, which is what the tests do. A local `negateSeries`
stands in for the minus sign in "integral of -sin"; the book would
write a negated stream inline.
