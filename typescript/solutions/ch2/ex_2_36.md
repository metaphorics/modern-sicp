# Exercise 2.36: accumulate-n

## Approach

The book's accumulate-n conses the accumulation of the cars onto the
recursion over the cdrs, stopping when the first inner list is empty.
The edition's `car` and `cdr` answer in `Option`, so the head and tail
walks are spelled as two helpers that narrow each list on `_tag`:
`heads` collects the first element of every list, `tails` every list
after its first, and `accumulateN` stops when the outer list or the
first inner list is `Nil` - the same guard the book tests with
`(null? (car seqs))`. The exercise's equal-lengths convention covers the
remaining lists.

## Numbers

For `s = list(list(1, 2, 3), list(4, 5, 6), list(7, 8, 9), list(10, 11, 12))`,
`accumulateN((a, b) => a + b, 0, s)` renders `"(22 26 30)"`:
1+4+7+10, 2+5+8+11, 3+6+9+12.

## Map class

`T`: the book's definition translates directly; only the car/cdr walk is
rewritten over the edition's tagged lists.

## Deviation

None.
