Exercise 5.32: the evaluator's symbol-operator fast path.

(a) The modified `ev-application` tests `symbol-operator?` first: a
variable operator is looked up in place, without saving `env` and
`unev` and without a round trip through `eval-dispatch`, and control
joins the ordinary path before the operand loop with `proc` about to
be set. Measured on the factorial of 5, the fast path saves 10 pushes
(105 to 95) at the same depth; an anonymous operator takes the base
path with identical counts. (b) Alyssa's plan does not remove the
advantage of compilation: each special case is a test repeated on
every evaluation, while the compiler decides once, and the register
analysis of `preserving` depends on surrounding code the evaluator's
dispatch cannot see.
