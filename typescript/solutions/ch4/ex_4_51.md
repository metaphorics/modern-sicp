# Exercise 4.51: permanent-set! (translate)

## Approach

`permanent-set!` assigns without installing the undo record, so the
trial that eventually fails still leaves its count behind. In the
statement's example the first answer is `(a b 2)`: the rejected `x=a,
y=a` trial raised the counter and survived. Under plain `set!` each
rejected trial's assignment is undone before the next alternative is
tried, so every answer reads 1.

## Numbers

Under `permanent-set!`: `(a b 2) (a c 3) (b a 4) (b c 6) (c a 7)
(c b 8)`, then exhaustion. Under `set!`: `(a b 1) (a c 1) (b a 1)
(b c 1) (c a 1) (c b 1)`, then exhaustion. Both tables match the rust
sibling's pin exactly.
