# Exercise 2.75: `make-from-mag-ang` in message-passing style

## Approach

Analogous to the section's `make_from_real_imag_message_passing`,
`make_from_mag_ang_message_passing(r, a)` returns a closure that
answers `magnitude` and `angle` directly from its captured components,
and derives `real-part` and `imag-part` from them by the same
trigonometric identities Ben's rectangular package uses in reverse.
Building the polar number with magnitude 5 and the angle of `(3 . 4)`
and asking it for its magnitude and angle round-trips to `5` and
`0.9272952180016122`; asking for its real part answers `3` (within
floating-point rounding). A message the object does not answer raises
the book's typed error, naming the constructor and the message.

## Map class

`A`: message dispatch needs closure objects per instance, matching the
map's Rust class for this row.

## Deviation

None.
