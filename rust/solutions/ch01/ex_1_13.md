# Exercise 1.13

The exercise is a proof by strong induction on `n`, using `psi = (1 -
sqrt(5)) / 2` alongside `phi = (1 + sqrt(5)) / 2`. Base cases: `Fib(0) = 0 =
(phi^0 - psi^0) / sqrt(5)` and `Fib(1) = 1 = (phi - psi) / sqrt(5)` (since
`phi - psi = sqrt(5)`). Inductive step: assuming the closed form for `n -
1` and `n - 2`,

```
Fib(n) = Fib(n - 1) + Fib(n - 2)
       = (phi^(n-1) - psi^(n-1)) / sqrt(5) + (phi^(n-2) - psi^(n-2)) / sqrt(5)
       = (phi^(n-2)(phi + 1) - psi^(n-2)(psi + 1)) / sqrt(5).
```

Both `phi` and `psi` are roots of `x^2 = x + 1` (the golden ratio's
defining equation, from 1.2.2), so `phi + 1 = phi^2` and `psi + 1 =
psi^2`, which collapses the last line to `(phi^n - psi^n) / sqrt(5)`,
completing the induction. Since `|psi| < 1`, `psi^n / sqrt(5)` vanishes as
`n` grows and is always smaller than `1/2` in absolute value, so `Fib(n)`
is the closest integer to `phi^n / sqrt(5)`.

The map class is `T`: the proof needs no host-language adaptation. The code
companion is a numerical check of the closed form, not the proof itself,
carried in `f64` for `n` from 0 through 70, where the Fibonacci values stay
exact integers in floating point.
