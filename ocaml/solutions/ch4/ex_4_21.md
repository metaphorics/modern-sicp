# Exercise 4.21 — recursion without define (translate)

The map class is `T`. The trick translates as pure object text: each
procedure takes itself as an argument and performs the recursive step
by calling that argument, so the base evaluator, which carries no
recursion support at all, runs both demonstrations unchanged. Part (a)
is the self-application analog for Fibonacci, computed on 10 to answer
55; part (b) is the mutual even?/odd? pair with the statement's blanks
filled, each procedure receiving both procedures plus the count,
applied to 4 to answer true. No Y combinator is needed for these
shapes: self-application hands each procedure enough of itself to
continue, which is the subtlety Louis's intuition in 4.20 missed.
