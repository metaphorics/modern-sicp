# Exercise 1.39 — tangent continued fraction (translate)

The map class is `T`. Lambert's formula subtracts at every level
instead of adding, so `tan_cf`'s fold uses `n i /. (d i -. result)`
where exercise 1.37's `cont_frac` used `+.`; the first numerator is
`x`, every later one is `x^2`, and `d i = 2i - 1`.

`tan_cf 0.1 10 = 0.10033467208545055` and
`tan_cf 1.0 20 = 1.557407724654902`, both matching `Float.tan` at
print precision. `ex_1_39 ()` returns both.
