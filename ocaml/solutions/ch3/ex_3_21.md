# Exercise 3.21: print-queue for the pointer-pair queue (adapt)

The map class is `A`: the book's point is that a naive printer shows
the queue's internal representation (a pair of a front pointer and a
stale rear pointer) rather than its contents, so `ben_view` prints
`(front-list . rear-item)` on purpose (the naive rendering the
exercise wants Ben to be confused by), while `print_queue` walks only
the front chain. Deleting the last item leaves the front pointer at
`()` but the rear pointer still designates the old last pair, so
`ben_view` answers `(() b)` even though the queue is empty; that
staleness is Eva Lu Ator's point, not a bug.

Sample: `ex_3_21 ()` answers
`("((a) a)", "((a b) b)", "((b) b)", "(() b)", "()", true, "(() b)")`.
