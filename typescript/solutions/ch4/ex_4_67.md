# Exercise 4.67: the loop detector (translate)

## Approach

The detector keeps, for each active deduction, the instantiated query
pattern plus the frame bindings relevant to it. Before processing a
recursive subquery it compares the candidate against the active
ancestors on the current path: the same pattern with the same bindings
is the same subproblem recurring, so that branch is rejected. The
history stays branch-local and is popped when a deduction returns, so
separate proofs of the same conclusion remain available and only true
cycles are cut.

## Numbers

The predicate pins are: same pattern with identical bindings against
itself is a repeat; the same pattern with one binding changed is not;
a different pattern is not. The tests pin all three verdicts plus the
branch-local wording of the summary.

## Class and deviations

Translated row. Deviation: the detector is a standalone predicate
over deduction steps rather than engine surgery; the core exposes the
`setFallback` seam where a full wiring would install it.
