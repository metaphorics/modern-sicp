# Exercise 1.18: Russian peasant multiplication as a loop

## Approach

Carry `(x, y, acc)` with `x * y + acc = a * b` invariant. Even `y`:
`x <- double(x)`, `y <- halve(y)`. Odd `y`: peel one `x` into `acc`,
`y <- 1`. Answer is `acc` when `y` hits `0`. The loop runs at most
`2 * log2(b)` passes. For `(17, 31)` the ten states hold
`x * y + acc = 527` throughout - the invariant, watched.

## Numbers

`timesIter(17, 31)` is `527`, `(2, 10)` is `20`, `(7, 0)` is `0`,
`(12345, 6789)` is `83810205` in 25 passes (for 14 bits: 13 halvings
plus the odd peels). The grid `1..12 x 0..12` matches the host product.

## Class and deviations

Adapted row, per the map: "loop replaces tail recursion". The statement
says so itself: the book's iterative `product-iter` is a tail-recursive
chain, and since Node performs no tail-call optimization the loop is
this edition's honest spelling, with the state transformation as the
loop body. The Rhind Papyrus footnote is preserved unchanged.
