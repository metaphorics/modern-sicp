# Exercise 2.34: Horner's rule

## Approach

Horner's rule is a right fold over the coefficient sequence from `a_0`
to `a_n`: each step multiplies the accumulated higher terms by `x` and
adds this coefficient. The fold therefore reaches `a_n` first, which is
the order the nested formula needs. The accumulator is a `Result`, so
the checked multiplication and addition of the number convention report
overflow instead of wrapping.
