# Exercise 2.33: list operations as accumulations

## Approach

Each missing accumulation folds right over the sequence, combining the
current element with the result already built for the rest. For map, the
element is transformed first: `(x, y) => cons(f(x), y)`. For append,
`seq1`'s elements are consed onto `seq2` itself as the initial, so the
spine of `seq1` is rebuilt ending in `seq2` - the same sharing the
module's append describes. For length, the element is ignored and one is
added per step, `(x, y) => y + 1`, counting the fold's depth.

## Numbers

`mapViaAccumulate((x) => x * x, list(1, 2, 3, 4))` renders `"(1 4 9 16)"`;
`appendViaAccumulate(list(1, 2, 3), list(4, 5, 6))` renders
`"(1 2 3 4 5 6)"`; `lengthViaAccumulate(list(1, 3, 5, 7))` is 4.

## Map class

`T`: the three definitions are the book's, with `nil` and `cons` taken
from the edition's list module.

## Deviation

None.
