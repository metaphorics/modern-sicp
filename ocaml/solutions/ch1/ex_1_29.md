# Exercise 1.29 — Simpson's Rule (translate)

The map class is `T`. `simpson` follows the book's formula directly: a
weighted sum over `n + 1` sample points (weights 1, 4, 2, 4, 2, ..., 4,
1), scaled by `h / 3`, where `h = (b - a) / n`.

`simpson cube 0. 1. 100` and `simpson cube 0. 1. 1000` both land at
`0.25000000000000006`, a rounding error away from the exact value 1/4.
Simpson's Rule is exact for any polynomial of degree 3 or less, and
`cube` is degree 3, so unlike the section's midpoint-sum `integral`
(`0.24998750000000042` at `dx = 0.01`, `0.249999875000001` at
`dx = 0.001`), refining the grid buys nothing here: both `n` already
hit the floating-point floor. The comparison the exercise asks for is
exactly this: Simpson's Rule needs no dense grid to beat the coarser
method's finest grid.
