# Exercise 5.47: compiled code calls interpreted procedures

With `CompilerConfig(compoundCalls = true)`, the call dispatch grows
a compound branch beside the compiled and primitive branches: the
compiled caller sets `continue`, parks the entry in `unev`, and jumps
to the interpreter's `compound-apply`, which runs the body through
`ev-sequence` with the return address riding the stack, the
interpreted calling convention.

`compoundCallRuns()` compiles `(define (f x) (g x))` with that
configuration and drives it with `(define (g x) (+ x 1)) (f 41)`,
where `g` exists only as an interpreted definition. The transcript
values are `ok`, `ok`, and 42, pinned by the test: the compiled call
crosses into the interpreter and back, and the answer is the book's 42.
