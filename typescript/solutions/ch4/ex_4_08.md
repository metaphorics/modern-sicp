# Exercise 4.8: named let

## Approach

Following the book's hint, `(let name ((v1 e1) ...) body)` becomes
`((lambda (name) (set! name (lambda (v1 ...) ...) body) (name e1 ...))
'ok)`: the helper lambda binds the loop name itself, set! installs the
loop procedure into that binding, and the final call starts the loop with
the initializers. The parameter must be the loop's own name so that
recursive calls in the body resolve to it. The throwaway initial actual
is the fresh quoted symbol `ok`, standing in for the book's
`*unassigned*`. Plain let and named let share one full dispatch.

## Numbers

`(let fib ((k 10)) (if (< k 2) k (+ (fib (- k 1)) (fib (- k 2)))))` is
`55`. `(let fact ((n 5) (acc 1)) (if (= n 0) acc (fact (- n 1)
(* acc n))))` is `120`. The transformation of `(let loop ((n 0)) n)`
prints exactly as `((lambda (loop) (set! loop (lambda (n) n)) (loop 0))
'ok)`. Plain let still evaluates: `(let ((x 3) (y 4)) (+ x y))` is `7`,
and a named let inside a defined body also yields `55`.

## Class and deviations

Translated row. Deviation: the initial actual is `'ok` rather than the
book's `*unassigned*`, since that variable is not bound in this dialect
and any value works before set! overwrites it; the set! shape is the
book's hint unchanged.
