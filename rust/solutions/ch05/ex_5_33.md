# Exercise 5.33: compiling the alternative factorial (T)

## Approach

The book's factorial multiplies the recursive result by `n`; the alternative multiplies `n` by the recursive result. Both answer `120` at n = 5 through a direct recursive transfer on both engines. The operand discipline saves each call argument, so both streams carry save traffic; the counts are computed for the comparison, never pinned.
