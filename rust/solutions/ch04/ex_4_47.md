# Exercise 4.47: Louis's recursive parse-verb-phrase (T)

## Approach

Louis's order does parse: the first `amb` alternative consumes a verb,
so the ordinary first parse comes out. The failure is on `try-again`:
the second alternative evaluates `(parse-verb-phrase)` before consuming
anything, so the resumed search descends the recursion on exhausted
input forever -- divergence, which a test cannot run. The demonstration
therefore bounds the recursion with a depth parameter and an `(amb)`
floor: the capped copy answers the same first parse, and its first
`try-again` descends to the cap consuming nothing and then reports
exhaustion -- exactly where the unbounded recursion would spin.
Interchanging the `amb` expressions is strictly worse: the first
alternative recurses before any word is consumed, so even the first
parse never returns; the capped interchanged copy burns its whole depth
budget before answering through the second alternative.

## Map class

`T`.

## Sample answer

Louis's version parses `(sentence (noun-phrase (article the) (noun cat))
(verb eats))` but every `try-again` diverges; the capped probe exhausts
instead. Interchanged, the recursion precedes consumption -- no parse
ever completes without the depth bound.
