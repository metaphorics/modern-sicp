# Exercise 2.61: `adjoin-set` for the ordered-list representation

## Approach

`adjoin_set_ordered` scans the ordered list only until it finds an
element not smaller than `x`: equal means `x` is already present
(return the set unchanged), smaller than that element means `x` goes
here. This mirrors `element-of-set?`'s early stop and takes on average
about half as many steps as the unordered representation's linear
scan-then-cons. The book's own recursive `cons`-based sketch is `Θ(n)`
in Scheme because `cons` shares the untouched tail; this solution
builds the result `Vec` in one forward pass instead, which keeps the
`Θ(n)` cost real for a type that does not share structure the way a
persistent list does. Inserting `5` into `[1, 3, 6, 10]` splices it
between `3` and `6`; adjoining the already-present `3` returns the set
unchanged.

## Map class

`T`: translates directly onto the ordered-list `element_of_set_ordered`
walk already in the section.

## Deviation

None.
