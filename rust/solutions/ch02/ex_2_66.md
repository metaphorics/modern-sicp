# Exercise 2.66: `lookup` for a tree of records

## Approach

`lookup` is `element-of-set?`'s tree walk, generalized from a bare
number to a record's key: compare `key` against the current node's
record and recurse left or right, halving the remaining tree at each
step on a balanced tree (`Θ(log n)`). Looking up key `5` in a tree
keyed `2`, `5`, and `8` finds `"bob"` at the root; looking up the
absent key `9` walks to an empty subtree and returns `None`.

## Map class

`T`: translates directly onto `element_of_set_tree`'s walk, with the
number replaced by a record's key.

## Deviation

None. The record tree is a small local type (`RecordTree`) rather than
a generalized `Tree<T>`, since the section's own `Tree` is fixed to
`i128` entries and this exercise's records need a separate payload.
