## Exercise 3.18: detect a loop in a pair chain

Approach: `containsCycle` follows only `PairCell.second`. It remembers each
visited cell and returns true when the same object appears again. Reaching
a non-pair datum, including `Empty`, ends the chain without a cycle.

Why identity matters: the graph may contain equal-looking cells that are
not the same object. A cycle exists only when the second-field walk reaches
a cell it already visited.

What the tests say: the cycle from exercise 3.13 is detected, finite chains
are rejected, and a graph that shares a pair through `first` only is not a
cycle in this traversal.

Class: A (the visited cells are compared by identity with `===`).

Deviation: cycle detection uses typed pair data directly.
