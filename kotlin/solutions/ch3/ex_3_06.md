## Exercise 3.6: rand with generate and reset

Approach: the book funnels `'generate` and `'reset` through the one
argument `rand` takes, with `reset` itself answering a further procedure
of the new value. This edition gives each request its own method on a
`ResettableRand` interface (the same "interface-implementing object"
shape section 3.1 uses for `makeAccount`) rather than modeling a
procedure that sometimes returns a number and sometimes returns another
procedure. `generate` advances the captured `x` through `randUpdate` as
the section's plain `rand` does; `reset` simply overwrites `x`, so a
`reset` back to a previously seen value reproduces every word that
followed it before.

Class: `T`, unchanged from the map. Deviation: none beyond the interface
shape, which is section 3.1's own established idiom, not a change of what
the exercise asks.
