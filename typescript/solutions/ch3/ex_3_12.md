# Exercise 3.12: append copies, append! splices

## Approach

The book's `append` conses a fresh chain for `x` and ends it at the
very `y` object, so `x` is unchanged; the book's `append!` rewrites
the final pair of `x` with `setCdr`, so the two lists share one
spine and `x` is changed. The edition spells both over the section
module's mutable pairs: `append` recurses with `mcons`, `lastPair`
walks to the pair whose tail is `mnil`, and `appendBang` calls
`setCdr` on that pair. `appendDemo` runs the book's interaction over
x = `[a, b]`, y = `[c, d]` and reports the four printed shapes plus the
identity pin.

## Pins

`z = append(x, y)` prints `[a, b, c, d]` and `cdr(x)` is still `[b]`:
append copied x and shared y. `w = appendBang(x, y)` prints
`[a, b, c, d]` and is the very x object; `cdr(x)` now prints
`[b, c, d]`. The identity pin: the
tail of the pair that was x's last pair is the y object itself
(Object.is true). append! on an empty first list throws "append!:
empty first list", the book's stated error. lastPair returns the
final pair by identity: for `[a, b]` it is the same object as the tail
of the first pair.
