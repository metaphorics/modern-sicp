# Exercise 2.50: flip-horiz and the rotations

## Approach

All three transforms are direct `transform_painter` calls with the new
frame's corners: `flip_horiz` runs the horizontal axis backwards,
`rotate_180` runs both backwards, and `rotate_270` moves the origin to
the top left and swaps the edges' roles. A deliberately asymmetric
one-segment probe shows each transform moving it somewhere different,
and the test pins the exact mapped endpoints (dyadic coordinates, so
the values print exactly). A second test proves the direct 180 agrees
with the composed `flip_vert` after `flip_horiz` that the book's
footnote and the spine's `rotate_180` provide.
