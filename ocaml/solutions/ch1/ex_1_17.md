# Exercise 1.17 — logarithmic multiplication by doubling (translate)

The map class is `T`. The book's starter redefines `*` itself, in a
language assumed to have only addition; this edition names the same
procedure `times` so it does not shadow OCaml's own `( * )`, a naming
choice rather than a change of substance.

`fast_mult a b` mirrors `fast_expt` from @ref{1.2.4} with `double`
standing in for squaring and `halve` for the exponent's division by 2:
on an even `b`, `double (fast_mult a (halve b))` computes `a * b` since
`2 * (a * (b/2)) = a * b`; on an odd `b`, `a + fast_mult a (b - 1)` folds
in one addition. Each halving roughly halves the work remaining, so the
process is `Theta(log b)`, against `times`'s `Theta(b)`.

The test pins `ex_1_17 3 7 = 21`, matching `times 3 7`, and checks a
zero factor (`ex_1_17 0 5 = 0`) and an even factor (`ex_1_17 6 8 = 48`).
