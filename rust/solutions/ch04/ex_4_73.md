# Exercise 4.73: the delay in flatten-stream (T)

## Approach

A probe stream whose second inner stream burns a 200000-tick budget at
construction. The delayed `flatten-stream` yields the first element
with the flag untouched; forcing the tail burns it. The undelayed twin
must construct before the first element emerges; on finite inputs both
agree element for element.

## Map class

`T`.

## Sample answer

Delayed: first element out, flag false, then flag true on drain.
Undelayed: flag true before any element. Finite inputs: identical.
