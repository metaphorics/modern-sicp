# Exercise 5.6: remove redundant Fibonacci save and restore

At `afterfib-n-1`, the original controller restores `continue` to the caller continuation saved before the first recursive call. It then saves that same label again before setting `continue` to `afterfib-n-2` for the second call. The restored value is unchanged at the save, so the pair `(restore continue)` at `afterfib-n-1` and the following `(save continue)` is redundant. Remove both instructions. The outer saved continuation stays on the stack until `afterfib-n-2` restores it, so the return path remains balanced.

Do not remove the `(restore continue)` at `afterfib-n-2`: it restores the original caller continuation and is needed to return. `fibonacciReduced` is the resulting executable sequence.

The test's n = 6 run computes both versions: both return 8 and reach depth 10. The original takes 281 instructions with 48 saves and 48 restores. The reduced controller takes 257 instructions with 36 saves and 36 restores, a reduction of 24 executed instructions and 12 pushes plus their 12 matching pops.
