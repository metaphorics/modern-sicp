# Exercise 5.16: instruction tracing on and off (T)

## Approach

`set_trace(true)` makes the driver append each instruction's
rendered text to the transcript before executing it;
`set_trace(false)` silences it again. The rendering is the same
text the assembler produced, and tracing never touches the
registers or the count.

## Map class

`T`.

## Sample answer

Traced gcd(12, 8) prints 14 instruction lines (two full loop passes
plus the final test and branch) and answers 4; with tracing off the
same run prints nothing and still answers 4.
