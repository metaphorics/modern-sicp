## Exercise 2.49: primitive painters via segments->painter

Approach: `segmentsToPainter` is given (it lives in the shared
`Painters.kt`, matching the book's own text, which shows it before this
exercise's statement); the exercise's actual content is choosing the
segment coordinates for the outline, the X, and the diamond, which this
file does directly on the unit square. Part (d), the `wave` painter, is
the shared file's primitive built the same way, over a fourteen-segment
list on a 1/8 grid so every transform later in the section lands on
exact coordinates. The tests check both segment counts and the exact
endpoint sets each painter touches.

Class: T. Choosing coordinates and calling a given higher-order
constructor needs no representation change from the book's shape.
