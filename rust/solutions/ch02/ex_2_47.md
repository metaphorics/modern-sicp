# Exercise 2.47: frame constructors

## Approach

Two representations, two selector sets: a fixed-size array rendering
the book's list constructor, and nested pairs from the section 2.1
`Pair` rendering the book's `(cons origin (cons edge1 edge2))`. The
selectors differ per representation; the test renders both frames
through their own selectors and gets identical output, which is the
representation-independence point of the exercise.

## Map class

`T`: the statement translates directly.

## Deviation

The list representation is an array rather than a cons list, because a
three-slot frame with fixed positions is the idiomatic Rust rendering
of the book's `(list origin edge1 edge2)`; the pair representation is
faithful to the book's cons nesting.
