# Exercise 2.5 — pairs as 2^a * 3^b (adapt)

The map class is `A`: the encoding survives, but `2^a * 3^b` overflows
a fixed-width integer for `a` and `b` that are not small, where
Scheme's arbitrary-precision integers would keep growing. The idiom
plan allows a bounded native `int` here (`Zarith stays optional`), so
`cons` is documented, not typed, as valid only while `a` and `b` keep
`2^a * 3^b` inside a 63-bit `int` — comfortably true for `a, b` under
20 and every value `ex_2_05` exercises.

`car`/`cdr` recover the exponent by repeatedly dividing by `2`/`3`
while the quotient divides evenly and counting the divisions; since
`2` and `3` are coprime, dividing out one never touches the other's
power. `ex_2_05 3 4` checks `car (cons 3 4) = 3` and
`cdr (cons 3 4) = 4`.
