# Exercise 2.55: quote in edition AST terms (replacement)

## Approach

`'x` is reader sugar for `(quote x)`, so `''abracadabra` reads as
`(quote (quote abracadabra))`. Evaluating the outer `quote` returns its
argument unevaluated: the two-element list `(quote abracadabra)`. That
list's `car` is its first element, the symbol `quote` — not
`abracadabra`, and not another `quote` form. The solution builds this
value directly as a tiny local `Quoted` AST (symbol, pair, or empty
list) rather than through a reader, since quotation disappears into
constructors in this edition, and reads off both the printed value and
its `car`.

## Map class

`R`: SICP 2.55 asks the reader to explain the Scheme reader's own
double-quote behavior, so the edition replaces it with the same
explanation carried out over the edition's own AST terms; the number
and the underlying puzzle (what does one `car` strip off a
twice-quoted symbol) are unchanged.

## Deviation

None.
