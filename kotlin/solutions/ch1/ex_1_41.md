## Exercise 1.41: double, applied to itself

Approach: `double(f) = { x -> f(f(x)) }`, generic over `T` so it can be
applied to a plain numeric function or, doubly instantiated, to itself.
`double(double)` in Scheme reads as one untyped self-application; in
Kotlin it is two separate instantiations of the same generic
declaration: `double<Long>` turns `inc` into `+2`, and
`double<(Long) -> Long>` turns a `(Long) -> Long` transformer, such as
`double<Long>` itself (wrapped as `doubleLong`, since a generic
function cannot be passed as a bare value without one), into its own
double-application. `double(double)` applied to `inc` therefore
quadruples it (`+4`), and `double(double(double))` applied to `inc`
applies that quadrupling twice more, i.e. `+16`; applied to 5, the
result is 21.

Class: T (translate); Kotlin's parametric generics express the book's
untyped self-application faithfully, needing only the one explicit
`doubleLong` wrapper because a generic function reference cannot stand
alone as a value at an unspecified type. Deviation: none in the
computed answer.
