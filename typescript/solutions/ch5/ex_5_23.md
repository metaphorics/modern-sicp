# Exercise 5.23: derived expressions via transformer operations

The derived form of this edition's object language is the switch. The transformer is one machine operation, `switchToIf`, that builds the equivalent `if` chain out of the switch's clauses as typed syntax data, and the dispatch entry that calls it re-enters eval on the transformed form, so the rest of the controller never knows the form existed. The splice point matters: the derived test goes before the basic form's test, and a switch the transformer declines falls through to the basic form untouched.

The transformer answers the clauses that end the switch (the derived-form discipline of the book's cond); a clause that would fall through belongs to the basic form of exercise 5.24 and is left to it. The session runs the three-clause classify program through the transformed path, answers the same values the basic form answers, and the counter reports one transformation per switch.
