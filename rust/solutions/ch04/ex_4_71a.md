# Exercise 4.71a: the divergence probe (T, edition addition)

## Approach

The query is `(outranked-by (Bitdiddle Ben) ?who)` over the Microshaft
data base with Louis's swapped `outranked-by` rule of exercise 4.64.
The fuel bound is 1000 simple-query invocations.

The delayed engine returns
`(outranked-by (Bitdiddle Ben) (Warbucks Oliver))` as its first answer.
The undelayed engine -- in which `apply-rules`' result is a value, not
a delay -- returns the same first answer. A Rust stream value is
already lazy, and recursion hides behind thunks. The construction
divergence that the book's Scheme-level delay prevents does not occur
in this port. Both engines exhaust the fuel while searching for a
second answer.

## Map class

`T` (edition addition; map cell records `chosen: rust`).

## Sample answer

Fuel 1000: delayed engine, first answer `(outranked-by (Bitdiddle Ben)
(Warbucks Oliver))`; undelayed engine, same first answer, same fuel
exhaustion hunting the second. The divergence the exercise hunts is a

absorbs.
