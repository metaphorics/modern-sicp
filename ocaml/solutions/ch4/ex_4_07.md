# Exercise 4.07: let* as nested lets

The map class is `T`. Sequential binding is an extension node beside the checked syntax, derived into one single-binding `let` per name nested in order. The clause the statement proposes, evaluating the rewritten nest with the evaluator, is sufficient once `let` is a clause of the same evaluator: the expansion terminates in plain bindings and no non-derived expression is needed.

Sample: `ex_4_07 ()` answers `["39"; "39"; "20"]`: the book's `x = 3, y = x + 2, z = x + y + 5` example through `Sec_4_6.eval` and through the standard evaluator, then a form rebinding `x` from its own earlier value.
