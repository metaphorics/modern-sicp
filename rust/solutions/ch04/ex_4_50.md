# Exercise 4.50: `ramb` random choice (T)

## Contract

`SearchEngine::with_seed(...).run_seeded(...)` over typed `Search::Choose`
alternatives.

## Lesson

The seed belongs to the search engine's choice-point ordering. The same seed
and program produce the same answer order; another seed permutes the same
answer set without changing search semantics.

## Map class

`T`.

## Sample answer

Seed `7` is repeatable, seed `8` differs, and both preserve the five answer
members.
