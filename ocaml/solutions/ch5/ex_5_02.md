# Exercise 5.2: the machine language description

The map class is `T`. Where 5.1 draws, 5.2 writes: the same iterative
factorial machine described in the register-machine language, as data.
The typed instruction list `factorial_iterative_controller` is that
description, and the exercise pins the assemble-and-run flow: the
simulator's `assemble` removes the `Label` entries and resolves each
to an instruction index, and the assembled machine runs.

The assembled sequence has 5 instructions and 2 labels, and the label
table shows the stop-address convention the section establishes: each
label names the position of the instruction that follows it, and the
trailing `fact-done` (the label the branch uses as its exit) names
position 5, one past the last instruction, where reaching means the
machine is done. `ex_5_02 ()` answers
`["5 instructions, 2 labels"; "fact-loop=0 fact-done=5"; "120";
"720"]`: the assembly report and the runs on n = 5 and n = 6.
