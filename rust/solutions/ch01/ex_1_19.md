# Exercise 1.19

Applying `T_pq` twice to `(a, b)` gives, after expanding both steps and
collecting terms, a single transformation of the same `T_pq` shape with

```
p' = p^2 + q^2
q' = q^2 + 2pq
```

(A short way to see it: `T_pq` is multiplication by the matrix `[[p + q,
q], [q, p]]` up to the book's `(a, b)` convention; squaring that matrix and
matching entries against the same form gives exactly `p'` and `q'` above.)
Substituting these into the even branch of `fib-iter` completes the
procedure, and specializing to `p = 0, q = 1` (the identity case) recovers
the ordinary linear `fib-iter` of 1.2.2, confirming the transformation is
consistent with it.

The map class is `A`: "integer width forces choice." The book's arithmetic
is exact and unbounded; Rust's is not, and the four state variables here
are products and sums of `Fib`-sized values, which overflow `i64` before
`n = 93` and `i128` past roughly `Fib(183)`. `fib_squaring` is written over
`i128` and checked against the ordinary linear iteration for every `n` up
to 90 before trusting `fib_squaring(90) = 2880067194370816120`.
