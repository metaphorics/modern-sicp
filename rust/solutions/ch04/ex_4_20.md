# Exercise 4.20: letrec as a derived expression (T)

## Approach

`letrec_to_let` rewrites to the text's shape: one let binding every name to
the quoted `*unassigned*`, one set! per name, then the body. `WithLetrec` adds
the unassigned-read check the semantics need. Mutual recursion works; a binding
that reads a later name names it in the error.

## Map class

`T`.

## Sample answer

The letrec of even?/odd? answers `#t`; `(letrec ((a (* b 2)) (b 3)) a)` raises
`the variable b is read before its define runs`.
