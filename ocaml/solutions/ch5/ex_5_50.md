Exercise 5.50: the metacircular evaluator compiled.

The object-language evaluator source is `Metacircular.source`, the
corpus's 4.1 text adapted to this machine (the ways are listed in
that module: environment procedures provided by the machine behind id
symbols because the book's list frames need mutable pairs; `apply`
reached through `m-eval`; no apply-on-compound session, which a
primitive cannot re-enter). Compiled and run on the 5.5.7 machine,
the program defines `factorial` inside the object world and answers
120.

The interpretation levels are timed on `(factorial 5)`: level 0, the
compiled factorial on the machine (steps counted by the machine);
level 1, the explicit-control evaluator interpreting it (monitored
pushes, since the 5.4 machine does not count steps); level 2, the
compiled metacircular interpreting it (53k machine steps at n = 5,
about 300 times level 0's steps -- each level of interpretation pays
its constant, and the wall clock is printed with the counts).
