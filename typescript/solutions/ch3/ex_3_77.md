# Exercise 3.77: integral with a delayed integrand

## Approach

The statement's recursive `integral` advances the initial value by
dt times the integrand's car and recurses on the integrand's cdr, the
integers-starting-from shape. In a feedback system the integrand is the
mapping of f over the very stream being defined, so that shape needs the
answer's first element before the answer exists. The exercise's modified
version expects the integrand delayed and forces it inside the tail
promise, so the head is produced without the integrand and each demanded
tail forces it exactly once:

    delayedIntegral = (delayedIntegrand, initialValue, dt) =>
      consStream(initialValue, () => {
        const integrand = delayedIntegrand();
        if (integrand === null) return theEmptyStream;
        return delayedIntegral(() => streamCdr(integrand), initialValue + dt * integrand.head, dt);
      })

with the statement's empty-stream guard on the forced integrand. `solve`
builds the figure 3.34 loop over it, delaying `streamMap(f, y)` until a
tail asks. The unmodified recursive integral is restated alongside, and
`solveWithPlainIntegral` demonstrates the statement's point on it.

## Pins

Computed by running. `streamRef(solve((y) => y, 1, 0.001), 1000)` is
2.716923932235896, matching the book's printed 2.716924 to the six places
shown (the test also bounds it within 5 decimal places of that value).
The delay is real: with an integrand whose supplier throws, the integral
still answers its head (streamRef at 0 is 7) and only demanding index 1
triggers the throw. On the finite delayed integrand 1..3 with initial
value 10 and dt 2 the stream is 10, 12, 16, 22 and then ends. The plain
construction fails before answering anything: calling
`solveWithPlainIntegral` throws a ReferenceError, message "Cannot access
'y' before initialization", pinned in the test.

## Map class

T (translate: syntax changes only). The delayed recursion and the

## Deviation

The book's failure mode is an unbound variable inside the original's sequential
internal definitions; TypeScript's counterpart is the temporal dead zone,
so the failing construction is demonstrated as the ReferenceError above
(the eager integrand read is routed through a function call so the
compiler permits the definition and the run time exposes the same
problem). On a finite integrand the delayed shape answers one element
more than the plain recursive shape: the force happens inside the tail,
so the final accumulated value is emitted before the null guard fires.
Each file follows its own statement snippet exactly; the extra element is
the modified shape's own consequence, visible in the pinned 10, 12, 16, 22.
