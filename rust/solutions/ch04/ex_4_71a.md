## Approach

The query is `(outranked-by (Bitdiddle Ben) ?who)` over the Microshaft
data base with Louis's swapped `outranked-by` rule of exercise 4.64.
The fuel bound is 1000 simple-query invocations. The measured result of
this edition: the delayed engine streams
`(outranked-by (Bitdiddle Ben) (Warbucks Oliver))` as its first answer,
and the undelayed engine -- in which `apply-rules`' result is a value,
not a delay -- answers the same first answer, because a Rust stream
value is already a lazy structure and the recursion hides behind
thunks. The construction divergence the book's Scheme-level delay
prevents does not reproduce in this port; the fuel probes pin the
equivalence and the shared divergence past the first answer.
