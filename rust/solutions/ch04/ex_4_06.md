# Exercise 4.6: `let` as a derived expression (T)

## Approach

The typed rewrite turns one `let` binding into an immediate one-argument
closure call. The initializer runs in the outer environment; the parameter
then shadows its name in the body.

## Map class

`T`.

## Sample answer

With outer `x = 5`, `let x = x + 1 in x + 20` lowers to a closure call.
The direct and lowered evaluators both return `26`.
