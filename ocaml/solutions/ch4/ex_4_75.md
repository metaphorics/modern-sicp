# Exercise 4.75: the `unique` special form (translate)

`uniquely_asserted` is the book's handler: for each frame in the
stream it runs `qeval` on the `unique` query's contents over the
singleton frame, keeps the frame exactly when that extension stream
has precisely one element, and emits the extension: the `not`-style
filter Alyssa describes in the exercise text. "Precisely one" is
forced lazily: the extension stream must be non-empty and its first
tail empty, which costs one tail force even for an unbounded extension
stream. The registration is the book's own data-directed step,
`(put 'unique 'qeval uniquely-asserted)`, done once at module load;
the base evaluator's dispatch table is code that survives
`the_query_system`'s reset, so every fresh session sees the handler
and the dispatching half of the exercise is trivial exactly as the
book says.

The demonstration pins the book's three behaviors on the Microshaft
data base: Ben is the only computer wizard (one row), the two
computer programmers print nothing, and the `and` of a job scan with
`unique` lists every singly-filled job with its filler in the
chronological data base's scan order, plus the test the exercise asks
for, the people who supervise precisely one person: only Hacker
Alyssa P (Reasoner Louis) and Scrooge Eben (Cratchet Robert) have
exactly one supervisee.

both conjuncts, so the `unique` half repeats the binding: the
engine's rendering, matching the base evaluator's `and` transcripts.
