# Exercise 5.37: disabling `preserving` (T)

## Approach

`Seq::preserving` is the analysis made concrete: synthetic joins prove it saves nothing for disjoint registers and one save for the live one. Parking every listed register instead buries the same join in five saves. The compiled factorial answers either way: the discipline costs stack operations, never answers.

## Map class

`T`.

## Sample answer

Analyzed joins carry zero and one save; the blind join carries five. The factorial prints `120` on both engines.
