# Exercise 4.13: `make-unbound!` (T)

## Approach

Unbinding removes a name only from the current frame. Removing an outer
binding from an inner scope would break shadowing, so a name absent from the
current frame is an explicit typed error.

## Map class

`T`.

## Sample answer

After unbinding inner `x`, the outer `x` is visible again; unbinding a name
the current frame does not own raises the environment error.
