# Exercise 5.38: open-coded primitive operations (T)

## Approach

Compile factorial with the ordinary compiler and with open coding for
primitive arithmetic enabled, then compare statement counts. The
open-coded path emits machine arithmetic directly instead of building
an argument list and dispatching through the primitive procedure. It
folds n-ary addition and multiplication through `val`; the generated
sequence preserves the remaining argument registers and `env` across
each evaluation that can overwrite them. Execute factorial, n-ary `+`,
comparison, and subtraction to check the results.

## Map class

`T`.

## Sample answer

Open-coded factorial has fewer statements than the ordinary compiled
version; the ordinary factorial listing has 79. The sample expressions
return `120`, `10`, `#t`, and `7` respectively. The open-coded count is
computed from the emitted sequence, not pinned as a fixed number.
