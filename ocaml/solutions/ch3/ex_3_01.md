# Exercise 3.1 — accumulator (translate)

The map class is `T`: the exercise asks for a closure with local
state, which OCaml states the same way the section's own
`make_withdraw` does. `make_accumulator` closes over an `int ref`
holding the running sum; every call updates the `ref` in place and
returns its new value. No new mechanism is needed beyond what the
section's main text already introduces.

Sample: `ex_3_01 ()` is `(15, 25)`, matching the statement's two calls
to `(A 10)` starting from `(make-accumulator 5)`.
