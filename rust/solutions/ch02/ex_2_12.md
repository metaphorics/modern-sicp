# Exercise 2.12: `make-center-percent` and `percent`

## Approach

`from_center_percent(center, percent)` converts the percentage to a
half-width (`center.abs() * percent / 100.0`) and defers to
`Interval::from_center_width`, the book's `make-center-width`, already
part of the section's main text. `percent` is the inverse computation,
`100.0 * width / center.abs()`. The `center` selector the exercise asks
for is `Interval::center`, unchanged from the main text. The test builds
a 5-percent interval around 100.0 and checks its bounds (95.0, 105.0)
and its recovered tolerance (5.0) round-trip exactly.

## Map class

`T`: two short procedures, translated directly on top of the section's
existing `Interval` type.
