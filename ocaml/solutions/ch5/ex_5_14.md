# Exercise 5.14: the monitored stack measures factorial

The Figure 5.11 controller gains two instructions:
`(perform (op initialize-stack))` before the recursion and
`(perform (op print-stack-statistics))` at `fact-done`, both served by
the operations every machine of this section carries. The statistics
action appends to the machine's transcript, so the run's measurement
is a collected line, not a host print.

`ex_5_14 ()` measures n = 1..7: pushes and depth rise 0, 2, 4, 6, 8,
10, 12. Both counters are 2n - 2 for n > 1: two pushes per recursive
level, n - 1 levels, and no pop before the base case, so the maximum
depth equals the total pushes. Linear with the two constants the book
asks for: slope 2, intercept -2.
